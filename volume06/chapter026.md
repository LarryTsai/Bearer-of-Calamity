# 第二十六章 戰臺先把規矩說完，兩個人才肯站上去

決賽臺比昨日那座厚三倍。

裁判先繞臺一周，把四面白線逐一點亮：「倒地十息、主動認輸或完全出界，直接分勝負。若時限終了仍無人出局，依有效攻勢、控制區域與迫退次數裁定。」

臺下有人不滿：「打贏還要算地？」

「外務不只在空地上殺人。」裁判道，「守不住身後，拳再重也不算首席。」

洛生衣在醫席翻開三欄病歷。陸沉右手新傷已收口，肩骨可承三次重擊，空手劫一旦連拆超過五次，反震不得再由他自行判斷。

她抬眼：「第五次後看我。紅旗起，停。」

「若他不停？」

「我判的是你，不是他。」

陸沉按下出戰印。

另一側，荒早已跨上石階。仙院使者送來的新條件被擱在他座位上，多一枚候選古種與一年本源庫權限；聖院也把煉體池名額加到兩年。

這些都只是重申。

荒把兩封信壓在水壺下，沒有再走一次選路的戲。

鐘響前，兩人在臺心相隔十丈。陸沉先看四角界線、三處修補縫與荒右腳落地深淺；荒則活動肩膀，目光從他包紮的右掌掃到腳下。

「這次不替我拆門？」荒問。

「拆你的拳。」

「那你得接得到。」

第一聲鐘落下，荒已越過五丈。

陸沉沒有退向預先看好的石縫，反而正面迎上。兩人的第一拳在臺心相撞，護臺光幕向外鼓起，最近一排觀眾同時抬手遮臉。

石臺沒有碎。

兩個人各退半步。

裁判筆下，同時多了一道有效攻勢。
