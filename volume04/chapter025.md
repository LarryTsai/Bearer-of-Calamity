# 第二十五章 她們帶著證詞上路，第一個攔路的人只想看副本

沈素決定親自送第二份證物。

不是因為沒人可以代送。

赤霞谷願意出人，荒離開前也留下兩條安全路線；洛生衣更可以把石匣藏進藥箱，獨自走得更快。

沈素仍把石匣抱進自己懷裡。

「他們若只看見你，會以為證詞是你寫的。」她對洛生衣說，「若只看見石匣，會以為裡面的人已經死了。」

「你走不到十里。」

「那就分十次走。」

洛生衣沒有再勸。

她替沈素換掉太重的外甲，把石匣分成證詞、物證拓印與失蹤名錄三層。三層不走同一個位置：證詞由沈素帶，拓印藏進一名照護散修的藥杖，名錄則由洛生衣自己收著。

不是防路上所有人。

是確保其中一人被攔，事情仍不會整份消失。

她們離開沉水古城兩個時辰後，第一個攔路者出現。

一名青衣女子站在乾涸水道中央，手裡沒有兵器，只亮出百曉樓的木牌。

「我不搶。」她先說。

沈素停下：「那你擋路做什麼？」

「看一眼副本。」

「看完呢？」

「記住內容，送你們過下一段亂林。」

「你記住後賣給誰？」

青衣女子沒有撒謊：「出價最高的人。」

沈素抱緊石匣。

「那跟搶有什麼不同？」

「我不會讓原本那份少一個字。」

「可我不知道自己的話會走去哪裡。」

青衣女子看向洛生衣：「你們需要路。」

前方亂林每隔半個時辰便會改變方位。繞路要多跨一層小千世界，沈素的神魂經不起新的空間轉換。

這不是毫無代價就能拒絕的交易。

洛生衣問：「你只看證詞？」

「是。」

「不看姓名與落腳地？」

「那會少一半價。」

「所以？」

青衣女子沉默片刻。

「可以。」

沈素卻問：「你賣出去時，會說刪掉了姓名？」

「會。」

「會說你沒看物證？」

「會。」

「也會說我沒親眼看見謫仙下令？」

「這句會讓消息更不值錢。」

「所以更要說。」

兩人最後達成的不是信任。

是一份範圍很窄的交換。

青衣女子只能看刪去姓名、地點與其他倖存者特徵的證詞副本；消息出售時必須保留「謫仙之名由荒辨認」「沈素未親見下令」兩項限制。她提供穿過亂林的當日路線，卻不成為證詞保管者。

洛生衣當場抄了一份。

青衣女子看完，只問一句：「你不怕真話因為留了限制，最後傳得不夠遠？」

沈素答：「傳得遠的若不是我的話，跟我有什麼關係？」

亂林比預期更難走。

第三次地貌變換時，沈素忽然停住，手指不受控制地抓向自己眉心。密盤裡神魂被剝離的感覺隨空間翻轉重新出現，她明知自己還在身體裡，視野卻同時看見水下那具軀殼。

洛生衣沒有說「都是假的」。

那不是假的。

是她確實經歷過的事。

生衣從洛生衣指間展開，沒有包住沈素全身，只托住魂身重新分離的那一線。她讓沈素自己把手按回心口。

「說名字。」

「沈……素。」

「再一次。」

「沈素。」

「現在在哪？」

「亂林，第三次換路。」

「要去哪？」

沈素喘了很久。

「送我自己的話。」

魂身重新合攏。

洛生衣也白了臉。

續接魂身時，她同樣感到那座石臺壓下來，感到自己的肉身在水底而神魂被人拿去稱量。她沒有因此比沈素更懂那段經歷，只是暫時與她共同承受了一小部分。

兩人在林邊坐了半個時辰。

青衣女子沒有催。

她原本可以趁機再看石匣，卻只站在風口替三人確認下一次換路時間。

傍晚，第二份證物抵達一座由七支散修隊共同維持的石塔。

塔不保證替任何人復仇。

只保證每份寄存內容都由三支互不隸屬的隊伍各持一枚開匣印，任何一方不能單獨取走或銷毀。

沈素把證詞放進去。

沒有掌聲。

沒有立刻傳遍仙古的真相。

石塔守印者只問：「寄存人姓名？」

她答得很穩。

「沈素。」

這一次，不需要別人提醒。
