# 第三十六章 別人的道火已經亮了，他先承認自己還點不起來

離開沉水古城後，陸沉被送到一座廢棄藥臺。

藥臺建在兩個小千世界交界處，早年種過養神草，如今只剩半圈石牆與乾涸藥池。往東可去三印塔，往南通赤霞谷，西北則連著一片正在甦醒的古地。

那片古地，這幾日開始出現道火。

第一道光在深夜亮起。

不是雷，也不是尋常火焰。數十里外的天空像被某種法則從內部燒透，雲層一重重顯出金、青、赤、白，再於天明前收回地平線。

藥臺上的年輕修士全站了起來。

有人立刻收拾行囊。

有人用半株寶藥換取路圖。

還有人只看了一眼，便盤坐點燃自身積蓄已久的神性精華，唯恐慢別人一步。

陸沉躺在擔架上。

他連坐起都得先確認右腿仍在同一層空間。

一名換路圖的修士認出他。

「你就是劫？」

陸沉點頭。

「聽說你打贏了白衣怪胎。」

「他逃了。」

「那也夠了。」修士看向遠方道火，「西北古地今日開第二層。去晚了，只剩別人燒過的道痕。」

他把多抄的一角路圖丟到擔架旁。

「算還你們救人的情。」

陸沉沒有立刻去撿。

洛生衣先檢查路圖上的藥澤與裂界標記，確認至少不是把傷者引進死地的假路。

「想去？」她問。

「想。」

「能去？」

陸沉看著自己右腿。

「現在不能。」

答案很快。

並不輕。

道火第二次亮起時，連劫命都在命圖裡震了一下。

五道雷性同時有了反應。

煌命想照見火中法則。

劫命想截取道火點燃前後的命數差。

鎮魄護住神魂，不讓外界道音直接灌入。

歸寂本能地將過盛波動往下沉。

鎮界雷胚則試圖固定所有變化。

五者沒有衝撞到吐血。

卻也沒有形成一條能點燃自身的路。

它們只是各自做了正確的事。

正確到彼此寸步難行。

洛生衣看著他胸口五處不同節律。

「你若現在點火，哪一道作主？」

陸沉沒有回答。

若讓煌命作主，其餘四雷會被迫成為被照見的材料。

若讓鎮界固定，尚未成熟的雷性可能永遠停在今日。

若以歸寂先壓平衝突，道火還沒真正燃起便會被沉下。

劫命可以截斷錯誤，卻不能替他決定什麼是自己的正路。

鎮魄則只會守住「他還是他」，不會告訴他接下來要成為什麼。

陸沉把五種反應逐一記下。

沒有嘗試。

藥臺另一端，一名修士點火失敗，胸腹炸出大片血霧。同行者立刻抬人去找醫者，留下的蒲團還冒著煙。

又有一人成功。

神火從脊背升起，照亮半座石臺。周圍響起壓不住的驚呼。

陸沉也看了。

沒有嫉妒到移開目光，也沒有因自己曾打贏更強的人，便認為境界可以稍後自行追上。

戰勝一個人，與走過自己的下一關，從來不是同一件事。

傍晚，玄衡回來了。

牠先在藥臺外停下，確認沈素一行已平安抵達廢藥田，才走到擔架旁。

陸沉問：「還走嗎？」

「暫時不。」

不是永遠留下。

也不是已經正式歸位。

只是今日選擇回來。

玄衡看向西北道火。

「你怕？」

「怕慢。」

「還有？」

「怕為了不慢，先把五道雷燒成同一種東西。」

玄衡伏下身。

牠曾見過太多修士以完整古法固定自身，也見過太多裂界被強行鎮成不再生長的死地。它沒有勸陸沉立刻去，也沒有說等待必然正確。

「那先別騙自己。」

陸沉將那角路圖收起。

明日仍是十八步。

不是前往道火古地的十八步。

只是確認右肺牽痛會不會再次提前、右膝冷感是否擴大，以及五雷在沒有外界道火刺激時能否各自安靜。

仙古深處，別人的火已經亮了。

有人走得比他快。

而陸沉第一次真正看清，自己接下來要面對的不是再找一種更強的雷。

是讓五種不肯彼此消失的雷，能在同一個人身上繼續長大。

他還沒有答案。

這次也沒有假裝準備好了。
