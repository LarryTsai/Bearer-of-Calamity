# 《劫》寫作風格

## 整體風格

- 中文玄幻／修真
- 氣質沉重、古老、宏大
- 不走無腦爽文
- 不走系統文
- 不使用現代網路語
- 不以搞笑沖淡關鍵悲壯場面

## 主角氣質

劫冷靜、果斷、能忍痛，重視效率。

他不是嗜殺，而是在確認敵我與代價後，不浪費多餘動作。

## 戰鬥描寫

- 動作清楚
- 節奏快速
- 招式有重量
- 少用長篇解說打斷戰鬥
- 肉身碰撞、骨、血、呼吸、步伐與承壓感要寫出來
- 雷不是只有光效，還要寫出壓迫、穿透、震魂、燃身、鎖界等差異

## 敘事原則

- 以場景與行動展示人物
- 少直接宣告「他很強」「他很痛苦」
- 避免反覆震驚與路人吹捧
- 重要能力應先埋伏筆，再正式顯現
- 成長必須有代價

## 對話

- 簡潔
- 符合人物身分
- 不說現代梗
- 強者不靠廢話製造氣勢
