# 專案規則

## 一、設定權限

文檔中的內容分為三類：

- `正式設定`：可直接用於正文，不可任意修改
- `暫定設定`：可用於討論，不可視為定稿
- `待補設定`：資訊不足，不得擅自補完

目前三份最高優先正史及其管轄範圍記錄於 `docs/INDEX.md`。發生衝突時，先按管轄範圍採用主設定，再回修摘要、時間線與舊草案；不得用較短的摘要反向覆蓋主設定。

## 二、禁止事項

- 不得把劫寫成純法修或純雷修
- 不得把四伴星寫成寵物、坐騎群或御獸流
- 不得讓劫依賴系統、簽到、抽卡等外掛
- 不得使用現代網路語、吐槽腔、輕浮梗
- 不得為追求爽點破壞能力取得順序
- 不得假設舊正文仍有效
- 不得擅自更名已定稿角色、功法、宗門、伴星

## 三、新設定新增方式

新增設定時必須包含：

1. 名稱
2. 定位
3. 出現階段
4. 與既有設定的關係
5. 是否造成衝突
6. 狀態：提案／暫定／正式

## 四、一致性檢查

每次寫章節後至少檢查：

- 時間線
- 境界
- 能力來源
- 角色稱呼
- 人物性格
- 物品持有狀態
- 地點與移動合理性
- 是否提前使用未取得能力
