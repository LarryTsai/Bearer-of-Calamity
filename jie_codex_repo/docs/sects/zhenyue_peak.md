# 太玄宗・鎮岳峰設定文檔

## 一、鎮岳峰定位

**鎮岳峰**，太玄宗七峰之一，主修煉體。

太玄宗七峰各有大道，而鎮岳峰最重根基。此峰不重術法，不喜外相，不收浮華之人。

鎮岳峰只問三件事：

> **站得住否？  
> 承得住否？  
> 崩不崩？**

因此鎮岳峰弟子極少，是七峰之中人數最少、門規最簡、修行最苦的一脈。

其他峰或收天才，或收靈根，或收悟性驚人者；鎮岳峰只收那些被命運壓過、被身體拖累過、被痛苦磨過，卻仍沒有倒下的人。

一句話定位：

> **鎮岳峰不教人飛天，先教人站穩。**

---

## 二、鎮岳峰根本理念

鎮岳峰的核心不是力量，而是**承載**。

普通體修煉肉身，是為了硬、為了壯、為了打。鎮岳峰煉肉身，是為了承載大道。

肉身不是外殼。

肉身是鼎，是山，是舟，是第一座道基。

鎮岳峰認為：

> 神識會亂，法力會竭，道心會顫。  
> 唯有肉身若能不崩，人便還有再站起來的可能。

這也是劫會選鎮岳峰的原因。

劫前身體弱，神識極強，意志極堅。他不是天生肉身無敵，而是最知道「身體撐不住」有多痛的人。

所以鎮岳峰對劫來說，不只是修體之地，而是他重鑄自身的第一座山。

---

## 三、鎮岳峰主修功法：萬體鑄身經

### 1. 功法定位

**《萬體鑄身經》**，太玄宗入門基礎功法之一，無屬性，鎮岳峰一脈尤重此經。

它不是最強功法，也不是殺伐神通。

它的地位在於：

> **萬法先鍛身，百脈始成基。**

《萬體鑄身經》不偏五行，不偏雷火，不偏陰陽。它的作用是把一個人的身體從「凡軀」整理成「可承道之器」。

### 2. 功法核心

《萬體鑄身經》核心分四步：

| 階段 | 內容 |
|---|---|
| 鍛骨 | 讓骨骼可承壓，不因靈力反噬而裂。 |
| 煉筋 | 讓筋膜可傳力，不因爆發而斷。 |
| 熱血 | 讓氣血可運轉，不因戰鬥而枯。 |
| 通脈 | 讓百脈可承法，不因大道入體而崩。 |

此經最重要的一句是：

> **先鍛其身，後承其道。**

也就是說，鎮岳峰不是教弟子一開始就走日月星辰、時間空間，而是先以《萬體鑄身經》把身體鑄成基礎，再依照自身缺陷、命格、傷痕與承受方向，走出各自的「體」。

---

## 四、鎮岳峰環境

鎮岳峰不是普通山峰，而是一座沉重到近乎壓人的巨山。

峰上常年陰雲壓頂，雷聲不絕。山體如黑鐵，石壁刻滿古老體修紋路。

鎮岳峰各處可分為：

| 地點 | 作用 |
|---|---|
| **鎮岳臺** | 新弟子入峰第一關，測能否站穩。 |
| **碎石場** | 鍛骨、承壓、練基礎拳腳。 |
| **煉體淬骨池** | 以藥液、雷意、山壓淬體。 |
| **萬體碑林** | 記載歷代體修殘法與體質演化。 |
| **鎮岳壹門** | 鎮岳峰正門，象徵「入此門者，先受山壓」。 |
| **鎮岳崖** | 弟子閉關承壓之地。 |
| **峰主殿** | 岳沉淵所在，不華麗，像一座壓在山中的古殿。 |

鎮岳峰給人的感覺不是仙氣飄渺，而是沉重、古老、壓迫，像一座把弟子壓到骨頭裡，再逼他們重新站起來的山。

## 五、鎮岳峰峰主：岳沉淵

### 1. 基本設定

| 項目 | 設定 |
|---|---|
| 姓名 | **岳沉淵** |
| 身分 | 鎮岳峰峰主 |
| 外號 | **古嶽真君** |
| 身高 | **203 cm** |
| 體質 | **古嶽巨人體 / 古嶽鎮身體** |
| 氣質 | 沉穩、厚重、寡言、不怒自威。 |
| 核心教義 | **站穩、承痛、不崩** |

岳沉淵不是普通大修士。

他身負古嶽巨人血脈，肉身厚重如山，氣血沉如地脈。他站在地上時，不像一個人，更像一座活著的古嶽。

### 2. 峰主體質：古嶽鎮身體

岳沉淵的體不屬於六位弟子的六極之一。

六位師兄姊各承一極：重、月、日、星、空、時。

但岳沉淵不是其中任何一極。

他是根。

> **鎮岳六極，皆立於古嶽之上。**

**古嶽鎮身體**的核心不是控制重力，不是操控山岳，而是身體本身承載了「古嶽」的意象。

他的肉身能承壓、承痛、承法、承劫。

一句話：

> **他不借山勢，因為他站著，就是山。**

### 3. 岳沉淵教劫三事

岳沉淵教劫的不是強大招式，而是三個最基礎也最難的東西。

**第一：站穩。**

不是站在地上，而是在劫雷、殺意、命數、敵意壓下來時，仍能站住。

**第二：承痛。**

體修最怕的不是痛，而是痛中失控。岳沉淵要求弟子能在骨裂、筋斷、血逆之時，仍守住呼吸與心念。

**第三：不崩。**

肉身不崩，道心不崩，命圖不崩。

這三事後來會成為劫修十劫雷身的根基。

## 六、鎮岳峰六位師兄姊

鎮岳峰弟子不多，但每一位都不是普通體修。

他們不是天生完美。相反，他們多半是被身體缺陷、命格偏折、血脈反噬、傷病殘缺逼到絕路後，才被岳沉淵收下。

岳沉淵不是把他們修成同一種人。他讓每個人沿著自身最痛的一點，煉出自己的體。

因此形成：

> **鎮岳六極體。**

六極不是大道本身，而是肉身對大道之影的映照。

## 八、大師兄：沈山河

| 項目 | 設定 |
|---|---|
| 名字 | **沈山河** |
| 排名 | 大師兄 |
| 體名 | **玄極重域體** |
| 對應方向 | 重力 / 重域 |
| 氣質 | 沉穩、可靠、首徒感。 |
| 外觀 | 成熟但不顯老，壯而不誇張，身形厚實，眼神沉定。 |

### 玄極重域體

沈山河不走峰主的古嶽路線。

岳沉淵是「山」，沈山河是「重域」。

他不是像峰主一樣本身就是古嶽，而是以肉身煉出一片沉重力場。

戰鬥時，他周身會形成無形重域。敵人靠近他時，會覺得筋骨沉重，血流變慢，步伐像陷入深泥。

他的力量不是爆炸型，而是壓制型。

一句話：

> **他不必比你快，只要讓你慢下來。**

### 與劫的關係

劫從沈山河身上學到：

> **雷不只可以劈落，也可以壓落。**

這會影響劫後來的鎮壓型雷法、命圖壓制、戰場控域。

| 外觀 | 白髮或銀白髮，月華冰輪背景，身形修長。 |

### 太陰映骨體

秦照雪不是普通冰系。

她的寒不是術法寒冰，而是太陰入骨。

她的骨像被月華照過，冷而不脆，靜而不死。她越在混亂中，越能保持身體穩定。

敵人與她近戰時，往往不是被冰封，而是先覺得血液變慢、筋骨發寒、出手失準。

一句話：

> **月不殺人，月照之下，血自成霜。**

### 與劫的關係

劫從秦照雪身上學到：

> **狂雷也可以收束，殺意也可以冷下來。**

她對應劫後來雷法中的凝、束、靜、準。

陸行烈不是單純血氣旺。

他的肉身像一輪近身赤陽，越戰越熱，越傷越烈。

他不怕短時間爆發，甚至適合在重傷時反殺。

但這條路極危險，因為赤陽焚身體若控制不好，會把自己的身體也燒乾。

一句話：

> **他不是燃血，是把整個人煉成一輪近身烈日。**

### 與劫的關係

劫從陸行烈身上學到：

> **燃燒不是自毀，而是在死局中換出一線勝機。**

這會成為劫後來「燃身雷」的重要前置啟發。

### 周天星脈體

柳青藤新設定不再走單純藤甲生息，而是星脈周天。

她體內穴竅像一枚枚微星，百脈連成一座小型周天。

她受傷時，傷勢不會集中在一處，而會被星脈分散到全身周天。

所以她的特色不是爆發，也不是單純治癒，而是：

> 分傷、續命、持久、循環。

一句話：

> **一處受創，百星分傷；一脈將斷，周天再續。**

### 與劫的關係

劫從柳青藤身上學到：

> **肉身可以像星圖一樣運轉，力量可以不只走經脈，也能走軌道。**

這會影響劫後來的命圖、十雷星位、雷身軌道。

| 排名 | 五師兄 |
| 體名 | **虛界不破體** |
| 對應方向 | 空間 / 虛界 |
| 氣質 | 冷硬、寡言、防線。 |
| 外觀 | 年輕冷甲鐵衛型，不顯老，不走工匠叔感。 |

### 虛界不破體

韓鐵衣不是傳統鐵骨硬扛。

他的防禦不是「更硬」，而是「隔開」。

他肉身外層像形成一層虛界。敵人的拳、刀、術打到他身上，像是先撞上一層不存在的距離。

不是沒打中，而是打中了也不完整。

一句話：

> **打中他，不代表真正碰到他。**

### 與劫的關係

劫從韓鐵衣身上學到：

> **防禦不一定要硬扛，也可以隔斷、偏移、錯開。**

這對劫後來的空間撕裂、雷界隔斷、虛渡類能力很有啟發。

## 十四、鎮岳峰與劫的關係

劫在鎮岳峰不是直接得到一門最強體術。

他真正得到的是六種方向的啟發。

### 見沈山河，知重域可鎮

雷不只是劈，也可以壓。

### 見秦照雪，知太陰可束

雷不只是狂，也可以冷。

### 見陸行烈，知赤陽可燃

雷不只是殺，也可以燃身換命。

### 見柳青藤，知星脈可循

雷不只是直線，也可以成軌、成圖、成命盤。

### 見韓鐵衣，知虛界可隔

雷不只是破壞，也可以隔斷空間。

### 見顧小滿，知剎那可殺

雷不只是快，而是讓敵人慢了一瞬。

最終，劫不是繼承六極之一。

他是看過六極之後，以自己的雷道全部打碎、重鑄。

總句：

> **鎮岳峰六極，各守一象。  
> 劫見六極，破六極，最後以十劫雷身自立。**

---

## 十五、鎮岳峰在太玄宗中的特殊地位

鎮岳峰人少，但地位不低。

因為太玄宗真正遇到大戰時，最先站出來守山門的，往往不是萬法峰，也不是問劍峰，而是鎮岳峰。

原因很簡單：

> 其他峰能殺敵。  
> 鎮岳峰能守住。

鎮岳峰弟子不是最多的，但每一個都能在戰場上扛住一角。

所以太玄宗內部有一句話：

> **鎮岳為根，六傑並肩。  
> 守護仙途，永鎮九霄。**

---

## 十六、鎮岳峰核心金句

> **鎮岳峰不教人飛天，先教人站穩。**

> **萬法先鍛身，百脈始成基。**

> **站穩，承痛，不崩。**

> **六極不掌大道，只以肉身映大道之影。**

> **峰主岳沉淵不是六極之一，他是讓六極能立住的山。**

> **鎮岳峰六極，各守一象；劫見六極，破六極，終以十劫雷身自立。**

> **雷若無身承，便只是天威；身若能承雷，方成劫道。**
