# 主時間線

狀態：正式相對順序；具體年份、卷數、章數與未標明的雷位取得點待補。

1. 下界早期成長。
2. 虛神界：劫與文奕相遇，共得完整《古神禁典》。
3. 百斷山：劫取得黑色天地雷火，完成淬體與承雷資格；沒有雷種。
4. 下界大劫。
5. 界海雷淵：正式取得第一雷「照命」。
6. 進入上界。
7. 加入太玄宗鎮岳峰，以宗門陣法文明補足禁陣系統。
8. 上界禁道篇：禁都與萬禁會；文奕奪魁，劫完成奪禁後被判出局。
9. 後續上界、仙古與伴星成長階段：劫厄、鎮無央、鎮界麒麟先後形成前三伴星；其確切章序須與各雷位取得表共同補完。
10. 帝關前後：劫與文奕逐步建立戰爭禁陣網。
11. 界路篇：前三伴星同行；遇燼長明；界路死戰；燼長明燃盡救劫並重生後自主加入；劫第二次承受並取得第八天地異雷「餘命燼雷」，命圖雷位「燃身」成立；五人回帝關。
12. 帝關交接：劫與文奕完成母陣、雷池網、傳送與備援體系；荒將被交付／離開時，劫把帝關系統交給文奕。
13. 異域潛伏：劫不是被抓，而是為荒秘密跟入異域，偽裝王族並逐層取得情報。
14. 異域情報戰：五人輪流受創，帝族逐步建立針對方案。
15. 五人大劫：帝族收網並引完整大道大劫；劫試圖獨承，四伴星反抗；吞、鎮、導、生與承、析、分形成五星循環。
16. 完整大道重塑後短促清場；五人仍重傷，必須隱匿休養。
17. 休養後重新追尋荒；具體會合節點與返回九天十地方式待原作接口確認，不得提前鎖死。
18. 更後期：異域所得完整大道理解回饋帝關與活禁研究；最終大劫中劫、文奕兩路合流，後世稱第三禁道盛世。

## 強制連續性

- 第八雷篇必須先於異域五人大劫，因其提供「努力活著回來」與分流的前置。
- 禁都／萬禁會必須先於帝關大型禁陣與異域完備偽裝，否則能力沒有結構性來源。
- 帝關交接必須先於秘密潛入，否則文奕留守與劫的責任選擇無法成立。
- 異域重塑後仍需休養，不得直接無傷銜接荒線。
