# 《劫》全書主線骨架

狀態：正式整合骨架。具體卷數、章數與尚未定名事件仍待後續規劃。

## 一、三條不可拆散的長線

全書不是「體修、十雷、禁制、四伴星」各走各的支線，而是三條因果鏈逐步合流：

1. **承載線**：肉身 → 萬體鑄身經 → 承雷 → 十雷 → 太玄命圖 → 完整大道重塑。
2. **禁道線**：神識與野路禁制 → 文奕與《古神禁典》 → 第一雷照命看見「線」 → 太玄宗陣法系統 → 禁都／萬禁會／奪禁 → 帝關母陣與雷池網 → 異域偽裝、情報戰與五星雷路 → 最終活禁合流。
3. **同行線**：劫厄 → 鎮無央（鎮魄獅） → 鎮界麒麟 → 燼長明 → 界路共同死戰 → 異域五人大劫 → 五星循環。

任何重要篇章至少推動其中一條線；大篇章應讓兩條以上互相產生因果，而不是只增加能力或同伴。

## 二、階段骨架與不可逆變化

### 1. 下界萌芽

順序鎖定：下界 → 虛神界 → 百斷山 → 下界大劫。

- 劫先以神識、肉身直覺與非正統思路接觸禁制。
- 虛神界與文奕因古神遺留相遇，兩人取得內容完全相同、完整的《古神禁典》。禁典只提出「禁有其令，可有其命」，沒有替兩人完成活禁。
- 百斷山只有黑色天地雷火，用於淬體、活化死禁與建立承雷資格；此處沒有雷種。
- 兩人第一次分開時，應已能從對方留下的禁制痕跡辨認彼此，但信任尚未成熟。

不可逆變化：劫從會破解局部禁制的人，變成開始追問禁如何與生命相連的人。

### 2. 第一雷與上界立足

順序鎖定：下界大劫 → 界海雷淵／第一雷「照命」 → 上界 → 太玄宗。

- 第一雷「照命」是第一顆正式雷種，使劫逐漸看見能量、生命、禁紋、陣法與規則之間的「線」。
- 太玄宗不是重新教他禁制入門，而是補足陣基、陣眼、迴路、多節點、傳送、引雷、空間與能量分流。
- 鎮岳峰的承載哲學令禁陣不再只是外物：劫必須先讓肉身成為能承受多路雷與禁反噬的核心節點。

不可逆變化：雷道、肉身與禁道第一次成為同一套方法。

### 3. 上界禁道篇

順序鎖定：太玄宗成長 → 禁都 → 萬禁會 → 後續分行。

- 劫進禁都後必須看見自己的正統基礎不足；《古神禁典》不能讓他自動精通整個禁道文明。
- 文奕代表結構、模組、備援、自循環與秩序；劫代表探查、尋隙、欺禁、改流與攻擊假設。兩人互相影響，但不變成同一種禁師。
- 萬禁會由文奕正式奪魁更合適；劫完成「奪禁」——讓完整禁制認錯主人——並因反噬規則被判出局。規則上劫輸，禁道上出現新問題。
- 現代「駭客」只作作者理解框架，正文不得直接使用該術語。

不可逆變化：劫從破禁者成為能改寫禁制信任關係的人；文奕從正統極致開始敢於開新路。

### 4. 四伴星逐步成形

- 劫厄是首伴星，不是寵物或坐騎。
- 鎮無央是鎮魄獅的正式姓名；早期可因身份未明而使用「鎮魄獅」稱號，正名後以「鎮無央」為人物稱呼。
- 鎮界麒麟目前尚無另定人名；「麒麟」是正文可用簡稱。
- 燼長明是鳳族伴星正式姓名；「玄燼凰」是廢止舊稱。
- 前三位同行後才進入界路；燼長明不能提前成為伴星。

不可逆變化：每一位伴星都因自身判斷留下，不得寫成劫收服神獸的重複副本。

### 5. 界路、燼長明與第八雷

- 劫帶劫厄、鎮無央、鎮界麒麟進入九天十地與異域之間的古老界路。
- 燼長明先因禁區、守界責任與誤判同劫厄交手；這場衝突只建立認識，不決定歸屬。
- 異域針對界路「餘命」設局。劫第一次強承餘命燼雷失敗，證明願死不等於懂得留命。
- 燼長明在本可撤離時回頭，追入死局，燃盡自身將劫送回；劫保存其灰，使最後一點餘命沒有散失。
- 燼長明重生後自行留下，四伴星才正式齊聚。
- 劫經戰後追索、理解雷境與第二次承受，正式取得天地異雷「餘命燼雷」，命圖第八雷位名為「燃身」。

不可逆變化：劫仍會先站出去，但第一次把自己的命列入必須保護之物；五人關係獲得共同死戰的根。

### 6. 帝關禁陣與交接

- 劫與文奕在帝關共同建立母陣、雷池網、空間道標、傳送網、能量分流、活禁節點、備援與欺禁層。
- 當荒將被交付／離開帝關時，劫決定追入異域，但不能公開把帝關防務一起帶走。
- 劫將自己建立的戰爭網路及重要之人交給文奕，因為文奕本就是這套系統的共同建造者。
- 對外，劫沒有與荒一同被擒；對內，文奕可知道劫準備行動，但知道多少細節應由實際場景決定。

不可逆變化：兩位禁道開道者第一次分守兩界；文奕不是留守工具人，而是獨立承擔帝關體系的人。

### 7. 異域潛伏與五人大劫

- 劫最初目的只有荒。他以雷、神識與禁制修改肉身、元神、生命波動與大道氣息，偽裝異域王族；偽裝必須持續面對驗證升級，不能一次成功後永久安全。
- 禁都與帝關累積必須在此兌現：情報分層、假身份、節點滲透、傳送退路、分身資訊污染、雷侵與欺禁共同構成潛伏方法。
- 五人輪流受創，帝族也逐步學會研究舊的劫；最後情報成為收網誘餌，敵人以封天鎖地、斷空間與完整大道大劫抹殺五人。
- 劫把五份大劫導向自己，是界路後仍會復發的犧牲本能，不得寫成他忘了第八雷教訓。真正進步在於四伴星能識破、反抗並拒絕讓他單獨決定所有人的生死。
- 劫厄吞、鎮無央鎮、鎮界麒麟導、燼長明生；劫承、析、分。五者形成雙向五星循環。
- 完整大道打碎並重塑肉身、神識與雷種；禁道則因新的「看見」而質變，但不能當場無所不能。
- 蛻變後的帝族清場要短而準，隨後五人仍必須重傷休養；最初目的回到尋找荒。

不可逆變化：四伴星由同行關係成為生命與大道結構；舊的劫被殺局逼死，新的使用方式誕生，但戰力仍受傷勢與境界限制。

### 8. 後續與最終大劫

- 與荒會合的具體原作節點目前不得鎖死。
- 劫在異域對完整大道之「線」的理解，日後必須回饋帝關禁陣與文奕的活禁道路。
- 最終不是劫獨自完成活禁。文奕走「禁 → 生命」，劫走「生命 → 禁」，兩條道路缺一不可。
- 第三禁道盛世只能由後世回望命名，當代人物不應自行宣告。

## 三、正文驗收鎖

寫作與審校每個相關篇章時必查：

1. 禁道是否透過決策與行動推動情節，而非只在解門時出現？
2. 文奕與四伴星是否各自有目標、選擇與代價？
3. 新雷、新禁或蛻變是否有線索、追索、失敗、代價與後續磨合？
4. 界路學會「努力回來」是否在異域被深化，而非被遺忘？
5. 異域潛伏是否兌現禁都與帝關建立的能力，而非臨時獲得完美偽裝？
6. 重大勝利後是否保留傷勢、資源消耗與追查後果？
7. 尚未定死的原作接口、雷位與正式術語是否仍保持開放？
