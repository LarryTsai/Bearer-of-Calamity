# 主角：劫

狀態：核心方向已確認，完整人物卡待補。

## 已確認

- 劫的根本是體修。
- 早期雷道只是一條逐漸成形的副線。
- 真正取得正式雷種後，雷修比重才逐步提高。
- 即使後期十雷與命圖極度耀眼，劫仍是以肉身承道。
- 戰鬥重效率，能硬碰時也能硬碰，但不會為表現強大而故意拖戰。
- 殺伐果斷，但不是無理由濫殺。
- 禁制不是副職，而是貫穿全書的核心主線；劫會攻擊規則、驗證與招式所依賴的假設，並把神識、禁制、陣法、雷、肉身、速度、分身與空間整合成同一套攻防思維。
- 劫的禁道風格偏怪盜與攻防破解：先探、尋隙、入侵、改流，能奪取目標便不拖戰；但正文不直接使用現代「駭客」術語。
- 文奕是劫的禁道知己、對手、鏡子與共同開道者之一，兩人不是單向師徒關係。

## 核心句

> 雷若無身承，便只是天威；身若能承雷，方成劫道。

> 荒把不可能打穿；劫找出它為何看似不可能打穿。
