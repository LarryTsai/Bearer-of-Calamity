# 名詞表

## 劫

小說主角。

## 太玄宗

劫的重要宗門階段。完整七峰設定待補。

## 鎮岳峰

太玄宗七峰之一，主修煉體與承載。

## 太玄命圖

劫未來由十雷、雷身軌道與外環伴星構成的核心命圖體系。完整結構待補。

## 四伴星

劫厄、鎮無央（鎮魄獅）、鎮界麒麟、燼長明。不是御獸，不佔十雷主星。「麒麟」可作鎮界麒麟簡稱；「玄燼凰」為燼長明的廢止舊稱。

## 奪禁

不破壞完整禁制，而是改寫其認主或信任判定，使它認錯主人。必須先理解認主邏輯並找到入口，不能作為無條件奪取高階禁制的通用能力。

## 雷侵

劫以雷的傳導與改流特性進入術法、禁制或能量迴路，依次完成探、尋隙、入侵、改流。正文不用現代「駭客」稱呼。

## 五星循環

異域完整大道大劫中形成的五者雙向生命與大道結構：劫承、析、分；劫厄吞；鎮無央鎮；鎮界麒麟導；燼長明生。不是第五伴星，也不佔十雷主星。

## 劫厄

伴劫而生，四伴星之首。
