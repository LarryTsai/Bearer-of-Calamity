# 三份核心設定閉環審校紀錄

審校範圍：禁道主線、界路／燼長明／第八雷、異域潛伏／完整大道蛻變。

## 已確認並修正

### P0：正史只有優先宣告，沒有可執行整合層

- 影響：寫章時無法快速判斷三份長設定如何落入時間線與能力取得順序。
- 修正：新增全書主線骨架、主時間線、禁道演化表及文奕人物檔。
- 驗收：三份設定的主要事件現在能沿同一條相對時間線讀通。

### P0：四伴星稱呼混用

- 影響：鎮無央／鎮魄獅、麒麟／鎮界麒麟可能被誤寫成不同角色；燼長明仍殘留舊稱風險。
- 修正：正式映射鎮無央為鎮魄獅之名，麒麟為鎮界麒麟簡稱，燼長明為正式名，「玄燼凰」廢止。
- 驗收：核心索引、人物骨架與四伴星文檔使用同一映射。

### P1：界路成長與異域獨承表面衝突

- 影響：若不處理，劫在第八雷學會留命後又獨承五劫，會像人物倒退或作者忘記前篇。
- 修正：定義為犧牲本能在更大壓力下復發；真正的深化是四伴星已有能力識破並拒絕他的單方面決定，迫使單向承受變成雙向五星循環。
- 驗收：故事骨架與時間線均明列此因果。

### P1：帝關交付與秘密潛入缺少橋接

- 影響：一份設定像劫與荒一起出去，另一份強調劫不是被抓，容易形成事件矛盾。
- 修正：劫先把共同建造的帝關系統交給文奕，再秘密跟入異域；是否讓文奕知道全部計畫留待場景決定。
- 驗收：帝關交接位於異域潛伏之前，且不再宣稱劫與荒一同被擒。

### P1：異域能力可能像臨時外掛

- 影響：完美偽裝、五星雷路與大道線成禁若缺前置，會削弱禁道主線與代價。
- 修正：將虛神界、照命、太玄宗、禁都、萬禁會、帝關系統逐層列為異域潛伏的能力來源，並加入驗證升級、錯判反噬與敵方研究等反制。
- 驗收：禁道演化表明列每階段能做與不可提前做到的事。

## 已驗證非問題

- 第八雷不是燼長明或鳳族創造；鳳族只是最理解餘命燼雷的生命之一。
- 四伴星不佔十雷主星；五星循環是生命與大道結構，不是新增第五伴星或改寫十雷數量。
- 完整大道蛻變不等於滿血或無條件跨境；清場後仍有傷勢、休養與更高層威脅。
- 文奕與劫共同開道不削弱劫的主角地位，因兩人解的是不同方向且最終互相依賴。

## 尚未定死且不得擅補

- 第二、第五、第六、第十雷及部分雷位的完整來源、取得篇章與代價。
- 鎮界麒麟是否另有人名。
- 文奕禁盤的正式名稱、境界與外貌。
- 異域偽裝王族、帝族敵手、大劫名稱、返本術語及與荒會合的原作節點。
- 具體卷章配置與每段故事容量；目前正文尚未正式開始，因此不存在發展版／出版版同步問題，也無法進行章長統計。

## 回歸驗收

- 寫作前須同時讀主線骨架、主時間線及目標篇章主設定。
- 搜尋廢止舊稱、百斷山雷種、劫被抓入異域、燼長明被收服等舊表述。
- 每次異域能力出現，都要能指出它在下界、太玄宗、禁都或帝關的前置。
- 每次五人關係升級，都要有共同事件、選擇、代價與後續記憶。
