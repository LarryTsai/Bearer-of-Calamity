# 寫作章節提示

請先讀取：

- `AGENTS.md`
- `PROJECT_CONTEXT.md`
- `RULES.md`
- `STYLE.md`
- 與本章相關的設定文件
- `docs/story/main_story_spine.md`
- `docs/timeline/main_timeline.md`

執行流程：

1. 列出本章已知前提。
2. 列出可能的設定風險。
3. 只在無衝突時開始寫作。
4. 正文使用繁體中文。
5. 章末附上簡短一致性檢查，不得混入正文。
6. 若涉及禁道、界路／第八雷或異域篇，必須指出本章承接的前置能力、人物關係與下一個後果，不得只搬運設定資訊。
