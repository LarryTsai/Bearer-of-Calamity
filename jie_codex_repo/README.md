這是一個供 ChatGPT、Codex、Claude Code、Cursor 等 AI 工具共同使用的小說設定 Repository。

## 專案狀態

- 正文：尚未正式開始寫作
- 原則：設定優先，正文不得反向修改已定稿設定
- 主角：劫
- 核心宗門：太玄宗・鎮岳峰
- 核心體系：體修為根、雷道為線、十雷與太玄命圖為最終大道

## AI 使用順序

1. 先讀 `AGENTS.md`
2. 再讀 `PROJECT_CONTEXT.md`
3. 查閱 `docs/INDEX.md`
4. 讀 `docs/story/main_story_spine.md` 與 `docs/timeline/main_timeline.md`
5. 寫作前讀 `STYLE.md`、`RULES.md` 及目標篇章設定
6. 正文僅寫入 `novel/`

## 重要提醒

本 Repository 目前只把已能確認的正式設定納入。未完成的設定文檔以索引中的「待補」標示，不可由 AI 擅自定稿。
