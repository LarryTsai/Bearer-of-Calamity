## 主角核心

- 名稱：劫
- 早期根基：體修為主，雷修為輔
- 發展方向：以肉身承雷，以十雷構築太玄命圖
- 戰鬥傾向：高效率、殺伐果斷、近身能力極強
- 核心反差：外界後期常只記得他的雷與命圖，忘了他本質是體修出身

## 禁道主線（必走）

禁制不是劫的副職，而是與肉身、雷道並列並貫穿全書的核心主線。作者最新直接裁示已遷至正式主庫 `../jie_rewrite/docs/author_directives/AUTHOR_DIRECTIVE_FORBIDDEN_PATH_MAINLINE.md`；本舊庫內容不再具有回填權限。

- 劫以怪盜／攻防破解式思維探索、布禁與戰鬥，但正文不直接使用現代「駭客」術語。
- 文奕是劫最重要的禁道知己、對手、鏡子與共同開道者之一，不可降格為普通軍師或工具人。
- 虛神界共同取得完整《古神禁典》，其後經太玄宗陣法系統、禁都與萬禁會推進至「奪禁」。
- 禁道歷經三次盛世；劫與文奕的兩條活禁道路最終必須在大劫合流。
- 鎖死前期順序：下界 → 虛神界 → 百斷山 → 下界大劫 → 界海雷淵／第一雷「照命」 → 上界 → 太玄宗 → 上界禁道篇／禁都／萬禁會。
- 百斷山只有天地雷火，沒有雷種；第一雷「照命」才是正式雷種起點。

## 宗門核心

劫進入太玄宗後，選擇七峰之一的鎮岳峰。

鎮岳峰主修煉體，核心不是單純強壯，而是「承載」。

峰訓：

> 站穩，承痛，不崩。

## 四伴星

- 劫厄：四伴星之首，伴命、守劫
- 鎮無央（鎮魄獅）：鎮魂、鎮場
- 鎮界麒麟：鎮界、定魂、吞災、歸序
- 燼長明：鳳族伴星，餘命、燃身、灰燼重生（「玄燼凰」為廢止舊稱）

四伴星不佔十雷主星，而是太玄命圖外環伴星。
