## 主角核心

- 名稱：劫
- 早期根基：體修為主，雷修為輔
- 發展方向：以肉身承雷，以十雷構築太玄命圖
- 戰鬥傾向：高效率、殺伐果斷、近身能力極強
- 核心反差：外界後期常只記得他的雷與命圖，忘了他本質是體修出身

## 宗門核心

劫進入太玄宗後，選擇七峰之一的鎮岳峰。

鎮岳峰主修煉體，核心不是單純強壯，而是「承載」。

峰訓：

> 站穩，承痛，不崩。

## 四伴星

- 劫厄：四伴星之首，伴命、守劫
- 鎮魄獅：鎮魂、鎮場
- 鎮界麒麟：鎮界、定魂、吞災、歸序
- 玄燼凰：餘命、燃身、灰燼重生

四伴星不佔十雷主星，而是太玄命圖外環伴星。
