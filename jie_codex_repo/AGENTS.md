# AGENTS.md

## 專案類型

本專案是中文玄幻／修真長篇小說《劫》的設定知識庫與正文工作區。

## 每次任務前必讀

- `PROJECT_CONTEXT.md`
- `RULES.md`
- `STYLE.md`
- `docs/INDEX.md`

若任務涉及特定角色、宗門、雷種、伴星或時間線，必須先讀對應設定文件。

## 最高優先規則

1. 已定稿設定高於任何臨時構想。
2. 不得因劇情方便偷偷修改角色能力、加入時間、境界、關係或世界規則。
3. 正文尚未正式開始；不可假設已有章節、卷數或既定劇情進度。
4. 遇到文檔衝突時，停止擴寫，列出衝突，不自行選邊。
5. 未定稿內容只能標為「提案」「暫定」或「待確認」。
6. 不得把四伴星寫成御獸、寵物或奴僕。
7. 劫的根始終是體修；雷道再強，也不能抹掉其肉身根基。

## 寫作工作流

1. 讀取相關設定。
2. 先列出本章會使用的既有設定。
3. 檢查時間線與能力是否合理。
4. 再開始寫作。
5. 寫完後進行一致性檢查。

## 檔案規範

- 設定：放入 `docs/`
- 正文：放入 `novel/`
- 提示模板：放入 `prompts/`
- 不要直接覆寫正式設定；修改前先產生差異提案。

## 語言

所有小說、設定、摘要與檢查報告均使用繁體中文。
