# 第八十六章 告別

> 定位：古界 Act5〈五島終局〉N-2 第7章（N2-6）。情感章，須痛，有呼吸。承接第八十五章夜半：阿磯來意（一條骨魚）；照護者解除停雷線；黎母遞乾根布包、「布不用還」；封寒與汐禾（她攔下承諾）；汐禾拒刻出隊骨、古界人繼續留下打仗；退勢日蒼梧不上石、木檀石迴照排，汐禾以應名向蒼梧告別（全名），蒼梧補退勢節律與第二次扛的備案（只點到）；陸沉將聽島令放進阿磯手裡（遺物歸還，非傳承）；阿荇、老柯、穆灰不來；汐禾封存記錄、阿磯自削路標步數（毀標記一半），「剩下的等你們走了我再毀」；最後一夜陸沉與蒼梧只有一個結與一只杯。窗口本身留待第八十七章。

阿磯把拳頭伸到他面前，張開。

一條魚，骨片刻的，巴掌長。眼睛、鱗、背鰭都刻完了，尾巴也刻完了，尾梢兩道分叉刻得比眼睛還深。魚嘴上穿著一截麻線。

「放他杯子旁邊。」阿磯說。

「你自己給。」

「他嘴大。他一開口，我就想削他。」

「那也是你給。」

阿磯把魚攥回去，攥了一息，又攤開，擱在石凳上的匣蓋上，離陸沉的手一掌遠。

「他問是誰放的，你就說不知道。」

「我說不知道。」陸沉說。

阿磯轉身走了。走出去一段，回頭補了一句：「你別看他戴不戴。」

陸沉把魚收進袖口。第二天天沒亮，他把它放在封寒枕邊那只杯子旁邊。杯裡的水是季朔倒的，滿的。

早晨，照護者拆陸沉背布的最後一道結。

斜光下三枚木牌，他辨對了三枚。她把布擱在膝上，說：「線我解了。雷是你自己的事，不是我的。」

他站起來，背上那道黑金色的舊痕露在晨風裡，比前幾日淡了一層。照護者把疊好的布放進他手裡，轉身去看下一個人。

黎母坐在棚口分草，木凳上腫腿抬著，鞋帶是緊的。陸沉經過時，她的手往旁邊一伸，遞出一個用舊布裹著的小包，遞在他腰那麼高，眼睛一直在筐裡。

「煮水放一根。」

陸沉接了。布包裡是乾根，布是洗過的，摺得方方正正。他解開一個角看了看，根是一根一根掰勻的，每根一樣長，一樣粗細，沒有一根帶著斷茬。

「布不用還。」黎母說。

「好。」

她又掰開一根乾根，一半放這隻筐，一半放那隻筐，沒有抬頭。陸沉站了一陣，她還在分，他便走了。

棚後平石中間那塊壓石，一夜之間往左挪了一指。賀嬸說不是她，老柯說他杖都沒動過，季朔說他量過，本來就是這個位置。三個人站在石頭旁邊，各說各的，說到日頭上來，誰也沒把它挪回去。

供水槽邊，童石在等他。也不算等，空匣擱在槽沿上，人蹲在旁邊，像是路過。

「阿荇說，東堤換手那張圖。」

「汐禾轉給我了。」陸沉把骨片遞過去，是昨夜刻好的：草匣轉角的兩個位置，各寫一個名字，中間一道橫線。

童石接過去，看得很慢。「向蓁站在左邊。」

「是。」

「她慣右手。」

陸沉把骨片拿回來，用刀把兩個名字刮平，換了位置，重刻。刀刃走在骨面上，指節慢一拍，刻得比平時費力。童石一直蹲著，看他刻完，沒有說謝，也沒有說別的，把骨片翻過來看了看背面，夾在腋下，提起空匣走了。

網架上午補網。封寒坐在架邊，左腕上的魚皮繩多了一件東西：一條骨片刻的魚，麻線穿過魚嘴，繫在汐禾教他的那個結上。

汐禾蹲下去檢查昨日補的那一排孔，一個一個用指腹點過去，沒有一個偏的。她看見那條魚。

「誰給的？」

「不知道。」封寒說，「早上就在枕頭邊，杯子旁邊。」

「尾巴刻得好。」

「眼睛更好。我猜是條有身分的魚。」

隔著半個院子，阿磯正低頭刻名冊，刀尖頓了一下，又走下去。

阿汀端著一盆洗網的水從架後過來，左手那圈舊布已經換成新的，是封寒前幾日纏的那一條，纏得歪，他一直沒有拆。他把水盆放下，湊過去看那條魚。

「那邊有魚嗎？」

「不知道。」封寒說，「我下去那一趟，只顧著找腳。」

「你回來，帶一條給我看。」

「帶不回。」封寒說，「我只帶得走半塊餅。」

阿汀「哦」了一聲，端起水盆，走了兩步，又轉身：「那你在那邊看見了，說給我聽。」

封寒還沒答，汐禾已經開了口：「明日你先過。」汐禾說，「那邊你一個人待一日，等他們。」

「有魚陪我。」

「魚不會說話。」

「那正好，我說，它聽。」

汐禾拉過他的手腕，拇指按在結上，用力扯了一下。結沒有動。

「船要是又來——」封寒說。

「是我們的事。」

「我知道。」他頓了一下，「我出去以後——」

「別說。」

「我還沒說。」

「你要說『我會回來幫忙』。」汐禾說，「你一說，我就得記。」

封寒把嘴閉上，過了一陣，說：「行。我不說。」

汐禾從袋裡摸出半塊乾餅，塞進他手裡。

「路上用。」

「我怎麼知道用不用得上？」

「用得上。」

封寒低頭看那半塊餅，塞進袖口，拍了拍。他身上要帶走的東西，算來算去，只有這半塊餅、一根繩、一條魚。

午時，汐禾把出隊骨搬到石板上。

皮袋磨得發黑，魚皮繩一解就掉鹽。她一片一片擦，擦完一片排一片，動作和每旬清點時一樣。陸沉走過去，站在石板對面。沒有人叫他來，汐禾也沒有叫他走。

阿磯家那一片排在最後，字面上壓著一層風乾的鹽。他伸出食指，在鹽上輕輕蹭了一下，指腹沾了白。

「你們不進出隊骨。」汐禾說。

「我知道。」

「刻了，我就得等一道橫。」她把手裡那片骨擦完，放下，「我等不起一格空的。」

「嗯。」

「下一支隊，我還是要排。」汐禾說，「船來了，牌要有人守，藥路要有人背。這裡的仗，是我們的。」

「你們留下來打，我們走。」陸沉說。

「是。」

她把最後一片骨收進皮袋，魚皮繩繞了三圈，打結。陸沉站在石板對面，看著那個結。指腹上的鹽乾了，他沒有去擦。

午後的退勢照常來。營地聽得見水聲低下去一階，又回來。木檀和石迴那一潮上了最外兩處高石，蒼梧沒有去，這是汐禾早上說的：「你今天不上石。」他在供水槽邊搓標繩，搓了半條，又細又勻。

傍晚汐禾去收牌帳，蒼梧跟在後頭。她沒有叫他，也沒有攔他。

礁背在暮色裡是灰的。走過第一處高石，第二處，最外一處。木檀還站在最外那處石頂上，退勢過後半個時辰，他還沒有下來。他看見汐禾，也看見她身後的蒼梧，點了一下頭，說：「石迴在第二處，剛換過。」像是在報一件每天都報的事。

石腳插著的牌，正面「守」，字是新的，炭色還黑；背面「替」，是蒼梧三日前寫的，鹽吹過幾個退勢，邊上的筆畫掉了，只剩中間一橫一撇還認得出。牌邊多了幾道小小的刻痕，一道一道，不是他的，是木檀和石迴各自用刀尖添的，過幾個退勢，就添幾道。

汐禾把牌拔起來，遞給他。

他把牌翻過來，用指腹摸那個「替」字。炭粉沾在指尖上，他沒有擦。

「字淡了。」汐禾說，「我沒讓人補。掉了，他們自己會寫。」

蒼梧把牌遞回去。她接過來，插回石縫，手在牌頂壓了一下。

「蒼梧。」

「在。」

「記了。」

指尖上那點炭粉被海風吹著，慢慢淡了。

回營的路上，汐禾走在前面，忽然問：「退勢明日午後，後日午後。窗口是兩個？」

「照這幾日，退勢每天午後。」蒼梧說，「窗口若跨兩個，隔一日。我是這樣推的，沒有哪一回走完過。」

「我毀標記，排在第二個之後。」

「還有一種。」

汐禾沒有回頭。「說。」

「第二次我若再扛一次，會多留一日。」蒼梧說，「我走不動。」

礁背上的腳步聲一下一下。

「那我兩種都排。」汐禾說。

「妳不問我選哪一種？」

「你自己選。」

「好。」

她沒有再說，潮聲在右邊。

天黑前，阿磯在供水槽邊洗刀，洗到第三遍。陸沉在他旁邊的石沿上坐下，從懷裡取出那枚貝殼，先擱在石沿上，貝殼壓著一小灘水。

阿磯沒有看。他把刀在袖口擦乾，又放回水裡。

「那是柁婆的。」

「是。」

「她給你的。」

「她走的時候放在我手裡。」陸沉說，「沒有說怎麼用。」

阿磯把刀從水裡撈出來，又放進去。

「我不聽島。」

「我沒要你聽。」

「你們要走了，」阿磯的聲音提高了，「就把東西丟給我？」

「不是丟。」

「那是什麼？」

「是她的。」陸沉說，「放在我這裡一陣子。」

阿磯把刀扔進水裡。水濺起來，落在他手背上。他抬手去按右肋，那是他心煩時的舊習慣；按完，右手仍攤著，擱在膝蓋上，掌心朝上。

陸沉把貝殼放進那隻手裡。

貝殼離開他的手時還是溫的。他沒有替阿磯合手指。

阿磯低頭看著手心。過了一息，五根手指自己蜷起來，握住了。

「你們走以後，」他說，「我還是不信外人指路。」

「嗯。」

「我指的是我站過的地方，不是路。」

「我知道。」

阿磯把貝殼和刀一起收進腰間的袋子，和骨片放在一處，扣袋扣，扣了兩次才扣上。他沒有問陸沉會不會回來，沒有問這東西該怎麼用。他起身走了，走到槽尾，提起水桶，去給傷棚打水。

陸沉的手心空了，貝殼壓出的一圈紅痕還在。

夜裡，石板上點著一枝油火把。

汐禾把陸沉那一疊骨片放進一只舊藥匣，匣口用魚皮繩纏了兩道，繩結打的是她慣打的那種。她拿起阿磯那片碎骨，沒有先看正面，把它遞給阿磯。

「你的步，你削。」

阿磯接過來。刀貼上骨面，先削最後那一組歪的，一下，削下薄薄一層。他削得很慢，五個一組，一組一組，骨屑落在石板上，白的，細的。封寒坐在對面，一句話也沒有插。

背面削平了，他把骨片翻過來，正面兩道交叉線和那個小圈還在。他把它遞給汐禾。

汐禾把石板上的骨屑掃進掌心，走到火把邊，攤手，骨屑落進火裡，一閃，沒了。

「正面我留著。」她說，「灘上的石子、標記繩、楔子，你們走了我再毀。」

「我幫妳。」封寒說。

「不用。我一個人做。」

她用魚皮繩把那片削過的碎骨纏了兩圈，收進袋裡。然後遞給陸沉一片新削的骨片，邊上還帶著毛。

「明日的行，刻在這一片。用完，留在礁上，我來收。」

陸沉接了。

「誰不來，我先說。」汐禾說，「阿荇在第二標。老柯圖沒畫完。穆灰在古渡。」

她抱起藥匣，往北坡去，一個人。火把把她的影子拉得很長，一直拉到石板的邊界外面。

石坪上，陸沉在膝上鋪開那條石匠的短繩。右手指節慢，要把繩頭繞出一個環，繞了兩次都沒收緊。

蒼梧走過來，蹲下，伸手按住繩頭。

「封寒教的。」他說。手指穿過去，繞回，拉緊，結落在繩環正中。

陸沉用拇指按了按結面，沒有動。「碰水不脹。」他又說：「木檀那塊新牌，名字還是歪的？」

「歪的。」蒼梧說，「我沒讓他改。」

「他說他打了三次才對，要我也打三次。」蒼梧說，「我打了兩次。」

「哪一次歪？」

「第一次。」

蒼梧從腰邊取出那只木杯，是傷棚借的，杯口磨得圓滑。他把杯子放在陸沉右手邊，離一臂遠，想了想，又往裡挪近一掌。

杯裡是滿的水。陸沉拿起來喝了一口，是傷棚的水，微鹹。他把杯子放回去，離右手一掌的地方。

蒼梧的指尖上還沾著牌上的炭粉，在杯沿留下一個淡淡的灰印。
