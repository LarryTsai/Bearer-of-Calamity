# 第六十二章 一份補給

驗名臺回來的午後，四只行囊並排放在院中。

旁邊的東西卻排了兩丈長。

清水、乾糧、繩索、火石、雨布、傷藥、照明燈油，還有盟試途中可能用到的破陣釘與替換衣物。洛生衣把藥分成三排，青璃在地上攤開路圖，封寒只帶來一柄劍，陸沉則將每樣東西的用處與失去後的後果各寫了一行。

四只行囊裝滿後，地上仍剩下一半。

「拿掉替換衣物。」青璃說。

「雨布不能少。」洛生衣按住另一疊，「淋一夜不會死人，帶著寒氣進下一場，會。」

封寒把自己的行囊往前推了半尺。「我只帶劍。」

洛生衣看了一眼他背上的劍：「劍不用喝水，你要。」

封寒便不說了。

陸沉蹲在四只行囊前，目光從左至右掠過。若按人分，本尊帶路圖與破陣物，洛生衣帶藥，青璃帶陣具，封寒空出大半負重帶水糧；最快，也最整齊。

可他沒有伸手。

門牆上忽然探下一張臉。

顧小滿倒掛著看了半晌，問：「還沒裝完？」

「裝得完。」陸沉道，「不知道丟哪一袋。」

顧小滿翻身落地，順手抓起一只空行囊：「這還不簡單？你們裝，我偷。被我拿走哪袋就走不下去，哪袋便裝錯了。」

她說完便跑了，連給人反悔的時間都沒有。

當晚，四人背著第一次分好的行囊走入後山。路程不長，從鎮岳峰下繞過兩道斷坡，再沿枯溪返回。陸沉走在最前，封寒壓後；才過第一道坡，左側灌木只輕輕一晃，洛生衣肩上一鬆。

顧小滿已站在三丈外，抱著她的行囊笑。

「傷藥沒了。」洛生衣說。

「還有嗎？」青璃問。

三個人同時沉默。

所有藥都在那一袋裡。

若這不是試走，若洛生衣同時受傷，另外三人連替她止血的東西都拿不出來。

第一次試走到此為止。

回到院中，洛生衣拆開自己排好的藥包。續脈與救命用的藥仍由她保管，最基本的止血、護脈與清創之物卻分成四份，塞進每一只行囊的內袋。

「藥不能平均分。」她說，「有些東西落到你們手裡只會用錯。但至少我倒下時，你們不能空著手看。」

第二日，他們重新上山。

這次顧小滿拿走青璃的行囊。

路圖、破陣釘與兩段陣索一起消失。陸沉記得來路，青璃也能憑山勢辨向，可封寒問了一句：「若我們兩個不在？」

於是第二次也沒走完。

青璃將路圖重新描了三份。不是每一張都畫滿全部細節，而是各自補上持圖者最需要知道的東西：洛生衣那張標水源與可避風處，封寒那張標窄口與斷面，陸沉手裡則留下岔路、退路與幾處可以重新會合的位置。

「四張都畫一樣，不叫準備。」她把筆擱下，「叫浪費四張紙。」

陸沉看著那四張不同的圖，將原先列好的分配表揉掉了。

他能在一瞬間想到十幾種失散、伏擊與傷退的可能，卻不能替青璃知道哪一根陣釘最要緊，也不能替洛生衣判斷哪瓶藥拆開後便會失效。準備不是他一個人多想幾步，再把答案交給另外三人。

那只是把所有缺口藏進他一個人的腦子。

第三日，顧小滿又來。

這回她先繞封寒，假意去抓青璃肩帶，最後卻從陸沉背後抽走整只行囊。陸沉在她抬手前便察覺了風向，也看見她腳尖的轉折；他沒有攔。

行囊離肩後，胸前舊傷驟然一輕。

他們繼續走。

封寒接過原本壓在陸沉袋中的長繩，青璃照自己那張圖領路；洛生衣沒有取回被分出去的藥，只在陸沉氣息變沉時，讓他吞下一枚她隨身保管的護脈丹。

少了一袋，速度慢了，能用的東西也少了。

但四個人沒有停。

顧小滿抱著偷來的行囊跟了半程，臉上的笑漸漸淡下去。到了枯溪，她把行囊丟還給陸沉。

「不好玩。」她說，「現在偷哪一袋，你們都死不了。」

「那便對了。」陸沉接住行囊。

第四日清晨，東側山門尚籠在薄霧裡。

沈山河核過四人的名牌，視線落在他們背後。四只行囊鼓得並不相同，繫法也各異；每一只裡面都有別人需要的東西，也都留著失去另外三只後仍能撐過一段路的最低限度。

封寒背了最重的繩與水。青璃護著路圖和分散後仍能起效的陣具。洛生衣掌著不能錯用的藥，卻不再是全隊唯一有藥的人。

陸沉那只反而最輕。

不是因為他有三具身體，而是三處舊傷還沒有好。這一點，另外三人沒有讓他拿來討價還價。

山門外，接引盟試隊伍的雲舟已垂下木梯。

陸沉回頭看了一眼太玄宗。顧小滿坐在門牆上朝他們揮手，像是還在挑哪一只行囊最好偷。

他轉回身，踏上木梯。

準備從來不嫌多。

可真正能帶走的，不是把所有東西都塞進自己手裡，而是即使其中一隻手忽然空了，剩下的人仍知道該怎麼往前。
