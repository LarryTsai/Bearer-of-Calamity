# 第040章 荒已廢

陸沉與洛生衣那段沒有任務的路，只走了兩日。背脊那道裂開的界痕才剛結痂，右膝舊界痕仍隱隱發熱，洛生衣每夜替他換藥。

第三日清晨，上界各城同時換下戰榜。

榜首沒有寫勝負，只寫荒遭殘仙出手、身中折仙咒，修為與道基持續衰敗。消息經三座書院、兩處帝關舊驛與石族公開印記交叉確認；最後一行是：去向不明。

市集裡有人說他已死。

也有人說，一個連真仙手段都撐不住的人，過去戰功應重新計算。原本依他名聲聚起的商隊當日便撤了旗，幾家曾受他庇護的勢力開始刪除往來記錄。

陸沉把公報讀了兩遍。

第一遍看到「折仙咒」時，他右手已扣住桌沿，淬骨黑紋沿腕部浮起。九道雷意在命圖裡同時轉向北方，連天譴都亮了一瞬。

第二遍，他把「出手者」「見證者」「消息來源」分成三欄。怒意沒有消失，只是不能替證據完成它尚未完成的路。

洛生衣問：「要查嗎？」

「查消息真假。」

「人呢？」

「不查。」

他們確認殘仙出手與咒傷屬實，也確認沒有公開求援。荒若刻意抹去行蹤，陸沉以九星域、舊戰友或天譴追索，都可能把敵人一併引過去。

曾在帝關與荒爭過功名的人也送來證詞，承認自己只看見咒發後的衰敗，沒有看見死亡。陸沉把這份不友善、卻可核實的證詞排在最前面；來源不喜歡荒，不使看見的事自動失效。

他能準備藥，不能替對方決定被找到。

洛生衣仍配了三種只針對道基崩裂的穩定藥，封進無名藥箱，交由不追蹤去向的公共驛站保管。箱上沒有命線，也沒有「只有荒可取」的印記；任何同類重傷者都能申領。

驛站問若藥被別人領完怎麼辦。洛生衣說照先到先用，不為一個可能永遠不出現的人扣住三份活藥。

陸沉則把殘仙名字記進公開責任頁。

不是判決。

更不是立即落雷的名單。

當日晚間，他們照原路繼續向南。身後議論仍在擴散，陸沉沒有分出雷身去追一個不願公開位置的人。

荒曾替很多人殺出路。

不代表他失去力量後，朋友便有權闖進他選的沉默。
