# 第四章 一頓飯，兩本一樣的書

食鋪沒有包廂。

文奕選了最靠牆的一張桌，先把三片錯標禁材收進證封匣，匣口壓上水橋事故簿的副印。店家端來兩碗麵時，他仍在逐片記材料表面與實際導力相反的方向。無門牌病戶的地址也夾在簿裡；今夜若停水，送水的人得先去那裡。

陸沉沒有催。

他先吃了半碗，發現文奕把每一根青菜都撥到同一側，與當年排白石沒有多少差別。

「你看了三次。」文奕沒有抬頭。

「確認是不是禁都規矩。」

文奕終於看向自己的碗，筷子停了一下。他故意夾起最歪的一根青菜，放到另一側。

「現在不是了。」

三年多以前，他會先惱得把石頭按正。如今仍會惱，只是不一定照著那股本能做。

證封寫完，兩人才把各自的《古神禁典》喚到內景最外層。

書不能完整取出。桌面上也沒有同時多出兩部能供旁人抄錄的仙王典籍；只有兩道薄得近乎透明的灰光，分別停在兩人掌心上方，顯出此刻各自已能讀開的最前層。

文奕先翻到「回力不歸原處」一節。

陸沉掌上的灰光也在同一位置翻開。字句、先後、缺損和仙王故意沒有補完的末筆完全相同。

文奕伸手去碰陸沉那一道書影。指尖穿過灰光，自己的掌心立刻浮出一道極細的反噬紋；陸沉同樣碰不到文奕的書。兩道傳承都只認各自神魂，沒有因文奕回到文家便多出家族註本，也沒有因陸沉持有實體第一頁便多一段內容。

「第一頁還在？」文奕問。

陸沉取出那張只負責喚醒與定位仙王的舊頁。文奕把百斷山帶回的陌生古印放在另一側。兩件信標靠近灰光，書影都沒有變厚，也沒有哪一部先亮。

「沒有正副。」文奕說。

「本來就沒有。」

確認完最簡單的事，真正不同的部分才露出來。

同一段「回力不歸原處」，文奕在旁邊留下十二條細註：供力來處、接續層、停禁後的殘力、維護者可否安全復禁。陸沉的內景註記只有四條，其中兩條是傷勢，另一條寫著若原主人已死，回力仍找他，便會把後來接近的人一併算錯。

文奕看了很久：「你把使用者也當成禁的一部分。」

「水橋今日差點把側門沒牌的人漏掉。」

「那是公共禁的責任層。」

「下界沒有這個名字。人還是在裡面。」

兩人沒有爭哪一種註記更高。文奕的十二條能讓陌生維護者接手；陸沉那一句則會先問原本目標是否仍存在。

文奕從證封匣旁取出兩塊同樣大小的薄木，要陸沉各刻一道最基礎的止流短紋。

陸沉沒有臨桌新刻。他先在食鋪外買了兩塊可抹的沙板，預畫兩種出口，再把其中一種移到薄木上。完成的短紋很醜，左側材料稍有變化便會失效；可失效以前，它會先把力量導向桌外，不會把同桌的人封在裡面。

文奕的短紋一筆未錯，止流、退力與復禁全在同一個小環裡。店家端湯經過時，桌腳被碰了一下，木片偏了半寸，紋路仍穩定運行。

「你這個能交給別人。」陸沉說。

「你的能在材料錯時先停。」

文奕把兩塊木片互換位置，各自原樣擱著。

店外水橋方向傳來一次停禁鈴。

文奕立刻收起書影。事故簿副印同時發燙，浮出另外兩座水橋的坊號——同批錯材也查到了那裡；其中一處尚未破裂，維護者卻無法直接全換，因為下層住戶的飲水、藥爐與夜間照明都依賴那條線。文奕先把側門病戶送水時刻報回值守簿，才將禁材的斜齒殘痕轉給陸沉看。

陸沉也收起第一頁：「材料從哪裡來？」

「表帳寫北六坊。」

「實際呢？」

文奕將三片錯材排在桌上。每片表面都有北六坊的雙環印，導力深處卻殘留一道被刮去的斜齒紋。那種紋不屬於正式材料坊，更像貨物多次轉手後留下的地下驗記。

「禁市。」陸沉說。

「可能。」文奕沒有把推測說成答案，「先查表帳，再查回收的那一批。」

兩人離開食鋪時，店家叫住他們，把桌上兩塊止流木片推回來：「自己的東西帶走。客桌不替禁師保存試紋。」店家又敲了一下窗外的停禁告示：「明早若還停水，麵也煮不成。你們查帳歸查帳，先把什麼時候能用水寫清楚。」

文奕付了被反噬紋燙黑的桌角修補費，答應把下一次停水的時段交給店家張貼。陸沉則把自己那塊短紋擦掉。

走到街口，文奕才問：「下界後來怎樣？」

這不是能用一句話回答的問題。

陸沉只先說離開太玄閣時，它已撐不了多久，七神下界前已有許多人死去；也說文奕焚錨時不可能知道後來會發生什麼。

文奕握著崩角白石，沒有用「若我留下」替死人重新安排結局。

「我回去以後，祖禁缺了一角。」他說，「這些年都在補替代節點。」

「補好了？」

「能運行。」

不是同一件事。

陸沉聽得出來，沒有說抱歉。

前方第三次響起停禁鈴。沿街路面嵌著的青線從鈴柱那頭起，由前往後一段一段轉成灰白，一直灰到兩人腳前。

兩人同時加快腳步，卻沒有走向同一條路。文奕去北六坊調正式表帳，陸沉則沿那道被刮去的斜齒紋，去找禁都地圖上沒有標出的下層入口。
