卷四至九是閱讀版卷號。`novel/volume02_v2/`、`volume03a_v2/`、`volume03_v2/` 仍是開發稿來源，舊 `novel/published/volume04/`～`volume09/` 是上一版，兩套目錄不可混讀。宏綱篇號維持第八至十三篇；卷七的文家遭難是第十二、十三篇間插段，卷八與卷九共同承載第十三篇。

閱讀版由 `scripts/build_upper_realm_reading_v2.py` 生成。正文修訂先回開發稿與相應大綱，再重新生成本目錄並執行 `py scripts/build_upper_realm_reading_v2.py --check`；不要只改閱讀副本。
