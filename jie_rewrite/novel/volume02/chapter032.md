# 第三十二章 翻裂

> 定位：Segment C 第二章。正常但強烈的雷汛觸發七峰古雷脈反向堆壓，五峰同時受災，宗門陷入「關陣則外雷直落山門，續開則主峰地脈數個時辰內翻裂」的兩難；陸沉在現場把先前的異兆直覺與眼前災情對上，但尚未公開雷池。
> 時間：ch031翌日午後至入夜。命圖尚未開。
> 唯一來源依據：`docs/events/EVENT_TAIXUAN_ANCIENT_THUNDER_VEIN_RECONNECTION.md` 二（七峰地脈大難全段，五項災情、關陣/繼續導入兩難）；`docs/factions/FACTION_TAIXUAN_SECT.md` 一（七峰名稱職能對應各自受災表現）。

翌日午後，天色未變，第一聲雷卻先落了下來。

入夏雷汛本就頻繁，七峰弟子多半只當是尋常光景。護宗大陣依例亮起，七峰外沿的引雷柱同時迎天而立，銀白雷光被拆成數十股細流，順著陣紋沉入地下——這套陣法運轉了不知多少年，從未出過差錯。

真正讓人抬頭的，是第二聲。

那聲音不是從天上來的。

陸沉正在鎮岳峰石場，協助搬運新鑿的山樁。腳下毫無徵兆地一沉，像是有什麼龐然之物，被死死堵在地底，狠狠撞了一次山根。

石場邊緣裂開一道黑線。

「離崖！」師兄的喝聲幾乎與裂聲同時落下。

眾弟子迅速後撤。陸沉沒有跟著退，他把手裡的山樁橫壓進裂口前方，替兩名尚未撤離的年輕弟子擋下傾倒的石架。巨力順著雙臂撞進肩骨，他退了半步，石架擦著山樁滑向一旁。

第三聲地雷響起時，整座鎮岳峰彷彿矮了一寸。

腰間雷訊令急促亮起，傳來的不是完整的話語，而是連續閃動的狀態碼——主峰火亂，萬靈焦根，問魂震魂，鎮岳裂。訊息尚未傳完，七峰訊臺已同時過載，後續全數斷成一片無意義的白光。

他抬頭看向天幕。護宗陣仍在盡職接雷，可地底的撞擊卻一次比一次沉，一次比一次近。

那一瞬，他想起那七次空白雷律，想起連著半月不肯安分的水面與雷眼。

不是誰在傳訊。

是七峰地下某條早已斷絕的舊路，在護山陣每次運轉時，借力向外撞了七次。

而今夜，它撞得比七次更重。

岳沉淵落在石場中央，一掌按地。片刻後，他抬起頭。

「古雷脈在回壓。」

峰內長老很快趕到，有人提議暫關護山陣，讓地底雷壓先散一散。話音未落，一道粗雷正中主峰上空，陣幕被壓得向下凹陷數丈。

關陣，那道雷會直接落進山門。

不關，所有被導入地下的雷，會繼續撞向那道封死萬年的斷口。

「主峰地脈還能撐多久？」岳沉淵問。

雷訊令那頭傳來天機峰的回覆，聲音被雜訊切得斷斷續續。

「照現在的雷勢，三個時辰。若雷汛再強一分，一個時辰。」

又一道訊息插進來：「萬靈峰外側靈田已燒穿兩片。」

洛生衣的聲音混在其中，一字一字被雜訊絞碎：「不是火……根在被抽乾，地下有東西，在往回拉。」

陸沉站在石場邊緣，望向宗外的方向。

那裡是雷池所在。這半月裡，水面的偏斜、子陣的自熱、雷訊令的空白律、靈植的焦根、主雷眼的轉向——五件事此刻疊進同一種震動，與腳下這一下下悶重的撞擊，節奏分毫不差。

不是敵襲，也不是雷汛本身過強。

是萬年前那道古雷脈的斷口，終於在這一次強盛雷汛裡，撐不住了。

這個判斷在他心裡成形的一瞬，他沒有說出口。宗門此刻要的不是一個尚未證實的推測，而是眼前這道還在撞的山根，還在燒的丹爐，還在震的神魂。他能確定的只有一件事——這場災劫不是他招來的，他自己一個人，也解決不了。

「先固山根。」岳沉淵已在點人，「天機、萬法各來兩人，鎮岳下去三人，護山陣維持最低接雷，其餘人撤離山根。」

眾人依令行動。陸沉抱起一根備用山樁，隨師兄們一同鑿進裂口最深處。

那不是解決之法，只是拖延。天機峰弟子把最新推演送上雷訊臺：利用裂口周圍尚存的舊靈脈，強行分出一小截側路，讓部分雷壓暫時偏離主峰核心。這道側路撐不了太久，卻能把「一個時辰」拖成將近三個時辰。

代價是側路沿線的護山石陣，幾乎全數報廢。

雷汛在入夜前總算緩了一線。地底的撞擊仍在，只是不再一聲比一聲近。眾人站在滿地碎石與焦土之間，誰都沒有真正鬆一口氣——那只是撐住了，不是解決了。

岳沉淵走到陸沉身側，擦去額角的灰。他沒有立刻說話，只是靜靜看著他。

「你方才站在裂口前，」他終於開口，聲音一如既往地不高，卻帶著陸沉極少從他身上聽見的審視，「知道石架會往哪邊倒，知道山根會往哪個方向裂。」

陸沉沒有回答。

「這件事，」岳沉淵的目光落在他臉上，「跟你私底下那個修行的地方，有沒有關係？」
