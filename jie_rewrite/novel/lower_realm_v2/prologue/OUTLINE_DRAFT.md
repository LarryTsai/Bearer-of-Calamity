# 序篇〈命落大荒〉章節架構草案

狀態：寫手1候選，供 PM／顧問／清道夫審；非正文、非正式設定。章界按不可逆的情勢變化安排，可由 chapter-editor 合併或拆分，不作章數 KPI。

## 核心問題與篇界

**主問題**：一個被族人照料、又被制度視作可犧牲之物的孩子，何時開始認為自己的命應由自己決定？

**進場**：陸沉未滿一歲，體弱而神識異常，洛清禾、陸守嶽與少數族人照料他；沉雷谷的雷潮逐年提前。**離場**：六歲血祭夜，陸沉判斷獻祭無法救谷，主動撕開封印引雷；老族長最後開出口，少數族人與孩子存活；陸沉埋葬力所能及的亡者，自稱「劫」，獨自離族，尚無完整修行法。此後的流浪、石窟斷片、守舊者追捕屬第一篇。

**現行正文處置**：`published/volume01/chapter001.md` 的埋人、反對派族老、父親 S1 口述、半枚舊令／殘雷紋／斷杖、獨自離谷都保留為血祭當夜後的收束，不提前放到開篇，也不讓老族長遺體離開祭臺。可以保留局部原文；新增當夜正面場景之後，需改掉 ch001 中為讀者補述前夜的句子，避免同一轉折講兩次。`chapter002.md` 開頭離谷數月、舊石窟斷片及覓食遭遇留作第一篇起點，序篇不搶用。

## 逐章場景卡

下列章位是工作代號；每張卡的場景須有具體行動，不靠旁白概述數年。年齡只鎖開篇未滿一歲、血祭夜六歲，其他年份暫不細定。

| 章位／情勢變化 | 場景、目標與阻力 | 選擇、代價、後續鉤子 |
| --- | --- | --- |
| P01 被留下的孩子 | 以照料者可見的具體難題開場：陸沉幼弱，雷潮提前使族中人力與藥食先投向守谷。洛清禾、陸守嶽、其他族人各有事要做，照料不是全員圍著孩子。 | 洛清禾以可見的照護或舊令處置替他爭一段平安，自己顯出衰弱，但原因只呈 S1；老族長決定把有限資源分給陸沉，引出族人對公平與「劫種」的不同看法。嬰兒期不強給陸沉成人式決策。 |
| P02 會聽見的孩子 | 時間推進至陸沉能自主行動。他想做一件谷內力所能及的小事，以證明不必總由人背著；弱身與提前聽見地底雷聲同時妨礙他。老族長教字、教辨別險兆，反對族老照料其他孩子，不是專職護他。 | 陸沉選擇先示警／帶人避開一處小險，而非逞強扛雷；救到有限之人或物，身體卻失衡，讓族人同時看見他的用處與風險。鉤子：他聽見的雷聲與祭臺對雷潮的說法對不上。具體小險須沿現有封印與雷潮機制設計，不創新雷種。 |
| P03 母親離開後 | 洛清禾離谷或已離谷的缺口進入陸沉日常：他想確認她何時回來，得到的只有去向不明與有限物件。照顧他的族人有各自家務及恐懼，不能像母親那樣無限補位。 | 陸沉在等候與照顧別的孩子／完成自己分內事間作選擇，第一次承認有事只能自己記住和準備；失去的是對大人會隨時回來的確定感。不得寫他知曉遮命、斷域、古洛氏或母親真實去處。若母親離開的確切年歲未定，此章只呈現離開造成的當下缺口，不定日期。 |
| P04 祭臺下的聲音 | 雷潮再提前，族內需要修補祭臺與安排撤離。陸沉記錄可觀察的雷聲、裂縫、祭痕與雷潮間隔縮短，想查出祭臺是否仍能護谷；祭臺危險、長輩封口，且他身體不能久留。歷代祭子的真正作用僅是作者層背景，陸沉此時不知。 | 他選保存可再核的具體異常而不當場宣稱全貌；為查證冒險，付出傷病或失去長輩信任。老族長一面保護他，一面選擇維持祭臺，使親情與職責開始相撞。鉤子只落在祭臺效果與長輩說法不符的疑問；此時最多 S1/S2，不揭世代機制、古雷道及完整歷史。 |
| P05 那一票 | 雷潮迫近，族老會須在撤人、續守、血祭間決議。守舊者以族群存續辯護；反對族老提出救孩子或撤離的實際路線與代價。陸沉要保命，依雷潮與祭痕提出「祭臺可能撐不住」的不完整危險推測，證據尚不足說服多數。 | 多數贊成，陸守嶽投決定票，親口要求陸沉入臺；反對族老開始準備救幼童，守舊者加固祭臺。陸沉的代價是失去最親近長者的庇護，並被迫在逃、被祭與自選第三路間作決定。父親在場或母親暗中出手均不可寫。 |
| P06 封印開口 | 血祭夜祭臺真正運作。陸沉以當夜祭臺與雷潮的實際反證，才有限確認「獻我也救不了谷」；族人想維持儀式、有人要帶孩子走，雷壓使撤路縮小。他仍不知歷代祭子的完整作用。 | 他在被投祭前主動撕封引雷，為讓雷離開人群承受可能致死的傷與劫痕；這是生死決定，不是取得第一雷或突然掌握成套雷法。陸守嶽先仍維持祭臺，見其無效後才以最後力量開唯一出口，死在核心。陸沉從雷海站起後依事件檔核心台詞首次自稱「劫」；洛清禾舊令護魂／界路只可作他所見的有限異常，不解說母親設計。 |
| P07 灰燼與名字 | 雷潮後，劫只能埋力所能及的幾具遺體，老族長遺體留在核心。反對族老救出的孩子仍需活下去；守舊倖存者也在，不會集體改悔。 | 保留現行 ch001 核心場：劫拒絕代勞、仍埋下逼祭者，族老另埋並給父親第一條 S1 模糊話。他對族老重申「劫，以後叫劫」，不是首次命名；帶舊令、殘雷紋、祭杖碎片獨行，不帶完整功法。代價是無族地庇護、傷未癒；鉤子接第一篇數月流浪與守舊追捕。 |
