## 入稿順序

1. 先完成八單元場景容量表及跨篇因果、原作時間、揭露邊界核對。
2. 以一篇為一批，先確定該篇進場狀態、主問題、必要場景、離場結果及與相鄰篇的因果；清道夫審查後由chapter-editor拆出逐章大綱。
3. 寫手1、寫手2依核准大綱分批落筆；每批連讀前後邊界並獨立review。某篇可先完成，不必等七篇全部設計完才開始。
4. 九個單元審定後採三卷閱讀版；上界至三千州的新版閱讀卷四至九已依 `docs/V2_VOLUME_READING_MAP.md` 建立，開發稿仍保留原施工路徑。

## 檔案規則

- 新章依核准的篇級章綱放入對應子目錄；不預建空章或以舊章占位。各篇可先用篇內章號，最後編卷時再統一對照。
- 只複用已核對仍成立的場景；既有好場景以保留為優先，不以增加章數為目標。
- 本目錄不存放已發布版本、唯一來源設定或未經裁定的新能力／新勢力。
