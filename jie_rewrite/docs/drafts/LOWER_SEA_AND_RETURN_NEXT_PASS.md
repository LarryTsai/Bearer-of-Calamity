## 保留結果，改變解法

### 018001：十三傷者與錯過巢門

保留陸沉選擇陪船返岸、錯過鯤鵬入口、十三名傷者含兩個孩子存活、船需修整。船主可在正文建立符合其身份的有限御舟手段，選實際可行的回岸線；不能默認全船修士只有舀水、扛板、牙咬繩。

陸沉只做當期短紋可承擔的局部預警或暫穩裂口，不用三輪反覆受傷證明留下的重量。代價已有錯過入口與修船停航。不可讓荒、魔女提前同船，搶改既定北海初遇與鯤鵬核心事件。

### 018002：退潮重逢

保留空匣船票、未回來的人、三人重逢與魔女承認委託紙出自自己。傷者迅速被移上岸，不延長傷者與救者互相添傷的操作。銀鰭獸由荒、魔女以既有實力乾淨處理；陸沉可指出纏網，不必每一環都不可替代。

### 018003：有限試手

開場明定石昊收力與試驗規則，例如限拳路／步法，陸沉爭取迫使換步或出圈的一次局部目標。具體規則落文時選一種說清，陸沉可真達標，也可敗後再約。

刪去「不是放水」與搬血傷者、已過鯤鵬核心機緣的荒似有對等殺招的暗示。不將有限驗路寫成全力平手。材料碎掉、輸一局已能構成結果，不再固定鼻血與胸傷發作。魔女見證多年關係，不重開入教考題。

### 018004：十七人

救助可短而有力完成。可用施工方向：魔女細光切斷纏船網筋；石昊截開近礁來浪，借落腳礁托住尚承重的船梁，將船送到近處淺灘。落文須交代船與灘的近距離、可用承重處，不能把此舉擴成控制整片北海。

十七少年全活；船在獲救前已壞、部分藥已濕，仍須改走陸路。少年自主性放在點人、分出乾藥、商量借宿與選路，不要求划槳成為強者救人不可替代的最後一步。刪新增礁傷、掌裂與陸沉再度耗傷神識的固定收尾。

保留三人各自去向、普通海螺非傳訊器、魔女不再招攬、黑錢未解。返閣交代實際剩餘傷勢與行程，不追問本次必須哪隻手又傷。

## 017～021日曆與搬段

1. **016之後先療養，再海市。** 將018001開頭自「谷中真刺客一戰後」起的返閣療養整段移到017開篇；第三日傷口仍泛灰，其後原文「五日後」灰線才退，依此先後計時。搬後刪除018重複段，不將其壓成返閣總共五日，也不在海市後再療養一次。
2. **017是療養後、出海前的短暫海岸停留。** 以主動看海族航路與海市的願望啟動，不再加救船。陸沉能出行但仍不能連戰，沒有御火、雷種或新御空能力。
3. **018001從出海接起。** 保留出海第二夜、巢門關閉與留下陪返的實際選擇；018002在核心機緣結束後重逢荒、魔女，003次日退潮試手，004救十七人後分路返閣。改寫時核實場內時間，不讓救船使鯤鵬入口重新開啟。
4. **018末只落返閣，原半年摘要交019～021共同展開。** 019相聚、日常鍛體與既定洞天突破；020同代技藝遊戲與競爭；021康復並成洞天後主動登昇龍台。三篇合用原北海返閣後約半年，不各加半年。
5. **保留突破因果與後續風暴順序。** 洞天由日常修行磨出，不由海市玩物、第一台古物或一场奇景直接授予。第一台正常登頂故事先完成，所得古物沉寂、無戰力、不替守閣解危；正式第一雷仍在既定雷淵／跨界鏈，不前移到北海。
