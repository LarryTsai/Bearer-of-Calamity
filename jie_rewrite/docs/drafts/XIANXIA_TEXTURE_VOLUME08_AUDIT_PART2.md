## 〇、總評

**核心測試句的結果**：刪掉功法名稱後，ch027、ch028（莫渡兩章）、ch032、ch039 最像修士，ch036（蒼梧）和 ch031、ch038、ch040（劫厄的尾巴）最出戲。偽裝段 ch022～024 大量凡人動作，**這是設計本身**，判斷為維持。

### 病灶（不是症狀清單）

1. **超凡訊號只剩一條通道：陸沉的神識。同伴的身體錨點在非戰鬥場景幾乎全部缺席，少數出現的又寫錯方向。**
   - 本段修士質地幾乎全靠陸沉「神識劈成兩半／沉入／貼著空氣游走」撐著（ch021、022、025、026、027、028、032 都有）。陸沉自己的觸覺判讀（掌骨、指尖雷意）只在 ch028 L49 用了一次。讀陣盤（ch029 L21）、讀殘帛書（ch033 L48）、察覺複驗（ch022 L31）都退回「看」。
   - **封寒**整整八章（ch021～024、026、032、033）沒有一個重量錨點。鐧只被晃、背、橫在膝上、扛上肩，全是道具動作（ch021 L13/23/25/137、ch031 L34、ch033 L10/38/44）。唯一一次超凡外洩（ch021 L93～97）寫成「周遭空氣彷彿**變輕**了一寸」，還加一句「那不是坍縮」。問題有三個：方向和他「往裡塌、變重」的道相反；「變輕」直接踩到203題保留給**黑洞誕生場景**的 canon 對話「是旁邊的東西開始變輕了嗎」；「坍縮」二字在 III-1 就用否定句提前出場（同 v07「鑑月沒有吼」的問題）。**這是本段最急的一條**（C1）。
   - **劫厄**三度寫「尾巴掃地／晃尾巴」（ch031 L22、ch038 L24、ch040 L30），還有「往身邊挪近半步」並由旁白解釋成「表達『我在』最常用的方式」（ch030 L31）。四處都違反 SPEC 犬類禁忌，全段也沒用過一次劫印或鱗縫雷紋（C8）。
   - **鑑月**施展負魂時寫「閉上眼」（ch034 L14），沒用額心新月印。人物檔明定「開闔時機＝能力觸發時機」。對照 ch030 L23 用對了，可見是單章疏漏（C6）。
   - **蒼梧**有骨刺錨點（ch036 L17，好），但動作退回「伏低挪動」「拍塵土」「輕輕笑」，度量與界感都沒出現（C7）。
2. **異域驗證體系被寫成資訊系統。** 「系統／辨識系統／特徵值／掃描／程序／機器」集中在 ch036～037，「通訊／訊號／信號」散在 ch025、026、028、038、039、040，「邏輯」在 ch029。性質和 v07 洩漏鏈、v03a 奪禁資安語彙相同。其中「驗證系統」「示警判讀節點」「因果場」「介面樁」是大綱或已登記的正式用語，交總控（見 D）；ch036 的電腦語彙不是大綱原詞，可以直接換。
3. **大綱驗收語與安全閥聲明滲進正文。** 最嚴重的是 ch025 L41 直接出現文件章節號「六之一那三個條件」。另有 ch021 L93 把自檢句「並非他當下真正的修為上限」原樣寫進旁白、ch025 L83「術法與大道機制層面的精準操作」、ch036 L33 整段安全閥說明。公式句型集中在 III-1～III-2：章末「他不知道……」懸念句四章連用（ch026、028、029、030）；「血、氣息、雷力殘留、禁紋、身份痕跡、驗證系統」六項清單重複五次；「低頭看著自己的手」三次；「沒有慘叫，沒有掙扎」兩次幾乎逐字相同。
4. **偽裝期的凡人化是對的，不要為改而改。** Q2-C、Q4 的戲眼就是「技術完美≠活得像」：陸沉走路太準反被看穿，封寒靠看人補盲區。這些段落加仙氣反而會毀掉主題。

## D、制度骨架現代化

原則：異域是成熟的血脈等級社會，驗證與官署本身是設定，不刪。要處理的是語彙把它寫成了資訊系統。

1. **「驗證系統」**：ch025 L97、ch026 L23/L57、ch028 L59、ch037 L22。大綱 Q5 原文清單「甚至誤導驗證」和 FORMATION_SCOPE 六之一都用「驗證系統」，屬**大綱核心用語，交總控**。總控若決定改，建議全卷統一成「驗籍之禁」或「辨命之禁」一類，不要逐章各改一套。
2. **六項清單「血、氣息、雷力殘留、禁紋、身份痕跡、驗證系統」**：大綱原句，保留結構。「身份痕跡」「驗證系統」兩項跟著第1條走。另見 B-3（重複次數）。
3. **ch036～037 古禁的電腦語彙**：辨識系統、特徵值、掃描、通用程序、機器。**不是大綱原詞**，章首只要求「理性／制度化／官僚式誤判」的基調，可以用古禁語彙寫出同樣的官僚感（成規、照例、殘印、在冊／未報備）。L27～29「只有兩種可能——正在服刑，或者，正在逃逸」這套官僚推論很好，保留。「掃描」一詞與安全閥字面綁定，交總控。
4. **示警判讀節點、連續性判讀（複驗）**：已登記（第248題）或列在章末待確認提案。保留，不動。
5. **觀星司**（ch027 L19、L33）：「考評平平」「入司不過六年」「官府定論……案子當日便結了」，官署感合理，保留。機構名首次入正文仍是待確認提案（ch027 自檢），交總控。
6. **驗籍檔房、抄錄吏、隨從簿冊、城主府**：符合異域官署，保留。
