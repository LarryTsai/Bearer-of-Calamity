## 〇、總評

**核心測試句**（刪掉功法名稱後，這些人還像修士嗎）：ch073～080的敵方（黑釘、骨符、骨粉、骨籤、替命索）和伴星分工最強，是全卷很好的「規則文明」質地。ch061雖然被刻意剝光，仍然成立。ch063～066掉進內心辯證獨白，刪掉雷名以後只剩「一個人在想道理」。ch068～072休養段的伴星動作幾乎全是泛用的人類姿勢。

### 病灶（不是症狀清單）

1. **大綱驗收語和一致性自檢的語言滲進正文（本段最大宗）。** ch078～080最嚴重，連自檢專用詞都直接出現在正文：ch078 L83「他沒有倒寫成一切仍在計畫」（「倒寫」是自檢詞），另有ch078 L45「命圖沒有替他直接解題」、ch080 L89「陸沉沒有因此變成天生肉身無敵的人」、L93「不是免費解封，而是……窄口」、L105「這不是八雷合一，也沒有新的星位亮起」、L167「這不是審判，也不是古禁忽然站在陸沉這邊」。ch063～066是同一個病灶的另一種形態：每重塑一雷，就由旁白把「這道雷教會他什麼」說完（ch063 L43、L45～47、L55；ch064 L13、L17；ch065 L16、L22、L36～38）。安全閥本身都對，但應該讓行為自己證明，不該由旁白宣告。ch080 L73～77的肉身戰演出極好，後面卻連續三段解釋句替它打補丁，反而把力道稀釋掉了。
2. **伴星形態沒有交代，錨點無處可落，於是退回泛用人類姿勢。** ch068～072劫厄有「手臂」「手背龍鱗」，是人形；蒼梧卻在包紮、坐下、拍塵土時照樣露出「肩胛骨刺」（ch065 L28、ch067 L35、ch068 L14、ch070 L10～12、ch072 L14）。SPEC第四節規定蒼梧人形不外顯骨刺。ch074起蒼梧又有「前足／後足」。因為形態不明，寫手只能用「拍了拍身上的塵土」（ch070 L42蒼梧、ch072 L12劫厄）、「抬頭看了他一眼」（ch072 L14）、「湊了過來，把肩膀壓低」（ch069 L12，劫厄有犬類風險）、「雙手撐地」（ch063 L67）。**先窄查形態，再改動作。**代詞也跟著亂：鑑月被寫成「它」（ch064 L11／13／17、ch080 L151），劫厄也寫成「它」（ch063 L69／71）。
3. **敵方質感兩極。** ch073～080的異域追兵個個有手藝（先收刀封息、以骨刀敲地、把傳訊刻回臂骨、在傷口裡撒新粉），是正面範本。ch066～067的帝族監劫使和甲士卻是凡人官僚：兩次「眉頭越皺越緊」（ch066 L33、L57）、「走下高台，身後跟著十幾名甲士」「從容地圍了過來」（ch067 L17～19）。他們是8→0→8的對手方，讀起來卻像衙門。
4. **斷界古禁的規則語言偏會計和權限系統。** 結算、帳、付帳、權限、血脈權限、禁臺權限、觸發、供能者、既有體系、介入。大綱原詞本身就是「守禁權限」「未結法勢」，這組詞整體**交總控**，不逐字換（見B-1、D）。
5. **數字母題重複。** 「十二息」出現在ch073 L55、ch077 L109、ch079 L39、L67，「十三步」在ch076 L29、L33，「十三息」在ch078 L81，「十二次」在ch080 L85。一再出現會讀成作者的習慣，而不是戰場上實際量到的數。

### 正面參照（改寫時保留，可當範本）

- **ch061 L47**「靠一身皮膚一起繃緊的那種最原始的警覺」：沒有雷、沒有神識時，身體本身就是感官。
- **ch064 L21**蒼梧「一掌按上禁紋根部……順著掌心的力道緩緩翻開」：精準落在SPEC的「立界一掌按地」錨點。
- **ch065 L28**三伴星承熱各付代價，寫法互不相同：蒼梧骨刺一顫、鑑月的域焦黑一圈、劫厄喉頭一鼓且眼睛泛紅。
- **ch067 L25～31**四伴星出手，一撞、一嘯、一掌界痕、一隻赤手握槍，四種道寫出四種做法；L43「輕得像是按熄一盞快燒完的燈」。
- **ch068 L14／16／18**蒼梧的身體比話先反應去擋風口、赤翎用涼手托住劫厄、鑑月「一遍遍，無聲地數」（正是「一個個看過每個人」的錨點）。
- **ch070 L28～30**鑑月新月印睜開，說完「還在」就收手，「像是查驗一件她一直記得住名字的東西」（喚名定魄的日常版）。
- **ch072 L18**赤翎「那點還沒穩的火在她眼底輕輕晃了一下」；L28「腳下的地氣越發沉」。
- **ch073 L45～51**黑釘分記時刻、方向、雷性；骨符把被截的訊息刻回臂骨。
- **ch074 L9**黑水城「黑河每逢倒流便露出一層街道……只轉運界路、戰俘與尚未結算的法勢」：路過式奇觀的現成範本。L73追兵「先收刀、封息，再沿陸沉留下的血走入」。
- **ch075 L71～73**名字刻左翼、路刻右翼：代價轉化成習慣。
- **ch076 L9**烏迭「以骨刀敲了一下地面」。
- **ch077 L49**「鑑月在命圖內敲了第一下停手警示」：回聲ch062的三下敲擊，是很好的跨章錨點。
- **ch078 L13～17**「右眼突然刺痛。那是示警。不是地圖。」；L67蒼梧「以完好後足敲地，分辨封路矛升起前的空腔聲」（傷後改用另一種界感，不重複ch074的踏界）。
- **ch080 L21**荒「肩背抵住收窄的門緣，把第一批人從自己身側一個一個送過去」：肉身先動，荒不被寫小。
- **ch080 L73～75**「他沒有向外探知，只看矛肩下沉的半寸；骨先承住矛桿，筋在接觸前改掉肩線」「對方的身體卻被自己的力線鎖成一座禁」：全段最好的肉身加禁理質感。
