# 下界生活第二批完成紀錄

007〈雨谷不收藥〉、008〈水源下的舊禁〉各四章。2026-09-25 原提交後依作者「欲望、奇觀與修士第一直覺」指示重構，現行正文取代採購／修水主導版本。

007主事件是陸沉想親採翻潮葉，追地氣換根的藥潮並成功；孟禾托起當輪氣葉，江嬸沿自己的採行路完成收成。主藥不合原方只在後段收束，十二片藤皮另購。008承翌日好奇問源，觀看伏泉院例行換流；三支逆泉與銅環映出根氣路，陸猜中支路得果，互看手藝後期待明年再來。小漏屬院徒日常維修，陸不接治水任務。

第二年春、距005／006返閣約一月不變。陸無雷種、御火或留水新術；只有一片試石、刻刀、冊子，新增普通翻潮葉書籤與谷路圖。書籤無能力增益；十二片藤皮在孟禾筐。孟禾洞天托氣葉、崔沅化靈借既有陣接局部泉路，各依自身境界行動。

當前重構覆核與生成結果合併記於[生活第三批](LOWER_LIFE_PHASE3_COMPLETION.md)，不以原稿的審查冒稱新版已驗收。上界第二台仍見[長息插入窗](UPPER_DRAGON_TERRACE_INSERTION_WINDOW.md)，未寫成正文。
