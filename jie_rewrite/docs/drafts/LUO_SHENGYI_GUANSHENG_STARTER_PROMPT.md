# 洛生衣「觀生」專屬起手式：最小化寫作提示（供 volume13+ 參照）

狀態：草案，2026-09-24 寫手1產出，供PM核對後決定是否併入 `characters/CHARACTER_LUO_SHENGYI.md` 第48行（該行為較長的舊版）。不新增設定，僅為寫作提示。

## 一句話版

她伸手碰人、看傷、看人的那一刻，先給一個「她自己的感官」，再說話或下結論；這個感官每次換一種，不要每次都是「指尖停一瞬＋生念讀數」。

## 使用規則

1. **先感官、後結論**：凡她把脈、換藥、檢查、旁觀他人狀態，落筆前先給一句觀察（厚薄、起伏、冷熱、穩滯、縮或鬆），再接對話。
2. **情感越重，越不能省**：她自己重傷、生離死別、重大抉擇的場景，最容易被寫成純對話，正是最該用的地方。
3. **每場戲只用一次**，放在動作前一句，不在同場戲結尾再回頭「看一眼生念」做總結。
4. **輪換切入點**（近五處已驗證不雷同）：
   - 身體感：指腹冷熱、脈的頓挫
   - 對象狀態：縮／鬆、厚、穩（各章輪換，別連用同一個字）
   - 外在觀察：呼吸、針尾顫動、針袋未動（她昏迷或陸沉視角時，不用觀生讀數）
   - 純動作：手停在襟口不往下（把觀生寫成關係，不給讀數）
5. **觀生有盲區**：青意看不出的（如記憶流失），她改用日常提問補上，這是她醫者身分的辨識度，不是缺陷。

## 禁忌

- 不要「指尖停了一瞬——生念……」公式；不要「卻沒有更X／不像上次那麼X」的否定對比連用。
- 不用「這是第一次／這半年來」這類替讀者翻譯的總結句。
- 不越安全閥：只限近距離接觸或視線內，不隔空、不精確定位、不讀殺意/記憶、**不下污染或無害的結論**（那是陸沉照命與陣師/儀器的差事）。
- 她昏迷時不寫成她在用觀生；感知由外在細節或明確的他人視角承擔。
- 「還在」「一直都在」要指明所指（例：這道裂），避免與陸沉〈還在〉三下自我錨定混淆。
- 不預告原因（如「像被什麼抽走」），觀生只能說當下所見。
