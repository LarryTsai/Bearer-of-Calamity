# 下界生活第七批：第一次昇龍台

本批021六章、首次古物及七處實體保管接縫。下界24篇均有正文，仍非全書完稿；上界第二台、必要長線與正式抵仙界待完成，統一精修後置。

## 六章的故事

1. 〈雲上真有一條路〉：陸將贏來青碗帶回家，說明往返行程，主動到斜雲渡爭首登。燕照想贏、桑越想走完去年未竟末段、羅衡自試，四人不是闖關固定隊。
2. 〈這一步踩向風〉：洞天場浮石隨地氣換托，陸近讀與肉身換重配合，交口主動搶路真成；桑越翼行有省路和调位作用，不被禁飛壓低。
3. 〈先過去的人〉：中臺先布兩片短紋，燕兩掌爭位，陸已有站實重心、一片緩收腳並連帶自己腳踝，用肩臂換重推離白線，先踏接石；燕下一輪追趕。
4. 〈最後半階〉：古陣托升石，登者自己接導氣座。燕短陡追回半階，陸長路以持續供氣、換重收勢首先登頂；桑越、羅衡各自完成。
5. 〈石座裡的窄片〉：先領普通薄石、穩紋細砂，觀老修士承石拆拱的公開演法；其後查退役石座局部舊扣，經台方验取留拓，才得唯一黑褐窄硬片，未知用途。
6. 〈匣裡另留一格〉：護臺歸還未用片、取回驛舍行囊；四人吃飯、分享各自結果，歇兩日後分路，六日返閣。古物布裹內袋帶回，入木匣隔格，與海螺／乾木分開。
