## 第一章 太玄閣

**一句話場景**：陸沉力竭倒在閣門，閣老開門、辨令、替他清膿包紮後便離開，陸沉自己處理其餘傷，縮在牆角。

**已有的修士世界痕跡**
- L3「門是從裡面打開的，沒有聲響地打開，像是早就沒上閂」（門似有感應，僅是隱約）。
- L5、L7 閣老看令牌的「形制、磨舊的傳承印與外層的包法」，沒因臉喊故人（辨令靠制式與傳承印，有門派制度感）。
- L5「小腿那圈裹著雷紋殘布」（物件層有雷）。

**缺口**
1. 醫療：L7「手背貼上額頭，又翻過來貼在手腕內側，像是在數什麼」。這是凡人把脈加試溫。活了很多年的修士醫者（哪怕是殘脈）會用神識或一縷靈氣掃過經脈與傷勢，看有無雷毒、灼傷、經脈損。全篇沒有任何修士診斷手段。
2. 治療：L9～L11 清水、酒、布、拇指擠膿，全是村醫手法，沒有丹藥、藥散、靈力、符，也沒說為什麼不用（L13 起連酒罈都只是放在盆邊）。
3. 山門制度：L5～L7、L21 閣老沒問名、沒問來意、沒登記、沒考察是否有根骨，連「令牌是半枚」都只淡淡看，之後「沒人問他要住幾天」。太玄閣作為修士山門，對一個攜舊令的陌生人零入門程序，太像荒屋收留流浪兒。
4. 傷勢反應：陸沉手上帶雷紋殘布與雷傷（L5），閣老完全沒針對「雷」做任何處置或反應（設計上閣老須「見令或傷痕可沉默反應」，這一點是被保護的）。

**合法理由判定**
- 缺口1、2：**無**（頁面沒給理由）。但可對接「資源不足／殘脈」（下界殘脈藥資源匱乏）與「角色刻意選擇」（閣老不暴露）。是「不合理的凡人化」，理由需補一筆。
- 缺口3：**設計保護**（OUTLINE：閣老認令制與傳承印、不由洛清禾私人命印授身分）；但只保護「不喊故人」，沒保護「零程序」。屬半保護，可補一行殘脈制度感即可。
- 缺口4：**設計保護**。

**最小補法方向**：診脈那一下改成「指腹停在腕上，像在聽什麼比脈更深的東西」一類，留白不明說；並在治傷處補閣老自己一句能讓讀者看出「殘脈藥資源有限、所以只用酒和布」的理由（如空藥架）。

## 第二章 牆外之路

**一句話場景**：陸沉養傷數日，發現閣老在牆與石階前必定止步；風吹走一塊布，陸沉跨牆取回，答「路」。

**已有的修士世界痕跡**
- L9、L13 閣老在矮牆、西側石階「像是踩到了什麼看不見的坎」，每次停的位置都不一樣（這是全篇最強的修士世界痕跡：看不見的界限）。
- L25「青磚上沒有線，牆根也沒有陣紋」（陸沉知道要找陣紋，且刻意寫無痕，暗示禁制高明或已殘）。
- L7「暗褐色的葉片」曬藥草（有藥材文明的邊）。

**缺口**
1. 取物：L19～L21 布掛在三步外，閣老拿竹竿夠，「竹竿不夠長，試了兩次」。閣老是修士，三步外的布用靈力一攝或神識一牽即可。凡人尺度。
2. 生活：L5 糙米粥、L3、L7 劈柴汲水，全是山村老人生計；沒有辟穀、靈米、靈泉、任何「修士餵養自己」的樣子。
3. 感知：L37「牆外有什麼？」閣老不知道牆外是什麼，看不見、聽不見、也沒有神識。修士被限制在界內，通常仍能神識外探；他連牆外一條路都要問一個孩子。
4. 山下交通與聯繫：L13「通向山下的石階」，全章沒有任何來人、傳訊、送物、巡山，山下是空的。太玄閣多年無人往來的原因沒有給一句。
5. 傷勢：L3 高燒兩夜後三日退燒、結痂，純凡人恢復曲線，沒有修士體質或雷傷特殊處。

**合法理由判定**
- 缺口1：**部分有**。閣老可能被同一界限束縛，靈力受封，屬場域限制；但頁面沒說「靈力也受限」，只說「腳停」。歸類為「理由存在但未顯」。
- 缺口2、5：**無**，屬凡人化，但也是第二篇「人體尺度生活章」的設計基調，風險較低。
- 缺口3：**設計保護**（閣老須是被定義的殘脈，不揭身分；L37 這一問是全篇情感點，不宜改）。
- 缺口4：**無**，但可留白（第二篇本來就在隔絕）。屬「殘脈尺度」邊緣。

**最小補法方向**：竹竿那段加一個閣老手指微動、什麼也沒發生的動作，讓讀者看出「連牽一塊布的力氣也被界限吃掉」；不改止步與「路」的情感點。

## 第三章 斧下修行

**一句話場景**：陸沉請閣老教劈柴，閣老只示範一次，陸沉硬做完，虎口二次撕裂，右手觸覺再度變鈍。

**已有的修士世界痕跡**
- L27 閣老仍在矮牆前止步（重複回收）。
- L37～L39 右手觸覺「又像隔了層什麼」（有隱約的異常感，但作者刻意寫成傷後遺症，不是雷或修士現象）。

**缺口**
1. 修行本身：章名「斧下修行」，但 L11～L13 的示範是村夫劈柴；沒有任何氣息、發力、身形的修士門道，一斧「乾淨俐落」是凡人熟手，不是修士。
2. 醫療：L33～L35 又是酒＋布，與第一章 L9～L11 完全同構，藥草在廊下曬著，卻沒人用來敷。
3. 山門日常：L3、L5、L33 只有一個老人、一個少年、一堆柴，沒有陣、沒有燈火、沒有守夜。全章看不出這是仙山。

**合法理由判定**
- 缺口1：**設計保護**（OUTLINE B03：手傷、握柄與力氣互相衝突，第二次撕裂是設計錨；閣老仍只留治傷工具）。
- 缺口2：**設計保護**（閣老刻意讓陸沉自己承擔）；但「為什麼不用藥草」沒有理由，讀者會覺得作者忘了。屬「輕度不合理」。
- 缺口3：**設計保護**（反奇觀章）。

**最小補法方向**：一句「藥草是曬給別處用的，不能碰」之類的閣老禁令或陸沉的自問，把不用藥的理由顯出來；劈柴本身不動。

## 第四章 站著聽雷

**一句話場景**：陸沉夜怕雷、身體先躲；閣老用兩碗水與《萬體鑄身經殘篇》薄紙教他分辨「自己的身體先動還是雷先來」，第一個成果是少一次跌回牆角。

**已有的修士世界痕跡**
- L27「萬體鑄身經殘篇」薄紙補過多次的線，字句短得像提醒（修士傳承殘件，質感好）。
- L17、L25 對地底雷響的感知、水碗波紋作為量尺（雷感被落成可測的凡人道具）。
- L31 閣老「傷先養。你再拿它去撞木頭，紙也救不了」（殘篇有邊界、不即學即強）。
- L53「這不能替他決定往後修什麼」（修行是選道，不是唯一路）。

**缺口**
1. 入門評估：L9～L27 閣老教站姿前，沒有任何測根骨、看體質、看雷感的動作。修士傳功前通常會先探資質。「先站」直接進入教學。
2. 語彙：全章沒有「氣、息、經脈、丹田、靈」任何一個修行語彙（僅「呼吸」「脊背承住呼吸」），教學讀起來像站樁、太極，去掉「萬體鑄身經」六字後接近武館。
3. 取物：L27「從袖中取出一頁薄紙」，沒有儲物；對殘脈可能合理，但與全篇無任何法器互文。
4. 環境：L3、L17 有雷但屋頂「並沒有震」，沒有避雷、聚雷、引雷的閣內陣（太玄閣按設定與雷、命圖有關，卻對雷全無制度性反應）。

**合法理由判定**
- 缺口1：**設計保護**（OUTLINE：不替陸沉選道；只教有限站姿）。半有理由：可以是閣老「不測，因為不打算收他為徒」。
- 缺口2：**設計保護**＋**留白**（殘篇未完整，第四篇才進階；不能憑空發明修行語彙）。
- 缺口3：**資源不足**，合法，殘脈尺度。
- 缺口4：**無**，但涉及太玄閣基礎設定，屬待確認，不宜自補。

**最小補法方向**：教學前補一句閣老看他一眼即知「你身上先動的是驚，不是雷」（不明說神識），讓「不測資質」變成閣老已看過的隱性；語彙不動，留給第四篇。

## 第五章 殘缺雷法

**一句話場景**：陸沉曬書時翻到殘雷法冊與斷劍卷，觸雷冊被嗡鳴擊退；閣老答「他們比你先感應到雷」；夜裡再看斷片，後又下山撿枯枝並記下廢殿方位。

**已有的修士世界痕跡**
- L13「太玄閣這麼多年，這樣的東西還有好些堆，都沒人收拾」（殘脈衰敗，是好的世界層訊息）。
- L17～L19 雷法冊字跡由工整到顫抖、末頁空白（前人代價，凡人書寫，但功用是修士的）。
- L21 斷劍片夾在劍修卷中。
- L23～L27 觸冊即發生嗡鳴與白光（殘留雷意，物件仍有靈性，最強的一筆）。
- L37「他們比你先感應到雷」。
- L45 無名斷片的短紋、以左右手辨紋。
- L47 遠處「坍掉半邊的舊石殿」。

**缺口**
1. 典籍保管：L13～L15 竹簡、卷軸、線裝散落成山，受潮發霉、蟲蛀、要曬。修士文明的典籍會用玉簡、陣或儲物保存，兩萬年的傳承不會被蟲蛀。這是最典型的凡人化，凡人古代藏書樓尺度。
2. 記載媒介：L17 雷法冊是墨字、紙頁（沒有神識烙印、沒有玉簡）。可解釋為下界殘脈。
3. 找路：L47「記下三棵歪樹的位置；若往後要去看，至少不必在天黑後從那裡找路」。憑地標記路、天黑找路，屬 Charter 列的凡人症狀。陸沉境界不夠、沒有神識，是「境界不夠」，合法；但作者可以讓他用雷感或斷片方向做定位。
4. 守閣、山界：L47 閣老讓病弱少年獨自下階撿枯枝，經過坍塌舊石殿，全無警示、巡界、山上其他修士或野獸。太玄閣的邊界與外部關係一字未提。
5. 燈光：L45「夜裡他重新拿出斷片放桌上」，光源不寫（凡人是油燈；修士世界可能是靈石或夜明）。全篇夜景均無照明描寫（ch1 L5 只有「門內透出的一點光」）。
6. 閣老隨口曬書、修桶：L29～L39 閣老修水桶、纏竹篾，全是村夫工序。

**合法理由判定**
- 缺口1：**無**。這是本篇最不易被合理化的凡人化，除非補「玉簡早被搬空／殘脈買不起護簡陣，只剩這些爛紙」的一句。屬「不合理的凡人化」。
- 缺口2：**資源不足**（下界殘脈），合法，可保留。
- 缺口3：**境界不夠**，合法，設計保護。
- 缺口4：**設計保護**（第三篇入口需要廢殿與斷片；本篇只記方位）；但閣老讓他獨自下山的理由沒有給，屬輕度缺口。
- 缺口5：**無**，純漏寫，成本最低。
- 缺口6：**設計保護**（閣老刻意保持人體尺度、日常）。

**最小補法方向**：曬書處加一句「玉簡類早不知去向，只剩不值錢的紙、竹、木」，把凡人化轉成衰敗證據；夜裡光源補一個小物（殘燈或微光的石）。

## 本篇整體判斷

**1. 世界層修仙痕跡的密度：低，且集中在「物件」而非「制度／社會／生活」。**
- 有的：止步界（ch2 L9、L13、L25）、傳承印／令制（ch1 L5、L7）、萬體鑄身經殘篇（ch4 L27）、雷法冊觸發嗡鳴（ch5 L23）、斷劍與斷片、衰敗傳承感（ch5 L13）、閣老一句「他們比你先感應到雷」（ch5 L37）。
- 沒有的：山下凡人／村落／集市／官府（全篇零出場）、傳訊、來往人員、巡山守夜、山門登記、任何靈藥丹藥、神識感知、儲物、法器照明、辟穀。閣老的日常全是凡人農戶（劈柴、汲水、曬藥、煮粥、修桶）。
- 去掉「太玄閣、雷、萬體鑄身經」等名詞後，本篇仍然像一位老人收留一個流浪少年的山居小說。Texture Guide 的核心測試句在本篇多處不通過。

**2. 大部分缺口有設計保護，不建議「補成奇觀」。** 本篇是反奇觀的人體尺度生活章（閣老不越界、只示範一次、不替他選道、右手觸覺後遺症），治傷用酒布、劈柴、站樁等凡人尺度屬設計。**真正不合理的凡人化只有：**
- 診脈與治傷全是凡人手法而頁面沒給資源理由（ch1 L7～L11、ch3 L33～L35）。
- 典籍以竹紙保存、受潮蟲蛀（ch5 L13～L15）——最突兀，兩萬年傳承不會如此。
- 閣老取物用竹竿、不知牆外有什麼（ch2 L21、L37）——需確認「靈力也被界限吞掉」是否為設計。

**3. 最缺的三類**
1. **衰敗理由類**：殘脈為何只有酒、布、紙、竹（資源／護簡陣／藥資源）。多數缺口只需一句「殘」的證據就可從凡人化轉為「衰敗的修士文明」，成本最低、收益最高。
2. **修士診斷與感知類**：診脈、探根骨、感知陸沉的雷、對來客有無感應（ch1 L3～L7、ch4 L9）。要寫成「不明說的一眼」，不可解釋。
3. **山門周邊社會類**：山下、訪客、傳訊、巡界、光源、守夜（ch2 L13、ch5 L45、L47）。目前全空；但第二篇本身是孤立場，可能不應補太多，建議只做一至兩筆。

**4. 建議處理者**
- **jie-writer（模式二）**：做「衰敗證據」與「一眼診斷」的一行補句，屬最小改，並須過 jie-author-intent-guard 確認不破壞反奇觀與閣老保護。
- **jie-creative／腦力激盪（標準流程 C）**：太玄閣殘脈的資源制度、典籍保存法、山下與山門關係、閣老為何連牽物都不能，屬第三層「仙人文明」，且涉及新設定，須使用者討論，不自動補。
- **jie-power-system＋作者裁決**：「閣老在界內是否仍有靈力／神識」（ch2 L21、L37）與「太玄閣對雷的制度性反應」（ch4 L3～L17）先裁定，再談補寫。
- **jie-canon**：不需要，本篇無原作侵入問題。
