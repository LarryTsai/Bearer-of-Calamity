# 仙俠質感審查：novel/volume02_v2（chapter021～040，20章）

狀態：2026-09-24審查完成，只讀不改。依據 `docs/XIANXIA_TEXTURE_GUIDE.md`、`docs/drafts/XIANXIA_TEXTURE_ROLLOUT_SPEC.md`。

## 〇、總評

- 本段落（丹閣雜工→煉丹試驗→私設子母陣→雷池雷汛全宗救援→七峰大比初賽）與volume05的問題型態明顯不同：volume05的缺口是「大量日常動作沒被超凡改寫」，本段落的核心敘事機制本身（三身分神/雷核共痛/離體時限/回歸反噬）已經是**結構性的超凡設定**，即使拿掉「雷息」「煌命」等專有名詞，「一人分處三地、彼此感官不互通、回歸時舊傷疊加」這件事本身仍然不像現代小說能寫出的東西。因此本段落**核心測試句大多能通過**，是四批審查目前為止質感最紮實的一段。
- 真正的缺口不是「凡人化動作」大面積存在，而是**洛生衣的個人感官錨點（眸底青意／看生念厚薄冷熱斷面）在多章的病患診斷場景裡被「按脈／監看脈象」這種通用中醫式手法取代**，這與volume05 D2/A11已經指出過的同一個病灶重複出現，建議列為跨卷共通修正項，不只是本段落的個案。
- 機械性現代詞遠比volume05少，但抓到幾個具體詞：「面試」「試紙」「配額」「資源」，其中「面試」用在修真書院語境裡尤其突兀。
- 旁觀反應模板（倒抽氣／驚呼／交頭接耳）**本段落完全沒有出現**，群像場景（ch032、ch039）反而做到了「同一時刻不同人做不同的事」的正面示範，值得作為全書其他卷冊的參照案例。
- 新增具名配角（沈山河、陸行烈、韓鐵衣、秦照雪、柳青藤等）目前多以「職務差異」而非「感官/道法差異」做區分，尚未落入「神識一掃」式的公式化問題，但沈山河因反覆出現（ch021領工陪同、ch028舊石鎖、ch032/034山根固定、ch039釘界石）份量已經夠格建立一個簡單錨點，見D節建議。
