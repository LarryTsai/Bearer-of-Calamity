# 《完美世界》下界敘事容量研究：給《劫》的設計依據

日期：2026-09-25。方法：核對章目、抽讀公開正文／試讀，對照《劫》現行65章接縫。這不是618章逐章精讀報告，也未統計生活與戰鬥的字數比例；下列敘事機制是依樣本提出的分析。

## 章數可作尺，分期不能當成原作事實

按619章進上界、1616章首次進仙域切，1～618、619～1615、1616～2015分別是618、997、400章，占2015章的30.7%、49.5%、19.9%。這是本次採用的地理切法。章目交叉核對來源為[中文目錄](https://www.hetushu.com/book/115/index.html)，不是官方卷界；站點收錄的公告亦不應算入正文。

使用者提供的194／203／221／252／745／400，算術成立，但不宜據此推論辰東將人生階段平均分配：

- 前194章已經外出、接觸虛神界、百斷山與補天閣災變。第198章公開試讀明說離村兩年、包含遊歷與入閣，因此不能拿194章全對比《劫》的初始18章。[第198章](https://www.wuxiaworld.com/novel/perfect-world/pw-chapter-198)
- 195章仍在災變撤逃，278章試讀開頭則切到祖父一線；把195～277全標為一次北海秘境會遮掉交錯敘事。[第195章](https://www.wuxiaworld.com/novel/perfect-world/pw-chapter-195)、[第278章](https://www.wuxiaworld.com/novel/perfect-world/pw-chapter-278)
- 871～1312不能全部當成天神書院篇。目錄顯示其前段仍屬仙古階段，1099才出現書院同名章、1103為入院。這組442章不是可直接複製的書院容量。[章目核對](https://www.hetushu.com/book/115/index.html)
- 1616進仙域後，1638又重回帝關；首次進入某界不等於從此永久生活於該界，更不等於當場成為該界高階強者。[章目核對](https://www.yodu.org/book/929/)

## 真正可學的結構

一次冒險可以有多波後果：出門前有想要的東西與準備；路上遇見同行者與不同利益；場內有嘗試、競爭、失敗與勝利；回來後所得改变修行、聲望、家園與下一次選擇。這些環節若各有新問題，便具有獨立篇幅；若只是反覆敘述同一後果，仍是灌水。

篇幅還來自同時存在的人生。主角不在場時，祖輩、朋友、宗門和競爭者仍在行动；再次相遇時各自已有變化。不能用新增十名等待陸沉救援的角色代替多線。

回到熟悉地方可以測量成長：以前想買的東西、羨慕的人、誤會的規矩，如今如何理解？舊地方也應會變，不只是站在原地讚嘆主角變強。

另一個重要容量來源是快意與驚奇。少年想看沒見過的天地、想勝過高手、想試出自己的辦法，本身就是正當動機。若所有新增篇都只談欠帳、修繕和責任，《劫》仍會單調，只是把戰鬥流水線換成辦事流水線。

## 落到《劫》：本輪修訂而非照搬

1. 以[24篇重建總綱](../outlines/LOWER_REALM_LIFE_MASTER_OUTLINE.md)承接現行65章，250～350只是容量檢查範圍。新篇若無獨立欲望與轉折就合併，不按618或比例補足。
2. 丹師有自己的成事目標、技藝樂趣與去留；保留洛生衣上界初遇，不造下界生道替身。
3. 坊市與藥谷加入感官奇觀、試藝和小勝；陸沉有能乾淨做成的事，不每次都以失敗學責任。禁制服務生活時仍必須符合當期能力。
4. 太玄閣與坊城反覆出現；百斷山的傷、文奕的離開、魔女的選擇各有後果，不在一場回家飯裡清帳。
5. 昇龍台跨三界分別承擔獨立登頂、不同道路合作、開啟跨界聯絡後的選擇。三次都先有當地故事，古物僅串聯長線，不能每到新地圖就自動導航。
6. 境界差異應改變看見與能做的事：下界辨一段禁與自身承載；上界面對不同傳承的相容與衝突；仙級開始處理跨界秩序與漫長歷史。具體能力仍逐期核設定，不能因寫「仙人視角」便提前全知。

本輪結論：每個人生階段需要自己的欲望、生活圈、勝負與不能回復原狀的改變。章數是這些故事成立後的結果；三界地圖也不能代替人生轉折。
