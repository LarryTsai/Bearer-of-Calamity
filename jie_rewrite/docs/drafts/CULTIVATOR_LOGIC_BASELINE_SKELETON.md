填寫細則：
- **(a) 尺度**用可比較的單位：影響人數、範圍、持續時間、對誰有效、是否可逆。例：「volume11 ch017~024 洛生衣七室並行，第一座全毀」。

### 6.3 審查規則（寫進 agent 定義時同步）

1. **只審「降格」，不審「刻意小」**：6.2 列出的章與正文明示角色刻意收斂、偽裝、保留力量的場景，不算降格。
2. **升級只能落在 (b) 上限內**。超出上限的想像＝新增能力，一律登記 CHECKLIST，交作者，並先過 `jie-power-system`。
3. **每次升級必附代價與限制**（力竭、傷、次數、不可逆、需他人配合），否則不成立。
4. **陸沉平衡**：任何升級提案不得讓陸沉再成為唯一解；須先以 `jie-protagonist-balance` 的標準確認其他角色有專屬領域。
5. **三類處置**：①合理人體尺度（保留）②可升級（提案，不預選，最多三個方向）③需新增設定（登記 CHECKLIST，不自行寫）。
6. **不改已寫章節**，先出報告。範圍（作者 2026-09-25 更正）：全書從 `lower_realm_v2` 開頭依序往後；volume11、volume07／08 戰場章是第一批優先驗證「道的尺度」的段落。
7. 大型合作場面（例如五人救一城）不進自動審查，走標準流程 C 多輪討論。
