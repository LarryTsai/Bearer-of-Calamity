## 〇、總評

**核心測試句**（刪掉功法名稱，這些人還像修仙者嗎？）結果：ch081～084返關四章、ch087壓境側線答案是「像」，有多處示範級畫面。ch085～086、ch090～097刪去「燃身／鎮界／生膜／主契」後，讀起來像**文書調查加醫療倫理個案討論**：同意權、風險承受者、覆核、外部決定權、樣本不足、成功率。ch089是刻意寫成凡人的呼吸章，寫法正確。

### 病灶（不是症狀清單）

1. **大綱驗收句與安全閥直接滲進正文，而且每章都有（本段最大病灶）。** 大綱第六、七幕的章題本身就是判斷句（「多留一息不是相信」「孩子先回來的人，功勞不會被……拿走」「死去的人讓正確選擇永遠少一點乾淨」），正文幾乎每章都把這類判斷句當敘述或章末收束寫出來。例子：ch082 L53～55、ch084 L29／L67～69、ch085 L85～87、ch087 L87～91、ch091 L85、ch094 L55、ch095 L101～105、ch096 L139～143、ch097 L93「下一卷要爭的」。另一種是「沒有燃身、沒有天譴、沒有……」的能力免責段（ch083 L17～21、ch086 L45／L59、ch087 L29／L49～51、ch093 L29）。這和03a段的缺口四是同一種病，但本段更密：17章裡**15章的章末是宣示句**。修法不是逐句刪。每章留一句最具體的物件或動作收尾，其餘判斷交給讀者（ch085 L89～91「他念的是荒的名字」、ch088 L105「兩樣東西相隔一掌」就是現成範本）。
2. **每場高潮的媒介都是文書，超凡世界的媒介被擠掉。** 連續13章裡，推動場景的關鍵動作多半是寫、簽、報、記、按手印：守路記錄、傷簿、斷路記錄、戰報三稿、封箱四方印、臨時行動簿、時刻木牌、外路記錄、破門條件簽名、七日簿、新規則、名冊。其中ch086 L83「四方印／裂印」、ch085 L71「剪頁角」、ch092 L61「短線六結」是**把文書換成修仙世界媒介的好寫法**。問題出在ch093、ch096、ch097：規則文字直接用現代政策／風險管理語言寫成（見D）。
3. **三伴星退化成「一伴星一分句」的功能清單，鑑月三次用同一個公式。** ch083 L15、ch087 L29、ch095 L83／L89都是「蒼梧固定……，劫厄……，鑑月護住魂息，赤翎……」並列句。鑑月三次都是「護住（傷兵／跨界／昏迷者）魂息」，完全沒用到她的錨點「喚名定魄」和額心新月印。蒼梧用「踏界」「挪界石」，不是錨點表的「一掌按地、界痕外延」「以臂量邊界」。劫厄ch083 L15「咬住腰帶往內拖」＝叼，**違反禁忌**。赤翎寫得最好（ch087 L29／L75命火數目、ch094 L15～19親口拒絕）。
4. **滲透段刻意收斂是對的，但收斂得太乾淨，陸沉的身體質地也一起消失。** ch090～095陸沉不能外放雷力，這個前提正確，查車轍、蹲門、走路、躺布兜都該維持凡人寫法。不過錨點表的「震從掌骨／雷痕傳上來」是**被動**感知，不會外放，本段只在ch087 L19、ch095 L55讓永久界痕「共振出血／泛黑」。在不外放的前提下，界痕可以當他的被動感官（見C8、C10），不必讓他全程像凡人偵探。
5. **顧小滿在本段變成通用醫者，錨點全失，還出現現代急救動作。** ch094 L15「按壓到第十九次」幾乎就是現代心肺復甦。她的錨點「拍子落在吸氣半中間、腳尖先頓」本段一次都沒用到。
6. **洛生衣觀生幾乎全缺**（寫手1範圍，列G，不放C）：ch083逐項報傷、ch095穩住九人主契、ch097分三類傷，三處都是天然的觀生場景，正文全用「按著腕骨報」「檢查過」這類凡人醫者寫法。

## D、制度骨架現代化

1. **ch096 L121～125、L135新規則**：「任務上限、失聯期限、外部停手條件與誰承擔提前突入判斷」「不得以保護為由單方面拘留」「由至少一名任務承擔者與一名外部救援者共同覆核」「違反即失去下一次外部決定權」。讀起來是現代組織的授權政策。**這些是大綱ch039原句，交總控。** 方向：規則內容不變，改變它的**媒介**。比照本段已成立的守路令（ch081）、四方印裂印（ch086 L83）、臨時行動簿三人押印（ch090 L77）、時刻木牌（ch091 L83），寫成一份三方押印的「約」，條款可以短一點，讓印和空格（ch096 L137阮禾聯絡人的空格已是好畫面）承擔重量。
2. **ch097 L65～77司天鑑處決提議**：最壞推演、機率、樣本、污染半徑、截災。「截災」是好詞，保留；其餘是現代風險評估語言。方向同C11、B-1：讓司天鑑用器具與舊案說話（「上一次這種血線出現，死了多少」），不用統計語言。「災害半徑」交總控。
3. **ch093 L83破門條件**：「失去表達能力不自動等同同意」「連續兩次失聯或生膜出現屠殺反應」。條件本身好，語言是知情同意書式的，見B-1。
4. **ch085、ch086戰報與封存**：戰報三稿、副本三份（軍令司／傷營／孩子）、按手印、調閱印、封條編號、四方印。這套制度骨架是傳統帝國文書，**不需現代化處理，維持**。只改「版本」「合照」。
