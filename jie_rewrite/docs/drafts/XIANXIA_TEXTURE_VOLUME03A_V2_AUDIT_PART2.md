## 〇、總評

**核心測試句的結果**：把功法名稱刪掉以後，ch011、ch012、ch013最弱，讀起來像現代的技職檢定或工程實作考。ch014、ch016最強。ch015、ch017、ch018居中。ch019是儀式章，旁觀模板最密。

- **缺口一：考核段的制度骨架很現代**（見D）。這一段依序出現了排號、素卡三問、不得重考、標準材料、標準測試傀儡、戰術評等／維護評等、單項總評、入場牌翻灰、離場程序、工時、總評榜、冠軍線、對局表。禁都本來就是成熟的制度文明（世界檔一、三），所以**不刪制度**。要改的是讓程序透過已建立的禁制媒介運作（停禁鈴、事故簿、公議簿、鏡砂、補位牌、校準牌、契文碑），用詞也換掉。
- **缺口二：奪禁三章（ch016～018）的機制語言滑成資料庫身份驗證和資安語彙**。用到的詞有檔案、可信度、調高、驗證、身份記號、供能網定時回報、操作者、供能開關、指令、外部訊號、入侵。這是本段最急的一項，性質跟v03的「兵陣電腦系統」（C10）一樣。ch016 L47「一份寫在紙上的『陸沉』」是現成的正確語彙，可以當全段的替換母句。
- **缺口三：文奕、律無咎沒有感官錨點**。文奕在ch013察覺不對、算撤離步數，全是心算（「心裡浮起一絲不對」「文奕算出……七步」），沒有任何超凡身體反應。人物檔明寫他是「具有強大正面戰力的禁制師，不是文弱解說型軍師」，這三章卻看不到他一個正面戰力的身體動作，連L45劃開最穩一筆都只用一句話帶過。律無咎的出手只剩通用武俠身法（ch014 L69「足尖點地，身形幾乎沒有多餘動作」）。錨點提案見本節末，只列方向，不定案。
- **缺口四：安全閥聲明句滲進正文**。大綱驗收條件被寫成了旁白，例如「……不能／不會替他……」「遠在別處的雷身也會承到共鳴，卻不會因此知道……」「他沒有另一具能替這隻手出招的身體」「這是真本事，不是作弊」。戰鬥驗收要求本身有達成（見A之二），但演出方式是條列心算段落，加上「念頭已到、手慢半拍」這個公式出現五次。讀者會覺得在讀章末一致性自檢，不像在看打鬥。
- **缺口五：陸沉的雷體只出現在受傷時**。虎口舊疤和胸肋舊傷在這九章出現十幾次，幾乎都是「又痛了、又腫了、又緊了」。只有ch014 L33和L39把虎口當成讀取工具（用挨打量數、數復位節律）。ch011讀引燈禁、ch012撥引線時，他用的是「蹲下去看」「指尖的直接感知」，前者是凡人動作，後者是作者替他解釋。這違反人物檔「思考優先於承受」的呈現原則，也浪費了掌心雷意的判讀錨點。
- **生活段本來就該用凡人寫法**：ch011 L35～39記錄吏答話、L59～61添油老人自己決定停禁日期；ch012 L59～67岑婆的話；ch015 L59～67榜前對話；ch019 L69～79藥布與對話。添油老人、記錄吏、接手的維護吏都是在地人物，不加仙氣。**ch011的添油痕、磨痕、野花這條「人的痕跡」證據鏈，必須維持肉眼觀察**，這正是本章主題。要超凡化的只有前面讀引路紋的那一段。

## D、制度骨架（萬禁會考核與禁都公共規則）

原則：禁都是成熟的公共禁制文明，制度感是設定本身（世界檔一、三），**不刪情節也不刪程序**。改法是讓程序經過已建立的禁制媒介運作，並換掉現代考試或行政詞。新機制標【待確認提案】並附退回寫法。

1. **ch011 L11～19識禁報名**：木牌「一人一次，不得重考」、排第三十七位、素卡三問、一炷香一座、寫完便走不許回頭改。讀起來是現代筆試考場。三問保留，排號和重考換詞。
2. **ch011 L47～57成績宣讀**：「九座滿評，一座依銷冊判停……八座滿評，兩座扣分」是評分細則體。改成評等語。
3. **ch012 L9布禁考題**：「以主辦提供之標準材料，於半日內……標準測試傀儡三次衝擊……抽籤所得之城籍維護吏接手……不得口述」是標準化實作檢定。改成制式材料、試禁傀儡；規則核心不動。
4. **ch013 L7～11**：「團隊」「協力人員」等。只換「團隊」即可。
5. **ch014 L9、L93～95**：守方預先登記、公開存檔。符合禁都價值，保留。
6. **ch015 L29～31、L39、L53～55、L69**：維護官搖鈴、入場牌翻灰、離場程序、工時、總評榜、冠軍線、對局表，組起來是體育賽事賽程。換詞為主。
