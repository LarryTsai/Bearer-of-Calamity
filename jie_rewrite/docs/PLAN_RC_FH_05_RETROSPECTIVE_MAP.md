## 2. 封寒同行切入點

**結論：不從陸沉越界當下（ch010）同行，稍後在ch013分線之後、ch014～015區間加入。**

理由：ch009/010是「唯一主動站到荒身旁的人」定調語的載體，封寒若與陸沉同框跨界會稀釋「唯一」的字面與情感重量。合理理由：**封寒自己主動選擇跟隨**——他已在帝關戰線附近，見陸沉跨界後，憑自己「先自己試過風險」的性格底線與已具備的坍縮之道感知，獨立找到另一處法則薄弱點強行跟入，時間比陸沉晚、落點不同，因此不被異域方視為交換名單一部分，也不與荒產生交集。

## 3. 拆王支線插入窗口

**建議窗口：ch018（感知線索）～ch019尾段（觸發）～ch019與ch020之間新增2～3章（正式展開與突破）。**

理由：
1. ch018〈黑水城〉本身是「斷界禁臺」古代封印初次現形場景，與「已崩解的古代王族先祖遺蛺」在世界觀質地上高度呼應，封寒在此感知另一處類似但不同的殘留法則不突兀。
2. 封寒必須在ch020〈戰神書院〉烏迭正式登場**之前**完成脫離或進入恢復期——因為ch020～024正是「戰神書院禁臺追獵隊」建立真實威脅、最終由陸沉單獨解決的核心段落，不能讓封寒有餘力介入稀釋其獨立戰力設定。
3. ch019〈燼長明救無槐〉本身是陸沉獨立完成的救援，不受影響；封寒的「回報線索」放在此章尾段是自然橋樑。
4. **誠實評估**：拆王支線在既有40章正文中**沒有任何現成的殼可以承載**——現有章節沒有陸沉以外的獨立戰鬥線、也沒有「已崩解遺蛺」的伏筆或空間留白，無法單靠EXPAND完成，必須INSERT 2～3個新章節。這是本次規劃中唯一需要真正開新場景的部分，其餘封寒的同行過場（ch014/015/016/018/019）均可用EXPAND完成。

## 5. 知識/力量隔離的具體落地建議

- 拆王突破的正式場景中，陸沉的敘事焦點應被安排在另一件具體任務上（例如壓制遺蛺周邊被震醒的次級法則餘波、擋住被驚動的守衛或環境崩塌），物理上沒有餘裕觀察技術細節，呼應event file「協防」定位。
- 突破完成後，明確寫出「陸沉聽見的只是聲音停止、感覺到的只是法則壓力消散」，**不寫**「他忽然明白了什麼」「他隱約看懂了坍縮的原理」這類句子，可仿照ch014「至於左路發生什麼，日後若荒願意說，他才會知道」的資訊邊界寫法。
- 此章的「一致性自檢」欄應明確列出「陸沉未因此獲得任何至尊級知識、禁制解讀或戰力增益」一句，作為硬性驗收點。
- 封寒的坍縮突破本身不能寫成「輕鬆」——需比照ch018/020/022的代價敘事密度（具體的傷、具體的失時、具體的失敗），避免這條支線讀起來像附贈的爽點而非與主線同等重量的獨立故事。
