# 文奕

> 狀態：作者裁示新增的長線核心角色。本文是人物唯一來源第一版；未經裁示的外貌、境界、親屬姓名與最終去向暫不硬定。

## 一、核心定位

文奕出身上界古老禁制世家文家，是完整禁道文明培養出的頂尖天驕，也是具有強大正面戰力的禁制師，不是文弱解說型軍師。他擅長禁理、結構、推演與把既有體系運行到近乎完美；他的長線缺口不是知識不足，而是是否敢離開正統答案，創造尚不存在的體系。

他與陸沉互為禁道路上的改造者：文奕把結構、冗餘、維護與系統觀帶給陸沉；陸沉則把假禁、誘導、臨場污染與創造性犯規帶給文奕。兩人不是師徒，也不是一人替另一人解題。

**思維定位補充（2026-09-12 新增，回應 `CHECKLIST_PENDING_DECISIONS.md` 第161題）**：面對「前人的答案」，文奕的第一反應是「先理解它為什麼是答案」——這與陸沉「先問它為什麼一定是答案」的質疑型思維互為對照，兩人不是誰比較高明，而是理解與質疑兩種同樣扎實的路徑。

## 二、不可改寫的事實

- 文奕幼年被派往下界的重要目的之一，是尋找失落的《古神禁典》。
- 文奕比陸沉年長約一歲；約八歲時以文家一次性降階禁渡真身下界，百斷山後與護道人經焚錨召回返回上界。禁渡自此永久失效。
- 《古神禁典》不是文家祖傳聖典；文家本已有完整仙王祖典與成熟文明。
- 文奕與陸沉在虛神界因古神遺留、禁制與仙王殘跡相遇。
- 兩人取得完全相同、同樣完整的《古神禁典》，不存在陸沉多一頁或文奕只得半本。
- 《古神禁典》的仙王提出活禁道路但沒有完成；兩人得到未竟之路，不是終極答案。
- 兩人多次分合：虛神界、百斷山、上界、禁都／萬禁會、仙古、文家事件與帝關。
- 帝關時兩人已是生死至交與雙軍師。陸沉進入異域前，把帝關重要的人與戰爭體系中可交付的部分託給文奕，因為文奕本就是共同建造者。

## 三、人物弧

1. **完美繼承者**：能讀懂並穩定運轉古老體系。
2. **被陸沉污染**：開始使用假禁、誘導與非正統路徑，並承擔風險。
3. **萬禁會奪魁者**：在正式規則下證明正統實力；陸沉的奪禁敗局則讓他看見規則盲區。
4. **文家守陣者**：家族遭難時先以自己的選擇守人與體系；陸沉只改變死局，不取代他的功業。
5. **帝關共同建造者**：走到能創造、維護並交付新系統，與陸沉共同推動第三次禁道盛世。

## 四、關係邊界

- **陸沉**：方法論對手、摯友與共同建造者；不寫成單向崇拜或隨身外掛。
- **文家**：承受家族文明的深度，也面對守成、利益與盟友退縮；文家不等於反派，也不壟斷禁都。
- **洛生衣及帝關眾人**：文奕接手共同建造且權責清楚的體系，不接管他人意志，也不成為陸沉替身。
- **荒**：陸沉入異域的核心仍是荒；文奕守住帝關側因果，不分享或取代荒的原作功業。

## 五之一、活禁雙路比喻（2026-09-12 新增，回應 `CHECKLIST_PENDING_DECISIONS.md` 第161題）

文奕與陸沉的禁道方法論可用一組比喻對照，兩人不是誰淘汰誰，而是雙向互補：

| | 陸沉 | 文奕 |
| --- | --- | --- |
| 核心句 | 讓生命進入禁 | 讓禁自己成為生命 |
| 依靠 | 神識、雷、自身生命、欺禁、臨場變化、異常思維 | 完整禁道基礎、文家積累、《古神禁典》、自循環、天地取能、自修復、陣禁結合 |
| 禁的樣貌 | 自身神經系統向外延伸 | 一個即使主人離開，也能自行運轉的生命系統 |

> 生命 → 禁，與禁 → 生命，是兩條方向相反卻同樣完整的路。

## 六、禁都／萬禁會已定回收

- 文奕返上界後已在禁都文明生活多年，不以《古神禁典》作為成為天驕的唯一理由。
- 他在萬禁會依正式規則奪魁；至少一次在陸沉不在場時主動留下非最優但可撤回的出口，證明兩人的互相影響。
- 陸沉完成奪禁卻依法敗退時，文奕先承認「你輸了」，再指出「但他的禁也輸了」；不無腦護短，也不否認新技術事實。
