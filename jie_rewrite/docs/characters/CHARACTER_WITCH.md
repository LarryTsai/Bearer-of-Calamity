## 二、她為何注意陸沉

魔女最初看中的不是陸沉的戰力，而是他在沒有完整功法、肉身孱弱、只能依靠神識的時候，仍能從必死規則中找出一線生機。這與她理解的「截天」相近：天地不肯留路，便從既定規則中截出一條路。

她對陸沉的判斷須隨故事逐次改變：

| 階段 | 她所看見的陸沉 |
| --- | --- |
| 虛神界 | 從別人留下的死局中找出生路 |
| 荒野追殺 | 開始替敵人留下死路，也防備看似幫助自己的人 |
| 真假委託 | 能看穿她的隱瞞，仍按自己的利益與底線合作 |
| 正式招攬 | 會認真考慮強大道統，卻不交出決定自己用途的權利 |
| 百斷山 | 把截天法理改造成不屬於截天教的活禁雛形，與她第一次互相救命 |
| 假殺荒 | 能改寫她與截天教共同設下的局，不盲從任何人 |
| 北海後 | 已有資格以自己的道路與荒正面互證 |

## 三、與陸沉的關係定位

- 兩人是長期累積出的知己、試探者與道路對手，不是突然熟悉，也不是單方面師徒。
- 魔女教過陸沉一小段截天法理，但沒有把他的禁制道路創造成自己的功勞；陸沉吸收的是「截走關鍵一環，使整體自行崩解」的思考方式，活禁與後續禁道仍由他自己走出。
- 陸沉知道魔女常說七分真話，因此不要求她變得完全坦白；他會確認她隱瞞的部分是否超過自己能承受的風險。
- 魔女欣賞陸沉，正因他適合截天教卻不可能真正屬於截天教。她三次邀請的分量必須遞進：試探性問句、正式招攬、最後一次真心邀請。
- 她可以對陸沉有偏心、維護與自己不願承認的在意；現階段不得自行定案為戀愛、道侶或三角爭奪，也不得削弱洛生衣作為陸沉既定感情核心的角色功能。若作者後續明確調整感情結構，再另案更新。

## 四、語言與行動方式

- 她很少一次說完真相，常以問題、玩笑或半真情報迫使對方自行判斷。
- 調笑不能等於輕浮；每次玩笑背後都應有試探、轉移注意、保護情報或逼人表態的目的。
- 她表達關心通常不是安慰，而是多給一條線索、替人遮掩氣息、引走追兵，或把危險包裝成一筆仍可拒絕的交易。
- 她不能總被陸沉看穿。至少一次她的局須真正超出陸沉掌握，至少一次陸沉須因資訊不足判錯；否則她會被降格成證明主角聰明的陪襯。
- 她也不能永遠操控全局。百斷山雷意失控必須讓她真被困住，才能使互救成立。

## 五、北海後的關係回收

北海四人相聚時，魔女把陸沉推出來與荒比試，不是隨口找人壓荒。她是在替自己一路看見的成長作證：月嬋只看見今日站在禁制中央的陸沉，魔女看過他最初連一道保命禁制都沒有。

這次維護不能寫成長篇履歷說明。她只說足以暴露偏心的一兩句，六段前史由讀者自行回想；陸沉也能看出，她表面在鬥嘴，實際在替他的道路辯護。

## 六之一、虛實之道（2026-09-13正式回填，回應`CHECKLIST_PENDING_DECISIONS.md`第182題）

**取得時機**：天神書院後、帝關入籍前，〈古世雙界遠行〉插卷（第十六、十七篇間新增卷）線B第三、四幕，與洛生衣共同誤入生滅／虛實雙界時首次開啟。正文見`novel/volume06b/chapter020~033.md`（B-11穿越第二層天首見規則、B-12首次小規模使用、B-13規模加重、B-17~B-18全卷最大規模使用「創造假的生」）。

**核心能力**：魔女原有的偽裝、佈局、情報操作之道，在虛實之界（「第二層天」，被相信的虛假可逐漸取得存在資格的世界背面）產生本質提升——從「騙過你的認知」走向「讓虛假進入現實」。這是全新開的大道分支，不是既有偽裝能力的簡單延伸。

**五項硬性限制（不可放寬，任何後續引用此能力的正文都必須逐一核對）**：
1. **合理因果**——必須有具體、可信的細節/記憶/情感作為基礎，不能無中生有。
2. **真信門檻**——必須有人相信；對驗核力越高的對象（如B-17面對「守界者」本人的直接詰問）越容易被識破，不是無差別必勝。
3. **極短時效**——持續時間極短，不能長期穩定存在。
4. **識破即潰**——一旦被徹底識破，虛假會快速崩潰，且有實質後果（非空話）。
5. **反噬機制**——魔女本人須承受「虛實反噬」，且代價規模隨使用規模遞增（已正文驗證：B-12唇邊滲血→B-13噴血身形淡化→B-17咬破指尖灌氣血、身形與霜光重疊整段呼吸、噴血、視野重影）。

**能力邊界（重要，避免未來誤用擴大）**：
- 不能無中生有創造真正完整的大道與生命；首先是一顆受限道種，不是立即成熟的完整戰力。
- B-18「虛假第一次獲得真正生命」是魔女虛實之道與洛生衣「續脈」（她既有能力，非新習得）**聯合作用下的一次性結果**，不是魔女個人能力的隱性升級——魔女獨立施展虛實之道時，上限仍是「短暫存在資格」，不能單獨創造真實生命。
- B-19灰沙皿「一線生機」的局部路徑創造，是綁定當場因果與見證的單場景應用，不是可重複調用、能影響世界命運的能力，不得在後續章節當成常駐工具使用。
- 落筆時一律使用「虛實之道」「存在資格」等本卷專屬語彙，不得使用「虛實轉換」字樣（該詞已被`systems/SYSTEM_FORMLESS_SEPARATION_SCROLL.md`無相離身卷占用，指完全不同機制）。

**與魔女既定安全閥的關係**：此能力不改變、不影響「不得自行定案為戀愛、道侶或三角爭奪，也不得削弱洛生衣作為陸沉既定感情核心的角色功能」這條既有安全閥；〈古世雙界遠行〉B-14「脫離劫的關係」是與陸沉無關的過命知己/戰友線，不涉及感情結構調整。
