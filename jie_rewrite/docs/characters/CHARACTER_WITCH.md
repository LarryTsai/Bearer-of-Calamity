# 魔女角色設定：截天而行，試劫而知

狀態：現行設定 v1.0（2026-08-02）

## 一、原作身分與使用邊界

| 項目 | 設定 |
| --- | --- |
| 稱謂 | 魔女；需要原作正式身分時再依同期使用截天教傳人／天狐仙子等稱謂 |
| 所屬 | 截天教 |
| 核心氣質 | 靈動、狡黠、擅長偽裝與情報差，說話真假相間，但不做沒有目的的欺騙 |

| 獨立目標 | 替截天教尋找下界線索與可造之才，同時判斷教中命令是否值得照做；她不是替陸沉送情報或替感情線服務的工具人 |

## 二、她為何注意陸沉

魔女最初看中的不是陸沉的戰力，而是他在沒有完整功法、肉身孱弱、只能依靠神識的時候，仍能從必死規則中找出一線生機。這與她理解的「截天」相近：天地不肯留路，便從既定規則中截出一條路。

她對陸沉的判斷須隨故事逐次改變：

| 階段 | 她所看見的陸沉 |
| --- | --- |
| 虛神界 | 從別人留下的死局中找出生路 |
| 荒野追殺 | 開始替敵人留下死路，也防備看似幫助自己的人 |
| 真假委託 | 能看穿她的隱瞞，仍按自己的利益與底線合作 |
| 正式招攬 | 會認真考慮強大道統，卻不交出決定自己用途的權利 |
| 百斷山 | 把截天法理改造成不屬於截天教的活禁雛形，與她第一次互相救命 |
| 假殺荒 | 能改寫她與截天教共同設下的局，不盲從任何人 |
| 北海後 | 已有資格以自己的道路與荒正面互證 |

## 三、與陸沉的關係定位

- 兩人是長期累積出的知己、試探者與道路對手，不是突然熟悉，也不是單方面師徒。
- 魔女教過陸沉一小段截天法理，但沒有把他的禁制道路創造成自己的功勞；陸沉吸收的是「截走關鍵一環，使整體自行崩解」的思考方式，活禁與後續禁道仍由他自己走出。
- 陸沉知道魔女常說七分真話，因此不要求她變得完全坦白；他會確認她隱瞞的部分是否超過自己能承受的風險。
- 魔女欣賞陸沉，正因他適合截天教卻不可能真正屬於截天教。她三次邀請的分量必須遞進：試探性問句、正式招攬、最後一次真心邀請。
- 她可以對陸沉有偏心、維護與自己不願承認的在意；現階段不得自行定案為戀愛、道侶或三角爭奪，也不得削弱洛生衣作為陸沉既定感情核心的角色功能。若作者後續明確調整感情結構，再另案更新。

## 四、語言與行動方式

- 她很少一次說完真相，常以問題、玩笑或半真情報迫使對方自行判斷。
- 調笑不能等於輕浮；每次玩笑背後都應有試探、轉移注意、保護情報或逼人表態的目的。
- 她表達關心通常不是安慰，而是多給一條線索、替人遮掩氣息、引走追兵，或把危險包裝成一筆仍可拒絕的交易。
- 她不能總被陸沉看穿。至少一次她的局須真正超出陸沉掌握，至少一次陸沉須因資訊不足判錯；否則她會被降格成證明主角聰明的陪襯。
- 她也不能永遠操控全局。百斷山雷意失控必須讓她真被困住，才能使互救成立。

## 五、北海後的關係回收

北海四人相聚時，魔女把陸沉推出來與荒比試，不是隨口找人壓荒。她是在替自己一路看見的成長作證：月嬋只看見今日站在禁制中央的陸沉，魔女看過他最初連一道保命禁制都沒有。

這次維護不能寫成長篇履歷說明。她只說足以暴露偏心的一兩句，六段前史由讀者自行回想；陸沉也能看出，她表面在鬥嘴，實際在替他的道路辯護。
