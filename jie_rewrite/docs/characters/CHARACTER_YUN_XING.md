# 雲行（單字法號：行）

狀態：作者裁示新增的長線核心角色（2026-09-12）。禪修、遊方修士，劫在宗門固定小隊（洛生衣、封寒、青璃）與四伴星（劫厄、鑑月、蒼梧、赤翎）之外所結識的重要戰友之一。本文件為人物唯一來源第一版；大量欄位依作者原意刻意保留「暫不硬定」，讓故事發展決定答案，不在此預先填滿。

> **與「外部戰友」規劃的關係**：本作原先曾考慮預先設定數名劫的外部戰友（劍修、丹醫、情報或推演型人物），使用者與協作者討論後正式取消「一定要有三名外部戰友」的框架。經全庫檢索 `docs/`、`novel/` 確認，目前不存在任何已成形的此類角色設定、伏筆或章節內容，故本次沒有需要刪除的既有內容——這個框架僅存在於專案外部的討論紀錄，未曾寫入本專案。往後原則：**故事走到哪裡，真正遇到值得留下的人，才讓那個人成為劫的戰友**；雲行是此原則下第一個被完整塑造的角色，後續若有更多此類角色，一律比照本文件的謹慎程度個別建檔，不預先湊滿名額。

## 一、核心定位

| 項目 | 設定 |

| 姓名（暫定） | 雲行 |
| 單字法號（暫定） | 行 |
| 身分 | 禪修、遊方修士 |
| 定位 | 劫在宗門固定小隊與四伴星之外所結識的重要戰友之一；非人生導師 |
| 核心意象 | 禪、酒、自在、不執、行於世間 |
| 外觀基調 | 俊朗秀氣的青年禪修（非傳統光頭僧人、非粗獷和尚），氣質可參考「乾淨、俊秀、略帶出塵感」的美型方向（使用者原文以《百煉成神》裴天耀的氣質為外觀參考，僅止於氣質類比，角色本身須靠巨型念珠×秀氣臉×酒壺×長髮建立自己的辨識度，不是該角色的翻版） |

**一句話定義**：行於世間，心無所住。

雲行不是逃離紅塵的禪修，他走進紅塵——喝酒、看山、看人、交朋友、歷生死、入戰場，也欣賞世間一切美好的東西，但不讓任何東西成為束縛。他的禪不在「避」，而在「身在其中，心仍自在」。

### 2.3 與酒的關係（角色理解之窗）

酒不是搞笑設定，也不是造型配件，是理解這個角色最簡單的一扇窗：

- 年輕時被問「修禪之人，也飲酒？」，他只笑答「想喝便喝」——但這不是終極答案。
- 某天他發現自己開始「期待」某一種酒，於是戒酒數十年。劫問「為什麼不喝了？」他答「最近太喜歡喝了。」——這代表他不是執著於酒，也不是執著於「戒酒」；若一個人非得喝酒才能證明自己灑脫，「灑脫」本身就成了另一種執。
- 他真正追求的是：**喝，可以；不喝，也可以。**

### 2.4 修煉方向：與劫相反（核心對照）

| | 劫 | 雲行 |
| --- | --- | --- |
| 方向 | 越修越多——承受、融合、增加（神識、禁制、雷種、雷身、陣法、雷池，最終融入「劫」） | 越修越少——少年時功法多、招式多、法相華麗、佛光滔天；後來一門一門放下，最後可能連法相都不要 |

範例對話雛形（供未來正文語感參考，非定稿台詞）：

> 劫：「你的法相呢？」
> 雲行：「不要了。」
> 「為什麼？」
> 「以前覺得挺強。」
> 「現在？」
> 雲行喝了一口酒。「太吵。」

此時的他，反而比曾經擁有巨大法相時更加恐怖。

### 2.5 特殊的突破方式

不靠閉關百年、煉化神物、衝擊境界。可能只是坐在某處看了一場雨、陪一個凡人走完生命最後一天、喝了一夜酒，第二天就不同了——劫昨天還能破解的東西，今天突然破解不了。

> 劫：「突破了？」　「沒有。」
> 「換功法？」　「沒有。」
> 「那是什麼？」
> 雲行想了一下。「昨晚有件事情想通了。」

這是禪修體系與一般修煉體系最重要的差異之一。

### 2.6 戰鬥反差

平時喝酒、笑、坐姿隨便，甚至可能直接躺著睡；真正戰鬥時不必變成怒目金剛——反差可以更高級：他安靜下來，酒壺放下，笑容收起，眼神清明，周圍原本躁動的天地開始異常安靜。這是第一次真正讓人明白，那個平常最不像禪修的人，可能擁有所有人之中最穩的一顆禪心。

**「收酒」——決定取人性命時的專屬儀式動作（2026-09-13新增，回應帝關前支線設計）**：平常他隨時可以喝——趕路喝、聊天喝、切磋喝、普通戰鬥甚至也喝，酒代表自在、鬆弛、與世界保持一點距離。但當他真正決定「這個人，今日我要取他的命」，他會反而把酒收起，佛珠纏腕，變得完全清醒——這個動作代表「我知道自己現在要做什麼，也願意承擔它」。**此動作務必稀少使用，越少出現越有重量**，不得寫成他每次戰鬥前的固定儀式，只在他做出不可回頭的重大選擇時才出現，這樣熟悉他的人（讀者、劫、封寒）之後只要看他收酒，不需要台詞就知道發生了什麼。

### 2.7 與劫的關係：道相反的朋友，非導師

兩人最有趣的地方不是能力互補，而是**道相反**。劫極執，遇到絕境會想「一定存在解法」，找線、找漏洞、拆禁制、算空間；雲行可能說「若真的沒有呢？」。

> 劫：「若前面無路呢？」　雲行：「走到那再說。」
> 「若真的沒有？」　「那就沒有。」
> 劫：「你不想破局？」　「想。」　「那你——」
> 雲行喝了一口酒：「**想破局，和非破不可，是兩回事。**」

**硬性界線**：雲行不能寫成專門負責講大道理、教育主角的高人。他和劫是**朋友**——道不同、互相理解、但不要求對方變成自己。雲行不會要求劫放下（若要求劫「必須放下」，他自己就執著於「放下」了）；劫也不會要求雲行變成自己。兩人甚至常互相覺得「這傢伙真的有毛病」，但真正的大事發生時，他們知道對方會在。

### 2.9 戰力定位

雲行的禪道應能走到極高境界，甚至非常後期仍有資格出現在劫與瘋所在的頂級戰場，但**不採用「劫10、瘋9.5、雲行9.4」這類具體數字化戰力對比**（比照 `CHARACTER_LU_CHEN.md` 十之二既定呈現鐵律）。他的強大應該很難量化，可能長時間不出現，再見時劫會發現自己已看不透他，甚至某階段可能出現「劫破不了他的定」——但這不是永遠的勝負關係，而是不同大道在某一時期交會產生的碰撞，不預設固定高低。

**使用者確認補充（2026-09-12）**：明確希望雲行後期戰力能到很高的層級，可與瘋（封寒）同階層——與本節既有原則不衝突，仍不具體數字化排序，但方向上雲行不應被寫成明顯弱於瘋或劫的陪襯角色，尤其呼應 `CHECKLIST_PENDING_DECISIONS.md` 第176題「Volume11大劫決裂常駐轉折」——雲行此時正式成為能與劫、瘋並肩頂級戰場的戰友，戰力份量須撐得起這個定位，不能只靠「疏落出場、神秘感」掩蓋戰力空虛。

### 2.10 名字與法號

- 「雲」：沒有固定形狀，聚則聚、散則散，遇山則繞、遇風則行，卻從不是因為逃避什麼。
- 「行」：不是坐著談禪，而是走入世界。
- 單字法號暫定「行」（非「無塵」「空」「寂」——那些名字太早替角色宣告答案；「行」保留最大空間：修行、行走、行於紅塵、知而後行）。可能的稱呼分層：世人稱他雲行，師門只喚他一聲「行」。

## 四、禪道可能涉及的領域（概念保留，非定案）

| 概念 | 方向 |
| --- | --- |
| 定 | 心不動；高境界後甚至可影響周圍天地——不是護盾、不是單純肉身防禦，而是進入「定」之後，外界的法、勢、意甚至空間本身開始失去原本的躁動 |
| 觀 | 不是普通視力，而是觀察事物本質——觀己、觀人、觀念、觀法、觀因果；**「觀」不等於劫的神識與禁制之眼，兩人底層邏輯必須不同** |
| 空 | 不是黑洞，不是空間消失，而是「無所依」——一門術法的成立可能依賴意、念、神識、殺心、控制、法則、執著；若所依不存在，法是否仍然成立，可作為雲行非常後期的方向 |
| 念 | 一念生、一念滅；念可以形成力量，也可以成為束縛 |
| 因果 | 只保留可能性，見上方「暫不硬定」的說明 |
| 自在 | 可能是雲行最終最重要的方向。早期以為是喝酒、睡覺、不守形式、遊歷天下；後來理解真正的自在是「境不能縛、法不能縛、生死不能縛、道也不能縛」；最終連「自在」兩字都不需要 |

## 五、角色長線（非鎖死進度表，僅記錄方向遞進）

我可以不守形式 → 我開始理解自己為何不守形式 → 連「不守形式」也只是另一種形式 → 有相、無相，本無分別 → 自在（但「自在」本身也不能成為最後必須抓住的答案，大道深處連「我是自在的」這個念頭都可以放下）。

## 六、初遇原則（給未來規劃初遇事件時的硬性提醒）

**不要因為要讓雲行加入而安排雲行。** 應先存在一個本來就合理的事件，劫因自己的理由進入，雲行也因自己的理由出現在那裡，兩人只是碰巧相遇，最初不需要互相欣賞。真正讓關係成立的應是**一次選擇**——例如危局中明明可以離開，雲行卻回頭：

> 「你認識他？」　「不認識。」
> 「那回去做什麼？」
> 他晃了晃酒壺。「欠了點東西。」

不必實寫成「欠命」，重點是雲行的第一次重要選擇必須讓讀者理解：不執，不代表他什麼都不做。具體初遇事件、時間點、地點均待後續規劃，比照全書慣例經 `jie-creative` 提案、`jie-canon`／`jie-continuity` 覆核後才能定案插入章節，不由本文件預先鎖定。

## 七、與劫最終的視覺對照（長線終局意象，非近期待寫內容）

劫站在大道盡頭：身後雷海、雷池、九雷、十雷、禁制、空間線、劫痕、萬劫交織，畫面越來越龐大複雜——因為他承載了這一切。雲行站著：沒有佛國、沒有巨大法相、沒有漫天梵文、沒有萬丈佛光，身後什麼都沒有，只有他與腰間那只陪了無數歲月的酒壺。這不是誰比較高明，而是兩條完全相反的路，最後都走到了極遠的地方。

> 劫，以執行萬劫。
> 雲行，以放得自在。

兩人相視，雲行把酒壺丟過去，劫接住，喝了一口——到了這一刻，也許已經不需要再談道。

## 八、創作原則提醒

- 不要把雲行寫成「喝酒的和尚」，要寫成真正理解禪、所以連「和尚應該長什麼樣子」都不執著的人。
- 「不執」是核心紅線，絕不能滑向「無情」或「什麼都不在乎」。
- 他不是專門教育劫的人生導師，是朋友——兩人互相不要求對方變成自己。
- 他的魅力不只來自外貌、酒壺、大佛珠、禪法，而是「活得很輕，但真正重要的人與事落到肩上時，從來沒有逃過」。

## 九、帝關前封寒×雲行×陸沉支線設計（2026-09-13，使用者裁定採用結構）

**來源**：使用者提供根目錄檔案《劫_帝關前_封寒雲行陸沉人物支線設計.md》（已移入 `docs/archive/root_drafts_20260913/`），總控與使用者brainstorm後確認採用其核心結構。**具體場次尚未逐章展開，仍待 `jie-creative` 提案、四方覆核、`jie-chapter-editor` 排入 `outlines/OUTLINE_BORDER_ROAD_EXPANSION.md` 或另立事件檔，本節只登記已確認的結構與設計原則。**

### 九之一、整體結構：Volume07帝關前段拆分為兩截

不是雲行單獨與陸沉主力同行一段，而是拆成前後兩段，順序不可顛倒：

- **前段（C線前半）：封寒＋雲行同行赴帝關**。陸沉此時不在場。這段讓封寒第一次在沒有陸沉陪同的情況下獨立撐起故事，也是雲行與封寒建立關係的起點。
- **後段（C線後半）：陸沉＋雲行帝關前戰線**。封寒不在此段（已抵達帝關或另有任務）。這是雲行與陸沉的深層對照戲。

**為何不讓文奕加入**：文奕此時故事根基已足夠厚（虛神界解禁、古神禁典、百斷山、禁都、萬禁會奪魁、文家遭難），不需要再塞一段帝關前冒險湊戲份；他在此期間可用少量切面交代「文家遭難後如何繼續成為文奕」（從「解禁」走向「讓結構能被人長久使用」），不進入這條支線。**這條原則同時適用於青璃、生等其他已有自身成長節點的角色**——本支線刻意不追求角色平均分戲，只補雲行（全新）、封寒（需要一次無陸沉獨撐的篇章）、陸沉（需要一次「承擔與放下」的反向照見）三人真正缺的那一塊。

### 九之二、封寒＋雲行段（C線前半）核心設計

- **兩人核心問題相反**：封寒面對未知＝「沒證明走不通，為什麼不試？」；雲行面對未知＝「不知道，不代表一定需要知道」，會先反問對方是真的需要答案還是只是手癢。**但雲行不能永遠負責踩煞車**——必須安排至少一次角色反轉：某次高風險路段封寒判斷成功率過低、不值得冒險，雲行卻主動決定走，理由只有一句「裡面還有人」，讓封寒理解雲行不是沒有執，只是更清楚自己願意為什麼執。
- **封寒此階段的道逐漸成形**：核心不是「我喜歡冒險」，而是「只要一條路尚未被真正證明不存在，我不接受別人因恐懼、習慣或權威提前替它宣判死亡」——與荒「沒有路，我打出一條」、劫「把能看見的路都算過，找出能活的那條」並列第三種態度。關鍵場次「未知古路事件」：安全路必須放棄後方一批人，另一條路成功率無法計算；成熟的封寒不是無腦衝，而是先進去一小段、驗證、找可用資訊，最後仍只能得到「不知道能不能通」——他的角色句：「不知道，所以才還有一條路。」
- **雲行此階段的「破禪」**：面對一群無法全部撤走的人，軍事判斷合理地要求放棄，雲行這次沒有說「緣盡便放」，而是坐下喝最後一口酒、把葫蘆放到旁邊，說「這個放不下」，然後收酒、佛珠纏腕、起身——這是讀者第一次真正看懂他的禪：不是沒有執念，而是「知道自己正在執著，仍然選擇承擔」。
- **兩人互相改變**：封寒學到「選擇不打開一個未知，也可以是主動選擇，不一定叫膽怯」；雲行學到「有些所謂放下，其實只是提前接受失去」。
- **抵達帝關前必須留下真實的失敗**（有人死在途中、某段古路永久崩塌、某個答應帶走的人最後沒能帶回），兩人埋葬沒能走到的人才進城，確立「他們是走過戰爭才抵達帝關，不是來尋機緣」。

### 九之三、陸沉＋雲行段（C線後半）核心設計

- **這是「承擔×放下」的深層對照，不是師徒**。此時陸沉已極度擅長承擔，這正是他的危險期——早年「我自己處理」已進化成成熟而危險的「由我承擔是整體成本最低的方案」，且他能為此提出合理證明，這才難解。**雲行絕不能寫成專門點醒陸沉的人生導師**（禁止「陸沉頓悟、人格升級」式寫法），兩人必須互相證明「對方只對了一半」。
- **雲行刺中陸沉**：見九之四／`CHARACTER_LU_CHEN.md`情感盲點「雲行問名字線」——陸沉戰後記錄一切可用資料卻不知死者姓名，雲行一句「那個人的名字呢？」讓他第一次看見「把死亡完整轉化成資料，也可能讓『那個人』本身消失」。
- **陸沉反過來刺中雲行**：一個小據點幾乎確定守不住，雲行合理判斷「已經救不了」，陸沉卻堅持「你說的是救不了，我還沒證明」，最後找到方案讓原本只能撤五十人變成能撤八十七人——代價可能是他自己多留、一件預布禁器永久報廢、一條退路被消耗、雲行也需回頭替他守一次。雲行因此理解「有些放下是智慧，有些放下只是太早接受失去」。
- **思想傳遞鏈**（三角，非三角戀式關係）：封寒給雲行「未知不等於沒有價值」→ 雲行給陸沉「記住不等於承擔」→ 陸沉給雲行「放下不等於成熟」。雲行最終的道：「看得清，所以能放；知道值得，所以不放」。
- **兩人相處基調應可以很安靜**，不必每場都是金句對決（原稿範例：雲行看陸沉布多重備用禁制線，一句「你活得挺累」，陸沉「還好」，雲行「你這個『還好』，貧僧一路上聽過不少」——不需要展開更多，兩人各自沉默做自己的事就是最合適的節奏）。
- **陸沉此段的變化只是埋下一根刺，不是立刻治好情感盲點**：他要到終局公開自己完整傷勢與恐懼時，這根刺才完全回收，此段不能寫成當場的性格轉折。

### 九之四、後續可回收的細節（散落回收點，非集中大場）

- 雲行看到陸沉又在隱瞞傷勢，只需一句「又是『還好』？」，陸沉便知道他在說什麼。
- 封寒後來準備走未知路時，雲行不再問「為什麼一定要知道」，而是問「值得？」——封寒「值得」，雲行「那走」，代表兩人已建立共同判準。
- 後期大戰某次，雲行默默收酒，不必解釋，熟悉他的人（讀者、劫、封寒）立刻知道他做了不可回頭的決定。
- 某次戰後，陸沉的記錄表在既有欄位外多加一欄「姓名」，不必解釋。
- 後期遇到幾乎不可能救回的人時，雲行第一次主動問陸沉「證明了嗎？」——代表陸沉也真正改變了他。

### 九之五、禁止事項（落筆時的具體紅線）

1. 不給雲行突然獲得完整強力傳承或神兵；不給封寒突然因古路取得追平劫的神兵。
2. 不讓文奕、青璃、生等已有自身成長節點的角色為了「帝關前也要有故事」硬加入本支線。
3. 不把雲行寫成封寒的煞車皮，也不把封寒寫成看到未知就無腦衝——九之二的角色反轉場次必須落實，破除這個刻板分工。
4. 不把雲行寫成只會講禪理的人生導師；不讓陸沉被雲行一句話點醒（人格升級式寫法明確禁止）。
5. 不讓古路事件全員無傷、全員救回——必須留下真實的失敗與代價。
6. 不把這段變成第二個「古世雙界遠行」（不掉進上古世界、不複製異世界生活史結構）。
7. 不以境界突破作為這兩段故事的主要回報。
8. 不讓雲行取代生、瘋、文奕、伴星等既有人物與陸沉的核心關係定位。

### 九之六、三人最終小結（供落筆時把握分寸）

- **封寒**：出發前「未知值得去看」→ 抵達帝關「未知值得被驗證，但不是每一個未知都值得拿別人的命替自己的好奇付帳」——瘋沒有減少，只是更成熟。
- **雲行**：「看得開，所以能放」→ 經封寒「有些可能不能太早放」→ 經陸沉「有些傷也不能永遠背」→ 最終「看得清，所以能放；知道值得，所以不放」。
- **陸沉**：「每一次失敗都必須留下可用的東西」→ 經雲行「留下經驗，不代表必須把所有死人永遠背在身上」，同時也反過來證明「不能把放下當成提前接受失敗」——不會立刻治好情感盲點，只是埋下一根深刺，直到終局才完全回收。
- **雲行的最終定位不是多一名強者，而是少數分別真正與封寒、陸沉單獨走過一段路的人**——他因此理解兩種「瘋」（封寒：對未知與可能性的瘋；陸沉：對自己、對承擔的瘋），這個定位需要在帝關後續與Volume11大劫決裂常駐轉折兩處持續被讀者感受到，不是帝關前用完就丟的功能性配角。
