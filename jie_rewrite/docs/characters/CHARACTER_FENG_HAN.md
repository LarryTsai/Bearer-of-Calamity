## 二、性格核心

| 層次 | 內容 |
| --- | --- |
| 表層性格 | 嘴賤愛鬧，話多，常出餿主意，把「試一次就知道」掛在嘴邊；旁人常誤判他行事莽撞 |
| 私下性格 | 對「還沒有人給出答案的事」抱著近乎渴望的好奇；讓他真正不安的不是失敗，而是明知某處有問題、卻因循苟且不去驗證 |
| 核心欲望 | 把每一個「大概不行」的假設，逼著自己或身邊人真的去試一次，看看那個「大概」站不站得住腳 |
| 核心恐懼 | 有一天發現自己其實只是拿「試一試」的姿態，逃避真正沉下心把一件事打磨到底——他怕自己的好奇心其實是懶惰的另一種樣子 |
| 致命缺點 | 容易把「試驗」當成繼續下去的藉口，該收手時收不了手，讓同伴替他的好奇心承擔風險 |
| 道德底線 | 不拿不知情的人當賭注；任何新辦法自己先擔一次代價、確認風險可承受，才會拉別人下水 |

## 三、行為與語言

- 話多，語速快，常常一句話裡先岔出兩個問題，卻能在關鍵瞬間收成一句短促的判斷——外人常低估他這種「鬧著鬧著突然說中要害」的節奏。
- 戰術討論時不甘於只挑「這裡不能」，即使沒有把握，也會先丟一個沒人試過的方案出來，並主動承擔第一次驗證的風險。
- 對隊友熱絡、愛開玩笑，但玩笑話與真正在乎的事之間界線清楚——一旦轉為認真語氣，隊友都聽得出差異。

## 四、與陸沉的關係

封寒與陸沉相識於太玄宗七峰大比正式選拔**之前**——兩人在藥閣、七峰小屋一帶的日常修行期就已結識，起因是一次共同闖下的小禍（具體事件待正文回溯時補寫，建議規模：一次未經許可的禁制/藥理實驗，後果可控但確實驚動宗門）。這段交情建立在「陸沉少數幾次沒有先算清所有後果、就跟著封寒的直覺走了一次」的經驗上——這不是陸沉性格的改變，而是封寒是極少數能讓陸沉願意破例陪他賭一次的人，兩人以此互為對照：陸沉教會封寒風險要先算過，封寒教會陸沉有些答案算不出來、只能先試。

代表隊磨合期仍保留一場具體戲：面對某道戰術僵局，封寒提出的非常規解法起初不被隊伍完全信任，陸沉選擇讓步支持他先試一次，結果證明可行——這場戲的功能與青璃線（`CHARACTER_QING_LI.md`）「陸沉判斷錯、對方反駁對」的戲區隔開：封寒這場的核心不是「他比陸沉判斷得準」，而是「陸沉願意為了一個尚未被驗證的假設承擔風險」，呼應两人相識之初的相處模式，不是重複同一種戲劇結構。

> **回溯提醒**：現行 Volume02 正文（`novel/volume02/chapter047.md` 一帶）已寫定「陸沉與封寒、青璃在代表隊階段才第一次建立關係」（即舊版 V10-03 修正的內容）。本版本設定與此正面衝突，回溯修訂需要在 Volume02 太玄宗初期章節（約 ch001～ch011 區間）補一段「藥閣／七峰小屋結識」的既定背景，而非只改代表隊階段的台詞。

## 五、戰鬥人格

- 主要戰鬥距離：近身至中距，靠兵胚形態隨戰局重新配置（輕便快擊 ↔ 沉重坍壓）。
- 優先目標：專挑「其他人手裡的常規辦法都打不動」的目標——他的價值是提供隊伍缺少的那個非常規選項，不做常規清場。
- 是否接受以傷換命：願意，但堅持「先驗證、後拉人」的底線——任何以傷換命的賭注，第一次必須由他自己承受代價。

## 六、武器與大道：坍縮之路（新設定，回應「瘋」的黑洞／白洞概念）

封寒沒有像同峰弟子一樣終身持劍。他隨身攜帶一件形態不固定的「兵胚」——與陸沉的萬劫兵胎（`systems/SYSTEM_MYRIAD_CALAMITY_WEAPON_EMBRYO.md`）是兩套完全獨立的來源，**不共用機制、不互相解釋、不互相借用**：陸沉的兵胎源自沉雷谷滅族夜雷種與求生本能的孕育；封寒的兵胚則源自他自己一次「劍解決不了問題」的瀕死經驗——具體觸發事件待正文回溯補寫，建議發生在太玄宗初期，是他放棄純劍路線、轉向「借重量與引力解題」的起點。

兵胚成熟後的常態形態是一截其貌不揚的短棍，戰鬥中可隨他對「重量、引力、坍縮」的掌握程度變化外形，成熟遠期形態暫定俗稱「金鐧」（正式命名可由使用者後續調整，本文件不鎖死具體外觀細節）。

**觸發時間點訂正（2026-09-12，回應jie-continuity覆核）**：兵胚正式覺醒的具體觸發事件**不早於**界潮／古界弧線（`outlines/OUTLINE_ANCIENT_REALM_WAR.md`），正式定型於Volume06〈天神書院〉書院寶庫（見七）。在此之前（含本弧線界潮／古界期間），封寒仍是問劍峰劍修、以劍應戰，尚無兵胚；界潮／古界期間出現的吞噬反應是純本能雛形，不代表兵胚已存在或已覺醒。原「建議發生在太玄宗初期」的措辭已刪除，避免與此時序衝突。

**轉折地點（2026-09-12 裁定，回應 `CHECKLIST_PENDING_DECISIONS.md` 第166題）**：封寒棄劍、轉向坍縮之道的關鍵觸動，**不**發生在已鎖定為「第三千次、也是最後一次開啟」且固定參與者為陸沉／謫仙／荒的仙古遺跡（`events/EVENT_XIANGU_RUINS_ZHEXIAN.md`），改為與陸沉共同前往「書院寶庫」（Volume06〈天神書院〉期間，見 `systems/SYSTEM_CALAMITY_ORDER_AND_SELF_RECONSTRUCTION.md` 五之一）——這場書院寶庫之行同時是陸沉觸發「驚鴻雷身」短暫預覽、封寒觸動棄劍轉折的共同事件，兩人各自的轉折在同一趟行程中發生，但成因與內容彼此獨立，不互相解釋或借用對方的機制。

**具體場景定案與護短起點（2026-09-12，回應 `CHECKLIST_PENDING_DECISIONS.md` 第180題，已經四方覆核）**：完整場景見 `systems/SYSTEM_CALAMITY_ORDER_AND_SELF_RECONSTRUCTION.md` 五之一「具體場景定案」——封寒在「三痕古域」滲漏出的「天煞痕」裡第一次觸及沒有「面」可砍的坍縮感，慌亂中放棄揮劍、下意識用兵胚接住下墜的力道，觸發「勢→重」的起點（這一下只摸到「引」最外緣的邊角，遠遠稱不上熟練，正式跨越「引」留待後續另一獨立事件）。同一場戲裡，封寒瞥見陸沉雷紋外洩、眼耳滲血卻被自己腳下的坍縮力量拽住、連伸手都做不到——這是他**「在乎的人出事、自己卻連伸手都做不到」的第一次真實體會，也是他此後一路護短陸沉這條性格線的起點**（此性格線此前未在本文件明確鋪墊，正式以此事件為唯一起源，日後涉及封寒護短行為的正文應可回溯至此）。封寒此時無入寶庫資格，是自己找漏洞混進去，陸沉事後才發現。

大道路徑（唯一來源，避免與既有十雷體系撞名，見系統文件 `systems/SYSTEM_FENG_HAN_GRAVITY_PATH.md`）：**勢 → 重 → 引 → 坍縮 → 奇點 → 黑洞 → 白洞 → 歸墟**。這是一套獨立於十雷／劫道之外的個人修行體系，核心精神與陸沉的雷道互補而非同源：陸沉的道是「劫染萬物、萬物皆歸序」，封寒的道是「萬物皆有其勢，勢盡則坍、坍盡則吐」。兩人私下常以「你的道是往外燒，我的道是往裡塌」互相調侃。

**與陸沉的功業邊界**（比照既有安全閥精神訂立，避免功業混淆）：封寒的坍縮大道是他自己的修行成果，不因與陸沉同行而稀釋為陸沉能力的副產品；陸沉也不得代替封寒完成坍縮路徑上的關鍵驗證，只能在旁協防或提供情報支援。

## 七、異域同行與「拆王」支線（新設定，回應根目錄舊稿核心情節）

**裁定範圍**：經使用者裁定，封寒隨陸沉一同進入異域（PW-22 系列，對應 Volume08〈異域同行與帝關守路〉），但**不改變荒與陸沉之間「強制分線、不得雙人橫推」的既定安全閥**——封寒是陸沉側線（追兵、界路、撤離後患）上的同行者，不參與荒的核心功業（尋人、救人、揭露七王與罪血真相、帶返原始帝城後裔），這條分界不因封寒加入而鬆動。

封寒在異域側線上的獨立支線暫稱「拆王」：他在協助陸沉處理側線追兵期間，遭遇一尊被異域某方勢力長期供奉、實為**已崩解只剩殘蛻的古代王族先祖遺蛻**（非活著的至尊或不朽者本體，避免牴觸「不得讓荒劫跳階成至尊」「不得提前授予成熟活禁／禁天能力」等既有安全閥），封寒以坍縮之道逐層拆解這具遺蛻殘留的法則壓制，藉此第一次把自己的道路推到「坍縮 → 奇點」的門檻。原稿中「不朽之王」「吞王」的說法，在本設定中降格為「拆解一具遺蛻級的殘存權柄」，不是擊敗或吞噬一位活著的異域至尊——這個降格是為了與 Volume08 既有安全閥相容，若使用者希望維持原稿「拆解活著的不朽之王」的字面規模，需另外重新審查是否與「不得讓荒劫跳階成至尊」衝突。

原稿「悟道茶會」場景（封寒與荒、陸沉三人短暫同席論道）**不採用三人聯手瞞天過海、共同奪取核心目標的版本**（該版本與第150題已否決的提案同構）；若要保留這個場景的氛圍，只能改寫成一次極短暫、非核心功業性質的交會（例如三人在側線任務途中偶然同桌，交換的是各自不涉及對方核心功業的閒話），且仍需經 `jie-canon`／`jie-continuity` 覆核後才能定案。

**知識與力量隔離**：陸沉在旁協防拆王支線期間，不因照命／神識觀察到遺蛻拆解過程而獲得任何至尊級知識、禁制解讀或戰力增益，此事件對陸沉而言只是側線協防記錄，不構成任何能力來源（完整表述見 `events/EVENT_FOREIGN_DOMAIN_COMPANION_RETURN_ROUTE.md` 八）。

**戰力邊界**：封寒推進到「坍縮→奇點」門檻時，戰力不得超過陸沉當前八雷綜合戰力，且不得讓 Volume08 既有側線挫敗場景（ch013、ch018、ch020、ch022）因他的加入而變得容易解決。

**待決事項**：拆王支線的具體插入章節（Volume08 現有40章五幕結構的哪個位置）、殘蛻的正式名稱與外觀，均未定案，需待正文回溯規劃時由 `jie-chapter-editor` 提案定位。
