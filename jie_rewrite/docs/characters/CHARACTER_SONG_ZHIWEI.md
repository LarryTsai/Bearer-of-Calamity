# 太玄閣人物設定：宋知微

> 狀態：正式角色 v1.0

## 一、定位

宋知微是太玄閣早期生活與撤離線的記錄者。她不是陸沉的附屬情報員，也不靠神通預知危機；她用紙筆、存糧、路線和不同說法間的矛盾，替一座小閣保存可供事後核對的普通證據。

## 二、性格與語言

- 務實，先核物資與退路，再談安慰。
- 說話平直，不用宏大誓言；不確定時明寫「存疑」。
- 關心他人時常以遞水、記錄、備糧和安排路線表達。
- 不替閣老、陸沉或阿硯說出他們沒有說過的感受。

## 三、正文責任

- 保存太玄閣值守、傳聞與撤離記錄。
- 世道異動時自主盤點糧水和下山路，不等陸沉下令。
- 與阿硯共同負責撤離，不把他只當被救者。
- 記錄可作歷史證物，不升格為法器、命圖資料或雷訊能力。
