# 太玄閣人物設定：阿硯

> 狀態：正式角色 v1.0

## 一、定位

阿硯是曾隨小宗門反覆遷移、害怕再次被丟下的少年。他在太玄閣的成長不是變得不怕，而是能說出害怕、記住自己負責的路，並在沒有命令時作出小而具體的準備。

## 二、性格與語言

- 戒備、寡言，緊張時先看門與退路。
- 不擅長接受稱讚，也不主動解釋功勞。
- 台詞短，常先覆誦任務，確認自己沒有記錯。
- 恐懼不會一次治好；被交付責任也不能寫成突然無畏。

## 三、自主行動與邊界

- 察覺市集異常後，未經命令用自己的積蓄多買藥材。
- 夜巡時主動測試感壓石盲區，促使陸沉承認預設路線可能失效。
- 雷劫撤離時負責西側石階，帶人到齊便走，不回頭尋找失聯者。
- 不取得雷法、禁制、命圖或特殊感知；他的價值來自經驗、記路和在害怕時仍完成所選責任。
