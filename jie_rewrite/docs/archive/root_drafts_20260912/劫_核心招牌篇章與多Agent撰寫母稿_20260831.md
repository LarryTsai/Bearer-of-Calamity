# 一、總體創作原則

《劫》的主角始終是劫。封寒、文奕、青璃與其他人物必須有完整人生與獨立目的，但不代表每段人生都要在正文完整演出。

正文呈現分四級：

- **A級｜完整演出**：直接改變劫的主線、核心關係或世界大局。
- **B級｜代表場景**：完整寫一至兩次關鍵事件，其餘用後果、傳聞、回憶或重逢變化帶出。
- **C級｜設定台帳**：正文只呈現新傷、能力、責任、立場與人物關係的結果。
- **D級｜候選事件池**：保存可能性，不預設一定發生。

篇章可以聚焦兩至四名人物，不必強迫全員到場；但沒有入場的人必須存在於合理的生活、任務與時間線中。少人是敘事聚焦，所有人無故消失才是世界失真。

小故事不得僵硬並排。每個事件至少留下兩項可被後文接續的內容：問題、物件、技術、傷勢、人情、敵人、錯誤結論、關係變化、制度後果或新限制。下一個相關事件至少使用其中一項。

每段故事都要能回答：

1. 它由前面哪件事引發？
2. 為什麼偏偏現在發生？
3. 為什麼由這幾個人參與？
4. 它造成什麼不可逆改變？
5. 它留下什麼供後文回收？
6. 若刪除，哪一段人物或大篇會因此變弱？

# 二、第一招牌篇章——劫與瘋：異域拆王、分離承劫、返本重逢

## 定位

目前完成度最高、最能代表《劫》友情與主題的大篇章，正文應列為A級超大篇。

它不是「吞掉不朽之王後升級」，而是從藥閣、七峰小屋、三分身、金鐧、異域臥底一路累積出的終極回環。

## 必須保留

- 藥閣第一次談「修到第三層才發現第一層有錯，便拆掉」。
- 七峰小屋與三分身共同推演、互相否定的日常。
- 劫與瘋多次失敗、第一次救命及「不然？」的交命關係。
- 仙古見鐧、放回仙王舊鐧、取得無答案兵胚。
- 七峰一版版雷煉金鐧，使兵器成為友情的實體見證。
- 劫為荒潛入異域，封寒主動同行。
- 劫以雷、神識與禁制改寫兩人的肉身、元神、生命波動、血脈表徵及大道氣息，假扮古老王族旁系。
- 異域生活、宴會、盤查、王族獵殺、悟道茶會與荒的短暫交會。
- 拆王不是突然發想，而是救荒、王道標記、戰爭通道、完整大道研究與身分暴露共同逼出的方案。
- 劫負責禁制、空間、隔離、切斷、欺騙與撤離；封寒以金鐧切入王道結構、震斷、剝離、承接與歸源。
- 拆王成功後封寒瀕死，需要無法戰鬥、不能被打斷的蛻變時間。
- 劫製造假瘋，引走整個異域；三分身在追殺中逐一死亡。
- 封寒的劍道、金鐧、肉身、神魂與王道全部反過來解構自身。
- 劫在絕境後進入返本，親手拆掉自己已經成功的雷種與大道。
- 重逢保持克制，以「分身呢？」「我有個問題」「下次還幹嗎？」完成情感回收。

## 核心鏡像

> 封寒因劫學會拆掉別人替他安排的成功人生。
>
> 最後輪到劫拆掉自己已經成功的大道。

## 原作安全閥

- 荒身落異域對應PW-22，原作核心經歷不可取代。
- 劫為荒主動越界，但入域後必須強制分線。
- 悟道茶會與假戰相遇需在精核原文章節後選定狹窄窗口。
- 劫與瘋只能協助荒避開原創危機或傳遞有限情報，不能替荒完成原作脫身與功業。

# 三、第二招牌篇章——劫與文奕：禁都

## 固定關係定位

> **劫是羅蘋。**
>
> **文奕是福爾摩斯。**

這不是輪流交換定位，也不是泛稱兩人都很聰明。劫固定是主動設局、潛入、偷換、誤導與優雅犯規者；文奕固定是從禁紋、用字、年代、施術習慣與不合理空白還原真相的人。

兩人的核心張力：

> 劫問：你能不能找到我留下的真相？
>
> 文奕問：我找到真相後，還應不應該抓你？

## 前置案件鏈

### 少了一枚禁釘

劫偷走不起眼的禁釘。文奕追到他後發現，劫是在證明庫房紀錄裡存在一枚本不該存在的禁釘。

留下禁釘製作者手法、禁都貨物流向，以及文奕第一次沒有立刻交出劫的關係變化。

### 沒有被偷的禁書

禁書仍在原位，內容卻少了一頁。文奕以為是劫，劫這次真的沒有動手；兩人由前案手法認出同一來源，並發現有人正在模仿劫。

### 劫故意被抓

劫公開偷取重要禁物，故意被文奕抓入禁牢。文奕隨後發現牢房本身正是禁都情報交換節點，前兩案留下的禁釘與缺頁首次拼成訊息。

### 被偷走的名字

某些禁道失敗者、旁支與試禁者仍真實存在，族譜、魂燈與記憶卻不再承認他們。此案連接青璃的混血族譜問題，也把禁都從遠方勢力推到人物身邊。

## 禁都大篇

- 文奕代表正統禁道進入禁都。
- 劫以不被承認的異統身分闖入。
- 表層是兩人爭奪禁典與禁都權限。
- 中層是兩人各自調查禁都吞噬居民記憶與生命的結構。
- 深層是兩人故意讓真正敵人相信他們仍在互鬥，把對方逼向唯一出口。
- 中間必須存在真分歧：文奕要保存累世傳承；劫認為把人當材料的底層結構應整體拆除。
- 結局不是一方說服另一方，而是共同創造能改寫、拒絕命令並停止吞人的「活禁之城」。

禁都應列為A級超大篇；此前案件多為B級中篇或短中篇，不必連續出現，但每案必須留下證據與關係變化。

# 四、第三招牌設定——雷法改寫生命與異域王族偽裝

這不是普通易容或幻術，而是劫「駭客」思路的生命層面運用：

> **先讀懂異域如何辨識自己人，再修改自己，使規則真的判定兩人是異域王族。**

必須呈現：

- 神識讀取驗證方式。
- 禁制重排生命結構。
- 雷種與雷的傳導、改變、生命特性。
- 第一雷對生命、大道與「線」的觀察。
- 肉身、元神、生命波動、血脈表徵與大道氣息改寫。
- 城門、祭器、王族血壇與帝族因果驗證逐級升高。
- 封寒必須自行理解並維持改寫後的生命節奏，動用金鐧、舊劍道與九天十地法則都可能令偽裝裂開。
- 偽裝不是一次完成，而是在異域生活中持續修補、惡化與付出代價。

此設定應貫穿異域全篇，不能只在入域時交代一次便永遠有效。

# 五、第四招牌段落——悟道茶會與荒的短暫交會

## 功能

- 展示異域王族社會、禮儀、血脈政治與完整大道。
- 驗證劫與瘋的古族身分是否經得起高層檢查。
- 讓兩人接近荒的情報與異常王道。
- 短暫呈現三種不接受既定答案的道路。
- 使救荒潛伏線自然轉向帝族追查與拆王線。

## 三人思想對照

- 荒：路走不通，便以自身打穿。
- 劫：先拆開規則，追問它為何成立。
- 瘋：既然答案不只一個，便把另一個推進現實。

## 必須保留的生活感

劫飲茶後研究茶如何使人親近大道；封寒盯著茶樹道紋，想用金鐧震一下。劫在桌下按住他。

> 封寒：「理論上不行？」
>
> 劫：「身分上不行。」
>
> 封寒：「那就是理論上可以。」

## 假戰提案

荒處境惡化後，兩人不能公開救走荒。劫暗改封鎖禁制，封寒以王族天驕身分挑戰荒並在交手中震碎禁錨，荒看懂意圖後借戰脫身。

表面是兩名異域王族圍攻荒；實際是三人共同演了一場沒有事先說明的戲。

此段列為B級關鍵中篇或A級大篇中的重要幕，不可獨立搶走荒的原作異域主線。

# 六、第五招牌篇章——仙古見鐧、放下劍、七峰煉鐧

封寒沒有被神器直接選中，也沒有繼承仙王完成品。

他在仙古看見仙王金鐧，第一次理解「劍不是唯一答案」；即使有機會接觸舊鐧，仍把它放回去，只取一塊沒有答案的成長兵胚。

七峰煉器必須兼具生活、失敗與人物轉折：

- 第一版太像仙王。
- 第二版太像槍。
- 第三版過粗。
- 前端與重心失衡。
- 三分身為方案互相爭吵。
- 封寒不斷要求加重，造成桌地破裂等生活後果。
- 劫與封寒逐步分清「能不能」與「值不值得」。
- 最終成品仍非完成品，而是一件能與封寒共同成長的兵器。

此篇是封寒從別人的答案走向自己的答案，也是劫與瘋友情最早的實體見證，應列為A級完整篇章。

# 七、第六招牌篇章——三伴星羈絆、燃身與燼長明加入

劫前往帝關及相關界路的核心羈絆線屬於劫與三伴星：劫厄、鎮無央、玄衡。燼長明要到帝關與第八雷階段才自主歸位，形成四伴星。

必須保留：

- 三伴星各有拒絕權，不是寵物、御獸或可替換裝備。
- 劫把燃身錯認成燃命，第一次嘗試失敗。
- 劫厄自主闖入火中，不是受命替主人取力量。
- 劫拒絕以他人餘命換取火與突破。
- 玄燼凰只守池讓路，不贈火。
- 劫自行承受燃身雷池考驗並留下生命空洞。
- 燼長明在看見其選擇後自主同行，不是被收服。

封寒、青璃、文奕不得進入這條核心考驗搶走伴星羈絆；他們可以在前後或其他戰區自然交會。

此篇列為A級劫之主線大篇。

## 五階段

1. **純**：我要證明自己並不低人一等。
2. **裂**：我做得再好，主脈仍保留拒絕我的權力。
3. **界**：不讓任何一半替我定義全部。
4. **璃**：裂痕不是缺陷，而是光改變方向的地方。
5. **青**：不再要求被收入主脈族譜，建立旁支自己的術法學堂。

終極人物句：

> **「你們要的是純。」**
>
> **「我要的是完整。」**

# 九、劫與文奕、劫與瘋的反覆故事引擎

## 劫與文奕

讀者期待的是：

> **這次劫偷了什麼？文奕能追到哪一步？看懂後還會不會抓他？**

可有多次不連續短篇、數次中篇及一至兩次超大篇。案件不能每次都是劫偷東西；可以是有人模仿劫、文奕故意設局等劫來偷、兩人分別查同一案件、文奕先知道答案卻等待劫證明制度有罪。

## 劫與瘋

讀者期待的是：

> **這兩個人這次又想到什麼，準備炸掉哪裡，最後會留下什麼有用又危險的東西？**

生活型事件包括金鐧重量事故、禁地過夜、活禁反追、交換武器、封寒第一次自行算出可行、封寒第一次否決劫。中篇包括廢雷井、反向雷瀑、會逃跑的禁制、金鐧失重、不能被打破的牆與必須輸掉的比試。

每次不能只爆炸收尾，至少留下技術原型、風險倫理、傷勢、人情、制度限制或大篇回收。

# 十、完美世界時空安全閥

所有正式擴寫前必須先列：

1. 對應的原作節點ID。
2. 荒當時的境界與位置。
3. 原作正在場的重要人物。
4. 不可被改寫的原作功業。
5. 原創人物可以活動的安全空間。

現行大段邊界：

- 三千州大戰／仙古對應PW-10～PW-14；荒的仙古第一、萬道煉身、仙氣、雷劫與核心勝負不可轉移。

# 十一、未來多-Agent正式撰寫流程

正式寫書時才啟動多-agent，建議分工：

1. **主筆 agent**：依母稿、原作節點與人物狀態完成正文。
2. **因果 agent**：檢查前因、當下壓力、選擇、阻力、結果及後續回收。
3. **人物 agent**：檢查劫的主角焦點、配角能動性、聲音與關係進展。
4. **戰術／能力 agent**：檢查地形、能力時序、境界、代價、反制與傷勢。
5. **原作 canon agent**：逐章核對《完美世界》人物、地點、事件先後與不可改寫功業。
6. **連續性 agent**：追蹤物件、信物、傷勢、情報、身分暴露、人物知情與時間。
7. **讀者 agent**：只讀正文，判斷是否生硬、是否像設定說明、高潮是否足夠、生活與修真是否自然融合。

多-agent不得各自自由新增重大 canon。所有新增族名、境界、能力、原作交會、傷勢與關係里程碑先回到總控彙整；主 agent依依賴順序修訂，完成後再交叉驗證。

每個大篇驗收：

- 劫仍是主角，其他人物完整但不搶走敘事重心。
- 重要轉折有具體事件，不靠設定句宣布。
- 小故事至少留下一項後文實際回收的結果。
- 生活細節日後能成為技術、暗號、傷痛或情感回憶。
- 沒有把原作人物當成原創角色成長的工具。
- 沒有挪用荒的核心機緣、勝負與歷史功業。
- 沒有無代價勝利、無限能力或突然取得的答案。
- 寫後重新檢查前後章、角色檔、事件檔、系統檔與發布版同步。

# 十三、未來 Agent 必須保持的《劫》創作精神

> **本節是故事開發方法，不只是文風偏好。未來任何 agent 在發想、拆章、寫作或審閱大型原創篇章前，都必須先理解並遵守。**

## 1. 從小問題長成大篇章

最符合《劫》的大故事，往往不從「出現終極強敵」開始，而從一件生活裡不對勁的小事開始：

- 少了一枚禁釘。
- 一本書每天自行換位置。
- 一碗麵每天味道完全相同。
- 一封多年以前的求援信現在才送到。
- 一堵牆明明沒有禁制，卻沒有人能打破。
- 一座雷瀑只往下流，封寒偏偏想知道能否往上。

小問題必須逐層打開人物、制度、歷史與世界，而不是在第二章突然換成無關的大反派。大高潮回頭看時，要能證明最早那件小事一直是核心的一部分。

## 2. 能力首先是理解世界的方法

能力不能只有戰鬥輸出。

- 劫的雷、神識與禁制用來讀取、滲透、改寫和承接規則。
- 文奕的禁道用來判斷一套秩序從何而來、被誰修改、付過什麼代價。
- 封寒的金鐧與解構用來驗證結構是否真的只能如此。
- 青璃的璃界用來看見元素、族群與道路之間被人刻意畫出的界線。
- 洛生衣的生命道路用來追問「救回來」與「讓誰承擔後果」是不是同一件事。
- 三伴星的選擇用來證明同行不是支配。

每個大篇至少要有一次：角色使用既有能力看見別人看不見的問題；以及一次，能力本身不能替角色完成道德選擇。

## 3. 生活與修真不是兩種模式

生活戲不能只是大戰間休息，修真設定也不能只在戰鬥時啟動。

最好的生活細節會在後面成為：

- 技術原型；
- 戰術暗號；
- 關係證據；
- 最痛的記憶；
- 制度改變的起點；
- 大高潮的解法或代價。

三分身在小屋爭吵，後來才有異域逐一死亡的痛；金鐧砸穿桌地的笑話，後來能成為封寒辨認重力失衡的經驗；文奕熟悉劫留下的禁紋錯位，後來能從一筆「太正確」的痕跡識破冒牌者。

未來 agent 寫生活戲時必須問：這個細節日後可能被誰記住？它會改變哪次判斷？如果完全沒有後續，也至少必須真實推進當下關係，而不能只為可愛或搞笑而存在。

## 4. 大高潮必須回收早期笑點、失敗與物件

《劫》的高潮不能靠臨時覺醒解決。早期的小事故與失敗紀錄應逐漸演化：

- 廢雷井的失敗結構成為後來排除死路的依據。
- 反向雷瀑從好奇實驗變成邊關技術，再可能進入拆王分流。
- 七峰小屋的共同推演放大成異域秘密據點裡的王道模型。
- 「理論上可行」從生活笑點變成讀者知道將出大事的警報。
- 「理論上可行」還必須完成方向反轉：早期由劫說給封寒聽；不朽之王前由劫提出完整拆王方案，封寒完成推演後反過來回答劫。這是兩人由引路與跟隨走到真正平等的核心回收，不得寫反。
- 「拆掉」從功法問題回收到封寒人生、拆王與劫返本。

正式拆章前要建立回收表：早期設置、首次變形、中期用途、高潮回收及回收代價。沒有前置支撐的終極解法不得直接落筆。

## 5. 勝利必須留下不可逆結果

不可只用重傷後迅速恢復假裝有代價。結果可以是：

- 一具分身永久死亡；
- 一段傳承、據點或撤離路線永遠失去；
- 假身分被某個勢力記住；
- 一名救援對象沒有救回；
- 某種能力從此不能無限制使用；
- 一段信任破裂，不能靠一句道歉修復；
- 救了一邊，因此另一邊承受真實損失；
- 敵人學會反制，下次不再吃同一套方法。

代價必須在後續人物行為、資源、傷勢、制度或關係中繼續存在。

## 6. 對手必須有能力，也必須會學

王族、帝族、禁都高層與原創敵手不能只是等待主角展示能力。

他們應：

- 從前一次交手取得情報；
- 改進血脈、因果與大道驗證；
- 研究分身與本尊的反噬；
- 利用劫會救人、封寒會正面破局、文奕尊重證據等性格；
- 製造真假情報及互相矛盾的合理線索；
- 在失敗後保存倖存者、紀錄或制度反應。

每個主要對手至少要迫使主角放棄一次原方案。帝族嫡系、禁都核心人物與超大篇敵手不得一招崩潰。

## 7. 主角是劫，但世界不只為劫存在

劫必須保持敘事核心；其他角色也要有即使劫不在場仍會作出的選擇。

篇章多數以兩至四名人物為宜，不強迫群像大集合。其他熟人可以不知道、在別處執行任務、選擇不參與或事後才知道；但不能在情理上應該受到影響時完全沒有反應。

配角不得只負責驚嘆、吐槽或收拾殘局。同一人物也不能永遠扮演同一功能：青璃不總是阻止，文奕不總是收尾，洛生衣不總是治傷，封寒不總是打架，三伴星不總是服從。

## 8. 關係本身要能生出故事

- 劫與文奕：羅蘋與福爾摩斯式追逐；劫固定設局與犯規，文奕固定追索與還原真相。
- 劫與瘋：從怪問題、生活事故與共同驗證生出修真冒險，讀者期待他們又會搞出什麼。
- 劫與荒：兩種主角道路短暫碰撞，彼此理解但不取代對方。
- 劫與三伴星：同行建立在自主選擇、拒絕權與共同承擔，不是收服。
- 青璃、封寒、文奕等人：有與劫交會的故事，也有未必完整演出、卻會留下變化的個人道路。

關係進展必須經歷共同決定、誤判、代價、拒絕、修正與記憶，不能用「從此互相信任」直接宣布。

## 9. 每個大篇都需要一個不能靠打贏解決的問題

禁都的問題不是誰戰力更強，而是該保存吃人的傳承，還是摧毀它連同歷史一起消失。

異域拆王的問題不是能否殺王，而是救荒、破壞戰爭通道、封寒承接王道與劫承擔追殺是否值得。

青璃的問題不是能否打敗純血天驕，而是她是否仍要用純血制定的標準證明自己。

未來新大篇必須先寫出其核心兩難。若答案只是「變得更強便能解決」，尚不足以成為《劫》的招牌篇章。

## 10. 原作交會必須增厚世界，而不是借名場面抬高原創角色

原作人物、敵手、機緣與功業不得變成替劫背書的工具。

與荒交會時，劫可以分擔另一條責任、傳遞情報、拆除原創危機或與荒形成思想映照；不能替荒完成仙古第一、以身為種、帝關核心戰績、異域脫身或終極功業。

所有原作交會在正式寫作前都要核對時間、境界、位置、知情範圍與不可改寫事件。窗口未核實時只能標為提案。

## 11. 風格基準提案：〈無歸城〉

〈無歸城〉目前僅作創作精神示範，不自動升格為canon。

故事從一封延遲多年的求援信開始。劫與文奕找到一座每天重演覆滅前最後一日、仍在等待昨日援軍的古城。劫試圖偷走城市的「昨日」，文奕則追查誰在修改古城禁制，最後發現整座循環不是為保存居民，而是在永無止境地審問一個根本不存在的叛徒。

真正真相是：援軍遭污染，開門者只是遵守了正確軍令；城破發生在所有人都盡責的情況下。建立循環的人不願接受制度本身可能失敗，寧可讓全城每天重死一次，也要找出一名有罪者。

解法不能只是打碎禁制：劫偷走重啟昨日的核心，文奕把最後循環改成不再審問死者的活禁記錄；封寒若短暫介入，只負責在黃昏前打碎那扇被規定必須遭敵人攻破的城門。結尾以老闆第一次煮出難吃的麵，證明今天不再重複昨日。

此提案之所以作為風格基準，是因為它同時具備：

- 生活小事進入世界級問題；
- 劫與文奕固定關係定位；
- 制度有效卻仍可能有罪；
- 非戰力型核心兩難；
- 少數人物聚焦而世界仍有人生活；
- 早期日常物件完成情感收束；
- 可置於原創支區，不需挪用荒的原作功業。

未來 agent 可以創造完全不同的事件，但應追求同等程度的因果、人物、生活、修真、兩難與回收密度；不得機械複製無歸城的循環、失憶或古城外形。

## 12. 新大篇立項門檻

任何 agent 提議新的A級或B級大篇前，必須提交：

1. 一句生活化入口。
2. 一個逐步擴大的異常。
3. 劫為何不可被其他人替代。
4. 一至三名最自然的同行者，以及其獨立目的。
5. 一個不能靠戰力直接解決的兩難。
6. 至少一名會學習與反制的對手。
7. 三項早期可在後段回收的物件、台詞、技術或失敗。
8. 勝利後的永久代價。
9. 對下一篇留下的因果接口。
10. 對應《完美世界》原作節點與安全空間。

缺少其中任何關鍵項，不得僅憑「場面很大」「敵人很強」升格為招牌篇章。

# 十四、大PM／全書總控 Agent

> **未來啟動多-agent寫書時，必須先指定一個大PM／全書總控 agent。其他 agent 可以負責發想、拆章、正文、戰鬥、人物或canon，但只有大PM能確認故事放在哪裡、需要寫多長、與前後篇如何銜接，以及是否升格為正式canon。**

多-agent不是多人各寫一段再拼接。大PM必須持續掌握整本書的時間、人物狀態、情緒節奏、伏筆成熟度與敘事重心，避免單篇各自精彩、連起來卻像不同小說。

## 1. 大PM的核心責任

- 維護全書主時間線與《完美世界》原作節點。
- 決定每個故事屬於A／B／C／D哪一級呈現。
- 決定故事應連續寫成N篇、拆散發酵、只寫代表場景，或完全留在設定台帳。
- 指定每段的主視角、核心關係、自然到場者與合理缺席者。
- 管理人物入場／離場狀態，包括境界、傷勢、能力、武器、物件、情報、承諾與關係。
- 管理伏筆何時埋、何時變形、何時回收，以及哪些暫時不能解釋。
- 防止新篇重複舊篇已經完成的人物課題。
- 防止支線搶走劫的主角重心或原作人物的核心功業。
- 統一不同agent產出的語氣、因果、章界與世界質感。
- 在每輪交叉審閱後決定修訂依賴順序，不能讓各agent同時按自己的理解重寫canon。

## 2. 不是每個故事都必須「有大意義」

全書需要不同重量的故事。

### 純生活片段

可以只讓人物可愛、熟悉、好笑或放鬆，例如金鐧砸穿桌子、三分身爭論、封寒與劫被自己做的活禁追逐。它們不必全部連到終局陰謀。

最低要求是：人物反應真實、不違反當下狀態，並讓關係或世界生活感增加一點。不要為了證明重要，硬把每張桌子都寫成不朽之王伏筆。

### 有局部意義的事件

完成一次小型關係移動、技術試驗、人物失誤或制度後果即可。它可能只影響後面三五章，不必跨越全書。

### 延遲發酵的伏筆

當下看似普通，隔數十章、數卷甚至更久才顯出作用。第一次出現時不能用作者口吻提示「此物日後極重要」，而要讓它先自然完成當下功能。

### 大篇主鏈

需要連續N篇才能完成壓力、嘗試、反制、轉折、代價與餘波。例如禁都、仙古煉鐧、異域拆王返本。不能為了章數切成重複追逐，也不能在高潮前突然跳去無關生活支線破壞張力。

大PM必須允許無深意的生活，也必須識別真正值得長期發酵的東西。全都無意義會鬆散；全都有終極意義則會顯得機械、世界像作者布置的機關。

## 3. 四種時間連接模式

### 模式A：連續N篇

適合單一危機持續升高、人物無法合理離場的大篇。每篇必須改變問題，不得只重複受困、追殺或辯論。

例如禁都進入後的封城、追查、互鬥、真分歧與活禁之城結局；異域拆王啟動後的拆解、暴露、假瘋、追殺、蛻變、返本與重逢。

### 模式B：不連續案件鏈

每一案能獨立成立，中間可隔時間與其他主線，但共享物件、手法、勢力或關係累積。

例如禁釘、缺頁、假劫與被偷走的名字逐步走向禁都。大PM要記錄每案留下什麼，下一案使用哪一項，不能只靠相同人物硬稱系列。

### 模式C：當下結束，後續才發酵

事件表面已結束，真正後果在較晚時期出現。

例如一次王族驗證留下異常雷痕，直到悟道茶會後才被因果追溯者找到；一份古人失敗紀錄多年後才在拆王推演中排除死路。

### 模式D：只留生活記憶

事件不服務陰謀或升級，只在人物之後的稱呼、習慣、笑話與相處中留下痕跡。它的價值是讓讀者相信角色共同生活過。

## 4. 場景轉場的連貫檢查

大PM在批准下一篇前必須回答：

1. 上一篇結束後，人物最自然會先做什麼？
2. 傷勢、資源、任務與情緒是否允許立刻進入新事件？
3. 新事件為何在此時找上這些人？
4. 前一篇的餘波是否至少在行為或環境中被承認？
5. 若時間跳躍，中間發生了什麼，正文需要寫、概述還是完全可省？
6. 讀者是否能感覺人物在章外仍繼續生活？
7. 轉換後的調性是刻意呼吸，還是無意中切斷張力？

如果新篇只能靠「某天突然收到任務」啟動，大PM應優先尋找更自然的接口：前案留下的物件、傷者、目擊者、制度回應、敵方反制、生活責任或人物主動選擇。

## 5. 全書節奏不能只有升高

大PM需要配置：

- 高壓連續篇；
- 中篇案件；
- 短冒險；
- 修煉與工作日常；
- 關係呼吸；
- 戰後餘波；
- 時間跳躍；
- 只留下結果的他人故事。

重大篇章之前要有足夠生活，使讀者知道角色可能失去什麼；重大篇章之後要有餘波，使代價不被下一次冒險沖掉。但呼吸篇不能機械地固定插在每場戰鬥後，而要依人物身體、情緒與世界局勢決定。

## 6. 大PM使用的三份總控台帳

### 因果與伏筆台帳

記錄事件起因、當下用途、留下物、預定或可能回收點、是否已變形、是否已完成。允許標記「無遠期回收，純生活記憶」。

### 人物狀態台帳

記錄每名人物在每一篇進出時的境界、傷勢、能力、武器、關係、知情、責任與目前最強欲望。沒有入場的人也要有合理去向，但不必在正文逐一報告。

### 篇章重量與節奏台帳

記錄A／B／C／D級、預計篇幅、連接模式、主視角、核心問題、情緒強度、前後呼吸與原作節點，防止連續數篇都使用同一種高潮或結尾。

## 7. 多-Agent交付規則

每個執行agent開始前，由大PM提供一份限定任務包：

- 原作時間座標；
- 入場與離場狀態；
- 本段必寫事件；
- 不可提前揭露事項；
- 可自由發揮範圍；
- 必須留下的後續接口；
- 不可改寫的角色與原作功業。

執行agent完成後不能自行宣布canon成立。大PM先檢查與前後篇是否自然，再交給不同agent做人物、因果、戰術、canon與讀者視角審閱；最後仍由大PM決定哪些修正採用、哪些只是局部偏好。

## 8. 大PM最終判準

> **故事不必每篇都指向終局，但每篇都必須像是發生在同一群人的同一生裡。**

讀者可以暫時不知道一件小事是否重要；真正不能接受的是人物在不同篇章忽然忘記自己受過的傷、做過的選擇、欠過的人情或已經學會的道理。

# 十五、人物成長連續性——心態、處事與關係不得重置

> **所有角色都會隨經歷成長。成長不只表現在境界、神通與武器，也必須改變他們怎麼理解問題、怎麼做決定、怎麼對待別人、怎麼承擔後果，以及哪些錯誤已經不會再用同一方式重犯。**

長篇最常見的失真之一，是角色在每個新篇都被寫回最初版本：劫永遠獨自承擔，封寒永遠只想冒險，文奕永遠只守規矩，青璃永遠只會阻止，洛生衣永遠只負責治傷。這種寫法會讓事件再多也沒有真正人生。

## 1. 成長必須追蹤的八個面向

### 核心認知

角色目前相信世界如何運作，哪些舊信念已經被打破，又形成了什麼尚未成熟的新答案。

### 決策順序

角色遇事時先看什麼：勝率、人命、規則、代價、退路、同伴意願、制度後果或自己的責任。成長應改變優先順序，而不只是讓答案變得更善良。

### 風險態度

角色願意讓誰承擔風險、何時會停、何時會求援，以及是否仍把自己的生命當成唯一可自由使用的資源。

### 對人方式

稱呼、解釋耐心、是否徵求同意、是否願意交代完整計畫、遇到拒絕時會說服、命令、隱瞞還是尊重。

### 錯誤模式

角色可以再次犯錯，但不能毫無理由用完全相同的方式重犯。若舊錯重現，必須因壓力更大、創傷觸發、資訊不同或角色明知故犯，並由正文承認這是回退。

### 能力使用倫理

角色不只學會更強的能力，也會形成何時不使用、對誰不能使用、使用前需要誰同意，以及使用後如何負責的邊界。

### 關係位置

同一對角色目前是陌生、試探、合作、交命、決裂、修復還是成熟同行。熟悉後的對話、沉默與衝突方式不能仍像初識。

### 自我敘事

角色如何稱呼自己、如何理解過去、是否仍需要外界承認，以及他認為自己正在成為什麼人。

## 2. 成長不是直線，也不是人格替換

人物可以回退、猶豫、嘴硬或在極端壓力下恢復舊習慣，但要符合三項：

1. 角色自己或熟人能察覺這次回退。
2. 回退有具體壓力、創傷或利益原因。
3. 後果不被當成第一次犯錯重新教一遍。

成長也不能把人物磨成同一種成熟好人。

- 劫成長後仍會設局、偷換與冒險，只是更願意交代接口、留下拒絕權並承認自己需要別人。
- 封寒成長後仍會追問、驗證與正面破局，只是不再把「有成功率」等同「值得做」，也會計算別人被迫承擔的代價。
- 文奕成長後仍尊重傳承與證據，不會突然變成第二個劫；他只是能分清尊重前人與服從掌權者並非同一件事。
- 青璃成長後仍冷、準確、自矜，不會突然變得熱情健談；她只是逐漸允許自己試錯、求助、承認不知道，也不再以主脈標準衡量自己。
- 洛生衣成長後仍願意救人，不會因學會設限便變冷漠；她會把停手權、醫療代價與照護者本身也納入救援。

## 3. 角色的「同一件事，不同階段做法」

大PM應為主要人物建立階段對照，檢查相似情境下的處理是否已改變。

### 劫面對高風險方案

- 早期：自己算、自己做，事後才讓人知道。
- 中期：準備退路，但仍可能替同行者決定是否承擔。
- 後期：公開代價、分配拒絕權、主動求援；若仍選擇獨自承擔，必須有無法轉嫁的具體理由。

### 封寒聽見「理論上可行」

- 早期：立刻問何時出發。
- 中期：先問錯在哪、如何驗證、誰會受影響。
- 後期：能反過來否決劫——成功率存在，但代價不值得。

### 文奕面對違規者

- 早期：先恢復規則，再調查原因。
- 中期：保留證據與退路，允許劫把局走到能證明真相的位置。
- 後期：必要時自己設計一場表面違規的局，但仍留下可被查證與追責的結構。

### 青璃面對主脈承認

- 早期：想用完美戰績換取資格。
- 中期：知道條件不公平，仍因旁支利益無法直接拒絕。
- 後期：建立替代制度，讓拒絕主脈不再等於拖整個旁支一起失去資源。

## 4. 關係成長也要改變場景語法

同一句話在不同階段應有不同重量。

「理論上可行」早期是劫給封寒的許可；中期是兩人的共同暗號；後期封寒已能自行完成推演，甚至反過來指出劫的方案不值得。

到了不朽之王前，必須完成最重要的一次反轉：劫提出完整拆王方案，問封寒能否做到；封寒算完所有節點、承接與代價後回答「……理論上可行」。這一句不能仍由劫說，否則兩人的關係會退回早期由劫替封寒確認答案的結構。

「不然？」第一次是劫回身救封寒；後來由封寒原句還回去，表示交命已經對等。

劫與文奕早期需要完整追查與證明；熟悉後，文奕可能從一處太刻意的錯誤便知道劫想讓他找到，但仍要查清劫這次是否值得信。

熟悉不能消滅衝突。真正成熟的關係，是雙方更清楚對方為何會做出自己反對的選擇，也更知道哪一條底線不能假裝沒看見。

## 5. 人物成長台帳格式

大PM除既有「人物狀態台帳」外，必須為主要人物逐篇記錄：

| 欄位 | 必記內容 |
| --- | --- |
| 進場心態 | 當下核心信念、恐懼、欲望與未解問題 |
| 既有教訓 | 已經付過代價、不能無故忘記的事 |
| 本篇選擇 | 在壓力下主動做出的關鍵決定 |
| 本篇錯誤 | 判斷錯在哪裡，角色是否知道 |
| 關係變化 | 對誰更信任、疏遠、愧疚、尊重或設下邊界 |
| 處事改變 | 下一次遇到類似情境會先做什麼不同的事 |
| 未完成成長 | 只理解但尚未做到，或只做到一次仍未穩定的部分 |
| 禁止回退 | 後續不得當成新課題重新學習的內容 |

「禁止回退」不是禁止角色犯錯，而是禁止作者忘記角色已經學過什麼。

## 6. 多-Agent任務包必須加入人物階段

大PM交付任務時，不能只寫人物性格標籤，例如「劫冷靜」「青璃高傲」「封寒瘋」「文奕守規矩」。這些標籤太粗，會令不同agent反覆寫早期版本。

任務包必須明列：

- 角色目前位於哪個成長階段；
- 已發生過哪些關鍵事件；
- 他已經不會再怎麼做；
- 他仍在哪些情況下可能回退；
- 與現場每名熟人的當前關係；
- 本篇允許推進哪一步，不能提前完成哪個未來里程碑。

## 7. 人物回歸時的最低要求

角色隔很久再次出場，不能只換境界和衣服。正文至少透過一至三個自然痕跡顯示他在章外活過：

- 處理問題的順序不同；
- 對舊稱呼或玩笑的反應改變；
- 身上有新傷、責任、習慣或同行者；
- 使用能力時多了一條限制或新的倫理；
- 對同一問題給出與上次不同、但仍像他的答案。

不必用長篇回憶解釋全部。讀者先看見變化，之後再依故事需要知道原因。

## 8. 人物成長驗收問題

每一個中篇或大篇完成後，大PM與人物審閱agent必須回答：

1. 角色在哪一個具體選擇上與進場前不同？
2. 這個改變由什麼事件與代價造成？
3. 後續哪一場戲會看見改變仍然存在？
4. 是否把成長只寫成角色自己說「我明白了」？
5. 是否為製造衝突，讓角色無故忘記已學會的事？
6. 是否把不同人物都寫成同一套成熟價值觀？
7. 關係變化是否同時改變稱呼、信任、分工或衝突方式？
8. 本篇留下的是完成的成長、剛開始的理解，還是尚會反覆的傷口？

人物真正的連續性不是永遠做對，而是：

> **今天的錯誤，必須帶著昨天留下的傷、已經學會的事，以及他現在仍然放不下的東西。**
