# 《劫》2026-09-14 修整版：封寒／瘋的完整進化線

> 本稿整合今日全部封寒討論，並依重新核對 GitHub 後修正「書院歸屬、荒一劫二、寶庫資格」等資訊。屬作者工作稿；候選調整尚未直接覆蓋現行正文。

## 一、封寒的長期定位

封寒不能靠一次「拆王」突然追上陸沉。劫走了很久才成為現在的劫，瘋也必須有大量小故事、失敗、試驗、獨立機緣與少數真正的大質變。

但封寒不是第二主角，不需要每一階都開專屬副本。採三種方式混合：

1. **大質變正式演出。**
2. **部分新用法在戰鬥中直接首次展示。**
3. **部分早期能力回收既有故事，事後才知道早已是大道雛形。**

## 二、坍縮大道骨架

保留現行骨架：

**勢→重→引→坍縮→奇點→黑洞→白洞→歸墟。**

但不要當成八次 RPG 升級。

### 第一時代：勢→重→引→坍縮
從劍修時代就開始。勢很早埋下；重、引逐漸改變他的戰鬥方法；坍縮是前期道路第一次真正成形。

### 第二時代：奇點→黑洞
坍縮壓到極致後產生奇點，進一步形成黑洞。黑洞是封寒第一個真正具有個人標誌的大質變。

### 第三時代：黑洞的漫長年代
黑洞不能很快升白洞。它應陪封寒走非常久，從吞力、吞術、吞空間／亂流，到拆解後吞法則碎片，甚至更後期觸及大道層攻擊。黑洞本身就有大量深化空間。

### 第四時代：白洞
白洞與黑洞必須隔很遠。它不是「黑洞反轉技能」，而是封寒多年後終於回答：**吞進去的東西去了哪裡？吞下去以後呢？**

### 第五時代：歸墟
黑白同源、吞吐閉環。應放極後期甚至仙王路；完成歸墟不是終點，而是歸墟之道真正開始。

## 三、為什麼最後不是劍

不能用「碰到劍砍不了的東西，所以棄劍」作唯一理由。封寒本來應是好的劍修；真正的分叉是他逐漸發現，自己的問題根本不是「怎麼斬得更好」。

問劍峰教他劍勢。別人研究如何以劍造勢，封寒卻開始研究「勢本身是什麼」：劍有勢、人有勢、山崩有勢、河流有勢、巨獸落地也有勢。

**其他劍修：以己之劍造勢。**  
**封寒：天地到處都有勢，為什麼不能直接借？**

之後他逐漸借勢、加重、牽引。劍仍在手裡，但真正讓他贏的越來越不是最後一斬。他會用劍身接、劍脊壓、劍柄撞、把劍當錨，越來越少依賴刃。

**不是突然棄劍，而是他的戰鬥方式一步步把「刃」淘汰掉。**

劍與鐧的哲學差異：

**劍：找一條線→切開。**  
**鐧：找一個點→壓下去。**

封寒最終道路是「萬勢匯於一點→坍縮→奇點」，所以鐧是大道自然選出的武器形狀。

問劍峰教他「問劍」，他最後真正問出的問題可以是：**「為什麼一定要是劍？」**

## 四、鐧應提早得到

封寒可以在太玄宗／較早歷練期就得到第一柄鐧，但它不是最終金鐧，也不是拿到就棄劍。

吸引他的不是神器品級，而是「沒有刃，卻能解決問題」。早期可形成很有辨識度的狀態：

**拔劍＝正常戰鬥。**  
**拿鐧＝封寒又想試怪方法。**

之後劍與鐧的使用重心逐漸反轉。

第一柄鐧一路被他修改：重量、長度、重心、握柄、材質、承載方式。陸沉可在某次故事以雷火協助重煉，但設計、選擇、試錯與大道都必須屬於封寒。

**劫的兵器是特殊生命歷程孕育；瘋的金鐧是自己一路試錯、改造、煉出來。**

這一方向可能需要修改 GitHub 現行「形態不固定兵胚、書院後才正式覺醒」的設定。

## 五、古界的功能

目前推薦：

**古界＝坍縮真正成形，奇點開始萌芽。**

「沒有面可砍」仍可保留，但不是棄劍唯一原因，而是長期分叉後的一次證明。封寒面對無面可斬之力，本能舉劍，最後自己放下劍，以勢、重、引去接、壓、聚，第一次真正完成坍縮。

**劍沒有輸，只是答案根本不需要劍。**

## 六、重新確認書院歸屬

GitHub 現行 `OUTLINE_TIANSHEN_ACADEMY.md` 已明確：封寒隨太玄宗另一批推薦弟子同期抵達**天神書院**。

因此現行版本不是「瘋去了不同書院」，而是：

**劫與瘋同在天神書院，但不同批次、不同宿舍、平時只偶爾碰面，各走自己的線。**

這個安排其實很適合今日方向：兩人不必黏在一起，卻能在重要節點自然交叉。

## 七、書院排位：新增「瘋第三」候選

GitHub 現行正文已明定：

**荒第一、劫第二。**

今日建議新增：

**瘋第三。**

推薦賽程之一：封寒在四強遇到荒。封寒以勢、重、引、鐧與坍縮系統把各種非常規答案丟給荒；荒則在戰鬥中一一適應、破解，最後擊敗封寒。這一戰讓瘋輸得有價值，也讓讀者先看見荒恐怖的臨戰適應。

之後荒與陸沉決賽，依排位規則荒勝，形成：

**第一荒、第二劫、第三瘋。**

這不是三人生死戰絕對排名，而是書院規則戰結果。

## 八、寶庫資格需要跟著第三名設定重修

現行正文 ch031 寫封寒「沒有名次，所以沒有寶庫資格，自己混進去」。如果正式採用「瘋第三」，這一段必須回修。

更推薦的新版本是：**封寒自己其實也有第三名對應的寶庫資格／區域，但他偏偏跑到陸沉所在的三品區或雜物區。**

理由不是貪獎勵，而是他聽說那裡有一件連管事都說不清年代、來歷、屬性的東西。

可以形成很封寒的對話：

陸沉：「你不是有自己的區？」  
封寒：「那邊的東西都有名字。」  
停一下。  
**「這邊這個沒有。」**

這比「沒資格所以偷進來」更能體現「凡我尚不知道答案之事，皆值得一試」。

具體寶庫分區與第一、二、三名資格仍需依世界觀規則重新設計，不能直接假定一品／二品／三品對應前三名。

## 九、書院寶庫不再是能力起點

現行 GitHub 把天煞痕寫成封寒第一次觸及坍縮、甚至勢→重的起點。若採今日完整成長線，這會太晚，也會讓異域前成熟黑洞變得過快。

建議重新定位：

**書院寶庫不是封寒第一次會坍縮，而是第一次被迫承認「自己的道已經不在刃上」。**

此前他已經有勢、重、引，古界也已有坍縮，鐧更早就存在。天煞痕只是把多年累積的事實擺到他面前，撕掉「我只是用劍方式比較怪」的自我解釋。

這樣 ch031～032 的戲劇功能可以保留，不必刪除，只需要改能力時間點與部分文字。

## 十、奇點與黑洞的位置

目前推薦：

- 太玄宗早期：勢雛形，仍是劍修。
- 太玄宗／早期歷練：取得第一柄不成熟的鐧，劍鐧並用。
- 三千州前後：重、引逐漸成熟。
- 古界：坍縮成形，奇點萌芽。
- 書院寶庫：道路認知轉折，正式承認自己的道不在刃上。
- 書院前中期：奇點成熟。
- **書院中後期：黑洞誕生並開始磨合。**
- 異域前：黑洞已有足夠成熟度。

黑洞不應拖到異域才出生，否則與八雷劫差距過大，也會讓黑洞→白洞太靠近。

## 十一、異域拆王重新定位

現行 GitHub 把拆王作為「坍縮→奇點」門檻。今日建議改成：

**拆王＝成熟黑洞第一次碰觸「法」。**

此前黑洞能吞力、攻擊、術法；遇到王蛻殘存權柄後第一次發現「吞不動」。

封寒的答案不是單純把黑洞做大，而是問：**為什麼吞不動？**

於是他逐層拆解殘存法則結構，把吞不下的東西拆成能處理的尺度，再吞。這才真正符合「拆王」之名。

它不是封寒唯一的大機緣，而是黑洞漫長進化史中第一次從力量層碰到法則層的重要里程碑。

## 十二、黑洞與白洞必須相隔很遠

異域後即使劫進入九雷、返本、命圖、萬劫雷身等巨大進化，封寒仍可長時間停留在「黑洞」這個名稱下，但黑洞本身持續深化。

這讓劫再次拉開；直到很後面封寒找到「出口」，白洞才作為另一場大質變出現。

白洞可考慮放在萬劫雷身附近或更後，但暫不鎖死。第十雷時代甚至可以仍是黑白並行、尚未真正歸墟。

## 十三、與劫的戰力波形

不要固定數字。

**早期：**兩人相近。  
**劫多雷／雷身高速成長：**劫拉開。  
**瘋坍縮／奇點：**逐步追近。  
**書院黑洞：**一次大追趕。  
**異域：**八雷劫 vs 成熟黑洞瘋，可站同一高階戰線，劫略強。  
**九雷／返本：**劫再次拉開。  
**白洞：**瘋再追近。  
**第十雷：**劫再拉開。  
**歸墟：**瘋完成另一場大追趕。

核心：**劫長期略強，但瘋從不被甩到無法並肩。**

## 十四、人格與大道同源

封寒不是無腦瘋子。他的核心是：**凡尚不知道答案之事，皆值得一試。** 他會先自己承擔第一筆代價，確認不是平白必死局，再邀別人一起看第二層。

大道問題可以一路演化：

- 「一定要斬嗎？」→ 從劍分叉。
- 「勢為什麼一定要自己造？」→ 勢。
- 「能不能讓它更重？」→ 重。
- 「能不能把不同力量拉到一起？」→ 引。
- 「一直壓會怎樣？」→ 坍縮／奇點。
- 「如果不擋，能不能吞？」→ 黑洞。
- 「吞下去以後呢？」→ 白洞。
- 「吞與吐真的需要分開嗎？」→ 歸墟。
