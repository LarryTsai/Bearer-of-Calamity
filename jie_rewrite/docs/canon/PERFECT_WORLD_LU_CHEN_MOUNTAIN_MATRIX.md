# 《完美世界》時間軸 × 陸沉主線山脈矩陣

版本：v1.0  
定位：在擴章、加角色、設計新事件以前，先確定陸沉沿《完美世界》時間線走過哪些大小山峰，以及每座山究竟改變了他什麼。

## 一、最高原則

1. **先有山，再有花草與動物。** 主角必須先有清楚的去處、阻力、選擇、代價與不可逆變化，配角與世界細節才沿途生長。
2. **原作事件是座標，不是必須參與的任務。** 陸沉可與荒同場、平行、承受餘波、只聞其名或完全缺席。
3. **荒的核心功業不可轉移。** 雙石之戰、七神死劫、仙古第一、以身為種、異域原始帝城後裔、安瀾與罪州、折仙咒後重起及終極黑暗等，仍由荒完成。
4. **每座主峰只回答一個人物問題。** 勝利和得寶不是山峰；一個人被迫改變判斷、關係或活法，才算翻過山。
5. **外部作品只借壓力結構。** 可研究《仙逆》《遮天》《光陰之外》的故事引擎，但不得搬用人物、名稱、具體場面、招式、台詞、謎底或事件排列。

## 二、判讀標記

### 參與方式

- **同場**：荒與劫面對同一大局，但必須承擔不同問題。
- **平行**：同一時間、不同戰場，彼此結果可造成餘波。
- **餘波**：陸沉只承受原作事件造成的世界變化。
- **聞名**：只從消息理解天下變化，不硬塞入現場。
- **缺席**：刻意保留原作孤獨性與功業完整性。
- **原創插入**：只填原作未覆蓋的時間、地域或責任。

### 山峰狀態

- **已成峰**：具備困境、選擇、代價、不可逆改變與後果。
- **需加固**：事件已存在，但人物問題或後果仍不夠完整。
- **缺峰**：時間軸經過了，陸沉卻沒有相應的人物考驗。
- **禁建**：此處不應另造陸沉高潮，以免奪取荒的功業。

## 六、目前真正缺少的山

按優先級排序：

1. **P0：異域完整法則主峰（PW-22）。** 不是再加一顆雷，而是讓完整大道、完整劫難、完整禁制共同拆掉陸沉所有外物，逼出雷禁肉身的閉合。
2. **P0：紀元戰爭公共責任主峰（PW-26）。** 從「我能殺多少」改成「我能讓多少人接得住彼此」。
3. **P1：上界社會主峰（PW-08～09）。** 陸沉必須曾因看不懂制度而敗，否則後期布局只像天生聰明。
4. **P1：三千州到九天的道路主峰（PW-14D～15）。** 不能從仙古結束直接剪到書院門口。
5. **P1：書院共同決策主峰（PW-16～18）。** 排位只能證明他能打，不能證明他的答案能成為別人的道路。
6. **P2：雙石至下界大劫前的小山（PW-05）。** 補一次「明明能走卻選擇留下」，為守太玄閣預埋人格因果。

## 七、擴寫與加角色的准入條件

任何新事件必須先回答：

1. 它位於哪一個 PW 節點？
2. 陸沉為何必須經歷，而不是換任何主角都成立？
3. 事件開始與結束時，他哪一點不可逆地不同？
4. 荒在同時期做什麼；哪項功業絕不可轉移？
5. 新角色代表哪一種道路、利益或情感壓力？移除後是否會使選擇變簡單？
6. 代價是否在三章以後仍存在？
7. 若借鑑其他作品，留下的是抽象壓力還是可辨認的換皮橋段？

未通過以上七問的內容，不進正文；它可能是花草，但還不是山路。

## 八、執行順序

1. 先逐章核 PW-15～PW-24 的原作先後，清除所有「待逐章核」硬風險。
2. 依本矩陣把現有 583 章標成已成峰、需加固、缺峰與禁建。
3. 先寫六座缺失／薄弱山峰的事件卡，確定起因、選擇、代價、不可逆變化與後果。
4. 再為每座山配置必要角色：引路者、同行者、競爭者、制度代表、受害者與後果承擔者。
5. 最後才進行章節擴寫；文字量只隨完整故事自然增長。
