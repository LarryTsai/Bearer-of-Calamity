# 無兵雷域・取得無兵白雷

> 狀態：正式事件 v1.0
> 時間：第九篇「命圖初成」前段，仙古兩座獨立雷境（玄寂神雷、玄黃界雷完整入圖）之後、天神書院追尋三刻瞬雷之前
> 機制唯一來源：`systems/SYSTEM_TEN_CALAMITY_THUNDERS.md` 六、二之一
> 正文落點：`novel/volume05/chapter003.md`～`chapter010.md`

## 一、定位

- 地點：無兵雷域，域心孕有空手本源，卻以雷意排斥一切可依賴外物——法器越強，承受雷擊越重；外放術法、護甲、符籙、陣盤與儲物法器會逐步失效。陸沉循雷跡主動追入，只有以本身走到域心者才能接觸並煉化雷種。
- 同行者：洛生衣。雷域切斷丹藥、法器、陣盤與外放生道後，她被困於崩塌雷層中，只能以自身生機暫時維持傷勢，不能替陸沉破域。
- 功能：陸沉在此以血肉承接、篩選並定形無兵雷域域心的外部白雷本源，取得第六雷空手；肉身不自行生雷，此地也不是十雷之外的新機緣。

## 二、經過

陸沉進入後，萬劫兵胎被壓制，外放雷法被撕散，《無相離身卷》的虛渡亦受空間雷壓限制。他只能以血肉承雷，使拳、掌、肘、膝和整副肉身成為雷路。骨、筋、血、脈反覆被擊穿並重鑄後，他才有資格接住域心本源，使外界空手雷種與自身肉身雷路完成煉化；雷種不是由體內憑空誕生。

肉身雷路的運轉原則是「骨承壓、筋傳力、血運雷、脈載劫」——雷不必先化成劍、矛或雷海，只要肉身接觸敵手，雷便能沿對方的發力結構逆入，打散肩、肘、腕與軀幹之間的力量傳遞，使敵人的攻勢由內崩散。故空手不是拒絕兵器，而是不再依靠兵器定義自己：身無一處不是兵，觸敵一寸皆可落劫。

此行與他同行的是洛生衣。她被困於崩塌雷層中，只能以自身生機暫時維持傷勢，不能替陸沉破域。陸沉因此沒有等待萬劫兵胎恢復，而是以血肉打穿雷域救她。洛生衣的存在提供必須立刻抵達域心的理由；本源來自雷域，承接與煉化仍由陸沉自身完成，不由她提供雷種或力量。

骨、筋、血、脈反覆被域心白雷擊穿並重鑄的過程，同步在肉身表層留下焦黑雷紋（「淬骨黑紋」）。它是外部本源進入肉身後反覆承壓、篩選與定形留下的傷痕，不是第二種黑雷，也不是肉身自行生雷；無兵雷域排斥的是可替代肉身承劫的器物與外放依賴，不排斥域心本源本身。

## 三、雷種誕生當下的能力邊界（本次收束，供後續章節銜接）

初成的空手難以留力，觸碰兵器、陣紋甚至同伴時都可能本能尋找結構弱點，陸沉自身也要承受同等反震；他必須重新學會如何觸碰與收力。**這場戲收尾時，陸沉尚不具備精準控制逆入範圍的能力**——他救出洛生衣依靠的是粗糙、危險、連自己都要承受反震的雛形爆發，不是可命名、可控的招式。收力與精度是他日後（見四、制勢指）經過大量實戰才逐步練出的成長弧線，此處不得提前兌現。

## 四、後續深化：制勢指（第十二篇「十凶血路」）

取得完整無兵白雷後，經第九篇命圖初成、第十篇天神書院、第十一篇帝關初戰等大量實戰磨練，陸沉逐步完成「重新學會觸碰與收力」的成長弧線。第十二篇「十凶血路」司天鑑死戰中，陸沉為了制服而非殺死已異變但仍保有人性的血祭殘煞倖存者（對抗司天鑑「尚未成災者也應處決」的立場），逼出空手的精度版本：逆入深度控制在使對方無法運力、但不傷及經脈根本，正式命名「**制勢指**」。

**安全閥（與天譴執譴資格的因果切割）**：
- 制勢指只解決「陸沉如何不殺地介入救人」這個戰鬥手段層面的問題，不是天譴執譴資格的替代條件或捷徑。
- 天譴必須由陸沉主動進入刑衡雷界、經問罪雷劫取得外部本源與自主執譴資格；司天鑑代天刑罰、聞硯與四十二人逐案因果是不可省略的考驗，不因制勢指成功便弱化。
- 司天鑑死戰的既定收尾——他因代天刑罰、業力反噬與承受被處決者因果而重創，並自主選擇相信陸沉一次、交出巡天令牌——不得被制勢指取代或稀釋；制勢指不用於直接制服司天鑑本人，只用於血祭殘煞倖存者。

## 五、安全閥（總則）

- 此地不孕育十雷之外的新雷種，空手仍是既定第六雷，不新增第十一種力量分支。
- 洛生衣在此不提供雷種、法則或力量，只提供「必須立刻破境」的敘事理由；她本體同樣承受外界風險，此地不能替她免除傷勢。
- 淬骨黑紋不是純粹的力量加成，是承壓與反震的傷痕；肉身劇烈承雷時隱隱作痛、該處皮肉較脆。
- 完整無兵白雷入圖瞬間與制勢指定型之間，必須保留足夠的實戰篇幅跨度（見四），不得在同一場戲內完成「完整取得」與「精準控制」兩個階段，避免代價與掌握的因果被模糊。
