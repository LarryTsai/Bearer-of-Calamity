# 血原巡獵區：斷生哨站與不補殺的門檻

## 二、洛生衣為何在此

洛生衣的獨立主線是追查散布上界的斷生節點——帝關側翼長期空間破裂、異域侵蝕，是最可能出現斷生節點的地帶之一。她因此以萬靈峰醫者身分正式介入戰地醫療，同時暗中持續查訪節點；醫者身分是掩護與並行任務，不是單純因為陸沉在帝關。此階段的調查僅止於「查訪、發現異常」，不得推進到揭露長生勢力抽取生機培養活體容器或蘇聽瀾師門真相的程度——那條深層真相留給十二篇與 `CHECKLIST_PENDING_DECISIONS.md` 第85題（洛生衣失蹤七日）。

此時陸沉與洛生衣物理上不同線：他在血原巡獵區執行既定戰役任務，她在自己的獨立調查點。

## 三、消息傳來

雷訊網有一套「尚安／需藥／勿來」暗語節律，是兩人長期建立的溝通系統。洛生衣所在哨站遭噬隙麾下一支潛伏死士小隊突襲——不是正面強攻，是慣用的假撤退／示弱戰術，先誘出護衛再回頭殺傷醫療點。訊號沒有傳來明確求救碼，只傳來一段異常中斷。對熟悉這套暗語規則的陸沉而言，沉默比任何一個碼都更接近他最怕的答案。

洛生衣本人未能自救——她的能力（生衣、續脈、觀生、留生一線）皆作用於他人，無自救先例。同行調查的助手以不完美的手法暫時穩住她的傷勢，配合她「留生一線」本身帶有的被動殘存特質，讓她維持在「穩住但未痊癒」的危重昏迷狀態，昏迷時間因此拉長，此刻無人能確認她是否會醒。

## 四、程序啟動又中斷

陸沉離隊前，讀者（與同行者）能先看到他一貫的戰術判斷開始運作——威脅評估、任務交接、退路思考。他自己打斷了這個程序：不是漏做，是清楚跳過。他戰前一貫會做的儀式（檢查地形、命線、確認無聲渡笛與萬劫兵胎分開收藏）此刻也被跳過或做得潦草。這是他放棄自己一定會做的判斷程序的第一個訊號，且是他自己清醒選擇的，不是失控看不見。

## 五、違反的不是訊問習慣，是「不補殺真心投降者」

血原巡獵區的日常戰法本來就是速戰速決、不拖戰、不留敵，不代表陸沉不做訊問——真正被violate的是 `CHARACTER_LU_CHEN.md` 十明文的具體規則：「對真心投降且不再構成威脅者不補殺；假降者一經判定不給第二次機會」。

噬隙麾下那支潛伏小隊的招牌戰術正是假撤退／示弱，陸沉平常必須、也有能力分辨真假，才能維持這條線不被敵人利用又不誤殺真心投降者。這一次，面對敵人再度祭出假撤退，陸沉不再嘗試分辨真假，直接視同威脅、一律不留——包含可能真心放下武器的人。

最後真正投降者名為卓赤，是北線第六暗樁的記骨人。他自行吐出毒牙、交出自毀與傳訊骨符，並通過鑑月查魂；死前只來得及留下「枯井，三橫一豎」與半句「你們的人裡有」。姓名與殘句必須進入後續傷室查問及問責記錄，使線索損失維持為可追溯的人與證詞，不退回無名敵兵的抽象代價。

這不是他殺紅眼看不見，而是一次清醒的門檻調整：他知道自己在放棄什麼——如果留一個活口查證，可能拖延、可能被反噬，他不願再賭一次「萬一是假的」；他選擇把「不補殺真心投降者」這條線整批調高成「一律不留」。手法仍維持一貫的乾淨俐落、不折磨，越界的是判斷範圍，不是殘忍方式。規模維持在「殲滅特定幾支潛伏小隊／暗樁」的量級，不誇大成大規模屠殺。

## 六、升級：驚動噬隙的上級指揮鏈

這波不篩選、不留活口的清算，規模與烈度驚動了噬隙本人或其上級指揮鏈——不是巧合式的「更強敵人剛好路過」，而是陸沉自己造成的因果：他打得太乾淨、太不留活口，逼得上級不能再用小股試探繼續觀望，必須親自出面止損或報復。

出手介入者境界維持在「比噬隙個人強一截、明顯低於或至多打平陸沉當前境界」，不得觸及異域年輕至尊等級——那個戲劇位置留給後續必要任務4與天譴截矛投矛者，不得挪用或提前透支。噬隙本人不在此戰死亡，仍是血原巡獵區既定戰役（必要任務2、3、5）的持續反派主體。

戰鬥不是乾淨反殺：陸沉必須靠既有雷種的代價機制才能解決——第五雷永久界痕從隱痛升級為戰鬥中期就開始影響行動與專注力（不可逆，留伏筆）；剎那式趕路以肉身遭時序撕裂為代價；空手連續處決觸發「難以留力、自身承受同等反震」，腕骨與經脈反震崩裂，戰後數日內無法運勁發力；雷身多線展開（封路截殺、斬傳訊者、本尊迎敵）後傷勢與痛苦一次性疊回本尊，至少一至兩身雷身熄滅、短期內無法再展開，且這次沒有戰場協同分攤代價，由他一人獨自承受。敵人重傷撤離，非確認擊殺，留下未查明的線索。

不留活口的代價不只是肉體：他永久失去了原本能指認上級指揮鏈全貌與後續陰謀的線索與人證，案子從此斷線，真相再也查不出——這是判斷代價，直接對應這場戲「破底線的是判斷範圍」這個定性。

## 七、事後

生理代價先於心理代價顯現：陸沉重傷需要休養數日，恢復期間才逐步出現心理迴避的動作細節——無聲渡笛長時間未被觸碰，拇指摩挲食指骨節的頻率增加，對戰前儀式的缺席，事後才被他自己意識到。不寫悔恨獨白，情緒透過行為細節呈現。

**問責**：他這次是擅離已授權的戰線任務，而非授權任務內的獨立處置，性質比周晏事件（`EVENT_TIANSHEN_ACADEMY_AMBUSH.md`）更重。王家／既有問責機制的懲罰力度須明顯高於周晏事件的「停權＋聯署審計」，且理由環環相扣（擅離職守＋重傷＋多日無法歸隊＋戰術真空），是代價鏈條的自然延伸，不是外加設定。他一如既往地平靜接受，不辯解、不要求理解或原諒。

情感盲點延伸：他不只可能隱瞞「自己做了什麼」，更根本的是——他在洛生衣昏迷、無法表態的狀態下，替她決定了她的仇要用什麼方式了結。這與他一貫「以為隱瞞是保護，卻剝奪對方選擇權」的情感盲點是同一個根，這次剝奪的是她對「自己的仇怎麼算」的話語權。他不會主動編故事掩蓋，也不會主動交代全部細節；被問到不撒謊，但不主動說。

## 八、洛生衣醒來

不建議「醒來」與「質問陸沉」發生在同一場戲的同一時間點。她剛脫離危重期，身體與神識都還在靠他人暫時撐住的狀態，此時直接進行精確冷靜的質詢，可信度會打折。她清醒時完全沒有第一手資訊——昏迷期間發生的一切只能透過旁人轉述。依她「相信生命應有延續機會，不代表罪責可以被免除」與周晏事件中先確認事實細節才下判斷的既有模式，她會先留一段自己穩定下來、主動蒐集旁人說法的過渡期（哪怕只是一兩天），再帶著蒐集完的事實走進與陸沉的對話。

對話中，她先查證細節（有沒有人試圖投降、有沒有非戰鬥人員被牽連、上級指揮鏈是否因此逃脫），再表態；不是單純心疼也不是單純譴責。生氣時不提高聲音，直呼「陸沉」全名——這是她既定的情緒標記。她不給出「完全正確」的背書，但也不是決裂式的譴責，可延伸她既有的台詞邏輯：「你總覺得留下是替所有人選的，但那是你替所有人選的，不是我們自己選的」——這次他替所有相關的人（包括她自己、包括那些死者）都做了決定，唯獨沒有人問過她的意見。

結尾不做乾淨和解——這是關係的一次後退，不必立刻修復，讓裂縫懸著。洛生衣應有自己延伸的獨立行動（例如去查證斷點、確認情報損失的實際後果），不只是對他情緒回應的被動角色，避免她淪為單純的「受害者兼裁判」。

正文具體落點：洛生衣保留兩人的四碼對令，但將自己的令牌切回公用醫療碼，暫停兩人私人「尚安／已歸」節律；「需藥」等公共救援功能仍可使用。這不是決裂或永久廢除，而是可被後文看見的關係後退。恢復私人節律必須由兩人後續共同事件重新建立，不得在換幕後默認自動恢復。

## 九、安全閥

- 不得出現燃身（第八雷）、天譴（第九雷）字樣或暗示性鋪墊——此刻陸沉手上只有第一～第七雷。
- 不得動用尚未歸位的赤翎；陸行烈尚未加入此階段，不應登場。
- 敵人上限：比噬隙個人強一截、明顯低於或至多打平陸沉當前境界，不得觸及異域年輕至尊等級，不得挪用留給天譴截矛投矛者的專屬空白名額（見 `EVENT_BORDER_RIFT_FRONT_CAMPAIGN.md` 九之3）。
- 噬隙本人不得在此戰死亡或被確認擊殺，須維持血原巡獵區既定戰役（必要任務2、3、5）的持續反派主體。
- 結局不得是乾淨反殺；本尊、雷身、界痕三者皆須有具體、可見、不可逆的代價。
- 陸沉的清算手法仍須乾淨俐落、不折磨，越界的是判斷範圍（不補殺真心投降者這條規則），不是殘忍程度；不得寫成他喪失判斷能力或殺紅眼。
- 洛生衣的獨立調查（斷生節點）此階段只能停留在「查訪、發現異常」，不得推進到揭露長生勢力活體容器或蘇聽瀾真相的程度。
- 洛生衣重傷未死須有他人（非她本人）以不完美手法搶救的具體交代，不新增她自身從未出現過的自救神通。
- 不得讓洛生衣在此事件中只是單純的「受害觸發器」；她需有自己的判斷、選擇（例如查訪動機優先於自保）與事後的獨立行動。
- 王家／既有問責機制的懲罰力度須明顯高於周晏事件（`EVENT_TIANSHEN_ACADEMY_AMBUSH.md`），不得原地踏步。
- 此事件是一次性的破底線事件，不代表陸沉從此改變處事方式；後續章節不得將「不留活口」誤讀為他的新常態。
