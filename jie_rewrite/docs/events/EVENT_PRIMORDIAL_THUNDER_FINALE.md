# 事件設定：無始劫終局

狀態：現行事件設定 v1.0（回應 CHECKLIST 第 67 題）

## 觸發

終局殘缺秩序依「找出災劫因果鏈起點並先行抹除」的規則運作。它不是有意志的誘惑者，而是在對抗中具體展示一條可能性：抹除沉雷谷滅族夜，便可連帶消去其後大量苦難。

陸沉同時看見代價：洛生衣、太玄宗、四伴星以及一路形成的真實關係也會成為從未發生。他拒絕用乾淨假設替換有傷痕的現在，沒有真正啟動重置；拒絕之後，無始才成種。

## 劫序

十雷歸源形成「劫序」，它是陸沉自成的承劫秩序，不是凡道十四階之上的新境界，也不使他追平或超越荒的至尊及後續原作道路。陸沉最後拒絕獨自化為永恆天道工具，將承劫方法開放給願意共同承擔者。

第十雷形成後，太古星天圖第一次以十雷全星位短暫完整展開，覆蓋的只是一城或一段戰線，戰後立即崩解、枯竭或回收，不成永久神國。終戰殘留中確有一批無法立刻消解的污雷與破碎法則，但固定的萬劫沉封域只能在戰後清點、共管制度成立後另行建造，不能倒過來成為本戰的無限後勤。

## 安全閥

- 無始不能復活死者、任意回溯或重置世界。
- 荒與同伴只能證明當下值得保留，不能替陸沉作出選擇。
- 殘缺秩序屬陸沉獨立終局對手，不挪用荒的原作終極敵手與功業。
