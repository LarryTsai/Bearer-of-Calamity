# 死寂雷域、無聲雷池與定疆雷界：玄衡同行

狀態：現行事件設定 v2.0（2026-08-02 來源裁示）

| --- | --- |
| 前置事件 | 陸沉墜入仙古死寂雷域，玄衡誤判他為災源；此地只提供需求、線索與關係轉折，不孕育十雷 |

## 二、死寂雷域：誤判與線索

Volume04 ch012～018中，陸沉為先送出俘虜而被動墜入死寂雷域。玄衡以四蹄鎮住四道界裂，受界壁深處「災源封殺令」長期薰染，看見命圖未全、諸雷衝撞與龐大厄命後，誤判陸沉就是新災源。

劫厄自主跨層追入，承受空間碎刃、鱗裂與斷角，替陸沉爭取辨明災域節律的時間。陸沉沒有奪取玄衡力量，也沒有在現場煉成歸寂；他只以既有諸雷和萬雷禁限流，讓部分失序暫時沉下，證明自己願意承災而非擴災。

四裂仍須由玄衡外鎮、陸沉作臨時界樁逐一固定。兩界撕扯在陸沉背部留下永久黑金界痕。這次救界產生的是鎮界需求與界樁雷跡，不是鎮界雷胚；界壁殘雷、玄衡與臨時界樁經歷都不能自行孕出鎮界。

玄衡因此停止敵對、協助拔除劫厄胸前碎刃，並暫時同行。牠尚未因勝負臣服，也沒有把魂印當獎賞交出。

## 三、無聲雷池：歸寂取得

離開災域前，陸沉辨出殘雷每九息出現一次並非「萬籟俱滅」的沉默：呼吸、魂念與草木仍各有節律，只有彼此撕扯的災亂被壓低。這道雷跡指向死寂域更深處、獨立存在的無聲雷池。

陸沉主動放棄較短離域路線，交換古戰場殘篇情報後追入雷池。池中保存歷代戰場未能說完的遺言與無聲雷獸，守關古鐘只提出「寂靜是否等於抹除」的問題，不提供雷種。

首次收服時，陸沉誤把歸寂當成消除所有聲音與意志，強壓遺言、呼吸和生機，遭雷池排斥。他改為逐一辨認仍該保留的節律，只讓死氣、怨念、詛咒與破碎法則之間的互相撕扯沉下。承受萬念回灌後，外部歸寂本源才自行認可、離池成種。

## 四、界樁雷池／定疆雷界：鎮界取得

歸寂只平息災亂，不能回答「世界應如何在移動中仍保持邊界」。陸沉循先前固定四裂留下的界樁雷跡，與玄衡一同主動進入更後方的定疆雷界。這裡不是死寂雷域的附帶房間，也不與無聲雷池共用孕床。

雷界由五座持續移動的界島、界紋藤與換界土金獸構成。舊史顯示，早期守界者曾把固定誤作永不移動，反而使遷徙生態大批死亡；現任界樁守衛與爭奪固定疆域的競爭者，分別迫使陸沉回答「守界」和「占界」的差別。

首次嘗試時，陸沉把五島全部釘死，令界紋藤斷裂、土金獸失去換界路線，鎮界本源拒絕他，永久界痕也再次崩裂。他停止追求絕對不動，改為守住五島彼此可辨認的相對位置、遷徙出口與回返座標，親身承受界島交錯的撕扯。外部鎮界本源由此認可並進入命圖。

取得不等於成熟。鎮界初期仍會自行固定傷勢、關節與錯誤位置，陸沉必須在復健和低強度運轉中反覆壓回；正文所寫十二步、十八步、右膝冷感、右肺牽痛與停走停雷，都是取得後的磨合代價，不是「雷胚正在界壁中長成」。

## 五、玄衡的自主歸位

玄衡全程以獨立真身守裂、辨路和保護遷徙生態。牠能提供經驗、反對方案或拒絕踩入地脈，卻不能替陸沉完成雷池考驗，更不是歸寂或鎮界本源。

陸沉取得鎮界、又拒絕把玄衡留作永久界樁後，玄衡才自主交出可解除魂印。魂印先留下麒麟星影；待命圖骨架足以承載伴星後，牠再自行踏入外環。此順序表明「取得外部雷種」與「生命選擇同行」是兩條互相關聯但不能合併的因果。

## 六、後續代價與能力邊界

- 永久界痕源於陸沉在死寂雷域作臨時界樁；跨界越多越易復發，歸寂與鎮界都不能無代價治癒。
- 歸寂只能沉下失序衝突，不能抹除生命節律、遺言或所有聲音。
- 鎮界守的是相對位置、邊界與回返座標，不是把活物、傷口或世界永遠釘死。
- 玄衡的鎮界天賦屬牠自身；陸沉的鎮界雷來自外部界樁雷池，兩者可配合但不互為來源。
