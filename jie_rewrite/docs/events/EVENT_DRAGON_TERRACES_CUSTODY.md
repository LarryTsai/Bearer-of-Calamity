# 昇龍台長線：揭露與實體保管

當前只落下界第一台及其後必要保管接縫。上界第二台待寫，仙界第三台與仙龍界內部依作者最新範圍後置。古龍界、五島古界、古世界路不因同名元素而合併。

## 已落第一件

首次取得：下界021〈昇龍台〉005〈石座裡的窄片〉。陸沉先完成本期首登、領普通禁材並觀正常演法，才查台側退役石座的可讀局部接縫；經台方驗取、留拓，取出唯一窄硬片。不是拆主陣核心，也不是完成第一段便因血脈被選中。

外觀：半掌長的黑褐窄硬片，上緣有缺口、下緣圓，一面細槽、另一面平。材質與年代未知，暫記「黑褐窄片／硬片」。不能混同父親線的石窟光滑斷片、半枚太玄令、祭杖碎片。

下界陸沉、羅衡、宋知微、閣老只知取得處與所見外觀，台方有留拓。羅衡猜過是舊器嵌片，並未識出用途。不知陽鑰、第二件、三台同源或仙龍界。沒有發光、力量、治傷、感應與導航；第一雷及跨界依原危機因果。
