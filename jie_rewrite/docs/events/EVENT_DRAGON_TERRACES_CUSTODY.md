# 昇龍台長線：揭露與實體保管

當前已落下界第一台、上界第二台及其間必要保管接縫。仙界第三台與仙龍界內部依作者最新範圍後置。古龍界、五島古界、古世界路不因同名元素而合併。

## 已落第一件

首次取得：下界021〈昇龍台〉005〈石座裡的窄片〉。陸沉先完成本期首登、領普通禁材並觀正常演法，才查台側退役石座的可讀局部接縫；經台方驗取、留拓，取出唯一窄硬片。不是拆主陣核心，也不是完成第一段便因血脈被選中。

外觀：半掌長的黑褐窄硬片，上緣有缺口、下緣圓，一面細槽、另一面平。材質與年代未知，暫記「黑褐窄片／硬片」。不能混同父親線的石窟光滑斷片、半枚太玄令、祭杖碎片。

下界陸沉、羅衡、宋知微、閣老只知取得處與所見外觀，台方有留拓。羅衡猜過是舊器嵌片，並未識出用途。不知陽鑰、第二件、三台同源或仙龍界。沒有發光、力量、治傷、感應與導航；第一雷及跨界依原危機因果。

## 上界第二件與首次共鳴

- 長息020出發：第三年接班後，陸沉將多年換衣時移縫的內袋布包帶在身上。第一件仍沉寂；封寒邀他看折嶺海，並非收到古物指引。
- 長息021～024：循古道與山勢各走自己的路，完成正常登頂與觀摩；沒有先用黑褐窄片解台、換取資格或提升能力。
- 長息025：實查退役旁座並獲允許後取得灰白弧片；完全離座後，黑褐窄片才首次反應。形制與近置同步槽痕提供同源成對的證據；分離即止。人物只知現象，不知古史、用途或第三台位置。
- 長息026：第一黑褐窄片由陸沉重新布裹收貼身內袋；第二灰白弧片交封寒實體收存。各持一件，後續不憑空送回陸沉身上，不新增魂藏或跨界傳訊。

## 尚待後續

抵仙界前若出現搜身、寄存、失物等實際情節，須延續兩位持有人的保管鏈；未發生的情節不預造事故。第三台先完成正常登頂、再揭用途，留後續作者閱讀進度，不以兩件古物代替本輪正常跨界資格。
