# 文奕下界、共同禁典與焚錨返程

> 狀態：作者已核准「一次性禁舟＋焚錨召回」方向。Volume01 ch011～013共同禁典及ch023～028百斷山再遇／焚錨返程已落正文；後續禁都、萬禁會與文家回收待建。

## 一、入場狀態

- 文奕比陸沉年長約一歲，出身上界文家。
- 約八歲時，只有尚未定道的文家幼修能被古錨承認；文奕不是被隨手犧牲，而是在候選中主動答應並通過選擇。文家以祖地祖禁與下界僅存古錨組成降階禁渡，把他真身送入下界。
- 隨行護道人不是第二名普通乘客，而是守錨人。他在出發前把高於下界上限的修為與祖器權能質押於文家祖禁；真身抵達後不能離開古錨範圍，只能提供知識、療傷、接應並在返程時穩住通道，不能代闖機緣或遠端介入下界主線。
- 界壓同時封住文奕大部分上界修為與祖器權能，使他保有正統訓練、結構直覺與實戰紀律，卻仍是缺乏野外求生、臨場犯規與離開正統答案經驗的孩子，不能以境界碾壓下界同代。

## 二、降階禁渡安全閥

- 下界古錨由文家先人在第二次禁道盛世末期、上下界尚未徹底錯層時預埋；它保存的是同一片天地被割裂前的因果對位，不是可重新測定的地理座標。
- 它不是公共界門，不連接古雷道、界海雷淵或陸沉後來意外進入的夾層虛空。
- 古錨只能完成一次降階與一次預設返渡，不能運兵、運送已定道或高境修士、臨時改目的地或由外人複製。
- 完整《古神禁典》入魂只作任務達標信標，不提供返程能量，也不因此增加傳承內容。

## 三、虛神界共同取得《古神禁典》

- 魔女與陸沉在殘殿共同逃生的既有事件完整保留；魔女不旁觀封典。
- 文奕從封禁古路另一入口進場。陸沉以九次試錯、傷勢記錄與可撤回路徑前進；文奕以正統結構、供能與權限判讀前進。兩人的方法各有盲區，不能由任何一人單獨完成最後解禁。
- 仙王殘識面對的是兩名共同解開最後古禁的人。他把自己補齊的同一部完整《古神禁典》，分別完整封入兩人內景。
- 兩份傳承不存在原本、副本、上下冊、缺頁或先後優先權。陸沉手中的實體第一頁只是進門鑰匙與早期可承載介面，不代表他多得一頁。
- 兩人當下都只能讀取極少部分。文奕的正統基礎使他讀得較穩，陸沉的求生試錯使他較早發現不按既有答案使用的可能；差異源於教育、人格與選擇，不源於傳承份量。

## 四、百斷山再遇與返程

- 百斷山時文奕約十一歲、陸沉約十歲。文奕只參與前段古禁結構判讀與另一批人的救援／自身任務，不能取代荒初見、魔女互救或天地雷火主高潮。
- 兩人能從對方留下的禁制習慣辨認彼此，第一次看見同一部典在不同道路上產生差異。
- 返航天窗在出發時已鎖定於百斷山後的一段有限時間。文奕與守錨人必須真人回到古錨，與上界祖禁同時應答才能啟動；錯過天窗便永遠滯留下界，不能在任意地點被隔空召回。
- 文奕必須在「留下或許能多幫陸沉一次」與「按時返回家族、帶回自己對禁典的理解」之間選擇。返渡啟動後，下界古錨自內向外焚毀，上界祖禁永久燒缺一角；守錨人返界後亦留下不可逆界傷，不能無損取回全部質押修為。
- 古錨焚毀時，天地分裂前的因果對位一併坍縮。如今若要重布下界端，必須先有人肉身抵達下界，形成先有通道才能布通道的閉環；故在現行天地與故事時間內，文家不能從上界單端重建同一路線。
- 因此文奕無法返回參與其後七神下界大劫。這是焚錨選擇的永久後果，不是他知道災難仍選擇缺席。

## 五、人物與後卷回報

- 文奕的護道人本輪不具名；其具體身分與返上界後命運留待文家篇需要時再定，不得提前搶走文奕的選擇。
- 文家祖禁缺角會在日後文家遭難時成為真實防禦缺口，但不能寫成「當年送文奕下界所以家族必然滅亡」的單一懲罰因果；敵方仍須有長期研究、內應或盟友退縮等獨立成因。
- 文奕返界後長年參與設計替代節點維持祖禁缺角，成為他重視備援與輪換的切身根源；日後敵人必須掌握替代節點輪換窗口，並結合資源斷供、盟友退縮及外部圍攻，才可能把缺角推成死局。
- 仙王封典與兩人的神魂及理解層級綁定，只能由本人逐層讀開。文奕可分享自己理解出的內容，文家不能以搜魂或抄錄把整部禁典立即變成公共財。
- 文奕返上界後不能立即與陸沉保持跨界聯絡。兩人下一次正式重逢須由上界禁都／萬禁會篇完成。

## 六、正文驗收

- 讀者可由行動而非旁白確認兩人缺一不可。
- 兩份完整禁典的等同性沒有任何模糊措辭。
- 文奕有獨立目標、判錯與代價，不是仙王安排給陸沉的解題助手。
- 魔女、荒與陸沉既有功業不被文奕挪走。
- 焚錨返程同時完成離別、世界安全閥及下界大劫缺席理由。
- 不提前展示成熟活禁、禁陣網、雷種或上界高境能力。
