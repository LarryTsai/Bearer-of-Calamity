# 事件設定：剎那雙戰場

狀態：現行事件設定 v1.0（回應 CHECKLIST 第 66 題）

## 定位

- 時間：T13、PW-18B 原創插入點。
- 四級銜接：平行；不得取代荒在書院後期的原作事件。
- 核心：正面戰場是佯攻，真正目標是書院外圍撤離據點的傷者、人證與傳承。
- 關鍵人物：顧小滿駐守第二戰場，回收她早年所教「快不只是速度，是節奏差」。

## 經過與代價

陸沉先在正面戰場應敵，察覺第二處才是真正目標時，正常移動已來不及。他強行催熟剎那雛形，以肉身承受時序撕裂，將「抵達所需時間」壓縮到一瞬。

他救下兩處當時仍活著的人，包括顧小滿，卻不能倒流時間。第二處據點、撤離陣及部分傳承已永久毀滅；剎那只能提前抵達，不能改寫抵達前已發生的結果。

## 安全閥

- 不把剎那寫成時間停止、回溯或免費瞬移。
- 顧小滿是事件的獨立守備者與思想前因，不是等待陸沉救援的工具。
- 正面戰場的原作人物與勝負不因本事件改寫。

## 正文落實

- Volume06 ch041～044完成正面真傷亡、天隙關真目標、顧小滿自主守撤與陸沉首次正式發出「需人」。
- ch045由六站回報時刻、方位與通路，陸沉只使用自身巡站雷痕、命圖道標及肉身承受時序撕裂，完整形成剎那；六站沒有遠端供雷。
- ch046～048保留天隙關、撤離陣、一名人證及部分裂隙監測傳承永久損失；一月後仍只維持六站輪值，第七格列為待查。
