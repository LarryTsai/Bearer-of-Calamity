## 經過與代價（v1.1 更新，2026-08-02 依實際正文回填）

剎那本源（三刻瞬雷）的取得不是雙戰場當下臨時催熟，而是陸沉先在ch044～045循三粒銀砂明滅間隔、百七十三年前戰報與崖腹鐘痕定位三刻雷池，主動穿門追入；第一次嘗試在第二池被候鐘者掃出，右臂錯齡、左腿受創，銀砂燒毀一粒，付出明確失敗代價。第七日陸沉主動二次追入，經歷候鐘者交代的雷池歷史、王家旁支競爭者強闖身亡的前例，以晨／息／暮三段節奏承受錯序雷劫（右臂先老、左腿退回幼時、神魂被拉向未發生的一息），才在ch046完整取得本源，命名第七雷位為「剎那」。取得後仍不能連續長距離踏行，直到ch050才完成域外首次長距離使用，代價仍留在肉身（淬骨黑紋裂血）。（2026-09-24章號更新：依RC-V06與書院寶庫插入後現行編號，定位ch044～045、取得ch046、首次長距離使用ch050）

雙戰場天隙關事件發生在剎那本源已取得之後（第四週），是取得後的應用場景而非取雷的觸發原因——陸沉先在正面戰場應敵，察覺第二處才是真正目標時，以已取得的剎那本源提前抵達，仍不能倒流時間；他救下兩處當時仍活著的人，包括顧小滿，但第二處據點、撤離陣及部分傳承已永久毀滅。

## 安全閥

- 剎那的取得須是完整的主動追索故事（舊缺口、雷跡、主動啟程、雷境歷史與生態、守關者／競爭者、首次收服失敗、承受劫難、取得、磨合代價、離場改變），不得由雙戰場事件憑空催熟或速成。
- 不把剎那寫成時間停止、回溯或免費瞬移；只能提前抵達，不能改寫抵達前已發生的結果。
- 顧小滿是事件的獨立守備者與思想前因，不是等待陸沉救援的工具。
- 正面戰場的原作人物與勝負不因本事件改寫。
