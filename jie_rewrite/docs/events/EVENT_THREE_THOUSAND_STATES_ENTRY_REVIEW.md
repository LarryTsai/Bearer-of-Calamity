# 三千州前夜：榜上沒有名字的人

> 狀態：Volume03 正文已落筆
> 正文章節：`novel/volume03/chapter001.md`～`chapter003.md`
> 來源：`CHECKLIST_PENDING_DECISIONS.md` 第81題

## 一、事件定位

- 時間：三千州天才戰報名前夕，Volume02卷末約一月後。
- 地點：道天界十二峰界舟放榜處與道天盟審錄臺。
- 功能：在天才戰正式開場前展示名額與宗門資源差距；由洛生衣主導查證，陸沉只承擔是否完整公開的選擇。

## 二、人物

- 唐野：道天界散修，六年整理遴選戰冊，東區遴選第七；原有名額被方家與玄曜宮經手者換走。
- 方策：方家子弟，知道家族替自己補了一個傷退空位，但直到重審前不知道受害者是唐野，也不知道傷退說法為假。
- 祝湛：赤霞州參試者，只存在於情報與既往戰冊；第三次換氣後火勁走滿肺腑，可能對右側有舊傷者造成致命重創。

## 三、完整因果

1. 唐野的第七十二位被方策取代；界舟載重沒有真正縮減，只以少帶法器箱騰出一人位置。
2. 唐野把六年整理的十七本對手情報交給陸沉，期待情報仍能進三千州。
3. 他在方策對祝湛的戰術中故意藏入一行錯誤，企圖讓方策等到第三次換氣後才出手。
4. 洛生衣以情報內部記錄、遴選醫務藥材消耗與傷退數交叉比對，確認該行會把方策推向不可控重傷。
5. 陸沉把名額交易與惡意情報一併公開，不替任何一方隱瞞。

## 四、結果與後續

- 方策此次名額取消；唐野因惡意情報不得遞補。
- 空位依原排名由未涉交易的東區第八名補入。
- 玄曜宮三名經手執事停職待查；載重卷與名額異動往後須在放榜前公開。
- 唐野仍未能進三千州。十七本情報由太玄宗帶入，但所有內容須先驗證；假情報頁被移除。
- 唐野、方策本段後不隨隊進三千州，不在第七篇立即反覆出場。
