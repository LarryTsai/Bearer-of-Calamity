# 第一次被稱作「劫禁區」的戰場

> 狀態：正式事件 v1.0
> 時間：PW-23D 第九雷補全後

## 一、形成

一場撤離戰中，陸沉預先鋪設戰雷母池、承雷樁、鎮界錨與雷訊短碼節點，再將太古星天圖投影於其上。九雷星位只亮九處，尚無第十雷；領域目標不是困殺全軍，而是守住撤離廊道並阻止追兵把殺劫轉嫁給傷兵。

異域軍士入內後逐步發現：傳訊延遲、裂界退路遭鎮住、元神遁逃被壓、替死印與復生標記不能跨過天譴星位。一名倖存者回報：「那一帶已成了劫的禁區。」稱號由敵軍傳開，旁白仍稱其為太古星天圖展開區。

## 二、禁區並非必勝

敵方沒有踏入即死，而是以遠程異質法則污染兩座承雷樁，逼玄衡離開主錨，再從三處同時進攻。雷訊網先斷、戰雷母池隨後倒灌，領域出現缺口。

陸沉必須放棄一條已蓄滿雷力的支線，讓雷身回歸承受反噬，再以本尊堵住缺口。撤離者得救，但外圍據點與半張戰雷池網永久報廢；敵軍也有一支成功撤出，證明「劫禁區」不是自動處刑領域。

## 三、荒的驗證

戰後荒曾從最難守的裂口正面踏入，連破數個節點，逼陸沉親自迎戰。他因此確認：完整預鋪時劫擅長拖長、封路、調度與收尾，但荒仍能靠正面爆發破開局部星位。

> 荒：「所以這就是他們說的禁區？」
>
> 劫：「名字是逃出去的人取的。」
>
> 荒：「能逃出去，就還不算禁區。」
>
> 劫：「本來就不是。」

## 四、安全閥

- 此時只有九雷星位，第十雷不得提前亮起。
- 不改名義境界，也不轉移荒的正面功業。
- 雷池網不生能量，雷訊網不傳殺招；異質污染可破壞兩者。
- 天譴只限制已具罪證或正在落下的殺劫，不自動審判所有入域者。
- 「劫禁區」僅為戰場俗稱，不登記為生命禁區或固定地理。
