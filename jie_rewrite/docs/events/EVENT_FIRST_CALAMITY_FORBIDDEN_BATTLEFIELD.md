# 第一次被稱作「劫禁區」的戰場

> 狀態：正式事件 v1.2（Volume09 ch041～048 已落筆）
> 時間：PW-23D 第九雷補全後

## 一、形成

一場撤離戰中，陸沉預先鋪設戰雷母池、承雷樁、鎮界錨與雷訊短碼節點，再將太古星天圖投影於其上。九雷星位只亮九處，尚無第十雷；領域目標不是困殺全軍，而是守住撤離廊道並阻止追兵把殺劫轉嫁給傷兵。

異域軍士入內後逐步發現：追索雷矛會被承雷樁引開、外放術法受歸寂壓制、魂刺受鎮魄震散、已投出的轉嫁殺劫會被天譴拆掉。領隊骨羅以俘虜試探天譴邊界，撤退時又用灰鏡碎片誘追；他在二十三人中帶十一人自行撤出、另拖回兩名重傷者，回報：「那裡不能硬闖……劫禁區。」稱號由敵軍生還者傳開；正式軍籍仍登記為「九星撤離域」。骨羅帶走「陸沉必先守有人撤離的缺口」這項情報，陸沉也從其撤退次序預判下一次的真假缺口戰術。

## 二、禁區並非必勝

敵方沒有踏入即死，而是以灰骨鏡沿泄力紋直接污染第一座承雷樁，逼玄衡自行離開主錨、拔樁出域；污染另藏進母池接過的舊雷，使第二樁冒煙、第三樁開裂。雷訊網先錯碼再斷，戰雷母池隨後倒灌，領域出現缺口。

老旗兵魏成左手缺少食、中兩指，十年前曾在同一條谷經歷斷訊撤離；他否決骨坑上的母池初址，要求四色旗同時具備不同輪廓與三段人數回報。雷訊斷裂後，魏成以實體旗和多人複誦接管撤離。陸沉必須放棄一條已蓄滿雷力、卻位於四十七名傷兵腳下的支線，讓兩具受損雷身回歸承受反噬，再以本尊堵住缺口。兩百一十三名傷兵撤離，守線者死五人；敵軍十三人活著撤出、四俘、六死，證明「劫禁區」不是自動處刑領域。三樁僅一座可用、鎮界錨僅餘一枚、西支雷路永久熄滅、母池污染封存，半張戰雷池網永久報廢。

## 三、荒的驗證

戰後荒曾從最難守的裂口正面踏入，連破數個節點，逼陸沉親自迎戰。實測因污染母池裂開、撤離路仍有人而中止，不登記為正式戰平：荒在肉身正撞、尚未使用完整殺式與繼續破域能力上明確握有主動；陸沉證明的是殘域能迫使荒改招，並在兩次模型失敗後仍重排守住撤離界線。完整預鋪時劫擅長拖長、封路、調度與收尾，荒則仍能靠正面爆發破開局部星位。

> 荒：「所以這就是他們說的禁區？」
>
> 劫：「名字是逃出去的人取的。」
>
> 荒：「能逃出去，就還不算禁區。」
>
> 劫：「本來就不是。」

## 四、安全閥

- 此時只有九雷星位，第十雷不得提前亮起。
- 不改名義境界，也不轉移荒的正面功業。
- 雷池網不生能量，雷訊網不傳殺招；異質污染可破壞兩者。
- 天譴只限制已具罪證或正在落下的殺劫，不自動審判所有入域者。
- 「劫禁區」僅為戰場俗稱，不登記為生命禁區或固定地理。
- 荒劫實測中止不等於正式平手；不得以撤離目標達成偷換正面勝負，荒保留肉身與繼續破域優勢。
