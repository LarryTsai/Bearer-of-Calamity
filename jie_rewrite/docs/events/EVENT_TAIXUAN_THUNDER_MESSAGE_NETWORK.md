# 太玄雷訊網試行事件

> 狀態：正式事件設定 v1.0

## 起因

本尊、第一雷身與承身雷白日分處不同地方修行，夜裡回到小閣，常須補齊當日見聞。劫因此先在夜間集合與近域工作時，試作一對只能短距離傳數句話、尚不能跨峰的雷訊令。真正促使他發展第二代七峰網的，是太玄七峰相隔甚遠：遇上傷患或警訊時，最快的人未必來得及跨峰。

劫提出雷律和定址構想，太玄陣法、煉器弟子把原型拆成可維護部件；洛生衣要求加入傷勢碼、求救優先級及神魂衰弱者的安全上限。

## 秘密原型

第一批對令在小閣與萬年雷池間封閉測試。公開紀錄只記作鎮岳峰、煉器與陣法小組共同試作，不公開本尊與雷身分工。

- 本尊校準訊息內容與雷序。
- 第一雷身刻錄高精度雷紋。
- 承身雷刻意製造衝擊與雜訊，測試反噬。
- 洛生衣以受傷、氣息不穩等情境測試求救能否送達。

萬年雷池只短暫供應測試能源；公開後，雷訊臺改由峰陣、靈石與地脈供能。

## 七峰試行事故

七峰同日測試時，多峰弟子同時傳訊，總臺出現延遲與串音。一道真正求救被誤當成演練訊息，直到第二次求救才被辨認。

劫趕到現場救下重傷者，卻沒保住被毀陣基與全部物資。眾人由此明白：讓聲音抵達，不代表事情已經解決。

事故後新增：

- 災害、軍情、醫療、日常四級優先序。
- 求救由鄰近節點覆核，但不得因等待覆核壓住首報。
- 過載熔斷、分段隔離與只收不發模式。
- 軍令雙印、訊息時刻印、失竊令牌黑冊。
- 值守弟子輪班與節點定期檢修。

## 後續

太玄七峰網成為第一個穩定網路。日常上，它讓弟子報平安、約定換班、通知煉器房領料；危急時，讓最靠近的人先行救援。

其後才逐步發展成三千道州中繼網和帝關軍訊網。每次擴張都須實際鋪設節點，並伴隨截聽、反定位、斷網與維護成本，不能一夜覆蓋天下。
