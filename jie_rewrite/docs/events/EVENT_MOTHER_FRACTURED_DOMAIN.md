## 二、與父親線的對照（不可重複）

父母二人的困境刻意設計成不同形式，正文須保持這個區隔，不寫成同一種橋段的重複：

- **父親**：部分肉身已與古雷道結構同化，是「物」的層面被困——強行拔除會使古雷道崩潰，救援的核心動作是物理上的分離。
- **母親**：以自身道行主動維持斷裂道域局部不再繼續崩解，是「意志」的層面在支撐——她不是被關住，而是選擇留下承擔這個責任；救援的核心動作不是分離，而是替換承擔者，讓她獲得可以安心放手的條件。

## 三、事件經過

### 1. 殘缺座標

陸沉先從自己持有的單半令讀出模糊路標，自行尋到斷裂道域外圍；另一半令仍在洛清禾手中，直到兩令隔界共鳴、短暫合令後才顯出精確入口（見 `systems/SYSTEM_TAIXUAN_OLD_TOKEN.md` 二）。他仍須修復通道並承擔風險，正文不得寫成在遠處先合令後立刻抵達。

### 2. 道域現狀

陸沉抵達時看見的不是一個等待救援的囚徒，而是一處仍在緩慢崩解、卻被一股穩定道行硬撐住的破碎空間。洛清禾常年維持這個支撐，容貌與體態早已不是他從老族長轉述中拼湊出的年輕模樣。

她第一眼認出陸沉，不是靠血脈感應，而是他身上帶著太玄舊令另一半的命印共鳴——這一點呼應 `systems/SYSTEM_TAIXUAN_OLD_TOKEN.md` 三「合令」機制。

### 3. 替代承載結構

洛清禾不會因為兒子到來就立刻放手——她比誰都清楚，一旦支撐撤走，道域會加速崩解，波及範圍未知。陸沉必須先建立替代承載結構：死寂雷域作臨時界樁的經歷教他承受兩個空間的撕裂，定疆雷界的外部鎮界本源則讓他學會守住可變邊界與回返座標（見 `systems/SYSTEM_TEN_CALAMITY_THUNDERS.md` 七）。這次他要把兩者轉化成母親離開後仍能持續運作的結構，而不是再次讓自己成為永久界樁。

正文落地時，第一張命圖雖能運轉，卻暗中把陸沉寫成無期限的活節點，被洛清禾否決。第二案才改為二十七枚可替換短樁、三班巡檢、記錄公開，且換樁者不得兼任判定者；全員撤離時結構會縮小保護範圍並封閉入口，不會抓最後一人填入中央。用的是陸沉一路承劫換來的理解，不是命圖無中生有給的答案。

**與既有界痕代價的區隔（重要）**：永久界痕源於死寂雷域中他親身充當臨時界樁、承受跨界壓力，不是鎮界本源形成時由雷池附贈的代價。本次建立的是不需要他持續在場的獨立結構，因此不直接疊加惡化既有界痕；若後續工程量仍短暫觸發跨界壓力，須另案明確交代，不得預設無代價。

### 4. 她的選擇，不是被拯救

替代結構完成後，洛清禾沒有立刻離開。她先確認結構真的穩定，用自己的方式又留了一段時間觀察——這不是陸沉能替她決定的事。她保留自己一貫的性格：不以母愛之名被兒子的到來牽著走，也不讓兒子替自己承擔本該由她自己判斷的風險。

> 「你能撐住這裡，不代表我現在就得走。我看夠了，才走。」

最終她主動解除自身與道域的綁定，是她自己的選擇，不是陸沉「救」出來的結果。

正文採完整四十七日震盪週期實測：期間發生短樁磨損、外側斷訊、主動縮界與四枚短樁更換。洛清禾確認輪值者能獨立判定後才離開。

### 5. 母子相認

她沒有給出完整真相，一如她離開時留下的原則——「選擇是否接近真相的鑰匙，而非替他決定道路的完整傳承」（見 `characters/CHARACTER_LUO_QINGHE.md` 二）。她補全的是上一紀元真相的一部分：劫族、太玄命圖與天罰一脈同源的「共同歷史問題」框架（見 `factions/FACTION_JIE_CLAN.md` 七）她確有所知，但終局答案仍要陸沉自己走完（呼應 Codex 對第 42 題「她能補全上一紀元真相的一部分，卻不能一人講完終局答案」的既有意見）。

## 四、與洛生衣、太玄舊令的呼應

- 母親線的收尾與太玄舊令的情感功能（見 `systems/SYSTEM_TAIXUAN_OLD_TOKEN.md` 三）在此正式閉環——半枚令牌帶著的不只是查驗資格，還有這次真正找到人的溫度。
- 洛清禾與洛生衣同出古老洛氏道脈遠支、互不相識（見 `characters/CHARACTER_LUO_QINGHE.md` 一），本事件不安排兩人在此相認或建立新關聯，避免节外生枝，該線索留待 `AUTHOR_SECRETS.md` 既有節奏另行處理。

## 五、解除綁定後去向（正式）

洛清禾不隨陸沉同行。她先赴太玄舊址，追查當年替她引開追查者的三人是否留下姓名或痕跡；與陸沉約定半年後主動前往古雷道上界端，再安排與無法跨界的陸承遠相見。
