## 二、與父親線的對照（不可重複）

父母二人的困境刻意設計成不同形式，正文須保持這個區隔，不寫成同一種橋段的重複：

- **父親**：部分肉身已與古雷道結構同化，是「物」的層面被困——強行拔除會使古雷道崩潰，救援的核心動作是物理上的分離。
- **母親**：以自身道行主動維持斷裂道域局部不再繼續崩解，是「意志」的層面在支撐——她不是被關住，而是選擇留下承擔這個責任；救援的核心動作不是分離，而是替換承擔者，讓她獲得可以安心放手的條件。

## 三、事件經過

### 1. 殘缺座標

陸沉先從自己持有的單半令讀出模糊路標，自行尋到斷裂道域外圍；另一半令仍在洛清禾手中，直到兩令隔界共鳴、短暫合令後才顯出精確入口（見 `systems/SYSTEM_TAIXUAN_OLD_TOKEN.md` 二）。他仍須修復通道並承擔風險，正文不得寫成在遠處先合令後立刻抵達。

### 2. 道域現狀

陸沉抵達時看見的不是一個等待救援的囚徒，而是一處仍在緩慢崩解、卻被一股穩定道行硬撐住的破碎空間。洛清禾常年維持這個支撐，容貌與體態早已不是他從老族長轉述中拼湊出的年輕模樣。

她第一眼認出陸沉，不是靠血脈感應，而是他身上帶著太玄舊令另一半的命印共鳴——這一點呼應 `systems/SYSTEM_TAIXUAN_OLD_TOKEN.md` 三「合令」機制。

### 3. 替代承載結構

洛清禾不會因為兒子到來就立刻放手——她比誰都清楚，一旦支撐撤走，道域會加速崩解，波及範圍未知。陸沉必須先建立替代承載結構，這裡直接呼應他在仙古死寂雷域第五雷鎮界成種時的既有經驗（見 `systems/SYSTEM_TEN_CALAMITY_THUNDERS.md` 七：「陸沉進入界壁裂縫、以自身作為臨時界樁」）——當年那是一次性的臨時承受，這次他要做的是把同一套「以自身承受兩個空間互相撕裂的壓力」的能力，轉化成一個母親離開後仍能持續運作的結構，而不是再次讓自己變成臨時界樁被永久綁住。

具體做法：以太玄命圖的鎮界星位為核心，結合鎮界雷的既有界痕經驗，在道域邊界重新佈下一套不需要人力持續維持的封界結構——用的是他自己一路承劫換來的理解，不是命圖無中生有給的答案。

**與既有界痕代價的區隔（重要）**：第五雷鎮界成種時留下的既有代價是「他體內留下一道永久界痕，日後跨界越多，界痕越容易崩裂」（見 `systems/SYSTEM_TEN_CALAMITY_THUNDERS.md` 七）——這個代價specifically綁定在「他親身充當界樁、承受跨界壓力」這個動作本身。本次他建立的是一套不需要他持續在場的獨立結構，不是再次讓自己成為界樁，因此不直接疊加惡化既有界痕；若後續要讓这次的工程量對舊界痕造成間接負擔（例如佈陣過程本身仍短暫觸發跨界壓力），需另案明確交代，不得預設無代價。

### 4. 她的選擇，不是被拯救

替代結構完成後，洛清禾沒有立刻離開。她先確認結構真的穩定，用自己的方式又留了一段時間觀察——這不是陸沉能替她決定的事。她保留自己一貫的性格：不以母愛之名被兒子的到來牽著走，也不讓兒子替自己承擔本該由她自己判斷的風險。

> 「你能撐住這裡，不代表我現在就得走。我看夠了，才走。」

最終她主動解除自身與道域的綁定，是她自己的選擇，不是陸沉「救」出來的結果。

### 5. 母子相認

她沒有給出完整真相，一如她離開時留下的原則——「選擇是否接近真相的鑰匙，而非替他決定道路的完整傳承」（見 `characters/CHARACTER_LUO_QINGHE.md` 二）。她補全的是上一紀元真相的一部分：劫族、太玄命圖與天罰一脈同源的「共同歷史問題」框架（見 `factions/FACTION_JIE_CLAN.md` 七）她確有所知，但終局答案仍要陸沉自己走完（呼應 Codex 對第 42 題「她能補全上一紀元真相的一部分，卻不能一人講完終局答案」的既有意見）。
