# 聖祭突破：三枚古種後的空祭臺

> 狀態：正式事件 v1.0
> 時間：Volume06 ch017，仙院招募實測期間

## 一、事件需求

Volume05 結束時陸沉仍是真一初期；天神書院排位時荒已有天神境。陸沉不能無聲升級，也不能憑六雷把兩個大境界差直接抹平。本事件只完成真一至聖祭初期，不讓陸沉跳至天神。

## 二、首次失敗

三枚古種都無法替六雷決定唯一位置後，仙院使者開放問道臺後的普通祭臺。陸沉第一次企圖祭去右膝冷痕、鎮界錯固與空手反震；祭臺把傷完整推回。既付代價不是可換境界的祭品，自我傷害也不是聖祭答案。

## 三、七日修正

洛生衣與醫修公開下達七日禁登，劫厄阻止當夜重試。陸沉重新檢查六雷、雷身、伴星與命圖，辨明真一舊結構仍預設「本尊永遠先決，其餘力量服從」。這條主軌曾讓分裂力量歸一，如今也會把命圖鎖成只有陸沉能居中的定盤。

## 四、正式突破

第八日，陸沉不祭雷、不祭傷，而切斷「本尊永遠先決」的固定主軌。六雷各守本性重新接續，雷身與伴星可以退開或拒絕代付；他本人承接重排反噬，正式進入聖祭初期。

代價固定為：胸裂延至左肋、右膝冷感由七步一次惡化為五步一次、兩具雷身十日不得離體。祭臺不賜雷、不補命圖、不治傷，也不使他成為天神。

## 五、排位邊界

排位時陸沉名義境界低荒一個大境界。場面戰平來自六雷、命圖、禁制、肉身與戰術共同跨階，不代表兩人已在九雷規則下正式同級；有效攻勢仍判荒第一、劫第二。
