# 太玄宗外萬年雷池

狀態：現行事件設定 v1.0

## 一、定位

- 時期：第六篇太玄宗・鎮岳入門；陸沉發現雷池在七峰大比前，三身固定共浴在第二具雷身穩定後逐步形成。
- 地點：太玄宗疆域外近域的一處衰敗禁地。
- 功能：長期淬體、穩固早期雷身與三身協作；不是十雷取得事件。
- 機制唯一來源：`systems/SYSTEM_THUNDER_POOLS.md` 一之一。

## 二、發現與設陣

陸沉在一次宗門外務中發現萬年不滅的墨紫雷池。禁地建築與傳承早已消亡，只有地下古雷脈仍供給純粹、無固定大道屬性的雷力。他未上報為雷種機緣，也不搬動池中殘紋，只以藏經閣學得的基礎《子母挪移陣解》在雷池石穴與鎮岳峰小閣地下各設一端。

兩陣必須由陸沉雷息校驗並以靈石供能，只能在太玄宗近域空間穩定時定點往返；封界、空間亂流或陣臺受損時立即失效，每次傳送亦留下短暫可追索波動。

## 三、三身夜修

第二具雷身穩定後，本尊、第一雷身與承身雷在無任務的夜裡共同入池。本尊以《萬體鑄身經》淬骨、煉筋、拓脈；第一雷身提純早期雷軀；承身雷把每日承根成果帶入三身共鳴。三者也在池中練習雷息同步、力量交換及回歸前協調。

外人看來近似承受雷刑，三身私下只稱之為「洗澡」。他們偶爾爭搶高濃度雷眼位置，但雷眼不含新雷種；高強度使用後雷池必須停養，不能無限供應。

## 四、雷池裡的日常

小閣閉門後，本尊、第一雷身與承身雷才一同傳入雷池。他們白日各有修行、課業和任務；夜裡有時各坐一角安靜引雷，有時把彼此缺失的白日經歷重新說一遍。這不是三個獨立神魂聊天，而是同源三身在分時行動後互補記憶與判斷。

三人私下把這段煉體叫作「洗澡」。雷眼最濃的位置只有一處，第一雷身和承身雷偶爾會為此爭起來：

> 「往旁邊一些。」
>
> 「你佔了兩道雷眼。」
>
> 第一雷身閉著眼：「先到先得。」
>
> 承身雷抬手便是一道電光，雷池當場掀起一圈浪。
>
> 本尊只說：「打壞陣法，你們自己走回去。」

這些夜談、靜坐與搶雷眼的小事，是小閣與雷池真正的生活感來源。雷訊令的第一對秘密原型也在這段生活裡誕生：三身起初只想解決白日分處各地的傳訊，後來才擴成太玄七峰可用的雷訊網。

## 五、安全閥

- 正文稱「本尊、第一雷身、承身雷」，不用「一雷、二雷」。
- 雷池不孕育十雷、不直接破境、不免費治癒神魂、雷種或因果傷勢。
- 雷身長時間離體仍受雷核共鳴與回歸反噬約束。
- 古雷脈與太玄宗地下古雷痕同源只作中期待回收伏筆，不預設祖種或祖師傳承。
- 中期伏筆於 `EVENT_TAIXUAN_ANCIENT_THUNDER_VEIN_RECONNECTION.md` 回收：主雷眼與小閣子陣永久毀去，每夜共浴日常至此結束。
- **小閣「等他回家」的對象是陸沉自身三種存在形態（本尊、第一雷身、承身雷），不是獨立於本尊之外的另一名角色**：小閣是陸沉離開沉雷谷、走過太玄閣後，人生第一個不會在關鍵時刻放棄他的空間，這份「有人等他回家」的情感重量須框定為「自己等待自己」，不得寫成雷身對本尊產生獨立於他之外的思念或依戀，避免與「雷身不是替本尊建立感情的工具，也不是獨立情敵」的既有安全閥（見 `docs/WRITING_GUIDELINES.md` 八）產生模糊解讀。
- 若正文加重小閣情感筆墨，優先擴寫本檔案已有的場景與台詞（如「打壞陣法，你們自己走回去」的呼應、雷眼爭搶、雷訊令原型誕生），而非新增未見於本檔案的情節；如需更多篇幅，建議由 `jie-chapter-editor` 評估是否將第六篇拆成「雷池／古雷脈」與「命藏／鎮魄雷」兩個子段落分別展開，避免稀釋命圖初開與第三雷取得在離場結果中的分量。
