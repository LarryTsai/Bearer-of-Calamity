# 罪州失界與蒼梧永久解印

狀態：現行事件唯一來源 v1.0（回應 CHECKLIST 第55、58、78、102題；長息原ch025～032／現ch032～039）

## 一、事件位置與原作安全閥

本事件位於PW-24B罪州被跨界抓走期間、荒受折仙咒與長息後段之前。安瀾、天淵、罪州被抓及原作主要人物的正面作為完整保留；陸沉與四伴星只處理一條原創平民撤離支路，不能阻止罪州被抓、不能對抗或削弱不朽者核心功業。

## 二、撤離分工

- 陸沉：維持撤離線、判斷升降級與最後斷路。
- 劫厄：越過節點搜尋仍有生命回聲者，但不得追進不朽者掌中。
- 鑑月：穩住跨界魂壓下將散的生魂。
- 蒼梧：固定罪州外緣與撤離裂口的相對位置；能守結構，救不到裂口另一端的人。
- 赤翎：保住已進撤離線者最後命火，不把餘命投向不可觸及的整州。

四者對「繼續搜尋」與「先保現有撤離線」發生分歧，仍各守本責，證明伴星不是只會同意陸沉。

## 三、不可逆失敗

撤離支路最終帶回九百一十六人，死二十三、失聯一百七十二；罪州本體仍被抓走。數字只計陸沉所在支路，不代表罪州總人口或原作全局結果。

蒼梧固定住裂口，卻親眼看見裂口另一端連人帶地遠去。他的鎮界能力沒有失效，只是能力能守住「空間」而不能保證守住「空間裡的人」。

## 四、解印原因

事後陸沉立刻把現存人員、下一條裂縫與敵方可能再抓取的區域列成風險表。這是他避免更多損失的真實責任，卻也使他再次用「下一場」處理尚未被哀悼的「眼前失去」。

蒼梧不指控陸沉害死罪州，也不要求他放棄下一場戰事。蒼梧只拒絕繼續留在一套會把自身鎮界能力默認納入陸沉長期計算的命圖外環。蒼梧依早已公開的撤回結構主動解除命印；陸沉不同意其判斷，仍親手完成解除，不拖延、不附加回歸條件。

## 五、永久結果

- 太玄命圖外環留下不可修復、不可替補的蒼梧空痕。
- 鎮界雷仍是陸沉自身第五雷，不因蒼梧離開而消失，但失去蒼梧外側固定後，戰場鎮界範圍、穩定時間與多點能力永久下降。
- 蒼梧返回罪州遺留的失序邊界，守護未被抓走的破碎界層與返流災害。
- 後續可作外部盟友並肩，但不恢復原命印、不重新占據外環、不被稱為重新歸隊。
- 此事件成為終局共同承劫契約中「同行者可以撤回，即使撤回會削弱核心」的首個真正案例。
