# 異域黑水城・戰神書院・角鬥場事件

狀態：現行唯一來源 v1.0

## 一、事件定位

本事件嵌入 Volume08 第十七至二十四章，與 `EVENT_FOREIGN_DOMAIN_COMPANION_RETURN_ROUTE.md` 並行。荒獨立完成尋找、救出並帶返原始帝城後裔；陸沉不分享此功業。他的獨立高潮發生在側線的黑水城、戰神書院舊禁臺與角鬥場，目的是完成「弱小肉身→萬體鑄身→自身成為最後兵器」的長線回收。

黑水城是異域斷界交通與戰俘轉運之城；戰神書院不是九天十地的天神書院，而是異域培養守禁人、界路獵手與近戰王族的軍事書院。斷界古臺位於其地下角鬥場，既用於研究異域完整禁制，也用於拆解俘虜的能力、驗證何種手段在完整大道下仍能成立。

## 二、與異域完整性的關係

- 異域大道完整：外來者的雷法、界法與神識不能沿九天十地習慣免費運轉，每次外放都必須在當地規則內取得結果。
- 異域禁制完整：禁制不是等待被破的機關，而有對象、邊界、供能、權限、代價、解除與回收；沒有便利陣眼，也不因主角看懂一部分就交出控制權。
- 異域劫難完整：劫因、聚勢、降臨、承擔與結算缺一不可。陸沉過去擅長截斷與封住，到了這裡第一次被迫承認「阻止事情繼續發生」不等於「已發生的事得到結算」。

## 三、敵人的正確判斷與唯一誤判

守禁人烏迭與戰神書院並不輕敵。他們從逃回者與黑釘記錄中逐項辨出陸沉的神識、外雷、禁具、命圖、雷身、四伴星與空手接觸技，因此在角鬥場依次完成：

1. 以完整異域大道壓回神識外探。
2. 以禁臺邊界禁止外雷離體。
3. 拔除雷釘、材料與預布禁具。
4. 以骨牌權限暫時鎖住命圖分流。
5. 以錯拍隔開雷身及四伴星支援。
6. 以長兵與替命索避免讓空手直接接觸核心發力點。

這些處置都應真實生效，陸沉必須受傷，不能靠藏著未公布的新雷法逐項破解。敵人唯一的誤判，是把《萬體鑄身經》視為「承載上述能力的容器」，沒有看見那具身體本身早已是完整戰法。

## 四、肉身揭底

所有外物被拆後，陸沉不應先說長篇宣言。他先以骨、筋、血、脈四路作戰：骨承正面衝擊，筋改變力線，血維持傷後節律，脈把被壓回體內的雷沿接觸處走完；早年神識累積的觀察仍在視野內運作，但不越過封鎖外探。

敵人問他還剩什麼時，回答只用一字：「我。」

可保留一次較長的追問式回收：「你們是不是忘了，我最早是怎麼把這副身體煉出來的？」此句只在敵人已逐項列出封鎖成果後使用，不能變成日常口號。

他徒手擊敗王族／守禁人的爽點，不是突然比荒更像荒，而是讀者記得他幼年連正面一拳都不敢接。勝利必須依靠幾百章鍛體累積與當場觀察，不依靠新境界、新雷或敵人失智。

## 五、與荒的鏡像

荒的異域熱血在於正面迎戰、一路打穿並親自把人帶回；陸沉的異域熱血在於敵人已把他最出名的手段全拆乾淨，他仍以最早、最笨、最痛的那條路站起來。荒不是只會打，陸沉也不是只會算；兩人在此各自完成不同方向的證明。

## 六、離場結果

- 陸沉證明肉身不是雷法與禁制的附屬容器，而是最後一道可移動的禁與最後一件兵器。
- 他仍不能靠肉身解決完整古禁的結算問題；肉身只讓他活到有資格面對那個問題。
- 八雷在斷界古臺完成一次有限承劫實證，但不形成第九雷。
- 「天若不罰，我罰」只在此後成為他主動尋找刑衡雷界的動機，不能在本事件生成天譴。
- 荒仍獨占原始帝城後裔的尋找、救出、帶返功業。
- Volume08 ch027 必須把角鬥場的右腕骨裂、左肩穿傷、肋側缺肉、斷肋與左掌掀傷逐項列入返關傷簿；洛生衣以此回收她記得陸沉弱小時期、也拒絕他把自己合併成免費代價的關係功能。
- Volume08 ch030 將戰神書院骨牌、替命索與活人承災名冊封存，並把異域俘虜承災位與帝關交荒議約的犧牲位並置；刑衡雷界道標仍須沉暗，僅形成主動追問罪雷池的理由。
- Volume09 ch034 必須讓兩案作為真證據進入刑衡雷界，但陸沉第一次將相似結構合併為同罪時遭雙面案卷石反灼；ch037 取得刑衡天雷時仍分案放置，以首次選擇不落雷完成資格驗證。
