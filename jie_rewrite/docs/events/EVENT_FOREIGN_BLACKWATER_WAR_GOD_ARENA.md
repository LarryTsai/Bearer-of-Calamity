# 異域黑水城・戰神書院・角鬥場事件

狀態：現行唯一來源 v1.1

## 一、事件定位

本事件嵌入 Volume08 第十七至二十四章，與 `EVENT_FOREIGN_DOMAIN_COMPANION_RETURN_ROUTE.md` 並行。荒獨立完成尋找、救出並帶返原始帝城後裔；陸沉不分享此功業。他的獨立高潮發生在側線的黑水城、戰神書院舊禁臺與角鬥場，目的是完成「弱小肉身→萬體鑄身→自身成為最後兵器」的長線回收。

黑水城是異域斷界交通與戰俘轉運之城；戰神書院不是九天十地的天神書院，而是異域培養守禁人、界路獵手與近戰王族的軍事書院。斷界古臺位於其地下角鬥場，既用於研究異域完整禁制，也用於拆解俘虜的能力、驗證何種手段在完整大道下仍能成立。

### 一之一、名稱與原作隔離

- 原作第1565章〈黑水天牢〉屬於荒的囚禁與異域核心經歷，陸沉不得進入、旁觀、營救或共享其中敵手與發現。
- 本事件的「黑水城」是原創側線城市，位於另一條斷界交通線；名稱源自穿城而過、倒流時露出街層的黑河，不是把原作黑水天牢擴建成城市。
- 正文第一次出現時必須同時給出地理識別：「沉在黑色河床下的轉運城」；不得只寫「黑水」二字讓讀者誤以為陸沉闖入荒的天牢線。
- 異域「戰神書院」是原創軍事機構，與九天十地的「天神書院」只有鏡像功能，沒有傳承、師生或建制關係。

## 二、與異域完整性的關係

- 異域大道完整：外來者的雷法、界法與神識不能沿九天十地習慣免費運轉，每次外放都必須在當地規則內取得結果。
- 異域禁制完整：禁制不是等待被破的機關，而有對象、邊界、供能、權限、代價、解除與回收；沒有便利陣眼，也不因主角看懂一部分就交出控制權。
- 異域劫難完整：劫因、聚勢、降臨、承擔與結算缺一不可。陸沉過去擅長截斷與封住，到了這裡第一次被迫承認「阻止事情繼續發生」不等於「已發生的事得到結算」。

## 三、敵人的正確判斷與唯一誤判

守禁人烏迭與戰神書院並不輕敵。他們從逃回者與黑釘記錄中逐項辨出陸沉的神識、外雷、禁具、命圖、雷身、四伴星與空手接觸技，因此在角鬥場依次完成：

1. 以完整異域大道壓回神識外探。
2. 以禁臺邊界禁止外雷離體。
3. 拔除雷釘、材料與預布禁具。
4. 以骨牌權限暫時鎖住命圖分流。
5. 以錯拍隔開雷身及四伴星支援。
6. 以長兵與替命索避免讓空手直接接觸核心發力點。

這些處置都應真實生效，陸沉必須受傷，不能靠藏著未公布的新雷法逐項破解。敵人唯一的誤判，是把《萬體鑄身經》視為「承載上述能力的容器」，沒有看見那具身體本身早已是完整戰法。

### 三之一、烏迭的獨立目的

烏迭不是為主角服務的陪練，也不是因高傲才把陸沉送進角鬥場。他有三個可以同時成立的目的：

1. 把荒返路之外的側線追蹤重新收歸斷界禁臺，避免污染穿回帝關後反噬己方界路。
2. 以活捉的外來禁制師完成書院試禁記錄，證明守禁體系能拆解九天十地的新戰法。
3. 保住守禁骨牌所代表的權限與名位；若禁臺留下無主劫果，他本人會成為下一名被制度追責的承擔者。

因此他會撤、會棄刀、會留下部下，也會在最後自碎骨牌；這些行動都服務他的責任與自保，不是為了讓陸沉展示能力。

## 五、肉身揭底

所有外物被拆後，陸沉不應先說長篇宣言。他先以骨、筋、血、脈四路作戰：骨承正面衝擊，筋改變力線，血維持傷後節律，脈把被壓回體內的雷沿接觸處走完；早年神識累積的觀察仍在視野內運作，但不越過封鎖外探。

敵人問他還剩什麼時，回答只用一字：「我。」

可保留一次較長的追問式回收：「你們是不是忘了，我最早是怎麼把這副身體煉出來的？」此句只在敵人已逐項列出封鎖成果後使用，不能變成日常口號。

他徒手擊敗王族／守禁人的爽點，不是突然比荒更像荒，而是讀者記得他幼年連正面一拳都不敢接。勝利必須依靠幾百章鍛體累積與當場觀察，不依靠新境界、新雷或敵人失智。

### 五之一、肉身戰的四段升級

1. **骨承**：用骨架接住原本會把他打離禁臺界線的正面力，不追求無傷；右腕骨裂必須在此成立。
2. **筋改**：不與王族純比力量，靠肩、腰、膝與足底改變力線，使長兵第一次失去安全距離。
3. **血續**：失血與斷肋後仍維持呼吸、步頻和判斷節律；不是燃身回血，也不是忽略疼痛。
4. **脈行**：被壓回體內的雷只沿骨肉接觸走完，不外放、不違反禁臺封雷；它服務肉身動作，不能變成隱藏雷招。

四段各自需要一次敵方有效反制：骨承後敵人改刺關節，筋改後改用替命索，血續後以拖延擴大失血，脈行後自碎骨牌把戰鬥轉為承擔規則。如此，肉身勝利與禁制結算才是兩個相連但不同的難題。

## 五之二、能力剝離順序與章內節拍

| 剝離 | 必須生效的證據 | 不可使用的逃脫方法 |
| --- | --- | --- |
| 神識 | 外探一離體便被完整大道壓回，造成短暫眩暈 | 不可改口稱「只用更細神識」繞過 |
| 外雷 | 雷離身便被禁臺登記並追索結算 | 不可臨時創造不受規則的新雷 |
| 禁具 | 雷釘、材料、池殼與預布節點逐件被拔除／隔開 | 不可再揭露早已藏好的萬能後手 |
| 命圖 | 骨牌權限鎖住分流，命圖只能標示尚未結算 | 不可直接算出出口、罪人或正確答案 |
| 雷身／伴星 | 錯拍切斷即時支援，離體共傷仍回到本尊 | 不可瞬間召回洗傷或共享全知 |
| 空手接觸 | 長兵、棄械與替命索讓接觸無法直達核心 | 必須靠步法與傷勢交換進入距離 |

每剝掉一層，陸沉都要先嘗試一次合理舊解、確認失敗並留下傷或失時；不能只由敵人口述「我已封掉你六種能力」。

## 六、與荒的鏡像

荒的異域熱血在於正面迎戰、一路打穿並親自把人帶回；陸沉的異域熱血在於敵人已把他最出名的手段全拆乾淨，他仍以最早、最笨、最痛的那條路站起來。荒不是只會打，陸沉也不是只會算；兩人在此各自完成不同方向的證明。

## 七、離場結果

- 陸沉證明肉身不是雷法與禁制的附屬容器，而是最後一道可移動的禁與最後一件兵器。
- 他仍不能靠肉身解決完整古禁的結算問題；肉身只讓他活到有資格面對那個問題。
- 八雷在斷界古臺完成一次有限承劫實證，但不形成第九雷。
- 「天若不罰，我罰」只在此後成為他主動尋找刑衡雷界的動機，不能在本事件生成天譴。
- 荒仍獨占原始帝城後裔的尋找、救出、帶返功業。
- Volume08 ch027 必須把角鬥場的右腕骨裂、左肩穿傷、肋側缺肉、斷肋與左掌掀傷逐項列入返關傷簿；洛生衣以此回收她記得陸沉弱小時期、也拒絕他把自己合併成免費代價的關係功能。
- Volume08 ch030 將戰神書院骨牌、替命索與活人承災名冊封存，並把異域俘虜承災位與帝關交荒議約的犧牲位並置；刑衡雷界道標仍須沉暗，僅形成主動追問罪雷池的理由。
- Volume09 ch034 必須讓兩案作為真證據進入刑衡雷界，但陸沉第一次將相似結構合併為同罪時遭雙面案卷石反灼；ch037 取得刑衡天雷時仍分案放置，以首次選擇不落雷完成資格驗證。

## 九、章節容量判定

- ch018～023雖多數低於一般大事件章建議字數，但各章已有獨立的錯誤、選擇、代價與下一章記憶，現階段判定為**保留短章並按缺失局部擴寫**，不為達標機械灌字。
- ch024是主高潮，可維持較長容量；其長度必須來自能力逐項失效、肉身四段戰與古禁結算三個不同問題，不能用重複攻防撐長。
- 後續若擴寫ch018～023，只能補：敵方如何取得情報、同行者的自主決策、具體空間阻力、傷勢如何改變下一章行動，以及返關後記得的後果。
- 不得新增無後果的小怪、額外傳承、臨時王族名單或與荒主線相似的連勝場次。

## 十、閉環驗收

1. 刪去開發註記後，讀者能否僅從正文理解黑水城不是黑水天牢？
2. 烏迭是否至少三次根據已取得情報調整，而非突然全知？
3. 神識、外雷、禁具、命圖、雷身伴星與空手是否各有一次可見的失效？
4. 肉身四段是否各有功能、敵方反制與傷勢，而非一句「極致肉身」帶過？
5. 陸沉是否只在荒完成尋救、孩子先過門後守最後支路？
6. 八雷是否只完成有限承劫，沒有生成第九雷、天譴或成熟活禁？
7. ch018～023形成的玄衡、燼長明、劫厄、無槐與陸沉傷勢是否在ch024～030逐項存在？
8. 烏迭敗亡／受困是否源於他的目的與選擇，而非突然愚蠢？
9. 返關的一息是否被異域完整大道追討，洛生衣是否有獨立斷路決策？
10. 荒與陸沉是否各自熱血，卻沒有重複同一種高潮？
