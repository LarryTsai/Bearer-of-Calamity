# 天神書院：荒遇陷害，周晏入劫

狀態：現行事件設定 v2.0

## 一、事件定位

| 項目 | 設定 |
| --- | --- |
| 事件 | 王家特定旁支／異域外接組借殘陣規矩殺荒，並利用周晏分流醫療隊；洛生衣承釘救人，陸沉斬仍在滅證的周晏 |
| 時期 | 天神書院篇第 8～16 章，首次兩院招攬與排位之前 |
| 地點 | 天神書院試煉殘陣及其停用檢修路 |
| 現場執行者 | 周晏；全事件只有這一名現場執行主謀與一次處決 |
| 幕後 | 王家特定旁支／異域外接組；第二枚定址印留到七站篇追查，不上綱整個王家 |
| 結果 | 四名傷者存活，洛生衣短期精細續脈失準，周晏死，陸沉被停權並接受聯署審計 |

## 二、周晏與妹妹舊案

周晏是書院陣務房記名弟子，修為普通，熟悉舊陣路、值守簿與外站求援格式。他早期真心幫助低階弟子、補送無人理會的求援，也曾以檢修經驗救出被舊陣門困住的人。

其妹妹早已死於一宗外站遲援舊案。現有證據只能證明：第一道求救抵達時仍有微弱生命指標，卻被舊陣芯降級、延遲轉送，使她失去一次可能的救援窗口；不能斷言準時抵達便一定能救活。

敵人剪接並加工她最後的呼吸、心跳、生機數值與求救語音，謊稱殘陣仍保存可被喚回的生命。此物正式稱「臨終醫訊殘響」：

- 不是魂魄或人格；
- 不能回應或更新內容；
- 不可能用他人生命復活；
- 不得稱為「生音」；「生音」專屬蘇聽瀾與無聲渡笛。

> 周晏聽見的不是妹妹留下來了，而是有人拿她最後一次求救，做成了不肯讓他放下的餌。

## 三、三次越線

1. **把人當情報**：周晏交出荒的試煉名額、陸沉的調查方向與殘陣檢修路，自認只是權貴間的試探。
2. **把人當誘餌**：他利用檢修權限逐一隔開並截傷四名低階弟子，再以真傷員引洛生衣與顧小滿進入醫療側層。
3. **把人當代價**：洛生衣給出停手與共同查證殘響的道路後，他仍將截脈釘推深，並在假降時再次啟動借命與滅證。

遲援解釋他為何恐懼，不能替第三次自由選擇卸責。

## 四、荒的死局與照命邊界

荒仍是殺局的主要目標。他認為這只是同代打壓，準備正面入局；陸沉在洛生衣受傷以前便以照命確認核心盡頭是真正死線，決定先拆局。這保留荒、劫對選擇權的衝突。

照命只能看見已形成的災點、虛妄與命勢，不能把周晏尚未作出的自由選擇當成固定未來。周晏最後再次啟動元神滅證時，模糊災點才閉合為確定殺線。

「荒尚未入局」指荒尚未踏入核心殺層，不代表試煉完全沒有開始，也不再另設一名先被陸沉暗殺的無名主謀。

## 五、四個真的求救

四名低階弟子都是真傷員。顧小滿發現四道求救每隔固定七息亮起，過度整齊；洛生衣則看出四人的截脈傷出自同一手法。二人不因訊號可能被利用便放棄真傷者。

洛生衣以續脈暫接四人的生命經絡。周晏將偽裝成陣眼固定器的截脈釘刺向最遠的傷者；洛提前察覺並轉身代擋。釘入體後才展開倒鉤，反扣她已接出的四道續脈。她若粗暴拔釘，反噬會先落回傷者。

洛生衣始終清醒，主動安排顧小滿撤人。她以帶血指節在私人雷訊令上敲出一段無字生息；此訊不是正式「需人」碼，第 22 章才建立四碼，第 44 章才由陸沉第一次真正發出「需人」。

## 六、折返、救援與一次處決

陸沉只能以單一公開身沿同座殘陣的檢修路折返：

- 不使用尚未形成的剎那；
- 不以古路瞬移或跨陣傳送；
- 不讓多具雷身同場公開；
- 只用六雷以內能力及既有檢修結構。

抵達後先分工救人：玄衡固定局部界層，顧小滿按順序搬運，普通醫修接手已解除者，洛生衣逐條收回續脈，陸沉以空手逆拆截脈釘與借命結構。空手須接觸且反震自身，不能無傷解題。

周晏佯作投降時，陸沉停手查驗；洛生衣確認其所謂停釘口令沒有活路，借命甲也從未解除。周晏隨即主動啟動元神滅證。鎮魄只能壓住爆裂半息；劫命沿仍在運轉的借命線逆截外接錨點，卻無法在施術者存活時永久斷開。陸沉趁這半息近身，一擊斷其生機；周晏死亡的同一刻，借命線才全部脫離四名傷者與洛生衣，未盡爆裂回落其自身。截線與致命一擊是同一個不可分割的止殺動作，不存在威脅完全解除後補殺。

> 「她給過你停手的路。」
>
> 「我沒有選——」
>
> 「有。」
>
> 「我把他們留下。你的命，只算你的。」

陸沉不折磨、不補刀，立即回身救洛生衣。周晏死於仍在傷人與滅證的持續威脅，不是完全制伏後的私刑。

## 七、證據、處分與人物後果

歸寂只壓住現場波動，不銷毀屍身、魂痕、截脈釘、暗令、陣證與半枚定址印。另一枚定址印及外接組位置仍未知，留到七站篇回收。

孟天正承認陸沉判斷死局正確，也指出周晏死亡造成口供損失，不能把正確判斷等同程序與手段毫無問題。他定調「下次留活口」，並暫停陸沉獨立處置嫌犯及獨自接取高危試煉的權限，要求陣師、醫修與執法長老聯署審計。

荒追究的不是周晏是否該死，而是陸沉無權替他決定是否入局：

> 「你會進。」
>
> 「那也是我進。」

洛生衣確認陸沉沒有擅拔截脈釘、沒有替她放棄傷者；她不廉價寬恕周晏，也不替陸沉宣布殺人完全正確。其短期後遺為精細續脈失準與偶發疼痛，不得廢去根基或妨礙後續醫療制度主線。

## 八、制度與後續回收

- 舊救援終端只保存歷史標記、延誤紀錄與停用路由，不能定位活人、傳送或認主。
- 周晏案證明有人會利用假訊；第五幕仍須證明即使人人善意，舊制度也會吞掉真訊。
- 第 34～40 章逐步回收舊新碼轉譯、無主回呼、第二枚定址印與外接組。
- 第 40 章只能確認七站暴露，不能把殺掉周晏寫成解決整個遲援問題。
- 洛生衣在本篇只能辨出醫訊殘響遭異常加工，不得提前揭露蘇聽瀾、長生勢力或活體容器真相。

## 九、安全閥

- 不擴大成王家整族通敵。
- 不新增原作具名敵手死亡或搶荒原作功業。
- 不提前第七雷、燼長明、雷身公開或「需人」正式使用。
- 不讓荒失去正面入局的主動性；終局由荒開路、劫收劫。
- 不把洛生衣寫成人質；她的傷來自知情救人選擇。
- 不把周晏洗白成制度先驅，也不抹去他早期真心救人的部分。
