# 太玄雷魂域：鎮魄取得與鎮無央歸位

狀態：現行事件設定 v2.0（2026-08-02 來源裁示）

## 一、事件定位

| 項目 | 設定 |
| --- | --- |
| 事件 | 陸沉循七峰大比所得線索，交換情報並主動申請進入太玄雷魂秘地深層的雷魂池／雷魂域 |
| 時期 | 太玄命圖初開後，早於三千州 |
| 來源 | 鎮魄來自外部雷魂池／雷魂域；事件現場本就存在本源 |
| 守關者 | 守墓獅鎮無央；牠分開破魂、守各魂歸位，不贈雷，也不是雷種化身 |
| 結果 | 陸沉經兩次錯誤收服後取得鎮魄；鎮無央其後自主交出可解除魂印，正式顯化延後至界潮／古界事件（見 `EVENT_DEADSTILL_DOMAIN_XUANHENG.md`） |

## 二、雷域歷史與生態

太玄雷魂秘地深層原是古戰場葬域。墓土保存魂名，記名碑記錄死者歸處，殘魂依碑與墓土循環；雷魂蟲啃去無主執念，避免不同魂魄黏成一團。這套生態的目的不是把萬魂壓成沉默，而是使每一道魂仍能辨認自己、回到自己的位置。

鎮無央曾追隨古代守墓者。主人消散後，牠仍逐一分開破魂，長年魂裂也不肯離位。牠攔陸沉，是要確認來者會不會把亡魂當資源，而非保管一枚準備送人的雷種。

## 三、主動追索與兩次失敗

七峰大比只讓陸沉確認自己缺少穩魂手段，並取得雷魂秘地異常資料。他交換值守紀錄、主動申請入域，沿墓土中反覆錯位的魂雷追到深層雷池。

第一次，他以威壓迫萬魂低首，把「鎮」理解成服從。魂群表面安靜，魂名卻彼此錯接，雷池將他逐出（`novel/volume02/chapter082.md`）。

第二次，陸沉本人已不再重蹈壓服的錯，但劫厄誤以為「壓倒守關者」就能替陸沉取得雷源，仍迎著魂威衝上去，把鎮魂理解成比拚威壓、把守關者當成必須擊敗的敵人——這是同一層「用威壓解決一切」的錯誤，只是主體從陸沉轉移到劫厄身上，仍抹平了鎮無央「分界而非制服」的本意。鎮無央以獅吼與魂威回應這層誤判；劫厄自主承受魂威、正面纏鬥並一度壓制鎮無央，替陸沉保住重新辨認的時間（`novel/volume02/chapter083.md`）。

**正文執行說明（2026-08-15補記，回應jie-continuity覆核）**：上段定義已依正文實際寫法調整——原案設想「第二次」由陸沉本人再次嘗試整齊劃一的秩序化，但ch083開篇明寫「陸沉沒有再用命圖壓萬魂」，實際演出的第二層錯誤改由劫厄的戰鬥式誤判承擔，人物不同但錯誤性質相通（皆是把「鎮」誤解為壓制/擊敗）,故予以保留正文寫法、修訂本文定義對齊，不回頭重寫已完成且彼此呼應的ch082-083。劫厄承受魂威具體演出為正面對峙、近身纏鬥、將鎮無央壓制、爪抵咽喉，比原文字面「自主承受」更具體，但仍嚴格守住「沒有替陸沉奪雷或擊敗守墓獅換取獎賞」的核心界線：陸沉在劫厄爪鋒落下前主動喝止（「放開牠」），最終的鎮魄取得仍是ch084陸沉以逐魂辨名法完成，不是憑劫厄的戰鬥勝負直接兌換雷種；鎮魄獅的力量與意志皆未被削弱或矮化（見ch083自檢「鎮魄獅強度未被削弱」），其退讓源於陸沉看穿牠並非真殺意、以同理心化解其守護執念，而非單純武力屈服。此演出屬於在既定安全閥精神內的戲劇化展開，不等同已作廢舊案「劫厄擊敗鎮魄獅後直接形成鎮魄」的因果鏈（該舊案是「戰勝→直接獲得」，現行正文是「戰勝但主動收手→透過理解與逐魂辨名才真正取得」，中間多了不可省略的關鍵轉折），故不視為舊案復發，予以保留。

## 四、取得鎮魄

第三次，陸沉不再要求萬魂服從。他逐魂辨名，讓破碎者各自回碑、執念者保留最後一句、將散者守住本我，再承受萬魂錯位回灌的神魂之劫。雷魂域的外部鎮魄本源因此自行認可，離池進入命圖。

鎮魄只能守住本我、分開錯接與壓低失序魂念，不能抹除人格、強迫臣服或把亡魂轉成供能。取得後仍需磨合，過度使用會使陸沉神魂震盪並放大他人的殘念。

## 五、鎮無央自主歸位

雷種取得完成後，陸沉以鎮魄協助穩住雷域中即將錯散的魂，卻沒有占有亡魂或要求鎮無央臣服。鎮無央確認他理解守墓之責，才自主交出可解除魂印。

此戰只完成結印與外環獅形投影，尚未對外顯化。鎮無央離開秘地後第一次正式出戰，是界潮／古界事件中截住封寒吞噬失控的獅吼截魂（見 `EVENT_DEADSTILL_DOMAIN_XUANHENG.md`、`characters/CHARACTER_ZHEN_WUYANG.md` 二之一）；牠仍保有拒絕利用亡魂、拒絕命令與解除命印的權利。
