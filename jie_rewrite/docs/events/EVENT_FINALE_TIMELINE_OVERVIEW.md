# 終局時間統籌：長息至大劫決裂

狀態：現行唯一統籌來源 v1.0（回應 CHECKLIST 第 68 題）

## 三段順序

1. 第十二篇尾聲：十凶血路與司天鑑死戰結束。
2. 獨立銜接段「長息」（PW-25）：父親古雷道最終狀態與替代承載準備；中段尋回洛清禾；後段見證同代老去、荒再起與舊怨清算——荒在此段平行進行自己的下界故土回訪（PW-25A／25A-1，重訪補天閣、石村故人）與元青等舊敵的清算（PW-25E），陸沉不知其具體行程，兩人不因此見面，正文不由旁白明說「兩人都在回頭清算來處」，留給讀者自行讀出這是第 50 題「兩座倒下山門」鏡像回音的第二次結構呼應（見 `CHECKLIST_PENDING_DECISIONS.md` 第 73 題）；元青清算完成後，陸沉只從公開消息得知結果，餘波帶出一句對太初古礦與帝關王肅所代表制度邏輯的簡短回看，不展開第二次元青支線（見 `CHECKLIST_PENDING_DECISIONS.md` 第 74 題）。此段不另編正式篇號。
3. 第十三篇「大劫決裂」（PW-26）：上一紀元執行者、劫化群體、殘缺秩序依序構成理念、實戰與終局壓力；無始成種，陸沉拒絕永恆劫序並開放共同承劫。
4. PW-26 結局／後記接口：清點終戰殘留後，才建立固定公共的萬劫沉封域；此段只處理本作戰後責任，不進入 PW-27／28 改寫荒的後續功業。

## 控制原則

- PW-25 必在 PW-26 前；舊有「第十三篇後五百年延伸收尾」說法作廢。
- 母親線在長息中段，父親線最終狀態在前，同代老去與荒再起在後。
- 第十三篇必須獨立完成本書核心命題；可選「萬古獨行」只作後記／番外容器。
- 曆年年齡、外貌階段、閉關／封存時間依境界時間表逐項登記。
