# 魔女與陸沉：北海以前的六次相遇

狀態：現行事件唯一來源 v1.0（2026-08-02）

## 一、總體目的

北海後魔女把陸沉推出來與石昊比試以前，兩人必須已形成持續多年的關係線。六段不是六次無關巧遇，而是同一問題逐步加深：一個極適合截天教的人，為何始終不肯成為截天教的人？

三場必須寫重：虛神界共同逃生、百斷山互相救命、假殺石昊委託。荒野追殺、真假委託、正式邀請負責連接能力成長、信任與三次招攬，不得全部壓成回憶摘要。

## 二、第一段：虛神界初遇——她第一次看見不肯死的人

- 魔女偽裝成普通少女，與神識遠強於同階、已能預布少量低階禁制但尚無法臨戰改禁的陸沉同陷上古殘禁。
- 她其實有強行脫身手段，卻暫不揭露，想觀察陸沉。
- 陸沉記住死者觸發禁紋的位置，以碎石、殘兵與神識逐次試探，在必死規則的運轉停頓中找出唯一生路；他不是打破古禁。
- 出禁後她試探是否願意跟隨能教他的人離開，陸沉反問她為何不自行脫身，揭示他早已察覺她藏力。
- 離場改變：魔女認定他具有截天之才；陸沉認定她危險、隱瞞甚多，卻未真正置自己於死地。
- 與仙王殘識線的邊界：本段只能發生在仙王封典之前或外圍，魔女不得旁觀完整禁典傳承，也不是仙王機緣的引路人。

## 三、第二段：荒野追殺——她看見劫第一次反擊

- 陸沉被下界勢力追殺，已有少量依賴材料、地勢與預備時間的粗淺禁制。
- 他串起山勢、毒瘴、獸群與殘陣，仍不能靠單一禁制正面殺敵。
- 魔女暗改一處地勢測試其應變；陸沉補上破口，並順著這次不自然改動找到她的位置。
- 真正的末道警示禁紋一直在魔女腳下，證明陸沉從未把看似幫助自己的人排除於風險之外。
- 離場改變：他從尋找別人留下的生路，跨到替敵人製造死路；魔女第一次隱晦提及「截天」。

## 四、第三段：真假委託——第一次平等利用

- 魔女請陸沉取得一卷上古禁制殘篇，隱瞞遺跡同時藏有截天教所尋下界線索。
- 魔女負責偽裝、情報與把守護者騙離核心；陸沉負責讀規則、改禁制流向與預留撤路。
- 真正遺物必須兩人合作才能帶走；任何一方單獨都會觸發封閉或毀物。
- 陸沉早知情報不全，仍因自己也需要殘篇而接受。他說「因為我也在利用妳」，確立第一次近乎平等的合作。
- 魔女多分一部分收穫，嘴上仍稱報酬；不能由旁白直接宣布她已在意，須讓分配與她原先談好的條件不完全一致。

## 五、第四段：正式邀請——跟我回截天教

- 時間置於太玄閣前後、百斷山以前；陸沉已有較完整煉體與禁制基礎。
- 魔女以較接近真實的身分出現，提供神魂法片段、上古禁制演示、上界眼界、庇護與不必獨自摸索的道路，第一次正式招攬。
- 她親自教一小段截天法理：禁制未必要補全所有規則，有時截走最關鍵的一環，整體便會自行崩解。
- 陸沉必須認真考慮，而非為顯示主角堅定立刻拒絕。他最後問入教後需要成為什麼；魔女能給好處，卻不能保證教門不替他決定用途。
- 他拒絕的不是魔女本人，而是任何會先替自己決定用途的勢力。

## 六、第五段：百斷山重逢——第一次互相救命

- 百斷山天地雷火不是第一雷、雷種或雷胚；它暫時活化禁紋並淬煉承雷肉身。
- 魔女發現陸沉已把截天法理改成自己的活禁雛形：不是從天地截取力量，而是讓雷意沿禁紋傳導，使禁制在有限條件下自行變化。
- 魔女為取寶引來強者，原想趁亂行事，卻因禁區天地雷意失控而真被困住。她不能保有隨時自行脫身的隱藏底牌。
- 陸沉本可攜機緣離開，仍回頭改禁救她；「妳利用我，與我讓不讓妳死，是兩回事」表明他的底線。
- 魔女隨後替重傷、正在承受雷火淬體的陸沉遮掩氣息並誤導追兵，兩人才活著離開。不得寫成單向英雄救美。
- 離場改變：魔女第一次由欣賞能力轉為理解他的選擇與底線；兩人有了不能被普通交易取代的共同生死記憶。

## 七、第六段：假殺石昊委託——最後一次招攬

- 時間置於百斷山後、北海四人相聚前，石昊已開始嶄露頭角。
- 魔女要求陸沉殺「石昊」。此時陸沉已知道她常說七分真話、替截天教觀察天才，也知道這可能是入教考驗。
- 陸沉接受調查與入局，但不照她給的殺法行動。他與石昊短暫交手後，看出局中另有真正刺殺者，與石昊聯手反殺。
- 魔女的多重目的：試探石昊、引出刺殺者、讓石昊與陸沉互認，也測試陸沉是否盲從她或截天教。她不能預知全部結果；真正刺殺者須有自己的情報與反制，使三方都需臨場改局。
- **谷中真正刺客的雇主歸屬（2026-09-12新增，回應 `CHECKLIST_PENDING_DECISIONS.md` 第179題）**：幕後雇主是天罰一脈更早期、持有古老指令的下界代理人／散修個體行動，非道統正式出動，不建立天罰一脈在下界的正式據點。石昊當時已因至尊骨遭多方覬覦，是該道統「提前抹除潛在災劫之人」教義的典型目標。正文中天罰一脈從未被點名，石昊、陸沉當下均不知情，只留匿名線索（兩組互不相識者買同批藏息粉、比魔女情報早兩日的刀痕、一枚黑錢暗記）；魔女言明「黑錢上的暗記，我去找源頭」，其下落留待後續回收。**揭曉節點**：正文本身不點名；最早於天神書院司天鑑正式登場後才可回溯連結為可疑線索，不早於界潮篇既定的「道統首次埋痕跡」定位，也不強制在十凶血路疊加（該處已有血祭殘煞主線）。完整唯一來源見 `characters/CHARACTER_RIVAL_TIANFA.md` 四「背景伏筆」。
- 陸沉回報「人沒殺」，並指出她要看的已經看見。
- 魔女最後一次問他是否入截天教；當陸沉問這次是否也是假的，她明確承認這次是真的。陸沉仍拒絕，她不再勸。
- 離場改變：她確認陸沉適合截天教的原因，恰是他永不會真正屬於截天教。

## 八、北海四人相聚的回收

- 北海原作核心機緣與石昊、魔女、月嬋關係不可被陸沉取代；陸沉只在主事件後的四人相聚／短暫同場進入回收戲。
- 魔女把陸沉推出來與石昊比試，是對六段成長的驗證，不是臨時拱火。
- 月嬋若質疑陸沉依靠布局、禁制與取巧，魔女的維護只需一兩句，不得當場講完六段履歷。核心意思是：月嬋看見他今日站在禁制中央，魔女看過他最初連一道保命禁制都沒有。
- 陸沉能辨認魔女表面鬥嘴、實際替他的道路辯護；他不必公開道謝，後續行動或一句短答即可承接。

## 九、寫作與驗收安全閥

1. 六段每次都必須改變能力、信任、邀請或彼此判斷，不能只是重複「她騙、他看穿」。
2. 魔女至少一次真正騙過陸沉；陸沉至少一次因情報不足重排，不得六次全勝她。
3. 重大場景須有目標、阻力、第一次方案失敗、選擇、代價與後果，不得靠一段旁白交代多年熟識。
4. 魔女有自己的教門任務、利益與風險；她不圍繞陸沉待機。
5. 陸沉的禁制根源仍是求生、神識、《古神禁典》與自身試錯；截天法理只提供一次重要啟發。
6. development 與 published 必須同步；北海回收落筆前先確認原作時間、人物同場資格與石昊的核心機緣未被改寫。
