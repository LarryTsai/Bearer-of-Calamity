# 命圖初成：定星模板與玄衡入環

> 狀態：正式事件 v1.0
> 正文：`novel/volume05/chapter011.md`～`chapter018.md`
> 時間：無兵雷域後、前往天神書院前

## 一、事件鏈

陸沉在無兵雷域承接域心外部本源、以肉身將空手定形後，因新雷難以收力、雷身時序傷尚未痊癒，進入北路定星院。院主依其現有六道雷息製作六槽定星石盤：它能固定當下星位、抑制空手自行逆入、讓煌命身與承身安全分合，卻會封閉未來空位，使鎮界永遠停在當前雛形，後續力量只能另建第二張無法歸一的圖。

洛生衣右腿仍在恢復期間，基於自身安全要求暫用六槽投影；玄衡因模板預設外環退出會傷及陸沉，拒絕進入獸格。待洛生衣能獨自行走，陸沉才決定撤圖，並接受院主所說「日後若有人因今日選的風險而死，也是他的帳」。

撤圖時鎮界與空手運行衝突，陸沉以一次性、精度不足的自我設限將六雷壓回各自星位九息，再以劫命切斷模板殘線。代價是命圖裂紋擴大、吐血、鎮界十二日不能主動喚起、右膝冷感回歸；這不是禁天正式解鎖。

十二日後，六雷依各自經歷長出不規整星路，形成可辨識的命圖初始骨架。玄衡確認陸沉即使不認同也不會阻止牠日後離開，才自主展開魂印，在鎮界星位外踏出保留出口的麒麟外環，正式入環。

## 二、離場狀態

- 陸沉：真一初期，不因空手或命圖初成自動升境。
- 命圖：六雷初始骨架，可梳理回位；不可投映戰場、不可保證推演、不可預畫後四雷。
- 空手：仍難精準留力，觸物與自身都會受損；制勢指尚未形成。
- 鎮界：仍為成長中的雛形，未因玄衡入環立刻完整。
- 玄衡：正式進入外環，但外環保留可退出缺口；非戰敗臣服或不可撤回的收編。
- 洛生衣：右腿可行走，轉向仍慢，不是完全痊癒。

## 三、安全閥

- 定星院與六槽石盤是針對現況製作的救治工具，不是十雷完整傳承、神器或敵對陷阱。
- 陸沉拒絕模板不代表固定道路對所有人都錯；終章把裂盤留在定星院磨平重製，供下一個只需先活到明日的人依自身情況重新畫槽。
- 自我設限只作用於陸沉自身九息，沒有禁制外界、敵人或天地大道。
- 玄衡入環的前提是撤回權；後續罪州解除命印時不恢復、不填平的既定結果不變。
