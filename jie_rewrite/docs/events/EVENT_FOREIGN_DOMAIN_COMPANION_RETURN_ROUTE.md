# 異域同行與帝關守路

狀態：現行事件設定 v1.0

## 一、事件定位

| 項目 | 設定 |
| --- | --- |
| 時期 | PW-22A～22E；荒身落異域、尋得原始帝城後裔並返關 |
| 外線 | 荒與陸沉入異域後強制分線；荒完成原作核心功業，陸沉處理追兵、界路與撤離後患 |
| 內線 | 洛生衣留在帝關保管歸身回路，阻止返程座標被過早抹除 |
| 結果 | 荒先帶原始帝城後裔返關，陸沉斷後最後通過；永久界痕惡化 |

## 二、陸沉主動越界

九天十地決定交出荒時，陸沉不在交換名單之內，也不能阻止荒遭自己人犧牲這項原作矛盾成立。他只做一件事：在交界閉合前自行跨過界線，成為唯一主動站到荒身旁的人。

> 異域要的是荒。陸沉是自己來的。

這項選擇不把二人都改寫成被交易的祭品。荒仍是被九天十地交出的人；陸沉則拒絕讓「被交出」等於「只能獨自被犧牲」。他沒有替荒決定是否離開，也沒有把同行包裝成救援成功。

## 三、進入後必須分線

二人入異域後不得全程雙人橫推。異域封鎖與追殺迫使他們分線：

- 荒獨自承擔原作所見所聞、具名敵手、敵方世界真相、尋得並救出原始帝城後裔及帶返帝關等核心功業。
- 陸沉只處理原作未聚焦的側線追兵、空間道標、被切斷的撤離支路及荒帶人撤退後留下的後患。
- 陸沉不得參與尋人與救人本體，不替荒證明七王與罪血真相，也不得以補刀取得荒的核心勝利。
- 二人可以短暫交換情報或在撤退節點重新會合，但每次交會都必須服務分線，而非把荒的孤身經歷改成雙人歷險。

此時第九雷尚未在 PW-23D 補全，不能提前套用「九雷完整後荒劫同強」；兩人也都尚未正式成為至尊。

## 四、洛生衣守住回來的路

洛生衣留在帝關不是被動等待。陸沉越界前以無聲渡笛的「歸身」節奏與命圖道標留下微弱返程回路；它只能證明陸沉仍在嘗試回返，不能精準定位、不能無成本開門，也不能保證通過者未被異域利用。

她的責任是保管這條回路、維持傷兵與陣路生機、阻止城內勢力以安全為名過早抹除座標，並接受公開監看。若回路反被異域利用，她必須親手斷路，所有空間與生命反噬先由她承受。

> 陸沉負責從異域走回來；洛生衣負責不讓回來的路被自己人關掉。

她保留回路不是以感情否決戰場風險，而是在承認風險後，把判斷、責任與代價一併留在自己手中。

## 五、返關順序

荒找到返程並帶原始帝城後裔先行通過，陸沉留下截斷追兵與界路污染。當孩子們已回帝關、追兵亦逼近回路時，守關者要求立即關陣；洛生衣從歸身節奏判斷陸沉仍在接近，只要求多留一息。

那一息讓陸沉最後踏回帝關，也讓異域餘威擊中陣路。洛生衣承受斷路反噬，陸沉既有的永久界痕則因強行跨界全面惡化。二人都不能把這次歸來視為無代價的信任勝利。

陸沉返關後才與荒共同介入原始帝城後裔遭受的處置爭議；尋找、救援、揭露真相與帶返的功業仍全部屬荒。

## 六、與安瀾壓境的界線

荒返關後的不朽者壓境仍依原作處理。荒與陸沉此時位於斬我至遁一線，確切小階待逐章核定，均非正式至尊。荒面對安瀾等不朽者的核心名場面不可分流；陸沉只能在另一節點鎮住次級界裂、保護守軍並承接不朽餘威，不得把爆發狀態寫成名義境界突破。

## 七、安全閥

- 陸沉不能阻止荒被犧牲，只能拒絕讓荒獨自被犧牲。
- 荒的異域核心功業、具名敵手與歷史位置不得轉移。
- 陸沉與荒進入後強制分線，不得全程雙人橫推。
- 洛生衣沿用續脈、無聲渡笛歸身與命圖外部調律，不新增萬能神器。
- 剎那劫不能自由往返異域；跨界須依道標、界路與陣法，並惡化永久界痕。
- 戰雷池陣網在異域沒有預鋪節點，整網失效；最多攜帶一枚一次性預充池，耗盡或受異域法則污染即棄，不能回充、聯絡帝關或提供返程定位。
- 本事件不得提前清算金家、不得讓荒劫跳階成至尊。返關後亦須先讓孟天正的原作問罪完整發生；劫只在其後依新增罪證另案執譴。
