# 燃身雷界：玄燼凰守池，赤翎歸位

狀態：現行事件設定 v2.0（2026-08-02 來源裁示）

## 一、事件定位

| 項目 | 設定 |
| --- | --- |
| 事件 | 陸沉循焚羽戰區的暗紅雷跡主動追入燃身雷界，在外部燃身雷池取得燃身；玄燼凰守池讓路，赤翎其後自願同行 |
| 時期 | 帝關血戰中期 |
| 地點 | 帝關外焚羽戰區深處的燃身雷界／燃身雷池；焚羽古巢是入口與守池地，不是雷種孕床 |
| 結果 | 外部燃身本源認可陸沉；赤翎自主交出可解除魂印，進入命圖外環 |
| 來源硬界線 | 玄燼凰不贈火、不供應源雷；赤翎的魂印也不是燃身來源 |

## 二、需求、線索與主動追索

裂界防線遭逼守、斷援，失聯軍隊困於焚羽戰區。陸沉以既有雷身和自身命力守撤離通道，留下血肉焦裂、雷脈灼傷與命圖外環裂痕；這次自燃只揭露「他缺少能分辨可燃之身與不可燃之命的雷」，不得寫成燃身已在戰場自行形成。

他在傷口、焦羽與戰區雷痕中辨出同一股暗紅脈動，交換古巢資料並主動申請追索。劫厄、救援隊與陸沉因此深入焚羽古巢，穿過凰族遺留的燼門，抵達本就存在的燃身雷界。

## 三、雷境生態與歷史

燃身雷界曾是古凰族以敗羽、壞肉與戰後殘軀換取新生的試煉地。食火藤吞噬無主燼屑，灰羽蟲替雷池剝離腐敗血肉，燼鴉則會把仍有生命節律的火種送回池岸；三者共同維持「燒去可捨之物，不焚核心命火」的舊秩序。

後來有人以壽命釘抽取雷池命焰，雷界生態失衡，古巢只餘焦骨。玄燼凰留守池門，不是等待把火贈給後來者，而是阻止任何人再把眾生命數當燃料。

## 四、守關者、競爭者與首次失敗

灰甲取火者沿途釘入壽命釘，企圖將整座雷池煉成軍用命火。玄燼凰同時攔住他與陸沉：前者把別人的命當薪，後者則習慣先燒自己的命，兩者都尚未理解燃身。

陸沉首次入池時仍把「燃身」誤解成燒得更狠。他令血、骨、魂與核心命火一同起燃，兩具分身雷身（承身、煌命身）相繼熄滅，本尊親歷瀕死重傷卻不能像分身一樣被消耗掉再重凝，胸口留下無法立刻補回的生命空洞；證明此次嘗試失敗，燃身尚未取得（本尊＋分身雷身數量硬上限見 `systems/SYSTEM_THUNDER_BODY_SCALING.md` 一之一）。

劫厄自主闖入雷界截斷壽命釘，受燼火重傷。陸沉沒有拿同伴或凰族餘命換自己續命，而是先收回外溢火勢、救劫厄並阻止灰甲取火者繼續抽命。

## 五、讓路、取得與歸位

玄燼凰確認陸沉願意承擔自己的選擇、卻不把別人的命當薪後，只替他守住池門並讓開十二息。牠沒有分出餘命之火，也沒有把自身力量灌入陸沉。

陸沉在十二息內獨自走入燃身雷池，重新分辨已壞死、可燃盡的肉身與不可拿來支付的核心命火。他承受焚身之劫而保住本我節律，外部燃身本源遂自行離池、進入命圖成種。取得後仍保留生命空洞、焦裂與雷身熄滅的長期代價；燃身提供的是承受與轉化資格，不是不死。

赤翎直到雷種已由外部雷池完成認可，才因陸沉守住「不再抽取任何人的餘命」這條界線，自願交出可解除魂印。牠以獨立生命同行，可拒絕、離位，也不替陸沉免除燃身反噬。

## 六、能力與限制

- 燃身可燃去已崩壞的肉身、雷身或可支付的自身力量，換取短時爆發；不能把他人壽命轉成自己的燃料。
- 核心命火若被誤燒，生命空洞會擴大，不能靠赤翎無限補回。
- 赤翎可守住撤離路、留下灰燼道標，或在陸沉失控時提醒界線；不得寫成替他供能、續命或代付死亡。
- 焚羽古巢、玄燼凰的判斷與赤翎的魂印都只構成門檻、見證與同行，不構成燃身本源。
