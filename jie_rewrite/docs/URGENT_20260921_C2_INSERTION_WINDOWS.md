2. 到場與試煉故事：用已核的當期戰法呈現天驕、地方競爭與陸沉選擇。不能預先承諾所有對手只是雷台機關；也不能把登台寫成純承壓。
3. 正常登頂／正常故事高潮完成：榜碑與傳承屬顧問容許形式，獎勵內容未定；不得新增雷種、完整戰鬥體系或跳境。
4. 由親見結構發現未完，局部解禁得到用途不明古物。陸沉獨立完成，但不代表所有人都看不見或已知他拿到鑰匙；鏡頭須決定信息边界。
5. 試煉地方的後果與陸沉返閣：補傷勢、實際攜物、普通生活；第一鑰保持沉寂。出窗接風暴，已有守閣因果照常成立。
