# Agent 擴充計畫：術法、陣法與跨作品靈感轉譯

## 一、計畫目標

本計畫旨在擴充 `story/jie_rewrite` 的創作 Agent 工作流，吸收耳根作品中令人喜愛的術法設計、陣法結構、因果意境、歲月感、真假變化與生死思辨，同時遵守以下原則：

1. 《完美世界》的世界觀、境界體系、時間線與既定規則具有最高優先級。
2. 只提煉創作方法、氣氛和設計原理，不直接搬用其他作品的專有名詞、角色能力或標誌性情節。
3. 新術法與陣法必須經過重新設計，成為本作角色、力量體系與劇情自然生長出的原創內容。
4. 每項能力都必須具備來源、限制、代價、破解方式及劇情用途，避免出現萬能能力。

核心方向：

> 骨架遵循《完美世界》，精神養分來自喜愛的作品，最終長成屬於本作自己的血肉。

## 二、預計變更範圍

- 新增 Agent：3 個。
- 調整既有 Agent：4 個。
- 暫不調整既有 Agent：3 個。
- 新增一份共用的術法與陣法設計規範。

## 三、預計新增的 Agents

### 1. `jie-mystic-arts-designer`

定位：神通、寶術、禁術、秘法與個人施展型能力的設計者。

主要職責：

- 設計術法的核心概念、道意、施展條件及視覺表現。
- 確認能力具有明確限制、消耗、反噬與破解方式。
- 建立能力隨角色境界成長的演化路線。
- 強化因果、歲月、真假、生死、封印、咒殺等玄妙感。
- 將外部靈感轉化為《完美世界》力量邏輯內可成立的寶術或修行成果。
- 避免直接複製其他作品的術法名稱、完整機制與招牌表現。

建議輸出格式：

```text
術法名稱：
核心道意：
所屬體系：
施展媒介：
發動過程：
外在異象：
實際效果：
代價與反噬：
破解方式：
境界成長：
劇情用途：
原創性風險：
```

### 2. `jie-formation-designer`

定位：陣法、禁制、祭壇、地勢與大型儀式的設計者。

主要職責：

- 設計陣眼、陣基、能量來源與運轉層次。
- 處理困陣、殺陣、幻陣、封印陣、傳送陣及養成型大陣。
- 將陣法與地形、遺跡、寶骨、血脈、星象或天地規則結合。
- 為陣法安排可被察覺的線索、推演過程、破壞方法及反向利用空間。
- 確保陣法效果源自其結構與資源，而非臨時增加規則。

建議輸出格式：

```text
陣法名稱：
設陣目的：
陣基與陣眼：
能量來源：
空間結構：
啟動條件：
陣內規則：
殺機層次：
破陣線索：
強行破陣後果：
主持者代價：
世界觀相容性：
```

### 3. `jie-inspiration-adapter`

定位：跨作品靈感的抽象、轉譯與原創性守門者。

主要職責：

- 判斷喜愛的部分屬於氣氛、結構、代價、戰鬥邏輯或哲學命題。
- 移除原作專有名稱、角色印記、標誌性情節及過於相似的視覺表現。
- 將靈感先抽象為通用創作原理，再重建為本作原創設計。
- 檢查新設計是否過度接近其他作品的既有能力。
- 說明新設計為何能在《完美世界》的世界觀及本作自有系統中成立。

必要的二次轉譯流程：

```text
具體靈感
  ↓
抽象創作原理
  ↓
《完美世界》規則與本作角色條件
  ↓
重新命名、重建機制與代價
  ↓
原創術法或陣法
```

此 Agent 同時承擔初步的原創性檢查，第一階段不另設獨立的 `originality-guard`。

## 四、需要調整的既有 Agents

### 1. `jie-power-system`：中度調整

調整後定位：不再負責包辦所有能力創作，改為力量體系、平衡性與境界適配的主要審核者。

新增檢查項目：

- 角色當前境界是否足以施展或承受。
- 能量、符文、寶骨或其他力量來源是否合理。
- 是否存在不合理的長期越級能力。
- 消耗、限制與破解窗口是否清楚。
- 新能力是否會令既有能力失去價值。
- 是否能與十劫雷、雷身、太玄命圖等自有系統結合。
- 在《完美世界》的境界體系中應歸屬於哪一層次。

分工原則：

- 新增 Agents 負責創造術法與陣法。
- `jie-power-system` 負責定標、平衡與駁回不合理設計。

### 2. `jie-creative`：小幅調整

新增任務路由規則：

- 單體術法、寶術或禁術：交給 `jie-mystic-arts-designer`。
- 多人運轉、地勢或空間結構：交給 `jie-formation-designer`。
- 明確源自其他作品的靈感：先交給 `jie-inspiration-adapter`。

`jie-creative` 繼續負責情節構想、衝突與創意方案，不包辦術法和陣法的完整技術細節。

### 3. `jie-canon`：小幅調整

新增「外來靈感相容性」檢查：

- 是否出現無法由《完美世界》規則解釋的力量來源。
- 是否繞過既有修煉境界或破壞力量邏輯。
- 是否直接使用其他作品的專有名詞或概念。
- 是否改變原作重大事件的成立條件。
- 新能力屬於原作既有寶術、角色自創術，還是古代遺法。

`jie-canon` 保有設定相容性的最高否決權。

### 4. `jie-writer`：小幅調整

新增術法與陣法的正文呈現規則：

- 不在初次出現時一次說完所有規則。
- 先以異象、結果與角色反應建立神秘感。
- 透過試探、失敗、受傷、推演與破陣逐步揭示規則。
- 戰鬥因果必須清晰，不能只堆疊華麗名詞與異象。
- 同一能力的名稱、手印、代價、效果與限制前後一致。

## 五、暫不調整的既有 Agents

### `jie-character`

現有職責足以檢查能力是否符合角色性格、經歷、選擇與成長，不需在第一階段調整。

### `jie-continuity`

現有職責足以檢查術法和陣法在不同章節中的名稱、效果、傷勢、消耗與時間連續性。

### `jie-chapter-editor`

現有職責足以檢查戰鬥可讀性、資訊揭露速度、章節節奏與文字效果。

待新工作流實際運行兩至三次後，再判斷是否需要補充規則。

## 六、完整工作流程

```text
作者提出喜愛的術法、陣法或創作感覺
  ↓
jie-inspiration-adapter
抽象、去除專有元素、進行原創轉譯
  ↓
jie-mystic-arts-designer 或 jie-formation-designer
完成能力或陣法的詳細設計
  ↓
jie-power-system
檢查境界、強度、代價、限制與破解方式
  ↓
jie-canon
檢查《完美世界》設定、時間線與原作相容性
  ↓
jie-creative
將能力嵌入人物衝突、伏筆與情節功能
  ↓
jie-writer
轉化為正式正文
  ↓
jie-continuity + jie-chapter-editor
檢查前後一致性、節奏與閱讀效果
```

## 七、分階段執行計畫

### 第一階段：建立基礎架構

1. 新增 `jie-mystic-arts-designer`。
2. 新增 `jie-formation-designer`。
3. 新增 `jie-inspiration-adapter`。
4. 中度調整 `jie-power-system`。
5. 小幅調整 `jie-creative` 與 `jie-canon`。
6. 建立共用的術法與陣法設計規範。

### 第二階段：案例試跑

選擇三個不同類型的案例：

1. 一門帶有歲月侵蝕感的雷道禁術。
2. 一座借眾生恐懼或情緒運轉的遺跡殺陣。
3. 一種真假難辨、但符合寶術邏輯的幻禁。

每個案例都需完整走過靈感轉譯、能力設計、力量平衡與設定審核。

### 第三階段：寫作落地與檢討

1. 小幅調整 `jie-writer`。
2. 選擇一個已通過審核的案例寫入測試場景。
3. 交由 `jie-continuity` 與 `jie-chapter-editor` 檢查。
4. 根據實際結果判斷是否需要新增獨立的原創性審核 Agent。

## 八、完成標準

本計畫完成後，Agent 工作流應能做到：

- 能清楚說明靈感來源中真正值得保留的設計原理。
- 不依賴其他作品的專有名詞也能成立。
- 新術法與陣法符合《完美世界》及本作自有力量體系。
- 每項能力具有代價、限制、破解方法和成長空間。
- 能力服務於人物與劇情，而非只追求華麗或強大。
- 正文呈現具有神秘感，同時維持可理解的戰鬥因果。
