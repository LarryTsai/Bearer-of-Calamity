此為從騙認知到讓虛假取得短暫存在資格的全新分支。五限制：合理具體因果、真信門檻、极短時效、識破即潰、本人反噬。不能無中生有完整大道與生命；與洛續脈聯合的一次結果不變成個人造生命；灰沙皿單場景生機路徑不成常駐改命工具。用「虛實之道／存在資格」，不占無相離身卷的「虛實轉換」。046身形虛化入陰影不能倒推已會這條大道。舊仙古04-002已失效，不能搬字改成古界到場。
