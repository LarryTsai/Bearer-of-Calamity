## 一、整體故事判斷

三條新主線不是互相競爭，而是同一條成長鏈：文奕使陸沉學會建造可維護的禁制系統；古界路讓這套方法面對完整／殘缺大道的結構戰；燼長明與第八雷改變陸沉把死亡當答案的習慣；異域再以完整大道真正毀掉五人的舊根基。後期玄衡解印與共同承劫契約，則回頭修正「危機中的自願」不能被制度默認為永久義務。

因此整合後，Volume10 玄衡離印與 Volume11 共同承劫不應刪除，反而會比現稿更有前史。

## 二、必須先解決的 P0

1. **文奕下界方式**：須在正文前鎖定他以實身或虛神投影下界、護送與返回機制、文家為何允許、以及他為何不介入下界大劫。
2. **共同禁典**：Volume01 ch011～013 必須由陸沉單人得典改為陸沉、文奕各自取得完全相同且完整的《古神禁典》；實體頁只能是鑰匙，不得造成版本差。
3. **燼長明與取雷順序**：Volume07 必須是首次取雷因陸沉把死亡當答案而失敗，燼長明自主回頭燃盡救人、重生並加入，修復界路後才第二次取雷成功。
4. **雷源地理**：餘命燼雷改為古界路天然核心的外部完整本源；焚羽古巢不能只換名繼續當孕雷池。
5. **荒功業隔離**：陸沉為荒潛伏，但不能替荒尋回原始帝城後裔、解決具名敵手或完成原作核心路線。情報目標應放在荒的轉移、敵方收網與返程封鎖。
6. **返關順序**：可讓陸沉五人與荒在同一撤退行動會合，但荒仍先帶孩子過門，陸沉五人斷後最後通過，洛生衣守一息後自主斷路。
7. **五星循環性質**：是五方在死局中自願形成、可撤回的第一次生命閉環，不是永久命印或不可缺一的綁定；否則會撞毀 Volume10 玄衡解印。
8. **能力時序**：完整大道只重塑現有八雷的承載方式、肉身、神識、雷種與禁制感知；不得提前第九雷天譴、第十雷無始、至尊境或成熟活禁。

## 三、建議重建範圍

### 禁道主線

- Volume01 ch011～013：文奕初遇、共同解禁、雙方同得完整禁典並分路。
- Volume01 ch023～028：百斷山短暫再遇；保留荒初見、魔女互救與天地雷火功業，文奕只承擔結構判讀與自主分線。
- Volume02：文奕不常駐，只讓其結構觀在陸沉的早期誤用與局部成功中留下影響。
- Volume03 現行 ch001 前：新增約 18～24 章禁都／萬禁會／奪禁篇；文奕正式奪魁，陸沉犯規敗局但完成奪禁。現有三千州篇整體後移，萬禁碑林仍保留。
- Volume04：在不搶謫仙與玄衡主線下，新增約 3～5 章仙古禁遺跡再遇。
- Volume05 命圖初成後：新增約 12～18 章文家遭難；文奕先守陣、先作不可逆選擇，陸沉只改變外部死局。
- Volume06：以少量禁訊／共同維護事件保持文奕存在，為帝關雙軍師蓄積可信前史。

### 界路與第八雷

Volume07 ch041～048 現有八章約八千字，應重建為約 14～18 章、2.2～3 萬字：

1. 入界路與龍鳳衝突。
2. 鳳族守界、陣禁駭客戰與界釘。
3. 第一次取雷失敗及真正界路死戰。
4. 燼長明可撤而回頭、燃盡救人、灰燼等待與有代價重生。
5. 五人療傷日常、鳳質問陸沉為何總把自己的死當答案。
6. 群體修界、建立替代平衡、第二次取雷與回帝關。

可保留雷跡搜救、雷界生態、三雷身熄滅、生命空洞、醫療封存、燼羽留名、傷者姓名、劫厄自主闖危局，以及「鳳不贈雷、伴星不供雷」硬界線。

### 異域潛伏與完整大道

- Volume08 ch001～012 可壓縮保留遺骸交換、交荒、主動越界、洛生衣守路及跨界代價。
- ch013 起重建為王族偽裝與情報戰；安排至少四至五種不同任務，而非連續偷情報：滅口／救人、玄衡古禁潛入、宴席欺詐、鎮無央誘敵、燼長明失火。
- 每次任務必須以一份持續傷勢換一份與荒的後續轉移或返路有關的情報。
- 後段依序完成帝族反解析、假情報收網、完整大道大劫、一命換四的失敗選擇、四伴星搶回自身之劫、五星循環、限定範圍短清場、真正休養、尋荒與共同撤退。
- 現行 ch033～040 洛生衣七日潛伏是可保留的獨立故事，但不宜在異域大劫後沖淡餘波；應移到 Volume09 前奏或另行調位。

## 四、角色成果保留線

- 荒：所有原作具名敵手、帝城後裔尋救與帶返功業不分給陸沉。
- 洛生衣：不是留在帝關等待；她必須處理假訊、污染、公開監看與斷路票決，但不能跨界通話、定位或供能。
- 燼長明：Volume07 是為陸沉燃盡後重生並自主同行；Volume08 失去凰火後靠自己點燃第一點新火，兩次事件不可重複。
- 玄衡：Volume08 自願進入五星循環；Volume10 因命圖把一次自願默認成未來義務而解印；Volume11 再以外部盟友身份選擇並肩。
- 文奕：每次登場都要有獨立目標、正面戰力與不可替代決策，不作陸沉的禁道百科或帝關替身。

## 五、戰力與反派安全閥

- 帝族的收網必須真的殺死五人的舊根基；返本是五人互相拒絕獨死造成的未知結果，不是帝族愚蠢送機緣。
- 大劫後清場只限被封鎖劫域、已投入解析模型的現場追獵者；依靠敵方封鎖反噬與重塑後的精準用力，不代表能越階橫殺所有帝族或不朽者。
- 清場後必須立即隱匿、休養，傷勢不得在下一章重置。
- 界路修復必須有失敗、資源和多方權限，不能由陸沉一人瞬間修完。

## 六、閉環驗收

- 讀者能從故事證明陸沉與文奕所得禁典完全相同，能力差異來自教育與人格。
- 燼長明可撤而主動回頭，重生支付具體且後續仍在的代價。
- 兩次取雷具有不同失敗／成功判準；雷不是鳳所贈，取走前先修界。
- 五人每道傷勢都有來源、治療限制與後續記憶；四伴星各有決定而非只列能力。
- 讀者能說清荒哪些功業完全獨立完成，洛生衣為何守路及何時斷路。
- 完整大道明確改變了什麼，也明確沒有提前給出什麼。
- Volume09 承接新傷勢與能力，Volume10 解印、Volume11 契約仍成立且因果更強。
- 宏綱、因果網、人物／事件／系統唯一來源、development 與 published 全部同步後，才可把三條裁示標為完成。

## 七、執行裁決

章數不鎖死。現行 583 章是舊版本的結果，不是新主線的限制。先完成宏綱與因果網重排，再依 Volume01 → 03 → 04／05 → 07 → 08 → 09～11 的依賴順序寫作；每一段完成後重讀前後邊界，避免一次改完整庫後才發現錯誤擴散。
