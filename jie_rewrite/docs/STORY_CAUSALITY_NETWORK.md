# 陸沉原創故事因果與伏筆總網

狀態：主線因果索引／高風險事件檢核 v1.1

## 一、核心原則

陸沉的原創故事不得以「需要一項能力，所以安排一座秘境」為起點。外界可以提供條件、偶然與錯誤線索；真正的重要能力不能憑空發獎，重大選擇也必須留下不可抹除的後果。

全書只保留三條硬規則：

1. **能力不得憑空發獎。**
2. **重大選擇必須留下不可抹除的後果。**
3. **原創故事不得奪走原作角色的核心功業。**

完整的跨篇故事鏈最終應能回答下列問題，但**不要求每個事件同時填滿**：

1. **從哪裡長出來**：承接哪一場失敗、傷勢、承諾、人物欲望或原作局勢。
2. **當下改變什麼**：人物作出何種不能無代價撤回的選擇。
3. **得到什麼**：法術、傳承、雷種、器物、關係或公共規則。
4. **欠下什麼**：肉身、神魂、關係、政治、倫理或制度上的代價。
5. **往哪裡去**：可能立即回應、隔篇翻義、跨篇回收，也可能只留下痕跡而不直接解答。

單一事件可以只負責種因、誤判、勝利、失敗、留物、揭價、改變配角或回收其中一項。事件的存在價值也可以是改變情緒節奏、讀者認知、地域質感與人物生活，不必全部服務能力或制度。至少一半日常不承擔明示伏筆；純損失、偶然錯誤與永遠只解一半的異象皆可存在。

## 一之一、因果不等於直線

- 因果可以隔數篇才閉合，不必前一章受傷、下一章立刻得法。
- 能力可以先出現，人物多年後才理解其真正用途。
- 代價可以延遲揭露；勝利當下不必立即列出損耗清單。
- 伏筆可以先被合理誤解，後來只翻轉部分意義。
- 配角可以先完成自己的故事，陸沉後到，只能接手或承認不是事件中心。
- 角色做對的事仍可能毫無所得，甚至沒有救成功。
- 偶然可以把人物帶進故事；進入之後的選擇與後果才須自洽。
- 世界不必每件事都與陸沉相連；有些古災、舊制與普通錯誤本就獨立存在。

## 一之二、事件功能與回收距離警戒值

以下是長篇節奏警戒值，不是逐十章機械配額：

| 主功能 | 約略比例 | 控制方向 |
| --- | --- | --- |
| 能力／雷種取得 | 約 10% | 不連續兩次以得雷、得器收尾 |
| 能力失敗、誤用、反噬 | 約 15% | 應多於能力取得 |
| 關係變化 | 約 20% | 包含疏遠、誤解未解與各自行動，不全是更信任 |
| 制度／公共規則 | 約 10% | 集中在中後期；早期私事不必都預演治理 |
| 懸案、異象、錯判 | 約 15～20% | 可跨數篇，部分只澄清一半 |
| 純損失 | 約 10% | 不兌換能力、情報或道德正解 |
| 日常、地域、職業生活 | 約 15～20% | 至少一半沒有直接回收 |

每十條伏筆或後果可大致分為：兩條立即回應、三條一篇內、兩條隔二至三篇、一條終局／後記、兩條不作直接回收而只留痕或成為背景。同一事件最多承擔一個明示伏筆與一個隱性後果；同一物件不反覆用特寫提醒讀者。

## 一之三、可交替使用的故事形狀

- **倒敘追因**：先看結果或殘局，再由多份證詞追查舊決策。
- **誤判翻義**：角色與讀者先接受合理解釋，後來改變理解而非領取獎勵。
- **配角先行**：顧小滿守站、生查斷生、普通維護者先完成選擇。
- **能力先有後懂**：空手、照命、鎮魄先被粗暴使用，真正故事是理解邊界。
- **勝利後揭價**：鎮界界痕、燃身空洞、雷訊反定位延遲出現。
- **無獎勵故事**：守對了仍失去，沒有雷種、寶物、聲名或完整答案。
- **喜劇埋雷**：生活習慣先造成笑點，後來才暴露真漏洞；不可每個笑點都轉伏筆。
- **制度拼圖**：多名專業者用數次小錯逐步補規則，不由陸沉一夜發明。
- **敵方學習**：敵人從主角上次成功中找反制，不靠突然降臨更強敵人。
- **拒絕／不行動**：高潮是沒有復活、沒有追殺、沒有落雷或沒有啟動回溯。
- **平行鏡像**：荒、生、玄衡等各自回答相似問題，並非每次都與陸沉同場。
- **多證詞**：血祭、遲援、公審由倖存者、決策者、敵人與物證提供不同版本。
- **傳承錯讀**：舊法原為一種用途，人物失敗後才把它改成另一種道路。
- **純情感回聲**：飯、藥、門、燈與一句玩笑只證明眾人一起生活過，不解謎、不升級。

## 二、全書總演進

> 身體屬於自己
> → 命運不能由別人指定
> → 一個人不可能同時承擔所有事
> → 個人力量必須成為別人也能使用的道路
> → 聽見所有求救仍不代表來得及
> → 有權降劫者也必須接受同一規則審判
> → 最終留下的不是唯一承劫者，而是可監督、可輪替、可退出的公共制度。

能力不是十次獨立升級，而是同一性格缺陷在更大世界裡反覆被追問：陸沉總想把自己留下、替別人決定離開；每一階段都迫使他把選擇權、責任與承擔逐步交還給同行者。

### 早期必要補橋

- 下界流浪必須有一名普通人物與一件跨篇日用品，不能只用旁白帶過體修根基。
- 太玄閣至少保留兩名能被記住的同門，其中一人應有後續或留下值守簿。
- 太玄閣殘雷須帶著陣心被擊穿的同一節律，陸沉追雷才同時是在追問「為何另一個容納自己的地方又倒下」。
- 斬祭線後短期失去血脈捷徑，必須靠體修考入上界太玄，第二雷不能成為入宗通行證。

### 太玄禁止事項

- 無相卷不得寫成入宗禮包，必須先有多工失敗與第一次離身事故。
- 雷池不得偶然尋寶取得；應由查失聯弟子或封雷害支流自然發現。
- 雷訊不得只為三身聊天；聊天是救急工具進入生活後的副產品。
- 無星古圖是失敗教具／空容器，不是天選神器認主。
- 第三雷前必須讓陸沉先犯過「以安靜代替尊重神魂」的錯。

## 五、中期主鏈：從個人力量到公共救援

> 命圖提供承載結構
> → 鎮魄解決神魂撕裂與奪舍
> → 謫仙之戰只驗證鎮魄
> → 謫仙禁術造成真實界災
> → 歸寂讓災沉默，卻不能修界
> → 鎮界補裂，也留下誰有權封鎖災源的問題
> → 空手劫反問失去命圖、伴星與兵器後還剩什麼
> → 書院排位只公開驗證六雷與荒劫分工
> → 七站把個人能力轉成普通人可維護的制度
> → 敵方反定位制度節點
> → 雙戰場逼出剎那，仍留下永久遲援。

雷色在此主鏈中只負責讓讀者辨認法則，不替戰力升級：歸寂成種後顯化的黑色玄寂神雷代表吞光、失聲與沉法，視覺上無聲無光、無具體雷紋；空手劫成種過程中骨筋血脈反覆擊穿重鑄，同步留下的「淬骨黑紋」是有形的肉身承壓傷痕，屬空手劫自身煉種的自然痕跡，不涉及外來雷源。兩者先在仙古死寂雷域與無兵雷域分別建立，視覺上一靜一動即可分辨，再由書院傷檢正式公開辨明，避免角色與讀者把兩種黑誤認成同一種能力。

### 七站准入規則

七站不是七個打怪副本。每站必須對應「找到人、判斷誰先救、讓訊息送達、維持節點、防止系統互污、留下證據、同時求救仍須選擇」之一；若某站只提供戰鬥、材料或新寶物，應併站或刪除。

## 七、高潮層級

後期不能每項能力都寫成篇末終戰。正式高潮依序控制為：

1. 帝關：燃身守撤離。
2. 異域：荒先帶人回、劫最後回、生多留一息。
3. 十凶血路：司天鑑死戰與第九雷補全。
4. 制度段：金王公審，以冷峻裁決取代第二場天譴大戰。
5. PW-26：拒絕重置、無始成種。
6. 後記：第一名承劫者合法撤回，其他人公開補位。

天譴截矛是篇尾能力鉤子；劫禁區必須有一次被污染節點破域的失敗；沉封事故只服務制度驗證，不再各自升格成重複高潮。

## 十、寫作檢查表

每次新增重大原創故事前，以此檢查高風險；不要求每項皆為肯定答案，日常與地域段落不適用完整清單：

- 是否由既有傷勢、欲望、承諾、敵方行動或原作節點觸發？
- 能力是否只是人物解題方式，而非作者發獎？
- 如果取得新雷，是否存在不可抹除後果？後果可當場、延遲、關係化或制度化揭露，不必立即對稱扣價。
- 是否至少使用一項既有能力解決問題，而不是每次靠新能力？
- 配角是否有自己的選擇，能否拒絕或修正陸沉？
- 所得是否需要造成新漏洞？若否，事件是否負責人物、世界、懸案、純損失或情緒節奏？
- 事件刪除後，是否會損失後續條件、讀者認知、人物呼吸或地域質感之一？
- 是否搶走荒、孟天正或原作角色的核心功業？
- 是否又在強迫同一件物品、同一句話或同一普通人物跨篇回收？有時應讓它自然消失。
- 是否控制高潮層級，避免連續「最強一戰」？
- 最近三個重大事件是否又用了相同的「危機→承受→得法→吐血」結構？
- 能否改用配角先行、倒敘、多證詞、誤判翻義、敵方學習、拒絕使用或無獎勵結尾？
- 是否允許部分異象不解、部分日常無用、部分損失永遠不被補償？

只有違反三條硬規則，或多項高風險同時成立且無其他敘事價值時，事件才不具備進入正式大綱的資格。
