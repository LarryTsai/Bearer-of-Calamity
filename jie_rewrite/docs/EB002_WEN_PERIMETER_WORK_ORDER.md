# EB-002 文家外圍破援：雷戰施工單

狀態：能力證據已核，完整候選正文施工中，未標名戰完成。目標是讓雷直接改變對手攻路與供力，避免重複七峰的步法解題。正式來源03a026、閱讀卷八026，边界024～028；EB-001固定。寫手1交戰局與正文、寫手2核能力、清道夫獨立讀稿，PM按段驗收提交推送。

守衛不得降智：識破假影、破止流片、改封乾渠、奪走短紋石保留。新增局部交鋒可由既有第二軍用供線分一支維持守門紋，須先演出接線；陸沉截的是封渠支，第二軍援主線仍亮。守衛改自力補紋，再以近身反攻；補紋與出掌有先後，不能兩手同時無限忙。雷掌限接觸，越牆到同側與車輪／乾渠位置須可看懂；不把動作寫成長串姿勢算式。

出口守住：外圍只撬右翼半條進退線，三道前陣仍能攻，027文奕親自半個時辰守家、辛墨之死、蘇溫背叛與契環撤援不改。陸沉胸肋／虎口、厄肩鱗傷延續028；短紋石歸敵且斷自身殘氣，帶回僅止流片碎片。026當期名稱與自檢已改煌命（2c9b1bc／09bce0c），028誤稱假禁石碎片已依026物件鏈改正（e41a86e），皆逐段同步提交推送。
