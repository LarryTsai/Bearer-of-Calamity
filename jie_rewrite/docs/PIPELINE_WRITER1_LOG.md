## 標準作業流程

1. 收到PM派的任務後，先讀 `story/jie_rewrite/CLAUDE.md` 了解多agent工作流程（若已讀過、規則沒變可跳過）。
2. 分辨任務性質：
   - **改寫既有正文**（如ch011-013、ch023-028、ch039-079類任務）：先讀現有正文全文，用 `jie-writer` **模式二**。
   - **全新寫作**（如文家遭難）：先確認章綱本身已通過四方審查，用 `jie-writer` **模式一**。
   - **純審查**（如百斷山、七峰大比/百宗盟試類任務）：只跑審查agent，抓到真衝突才動筆局部修正，不要因為有新大綱就整章重寫已經寫得好的內容。
3. **交付前務必自己先跑一輪 `jie-continuity`／`jie-canon`／`jie-character`／`jie-power-system` 審查**，抓到問題用 `jie-writer` 模式二修正過關後才回報PM——不要只憑自己的自檢清單就回報。
4. 章綱裡的分節/分章數量不是死的，可依實際寫作節奏調整，只要保留核心情節、安全閥與轉折順序；大幅偏離規劃才需要先問PM。
5. 遇到牽涉多份「正式」設定檔互相矛盾、或規模大到需要作者裁決的結構性問題（例如洞天突破那次、三隊制那次），**停下來回報PM，不要自己拍板**；局部措辭/命名/單一場景調整可以自己判斷處理。
6. 完成後跟PM回報：做了什麼、審查結果、有沒有改動。份量大的任務可以自己判斷要不要分批回報，不用等全部做完才一次交付。
