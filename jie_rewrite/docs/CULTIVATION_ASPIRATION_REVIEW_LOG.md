- N單元本身的場景設計（`OUTLINE_ANCIENT_REALM_ACT5.md` N列）已經是manifesto意義上的高潛力場景：封寒第一次主動放下劍、向柁婆舊物與生還者告別、陸沉復測「線」——這是整個Act5少數天生適合manifesto第十三節「大招必須被看見」與第十一節「大道要活在日常」的收尾點，不需要新加能力或奇觀，用既有事實就能達到。
- 沿用J單元取樣時發現的分寸：**見證者反應句可以加，事實/代價/數字不能加**。例如封寒放劍那一刻，可以讓蒼梧、汐禾或某個古界生還者有一個具體的「看見」反應（manifesto十三節：旁觀者證明這件事連世界內的人都覺得不可思議），但不需要、也不應該讓放劍這件事變得更容易、更沒代價。
- G～M已建立的「人體尺度為主、物資與傷情紀律優先」寫法本身不是缺陷，是圍城生存弧線的刻意調性；N之後若接上三千州或後續古界情節，若場景重心轉回日常／修煉／境界成長，才是manifesto核心條款（師父教天地、悟、境界多一層、大招）該重新大量套用的地方，不必勉強在撤離/記帳段落裡找憧憬感。
- 每完成一批新章節，比照本台帳J單元的作法，先問manifesto第二十節的兩個驗收問題（換掉靈氣名詞能不能搬到現代／有沒有讓讀者想修到那裡），但**先確認這是不是刻意的人體尺度或紀律優先段落**，避免像序篇分析時一樣誤判。
