# B級完整候選梗概第二批｜住進三千州與七峰成家

狀態：R16、R12、R13候選梗概第一稿。R13為跨篇關係脊柱，不另擴成任務長篇；人物發起事件與部分生活細節仍是候選。

## R16〈天地有重〉｜先在上界有一張會回去坐的凳子

### 舊版病灶

現稿的界壓、重傷、追殺、斬命與叩門都成立，卻幾乎占滿初入上界。讀者知道上界更重，還不知道不同種族、城鎮與普通修士如何把這種天地過成日常。

### 故事梗概

陸沉取得第一雷後穿過界壓，墜在聽雨渡外。完整界淵銀雷只能保住命火，托不起重傷身體；劫厄是旁人難辨的魂影。他第一次發現，下界足以稱奇的靈材在此只是船家燒水用的炊火，自己珍藏的藥也因天地法則不同只能換半日床位。

洛生衣先護住正在發熱的非人族孩子與一籃不能斷氣的活藥，才回頭救他。她沒有因主角出現停止生活。渡口恰逢「重潮」：高境修士遠行留下的餘威每日壓過河面一次，船班、攤販與搬運者都依它改時辰。陸沉傷勢、舊令查驗與停航使他必須住下二十一日，不能靠一個轉場直奔宗門。

城裡一名背甲族孩子總叫他「太輕的人」。對方不是天才配角，只在渡口替家裡量貨重，夢想存錢換一副不會在重潮時陷進泥裡的靴。陸沉起初替他修秤，沿用下界習慣把秤調得過靈，反使上界重潮一來便全部失準。他只好跟著搬運者重新學：此地的準確不是永遠不變，而是知道天地每天會壓回多少。

同時，他循被截斷卻未散的命光追到補斷生雷池。第一次，他以為所有延續都值得保留，被雷池拒絕；回城後看見洛生衣尊重一株活藥自然斷去枯枝，也看見渡工主動拆掉一條已害人的舊牽索，才理解「留下」不能代替當事者選擇。第二次入池，他取得第二雷劫命，卻沒有境界突破。

舊令核准時，渡口遭遇一次比往年更重的餘威潮。陸沉可以立刻搭宗門接引舟離開，也可留下幫忙把失準的秤與繫舟石重新標定。留下會錯過宗門發放的一批入門資源。他選擇留下，不是因全城非他不可，而是那張小凳、那雙靴與二十一日已讓此地不再只是路過背景。

抵達太玄宗後，半枚舊令只替他叩門。岳沉淵收徒看的是他在重臺上知道何時退出。故事離場時，陸沉有雙雷與弟子牌，也把一張修好的秤留在渡口；背甲族孩子替他保留靠牆的小凳，說下次重潮時再看他是不是還那麼輕。

### 邊界與待確認

- 渡口停留不新增機緣、伴星或境界。
- 背甲族孩子不進主線隊伍；其作用是證明上界有與主角無關的生活關係。
- 第二雷仍由完整外部雷池取得，洛生衣只提供人物參照，不替他解題。
- 待確認：是否採用「重潮下每日校秤」作初入上界的生活核心。

## R12〈七峰一家〉｜同一座山裡，七種人都不肯用同一種活法

### 舊版病灶

現稿大比結果與人物能力清楚，但讀者主要在擂臺認識七峰。若各峰只剩招式與職能，本篇仍會和下一篇百宗盟試形成連續比賽。

### 故事梗概

雷汛撕開太玄宗一段山脊，大比因此延後。七峰沒有交給同一支工隊修復，而各自領一段山：鎮岳峰先問承重，丹霞峰把崩土養成藥圃，聽雷峰留下焦木記錄雷路，問劍峰把斷石劈成能重新嵌合的切面，另有一峰先替山下凡役修屋，因為他們認為宗門若只修天驕走的路便不算修好。

陸沉原以為七種方法最後會統一，實際上它們留下七種都能使用、也彼此嫌棄的痕跡。大比規則因此改成：參賽者先到別峰生活三日，再帶著對方一道「不認同也不能忽略」的修行習慣回到本峰。

陸沉到一座把敗招供在廊下的峰。弟子輸後不銷毀錯法，而把當時為何會錯寫在木牌上，後人可續寫也可反駁。他第一反應是找最快修正，卻被問：「你若只留下答案，下一個人怎麼知道自己錯在不同地方？」青璃則到一座以血脈混雜為教材的峰，第一次看見自己的出身不是政治麻煩，而能成為可公開研究的修行條件。封寒去看一場不判勝負的守夜劍，洛生衣在勝者必須替傷者守爐的峰裡，拒絕把醫者責任只交給輸家。

正式大比仍分勝負。陸沉依法取得個人第一，與青璃的決賽保留她完整的血脈與政治選擇；戰場判斷另行評分，不用綜合表現偷換結果。真正高潮發生在賽後雷汛餘波：七段修好的山路同時承壓，沒有任何一峰的方法能獨立保住全山。弟子們不是突然團結，而是一邊爭吵哪段設計最蠢，一邊把七種痕跡接起來。

十二人分三隊時，陸沉、封寒、洛生衣與青璃公開說明能力與極限，沒有人把隊長欄填上。四人約定的不是永遠同行，而是每次出發前重新回答：誰最想去、誰有權決定、誰可以中途離開。

陸沉取得命藏資格，命圖雙星初開；劫厄穩定成形。篇章最後，各峰仍互不服氣。陸沉第一次明白，一家之所以是一家，不是終於活成同一種人，而是七種人都能在同一座山留下自己願意維護的路。

### 邊界與待確認

- 七峰名稱與七段修山方式可依正式宗門設定調整。
- 大比結果、陸沉第一與三隊編制保留。
- 不提前第三雷、鑑月或命圖初成。
- 待確認：是否採用「先住別峰三日，再帶回一道不認同也不能忽略的習慣」作大比核心規則。

## R13〈隊長欄一直空著〉｜四人不是一支隨叫隨到的隊伍

### 舊版病灶

若另立四人小隊篇，最容易回到接任務、磨合、遇險、形成默契。三位同伴會變成陸沉出門時可調度的能力，日後分路也只像退隊。

### 跨篇梗概

這條線由四次「一人發起、其他人可以拒絕」與一次純生活構成。

第一次由封寒發起。他聽說一座小城每年會在無風夜把舊劍掛上城牆，讓劍自行鳴出還沒有人走完的招。他邀三人去看，不為奪劍。洛生衣因病人晚到，青璃當夜便離開處理族訊，陸沉陪他坐到天亮。封寒沒有得到招式，只記住一柄始終不鳴的劍；這成為他日後拒絕完美劍影的早期根。

第二次由洛生衣發起。她要把一株必須活著抵達的藥送給一名已決定不續命的老修士。陸沉一路都在算最快路徑，抵達後才知道藥不是讓老人改主意，而是讓他在最後數日能清醒整理傳承。四人第一次正面承認，救治不能替人決定活法。

第三次由青璃發起。族中要求她交出一段混血修行紀錄換取政治保護，她不願宗門代辦，只請同伴作見證。封寒拒絕進議堂，因他不願成為武力威脅；洛生衣陪她談身體代價；陸沉只保存可公開的禁印記錄。青璃自己作出交換與拒絕，沒有被救出家族問題。

第四次由陸沉發起。他只是想去看一場據說會從地底往天上落的雷雨。青璃不去，洛生衣中途轉往採藥，封寒陪到山腰便追另一道劍痕。陸沉最後獨自看雨，回程時卻在三個不同地方收到三人留下的食物、藥與一句嘲笑。同行沒有發生，關係仍然成立。

純生活段放在百宗盟試前。四人借同一間院子住數日，爭晾衣位置、把飯煮壞、切磋一個沒人擅長的小遊戲。陸沉輸得最慘，封寒作弊也輸，洛生衣記仇，青璃把結果刻在桌底。沒有獎勵、救援、伏筆或能力成長；多年後他們仍記得這件毫無用處的小事。

百宗盟試後，隊形自然鬆開。封寒追自己的劍與古界，洛生衣走生道與古世，青璃回到血脈與族群問題；陸沉不能用隊長身分召回任何人。四人關係真正成立的標誌，是分路多年後仍知道哪件事不能替對方選，也知道若重新同行，隊長欄仍須重新討論。

### 邊界與待確認

- 四次發起事件是跨篇節點，不必各自擴成長篇。
- 每次只推進發起者的道路，其他人可缺席、晚到或中途離開。
- 純生活段禁止附加陰謀、事故、救援與機緣。
- 待確認：是否採用「無風夜掛舊劍」「活藥送給拒絕續命者」「混血紀錄交換」「倒落雷雨」四個關係節點；可替換事件，但保留一人發起與拒絕權結構。

## 本批希望作者確認

1. 初入上界是否採用聽雨渡二十一日與每日重潮校秤，讓陸沉先住進三千州。
2. 七峰是否採用「修同一座山＋短住別峰」區隔百宗盟試。
3. 四人關係是否採四次個人發起與一次完全無用的共同生活，不另設小隊任務篇。
