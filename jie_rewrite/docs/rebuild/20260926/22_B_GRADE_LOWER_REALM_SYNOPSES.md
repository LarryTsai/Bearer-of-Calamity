# B級完整候選梗概第一批｜凡軀、鑄身與假路

狀態：R02、R05、R10候選梗概第一稿。三項均保留既有核心；新異象、路法來源與段落配置仍待作者確認，不回填正式設定或正文。

## R02〈凡軀立命〉｜不是只求活，而是第一次想修

### 舊版病灶

現稿的六歲求生很紮實：陸沉會因多跑一段呼吸失序，冷水藏身逼近昏厥，選錯渡河處便多付數日代價；但故事主要回答他如何沒死。若拿走光滑斷片與少量短紋，骨架仍像完成度很高的荒野逃亡，尚未讓讀者感到他為何會被修行本身吸引。

### 故事梗概

沉雷谷滅族後，六歲的陸沉只帶著半枚太玄舊令、父親的殘缺雷紋與老族長斷裂的祭杖碎片離開。他不懂方向，只知道不能走祭司替逃亡者預留的路。山外正逢雷季，凡人村落以焦木辨哪座坡能過，採藥人會在石縫留下一小撮白灰，提醒後來者此地曾有靈獸換巢。一次為避人跡躲進坍塌石穴時，他才拾得一片刻有淺紋的光滑石頁；石頁離土，穴中蟲聲短暫全寂，他卻不知道它是什麼。陸沉也第一次看見，修行世界並不只存在於強者鬥法，也滲進普通人如何認路、避雨與保存一袋糧。

他靠觀察活下來，卻沒有被寫成幼年獵殺高手。遇見給完整餅的陌生人時，他發現善意也可能帶著套索；遭追兵逼近時，他只能用三日準備換一次有限反擊。虎口傷後，他的細覺不再完整，往後每一次抓握都會留下這個夜晚的代價。

真正改變方向的不是追兵，而是一場山雨。陸沉已虛弱到無法再逃，只能躲進一處被雷劈開的石腹。斷片上的短紋在雨水與山勢之間顯出一個遠超陷阱用途的完整角落：雨落進來，沒有被擋住，卻沿著紋路分成數十股，各自繞過石腹中沉睡的蟲卵、枯根與他的傷口，再在另一端重新合成一線。

陸沉一開始以為斷片在救他，後來發現它沒有替他擋追兵，也沒有治傷。短紋只是照著某種他尚不理解的規律，使每一滴雨都抵達「可以抵達的位置」。他把手放近，紋路沒有因他沒有境界而熄滅；其中一股細水甚至短暫繞過他的指節，再回到原路。

這是他第一次看見天地之力並非只屬於祭司、追殺者或路過高人。它沒有選中他，也沒有嫌棄他。它只在那裡運行，而他第一次有可能學會看懂。

雨停後，追兵仍在，傷也仍在。他靠自己選河段、藏氣味、忍住一次錯誤反擊的衝動，才走到太玄閣牆外。當閣老問他為什麼來，他不說要報仇，也不說要天下無敵。他拿出那片仍舊沉寂的斷片，問：「這上面的路，我能不能學？」

### 保留與改變

保留六歲身體限制、完整的餅、三日一擊、虎口傷與自行抵達太玄閣。新增的山雨異象只提供欲望，不贈能力、不治傷、不指路；它把故事的終點由「找到安全處」改成「主動想進入修行世界」。

### 邊界與待確認

- 不新增高人、器靈或血脈意志出面解說。
- 斷片仍是《古神禁典》第一頁，正式身分到虛神界才確認。
- 雨流繞行只是禁紋規律的一次自然顯影，陸沉此時不能複製或施展。
- 待作者確認：是否喜歡「雨不被擋住，而是各自抵達可抵達的位置」作凡軀第一次正面看見修行的畫面。

## R05〈太玄鑄身〉｜不是一篇訓練，而是下界半生的暗線

### 舊版病灶

兩章已有正確種子：少挑半瓢水、第三階先放下扁擔、把撞樁拆成三段，以及明白疼不等於站穩。問題在於獨立擴寫會變成多年訓練蒙太奇；不擴，又不足以承擔「凡軀如何成為自己的道」。

### 跨篇梗概

這條線不另立長篇，而以七次「出門看見別人的手藝，回閣改掉自己的做法」貫穿下界。

第一次在太玄閣，陸沉只會把多做當成有用。他挑水走到第三階時雙膝失序，仍想靠疼痛證明自己能撐。閣老沒有讚他，只把灑掉的水指給他看。陸沉第一次少挑半瓢，在還能控制落腳時主動放下扁擔。這不是示弱，是第一次把結果放在自我證明以前。

第二次從修士市集回來，他見過同一塊靈材因產地、紋理與修法不同而有不同價值，便不再把身體只分成強與弱。他把撞樁拆成骨、筋、呼吸三段，記下哪一段先亂，而不是只記自己撞了多少次。

第三次看孟禾守一爐兩主，他理解同一張方不能抹平兩具身體。回閣後，他不再用健全左手的進度要求傷過的右手；兩手練不同次數、停在不同位置，虎口舊傷第一次不再因逞強重新裂開。

第四次從雨谷回來，他看見藥潮不是固定時辰，而是根氣、濕度與山勢共同形成的窗口。他開始依當日身體狀態調整練法：寒日先養筋，雷前只站樁不撞樁，傷後先恢復感覺再加重量。這使修行第一次像讀天氣，而非執行課表。

第五次看逆山靈泉換流，他明白力量可以改道而不必硬堵。原本每次承力都把衝擊壓進同一處骨節，他開始讓力沿腳、胯、背逐段流走。沒有新招式，只有一次挑水時桶中水面終於不再因每一步劇烈晃動。

第六次在百斷山，天地雷火沿神識與禁紋進入肉身。他確定自己已具備搬血根基，也看見這具身體離真正承雷仍有多遠。凶獸潮沒有替他突破；回來後，他拒絕讓那場奇景替自己跳過最笨的功夫。

第七次在山野假路與北海短聚後，他已能在追殺中判斷何時不用傷手、何時必須承受一次反震，也能在荒拳壓潮頭時看出兩人身體道路的根本不同。返閣約半年，他仍每日蹲樁、鍛骨、煉筋，沒有天降異象。某日收樁後，背後光影第一次自行吞吐天地精氣；他再試、停下、向同伴說明，才確認由搬血根基正式入洞天。

這條暗線的高潮不是突破本身，而是突破前他已學會停手。六歲的陸沉靠多想一步活命；洞天期的陸沉則終於知道，身體不是拿來證明自己願意受多少苦，而是他此後所有選擇真正要居住的地方。

### 保留與改變

保留〈腳下的路〉、〈第一個冬天〉作第一次立法；市集、丹爐、雨谷、水源、百斷山、假路與返閣各承一個改法。R05不再與R06至R10爭篇幅，而成為讀者能跨篇辨認的身體成長。

### 邊界與待確認

- 不增加三年訓練期，不提前雷體、命圖或正式雷種。
- 百斷山只給承雷資格，不觸發洞天突破。
- 突破發生在返閣約半年內的尋常修行，不由升龍台古物或戰鬥贈送。
- 待作者確認：是否採用「七次看手藝、七次改身體」作跨篇脊柱；數量可調，因果順序不變。

## R10〈山野假路〉｜誰能讓天地暫時相信一條不存在的路

### 舊版病灶

現稿已有鎖氣藥、山匪標誌、轉界石、藏碎紋、黑砂遇血與水壓反獵，真假交鋒成立；但追兵、魔女與黑衣人的目的仍偏向懸念功能，容易像換皮諜報戰。

### 故事梗概

百斷山後，陸沉下山替太玄閣取燈油。原本熟悉的山道多出一排山匪記號，位置、刀痕與氣味都對，只有一處不合：真正山匪會把記號刻在雨沖不到的背面，這一排卻故意留給持太玄舊令的人看。

追兵尋找的不是陸沉本人，而是一種失傳路法。傳說太玄舊令能使殘禁承認持有者，讓一條已斷的古路短暫接回天地；他們多年用假山匪、假商旅與假地勢測試，想逼真正持令者走出只有舊路才會回應的步法。

魔女也在追這群人。她查的是某種能讓身份與地勢彼此作證的假法：一個人只要站在被天地承認的假路上，沿途禁制便會替他的假身份補齊破綻。這種法若進入截天教外線名冊，叛徒可以讓整條情報鏈都相信他從未離開原位。

她沒有向陸沉交代全部，只在最危險時真幫一次，把追兵的鎖氣藥引向自己；下一刻又轉動界石，逼陸沉暴露備用退路。陸沉也不信她，卻看出她不是單純拿自己作餌：她每改一次路，都在逼對方使用更深一層辨路術。

兩人逃進一座雨後谷地。追兵展開殘缺路法，使谷中出現三條都能留下腳印、折斷枝葉、驚動鳥獸的路。神識、氣味與實物全都證明三路為真；選錯者則會在走出百步後回到原地，逐漸被天地忘記來處。

陸沉沒有破解整座谷。他以短紋聽三路與地下水壓的回響，發現假路能複製表面因果，卻無法讓山腹舊水脈為它改道。魔女則故意在其中一條假路留下真正血跡，逼追兵相信她已選錯。兩人各自保留一層計畫，在沒有互相交底的情況下把敵人引到同一處水壓將開的石口。

高潮時，追兵以舊路法要求谷地承認「此處本有出口」。陸沉不與他爭誰的禁制更強，而把太玄舊令放在真正水脈與假出口之間，只要求殘禁承認一件較小的事：水曾經從這裡走過。谷地只相信了一息。那一息使水壓提前開口，沖垮假路的自證循環；魔女同時截斷對方藏在假身份裡的退路。兩人共同反獵，誰也沒有單獨掌握全局。

其後魔女提出假殺石昊的委託。陸沉接受入局調查，不照她給的殺法行動；與石昊短暫交手後，兩人辨出真正刺客並反殺。魔女的目的包括試探石昊、引出刺客、測陸沉是否盲從，卻仍有她未預知的變數。北海主事件結束後三人短聚，陸沉邀荒走一次預布小禁，五步取木落敗；荒隨後拳穿厚礁，清楚表明這不是全力平手。

陸沉帶燈油回閣，也帶回一個沒有被解答的判斷：看穿一條假路，不等於看穿造路的人。魔女仍只讓他看見她願意顯露的一層；他也沒有把自己最後的退路交給她。關係因此能繼續，而不是靠一次共患難立刻結算成信任。

### 保留與改變

保留取燈油、鎖氣藥、山匪標誌、轉界石、藏碎紋、水壓反獵、假殺荒與北海短聚。改變的是所有欺騙都掛回修行規律：身份能由地勢作證，假路能暫得天地承認，破解則受水脈、舊令、材料與一息時限約束。

### 邊界與待確認

- 太玄舊令只能使殘禁回應，不是跨界萬能鑰匙；真正跨界仍走界海雷淵因果。
- 谷地只短暫承認水路，不成永久禁域，也不解鎖高階活禁。
- 魔女不能全知；真正刺客有自己的情報來源與反制。
- 北海核心機緣、荒與魔女原作初遇不被陸沉取代。
- 待作者確認：是否採用「假身份必須由假地勢作證」與「水脈無法被表面因果完全複製」作新版真假之爭核心。
