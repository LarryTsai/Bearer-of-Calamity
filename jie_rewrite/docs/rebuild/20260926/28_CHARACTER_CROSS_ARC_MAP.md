## 三、四伴星

### 劫厄｜最早陪伴，也最晚擁有自己的家

- **主動發起**：第一雷時自行凝成魂影跟上；多次在陸沉自毀前直接阻止，不等命令。
- **明確拒絕**：拒絕被當戰獸或雷身；異域返本時有權不重新締結。
- **離場**：劫後主動回古龍界，不是被派去尋機緣。
- **重會**：造好朝雲巢後自主往返沉封域，關係由「只能跟著陸沉」變成「有家仍願同行」。
- **不可代答**：龍族歸屬、朝雲巢如何建立、何時回來都由牠自己決定。

### 鑑月｜叫對名字，不替任何魂完成最後一步

- **主動發起**：守雷魂域、逐魂記名；認可陸沉後才交可解除命印。
- **明確拒絕**：拒絕把魂海視為資源；能力受限時不以新招替封寒跨過最後一步。
- **離場／重會**：可因守墓、記名或傷魂回到自身職責，再由具體名字與未完記錄帶回主線；不能只在需要鎮魂時出現。
- **不可代答**：誰仍是一個人、哪個名字不能被統計抹平，她可以指出，卻不能替本人選擇活法。

### 蒼梧｜選擇同行，也選擇永久離開命圖

- **主動發起**：古界以獨立守序者阻攔外來者；找回轄域未果後自主暫往三千州。
- **明確拒絕**：拒絕被當永久界樁；入環前確認可自由退出。
- **離場**：罪州事件後，因陸沉開始以同類計算語言處理失去者，主動永久解除命印，留下外環空痕。
- **重會**：終局依公共警報自主赴戰，只作外部盟友；不入命圖、不接受召回、可公開反駁陸沉。
- **不可代答**：守住空間是否等於守住人，以及他願不願繼續屬於命圖，只能由他本人判斷。

### 赤翎｜留一口命，不把求生變成別人的命令

- **主動發起**：先作餘命燼池守護者，外部本源認可陸沉後才自願同行。
- **明確拒絕**：不贈火、不作取雷材料；不讓「能重生」變成要求族人反覆燃命的理由。
- **離場／重會**：須定期回到仍在世的鳳族生活與自身記憶問題；異域返本時自行決定是否重締。
- **不可代答**：何時燃、為誰燃、留下哪一口命，陸沉與命圖都不能替她決定。

## 五、跨篇最低出場責任

1. 每名核心人物在重要重會前，至少有一則訊息、物件、旁人提及或獨立短場證明其缺席期間仍在生活。
2. 重會第一場不得先服務陸沉的新任務；先讓對方完成正在做的事。
3. 任何離場都不能只用「另有任務」帶過，必須由核心欲望推動。
4. 任何和解都不能靠共同遇襲自動完成；須回到造成裂痕的選擇與後果。
5. 四伴星同場不等於命圖復原。蒼梧永久空痕、各自退出權與異域返本選擇始終有效。
