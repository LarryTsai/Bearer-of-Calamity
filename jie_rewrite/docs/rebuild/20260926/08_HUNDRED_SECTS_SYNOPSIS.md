# 百宗盟試｜一百種答案

狀態：C級重構候選梗概第一稿，待作者確認方向。現行賽果、四人隊與「劫」之名外傳先作保守保留；新場域機制、各宗道路與配角均是候選，未回填正式設定或正文。

## 舊版病灶

現行故事由驗名、真假界標、積分預選、護旗淘汰、取戰印、守烽臺、奪中央旗與臨時災害串接。規則、傷停與物資因果相對完整，四人也各有判斷；但把宗門名稱換成校隊名稱，主要事件仍大致成立。百宗的差別多半只表現在戰術和招式，讀者看不見弟子為何選這條道、這條道如何改變生活，以及一宗兩千年傳承究竟在守什麼。

舊高潮另有兩層削弱：空蟬作弊與殘陣突然喚醒舊戰痕，讓最重要的選擇依賴外加事故；陸沉整篇主要在準備、判斷、守規則與救人，沒有一件「他只是因為想看，所以偏要走近」的事。救人本身可以保留，但不能再次取代百道爭鳴成為故事本體。

## 故事梗概

百宗盟試開在一片沒有固定模樣的古戰原上。每一宗入場前，都要將一縷本門道痕送入天幕；百道齊聚以後，沉睡的戰原才會醒來。問劍者走過，草葉生出細刃；養獸者落腳，地底沉眠的古獸骨會翻身聽他們號令；修夢的弟子睡在帳中，夢卻在數里外搭出另一座營地。有人背棺赴會，有人把自己蛻下的舊皮掛在宗旗旁，也有小宗弟子守著兩千年沒人真正練成的怪法，明知拿不到名次，仍想看看祖師留下的那句話在百道之中能不能活。

陸沉抵達後，先發現這裡連煮茶都沒有同一種辦法。烈陽宗以自身火息煮，青靈庭讓茶芽在盞中重新長一遍，天衡院則先稱茶、稱水，也稱飲茶者今日能承多少。封寒到處找人試沒見過的招，洛生衣去看各宗如何處理修行留下的傷，青璃則第一次看見有宗門把混雜血脈當成一條可修的路，而非需要遮掩的缺陷。四個人還沒正式上場，便已各自找到比名次更想弄懂的東西。

盟試仍然分勝負，但比的不是同一套招式誰更大。百道天幕會把各宗之道投進古戰原，參試者必須帶著本宗道痕穿過別人的天地，再讓自己的答案留下可辨認的證明。天衡院的路所過之處，所有力量都有明確砝碼，借一分便要還一分；青靈庭不搶最快的道路，沿途種下的靈木卻會在後半程長成別人繞不開的森林；空蟬宗以一次次蛻殼把敗招留在身後，真正的人總比對手以為的位置更遠一步。

太玄四人一開始仍把這些差異當成待破解的場地條件。陸沉畫退路、算承載、安排誰守哪一段，第一輪做得沒有錯，卻只勉強晉級。他們在一處由夢道與獸道重疊的谷地第一次吃了大虧：陸沉看見的出口確實存在，封寒也能劈開擋路的骨影，但洛生衣發現那條路每走一步，都會驚醒一頭正在替幼獸承夢的母獸。出口不是假的，只是走法會毀掉別人的修行。青璃最後從兩種道痕交界處找到一條窄路，四人因此晚到，卻第一次承認「看懂怎麼通過」與「知道該不該這樣通過」不是同一件事。

真正讓陸沉停下來的，是那個守著兩千年怪法的小宗。其術暫稱「留一線」：每次出手都故意不把結果做滿，在最有把握的一刻留下一處未定。歷代弟子沒人靠它贏得大名，外宗多半把它當成祖師失手後不肯認錯的殘法。當代弟子也說不清它最後能成為什麼，只知道祖師留下的話是：「世上若只剩一個答案，後來的人往哪裡走？」

陸沉不相信一句漂亮話便能支撐兩千年，於是主動去看。他在對方一次次敗局裡發現，留出的那一線並非退縮：別人的道痕進來時，它不立刻排斥、不急著吞併，而是讓兩種答案短暫同在。這門怪法仍不完整，也未必值得他學；但它讓陸沉第一次親眼看見，一條道可以靠「容許後來者改它」延續，而非靠祖師早已答完所有問題。

進入最後戰原時，太玄、天衡與青靈仍按既定積分爭第一。天衡院隊長謝衡不是傲慢的陪襯。他認為百道可以不同，勝負仍必須有人承擔；若所有人都拿「答案不同」逃避比較，盟試便毫無意義。他的衡道使每一步代價都清清楚楚，也因此比太玄更早抵達中央道旗。

百道同時逼近中央後，古戰原真正的危險才顯露。這不是某個宗門作弊留下的炸點，而是古戰原本身的舊傷：它曾承受過無數強者把自己的道當成唯一答案，地底仍留著彼此排斥的斷痕。盟試歷代只同時容納較少道痕，這一次百道齊至，中央開始把所有互不相容的道路往外推。各宗都有退印，強隊足以自行離場；真正被困住的是那些道痕已與戰原纏在一起、不能一拔便走的人。

太玄此時仍有奪旗機會。謝衡則只差一息便能完成天衡院的取旗印。他沒有假裝看不見危險，也沒有把第一名讓給陸沉：他完成那一息、取得中央旗，隨即按天衡院自己的判斷轉身救人。這使天衡第一成立得乾淨——他選擇先把能完成的事完成，再承擔其後代價。

陸沉作了另一個選擇。他在那一息以前便離開旗線，回到百道交纏最重的地方。封寒沒有問值不值得，先去試哪一處斷痕能承一劍；青璃只處理道痕交界，不替任何宗門改寫自己的術；洛生衣讓受傷者先說清楚哪一道痕不能拔。那名小宗弟子把「留一線」展開，讓互斥的百道多出一瞬尚未決定的空白。陸沉站進那一線裡，以自身承住率先合攏的舊戰劫痕，讓其他宗門各用自己的方法帶人離開。

於是救援不再只有太玄一隊。御獸弟子讓伴生獸背走不能移動的人，夢修把出口投進仍清醒者的共同夢裡，青靈庭用根系辨出哪幾道法不能硬拔，烈陽宗燒掉自家已取得的一段道痕換出一條短路。各宗救人的方式，正是他們一路爭勝的方式；有人付出名次，有人付出所得，也有人先拿到自己應得的勝負，再回來承擔。

中央道旗最終仍屬天衡院。太玄宗第二，青靈庭第三。沒有人替陸沉重算救援分，也沒有人宣告他的答案比謝衡高尚。謝衡只在事後問他，若那一線合得再快些，他打算怎麼辦。陸沉說出自己當時真正算到的上限；超過那裡，他也沒有答案。

「劫」的名字由此傳開。別宗記住的不是一名把百道都壓下去的天才，而是一個明明看見許多答案，仍願意站進它們互相傷害之處的人。那名小宗弟子沒有因這一役突然練成祖法；他的宗門仍小，那門怪法也仍缺最後一段。離開前，他請陸沉在祖師舊卷後添一句。陸沉想了很久，只寫：「這一線，今日有人走過。」

## 這版保留與改變什麼

保留：太玄三隊出發、主線四人隊、天衡第一／太玄第二／青靈第三、「劫」之名跨宗傳開、救人不重算積分，以及四人各自具備獨立判斷。具體積分、界標、護旗與現行24章不作新版硬鎖。

改變：百宗差異由隊名與招式，提升為會改變營地、生活、地貌、勝負觀與救援方式的修行道路；臨時事故改成百道共入古戰原後自然暴露的舊傷；陸沉有主動追問「兩千年怪法」的欲望，救援則成為百道爭鳴的後果與共同選擇。

## 設計邊界與待確認

- 百道天幕、中央道旗、謝衡的衡道、小宗及「留一線」均為候選。作者確認前不回填正式設定。
- 「留一線」不授予陸沉新功法、禁制能力或命圖進度，也不等同古界白鹿棄筆；前者重點是不同道路如何共存，後者重點是修成者為何主動修改自己的完美答案。
- 古戰原舊傷不得寫成主辦方明知必然爆發仍放任弟子進場。正式大綱需交代歷代承載基準、這次百道齊至的異常條件與退印為何仍不足。
- 謝衡必須有完整實力、判斷與責任，不能因主角需要道德選擇而被寫成只顧名次的人。他先合法完成取旗再回身承擔，天衡第一不降格。
- 四人仍受當期能力限制：陸沉不能多目標全場指揮；封寒仍持劍且未有鐧／坍縮；青璃只處理局部交界；洛生衣不能無代價全域救治。
- 雲行若保留同場，只能作遠處另一個自行回頭的人，不在本篇與陸沉正式相識，也不搶走百道主軸；是否保留待全書人物線重排後決定。
- 賽後古戰域深層40章與雷魂域7章屬另一項重建判斷，不能因本梗概成立便自動沿用或刪除。它們須回到全書結構另評，尤其「能力不等於決定權」是否值得獨立成篇。
