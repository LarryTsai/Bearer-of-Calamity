# 《劫》新版全書結構 v0.2｜先排人生，再排事件

狀態：42項仙感總審及B級第二輪完成後的第一版全書結構提案。這不是最終篇名、章數表或正文目錄；除作者已確認的古界〈萬法歸潮〉外，其餘新合併與篇界仍待整體閱讀後確認。v0.2 已修正第三雷與第二座升龍台的時序錯位，詳見 `18_STORY_DEPENDENCY_MAP.md`。

## 一、這版結構先解決什麼

舊版不是缺事件，而是太多事件以同一種工作方式推動：接到問題、查驗、修補、救援、撤離、結案。新版先排列陸沉一生真正經歷的世界，再把舊事件放回適合的位置。

全書暫分四個時期、二十六個故事位置（含序篇與留白終篇）：

1. **下界成根**：一個凡軀先發現天地值得修，再在宗門、市井、丹爐、雨谷與秘境中學會不同的人如何活。
2. **上界成道**：新世界由「更強」變成真正的三千州文明；陸沉依次看見同宗七路、天下百道、禁道之城、荒的路、高境古界、三院與已逝盛世。
3. **邊荒承劫**：先走到世界沒有路的地方，再進入兩界大道戰爭與敵方文明；天譴、生道與終局選擇都由前面活過的人生累積而來。
4. **劫後有家／仙界留白**：證明共同承劫不是一句制度口號，而能長成茶攤、花、巢與可以離開的家；第三座升龍台仍不提前填答案。

結構上的四項取捨：

- R05太玄鑄身不再獨立擴成訓練長篇，改作下界多篇持續生長的肉身脊柱。
- R13四人小隊不另立任務篇，改作七峰至百宗、三千州分路的關係脊柱。
- R19舊五島古界併入R20〈萬法歸潮〉，只回收人物、地方生活及已確認的前因。
- R29帝關初戰與R35西三垛合為同一場兩界大道戰爭；R30血原與R31燃身是其中不同人物階段，不再像連續軍事任務。

## 四、四條跨篇成長線

### 1. 凡軀如何成為自己的道

R02第一次感到天地可修 → R03站著聽雷 → R05在各次出行後改練法 → 上界天地壓回舊習慣 → 七峰承重而不站到死 → 無兵雷域讓骨、筋、血、脈成為雷路 → 返本時重新選擇身體 → 終局仍留下不可逆傷勢。

肉身成長靠讀者長期看見動作改變，不靠一次多年訓練摘要。

### 2. 同伴不是固定隊伍

封寒、洛生衣、青璃在七峰形成可同行關係；其後每人都必須至少有一次自己發起、主角可缺席的故事。百宗後隊形鬆開，三千州與古界依個人欲望重新組合；封寒、生、文奕及青璃的離場不是退隊通知，而是自身道路自然走遠。

### 3. 禁、雷、劫依次改變問題

- **禁**：由求生找縫，到看見規則由誰使用、誰能撤回。
- **雷**：每一道必須來自完整外部天地，取得後先帶來承載與關係問題。
- **劫**：不是十種能力集合；從書院起，陸沉逐步承認每一道雷、每位伴星與每個承劫者都不能只服從中央答案。

能力事件只在它改變人物選擇時進主篇；命圖整理、傷勢驗收與系統說明不另行占據大型故事。

### 4. 三座升龍台只問一個逐步變大的問題

- 第一台問：一個下界人是否敢離開已知天地。
- 第二台問：看見更大的道路後，是否仍能拒絕預先寫好的完整答案。
- 第三台問什麼暫不決定；必須由前兩次實際故事與全書終局自然推出。

## 五、相鄰篇的味道檢查

新版暫定閱讀節奏依次是：血脈災夜 → 凡軀仰望 → 虛界古禁 → 山下修士生活 → 秘境 → 假路與關係 → 跨界離鄉 → 新天地居住 → 宗門七路 → 天下百道 → 禁道城市 → 大世同行 → 高境古界 → 無兵內問 → 三院求道 → 古世生活與失落 → 界路探險 → 兩界大道戰爭 → 敵方人間 → 生死與天譴 → 仙人時間 → 紀元終局 → 聚落生活 → 龍族歸巢 → 仙界留白。

目前刻意避免的連續同型段落：

- 七峰大比與百宗盟試不再都是排名賽：前者寫一家七路，後者寫天下百道。
- 禁都與三千州不再都是查案：前者寫一座禁道城市及合法落敗，後者寫三人同行與分路。
- 古界、古世與界路不再都是修界救災：分別是高境求道、活過歷史、走入世界遺骸。
- 帝關、異域與十凶不再都是軍事／情報／醫療流程：分別是大道戰爭、敵方文明、生死選擇與執譴資格。
- 沉封域不再作第二次終局戰，而是證明終局選擇能否成為普通日子。
