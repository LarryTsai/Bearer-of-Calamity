# 《劫》新版十三卷跨卷總審

狀態：已對 `33`～`58` 的十三卷章群大綱與單卷驗收做第一輪跨卷閉環。結論為通過，可進下一階段的卷一正文施工卡；位置25仙界繼續留白。

## 一、總判定

十三卷共448章，完整覆蓋位置00～24，沒有漏位、重收或章號斷裂。全書已形成四段清楚的長線：下界成根、上界成道、邊荒承劫、劫後有家。每段都先讓地方與人物生活成立，再讓能力成為回答；陸沉取得十雷，沒有因此收走荒的原作功業、四伴星的退出權或世界自行運作的能力。

本輪未發現必須推翻卷級設計的P0矛盾。已直接修正三項接縫：明確區分禁典頁斷片與兩座升龍台構件；補上卷十三位置23至24的數日間隔；補齊劫厄三枚普通靈晶的借、賺、還閉環。

仍須帶入正文施工的主要風險有三項：卷七三院生活不得被34章下限壓薄；卷八至卷十連續124章重內容須靠生活、遺骸、戰爭與敵方人間四種不同閱讀節律分隔；卷十至卷十三的制度語彙必須落成修士可見、可操作、會損壞的器物與行動，不能直接寫成現代行政說明。

## 八、修仙世界與《完美世界》尺度驗收

### 通過理由

1. **世界先於機緣存在**：山下手藝、聽雨渡、七峰、禁都、五島古城、三院、古世、帝關、負碑院、折嶺海、沉封域與回潮巢群均有人在主角到來前後繼續生活。
2. **高境改變的是文明方法**：古界以相對方位生活，帝關以兩界法則爭地，異域以碑泥保存死亡，長息以三十年換代，龍巢以公共環禁讓巢穴隨地脈移動；仙感不是招式名稱堆疊。
3. **奇觀與日常互相證明**：倒懸天河、魚背亭臺、死界夕陽、移位石巢都直接影響交易、耕作、育幼、葬俗與修繕。
4. **力量受境界、場域與責任約束**：九雷均有外源與首敗，古世不免費結算修為，十星只及一城／一線，沉封域公開容量，第三台不提前導航。
5. **原作主角仍是原作主角**：荒保留關鍵選擇、勝負與時代功業；陸沉的價值來自另一條完整問題線，不靠搶走名場面證明重要。

### 正文施工紅線

1. 卷十至十三的「公審、席位、複核、停權、流程、容量」是作者端結構詞。正文每次至少要落在一件修士器物、一種法則反應、一個具名行動者和一項可見損失上，避免現代制度換皮。
2. 高境人物不能只靠「一眼看穿」縮短場景。境界越高，應更多呈現其感知範圍、錯判規模、因果責任與漫長生活，而非只放大攻擊。
3. 每一新地點最多保留能改變人物選擇的奇觀；不可在章群之外再加景點清單、守關獸或寶庫。
4. 戰鬥勝負須繼續由規則理解、準備、地形、同伴決定；永久傷勢不能只在醫療章出現，應改變日常與戰術選擇。
5. 位置25在仙界自身的生活、核心問題與原作年代邊界未成立前，不得以第三台、雙片、朝雲巢或無始當通行證。

## 九、節奏與人物覆核

- 十三卷的卷末鉤子分為欲望、後果、分路、時間與主題收束，沒有連續用急報把人物拖往下一地圖。
- 卷三、六、九、十二雖都有大型災變，讀法分別是離鄉、古界選答、大道戰爭與秩序決裂，不是四次同型升級。
- 洛生衣、封寒、文奕、青璃、魔女與四伴星都有至少一段陸沉不在仍推進的生活或選擇；但正文施工仍須在重要重會前保留一則可見近況，不能只靠設定表宣稱他們獨立。
- 卷七目前用34章同時承擔返程、共鍛、蒼梧結印、無兵雷域、三院生活、排位與第七雷，是全書最需要允許擴章的一卷；新增只能用於師生、同窗、課業與失敗生活，不得增加試煉站數。
- 卷十48章是最長的高壓卷之一，但前後兩半分別是敵方生活與裁罪責任；施工時必須讓負碑院的普通日子佔足篇幅，避免前24章也被追查流程吞掉。

## 十、最終判定與下一步

十三卷跨卷總審通過。這個版本已不再是「為主角取十雷安排十三張地圖」：十雷每次都迫使陸沉拆掉一種舊答案，而各地修士、居民、敵人與非人族群在他離開後仍有自己的生活。全書也已守住《完美世界》同人最重要的邊界——荒的時代功業完整存在，陸沉則以承劫、撤回、記名與共同負責建立另一條不可替代的長篇。

下一步不是設計仙界，也不是再加奇觀。應從卷一開始製作正文施工卡：逐章確認視角、時間、場景目的、人物主動、能力上限、前後物件與永久傷勢，再對照現有正文判定保留、改寫、合併或新寫。每完成一卷正文施工卡，先做該卷因果與仙俠感驗收，再進實際正文。
