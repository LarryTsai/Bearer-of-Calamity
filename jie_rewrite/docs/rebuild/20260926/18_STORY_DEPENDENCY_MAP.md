# 《劫》新版故事依賴表｜境界、十雷、伴星與原作功業

狀態：配合新版全書結構 v0.2 的第一輪硬依賴核對。本表只回答「這時能有什麼、不能提前什麼」；它不把設定說明當成故事梗概，也不替尚未確認的故事方向定案。

## 一、本輪查出的兩個結構錯位

1. **第三雷不能含糊塞在〈七峰一家〉結尾。**正式事件已規定：七峰大比先取得命藏資格，百宗盟試入場時命圖雙星初開，但尚未取得第三雷鎮魄或鑑月命印。因此新結構改為「七峰→百宗→禁都→萬魂歸名→三千州」，另立必要橋接篇〈萬魂歸名〉。
2. **第二座升龍台不能放在天神書院。**現行正文與保管鏈已把它寫在〈長息〉第三年、折嶺海二十至二十六章。它只使兩件古物首次確認同源成對，不授予能力、不開仙龍界門，也不指向第三台。新版已把 R25 移回〈長息〉。

這兩項修正使全書由二十五個位置改成二十六個位置；42項審查對象仍全部有去處，新增的是原盤點沒有單列、卻不能省略的第三雷取得故事。

四者加入順序也是關係成熟順序：先被陪伴，再學會逐名看人，再接受同伴有自己的秩序，最後才理解「留一口命」不是替別人決定怎麼死。

## 四、石昊功業邊界

| 時期 | 可交會 | 必須留給荒 |
| --- | --- | --- |
| 百斷山與下界 | 初見、有限合作、北海主事件後短聚與試禁 | 百斷山與北海核心機緣、補天閣覆滅後清算與重建、七神下界正面主功業 |
| 三千州與書院 | 荒主動尋劫、同行生活、規則保護下公開交手 | 仙古遺跡、萬道煉身、大道鍘刀、以身為種的創立與完成 |
| 帝關與異域 | 同道、並肩、分戰場；九雷後綜合戰力可同級 | 帝關核心名場面、安瀾與罪州主線、荒在異域的核心功業與返關道路 |
| 終局 | 「荒開路、劫收劫」的分工 | 荒開闢紀元道路及其後續原作功業；陸沉的終局不進 PW-27／28 |

相遇時陸沉原則上低荒一個小境界。九雷與十雷只改綜合戰力判定，不自動改名義境界：九雷後可與同期荒同強；十雷形成後，只在同境、無外援、全體系完整死戰的限定下由陸沉重傷小勝。

## 五、三座升龍台的保管與揭露紅線

1. **第一台在下界。**陸沉完成正常登頂後取得黑褐窄硬片；它長期沉寂，沒有力量、感應、治傷或導航功能。
2. **第二台在〈長息〉第三年。**陸沉與封寒因折嶺海本身值得探訪而同行、分路登頂；灰白弧片出現後，兩件物品才首次共鳴。第一件由陸沉保管，第二件由封寒保管。
3. **第三台在仙界。**目前只知道它須回收前兩件的同源成對；不得由前兩件直接導航，不得在真正登頂前開門，也不得把雙物寫成抵達仙界的資格證。

## 六、下一輪大綱施工規則

每一篇正式展開時，固定先寫五格：

1. 陸沉為什麼此刻主動離開上一處生活；
2. 這一地自己的修仙日常與長久存在方式；
3. 陸沉真正想看、想學或想問的東西；
4. 中段哪個選擇使原本目標失效或變難；
5. 離場時人物關係與世界認識改變了什麼。

能力取得只放在這五格能自然推出的位置。若拿掉新能力後故事不成立，該篇仍須重想；若拿掉陸沉後地方就不再像能自行生活的世界，也仍未達到本輪要求。
