# 找回原始奇想｜先保護讀者當初想看的故事

日期：2026-09-26，作者對全書重建的最新校正。
狀態：已保存本輪作者親自重述的八個核心 idea 及展開方式；尚未完成歷次原始對談、設定母稿與正文之間的逐項溯源，亦未開始重写正文。

## 一、作者真正不滿的地方

作者已給出許多有畫面、有修行吸引力的大故事，但發展成正文後，奇想容易被翻譯成任務：主角抵達、遇到問題、測量、修補、救援、撤離、結案。即使各步合理，最初吸引作者與讀者的經歷反而消失。

作者稱這種失真為「想像力降維」：從「如果世界可以這樣呢」，過早縮成「下一個合理事件是什麼」。這是本輪要矯正的創作方法，不是已完成全書逐章調查後的統計結論。

因此，先搬離的是 Agent 後來堆疊的舊展開與它對新設計的支配；原始 idea 要救回來。不要把「舊稿可能不行」解讀成作者需要再想一批更好的題材。

因果、原作、人物自主、境界、傷勢和知情順序依然重要，但審查應幫奇想找到可信的成立方式，不能把所有不容易落地的部分換成最安全的勤務。

本表的來源都是作者本輪訊息，不冒稱已找到最早版本。中欄是作者要看見的體驗；末欄是要防止的展開偏移，不等於該篇舊正文每章都如此。

以上保存的是敘事承諾。具體能力程度、原作時間、同行場合與機制在新梗概中提出可行解法；遇到矛盾要指出哪一處並保住其吸引力，不可默默把原始畫面刪成一項低風險工作。

## 三、三個失真的例子要完整記住

### 古界：巨人國先問「這裡有什麼」

從這個 idea 長故事，首先應問：他們看見什麼前所未見的東西？那裡的人如何修行、如何生活？有什麼文明與生物？什麼讓劫或瘋想靠近？他們如何在高於自己的層級留下名字？

求生可以回答其中一部分，不能把全部注意力收進安全區、界災與出口。開頭說了一次「高境危險」之後，若後面長期只剩災區工作，原始承諾仍未完成。

### 古世：先讓人活過，再讓人失去

作者要看的包括古代仙人怎麼生活、失傳道統的當年模樣、認識什麼人、有沒有愛喝酒的老修士，以及後世只剩名字的人此刻就在身旁。重要的發現可以是：某天才認出這裡原來就是後世那座尚未毀掉的遺跡。

「生活很久」須由相處、習慣、喜歡的人與地方累積，不只用時間數字證明。戰爭仍可發生，但守城不能代替整個時代。失去文明的重量，來自先讓讀者覺得那段日子值得活。

### 界路：互補的天才與不可能的路

線的扭曲、斷裂與重新相接，是讀者能感到陌生與驚奇的畫面。它應引出親歷、試探、交手、發現與兩人的選擇，讓人期待他們會走到哪裡。

座標、界釘或承載可以協助某一行動，但不能把這份陌生感逐一翻譯成測量報告。也不能因怕能力寫錯，就讓兩人只旁觀解說而不敢做任何值得看的事。

## 四、三道創作審查

這是既有 PM 與顧問要承擔的三種閱讀角度，不要求新增三名 Agent。與原有「仙感＋主動探索」對應：Wonder 補足驚奇與嚮往，Desire 深化主動探索，Fantasy Transformation 檢查修仙是否真正改變故事。

### Wonder：有沒有我想親眼看看的東西？

作者建議以連續約5～10章作閱讀觀察窗口。可以是一個文明、一種生物、一種修行方式、不可思議的地方、奇怪的修士、天地規則，或只有修仙世界才有的一件生活小事，不限漂亮風景或大招。

在梗概期，以一段連續故事代替章數。窗口是提醒，不是每到第十章機械插一個奇景；節奏可以沉靜，也可以暫時失去力量。若長期沒有值得親歷的東西，回頭重想這段經歷，不以加一段華麗景物充數。

### Desire：人物想做什麼？

每段要看見人物自己的欲望、好奇、偏愛或決定。作者的警訊是：若連續十章都只有「有人需要他」，就該檢查責任是否吞掉了人生。

「我想看看」「我想去」「我想知道」「他們說不能進，為什麼」應能改變行動方向。不要在原委託流程前加一句好奇，便宣布主動性已補回。責任型故事仍可有力，但長篇不能只有一種起因。

### Fantasy Transformation：修仙有沒有改變故事本身？

把靈力、仙、雷、禁制、境界換成現代名詞後，如果整段仍近乎原封不動地成立為災防工程、土木測量、軍事勤務、戰地醫療、校際競賽或諜報片，就退回重新設計其核心經歷。

不是禁止這些動作，也不是禁止跨類型的樂趣。要檢查超凡世界是否改變了人物能欲求什麼、如何行動、何事構成阻力，以及選擇會留下什麼後果。人情與日常可以很普通，不必每次以奇觀自證。

## 五、好看要獨立判斷

作者舉出的 continuity 100、causality 100、character 95、cultivator logic 95，卻仍不好看，是批評「抓錯通過不等於小說成立」的示意，不是現行書稿的實測評分。

PM 與顧問必須另外回答：

- 若是讀者，我會因為哪件具體的事想繼續看？
- 原始 idea 最吸引人的畫面或經歷，在這份梗概裡真正發生了嗎？
- 這一段是否讓我接觸到未曾想過的修仙生活、天地或人物？有趣與陌生也可以來自熟悉事物的新組合。
- 哪段讓故事變普通、重複或只剩工作？指出場面與原因，不能只說「仙感不足」。
- 若沒有能力衝突，這份故事是否仍值得寫？不能以其他檢查通過代替答案。

顧問保留自己的閱讀判斷，但不把主觀喜好包裝成客觀分数。對有分歧的故事提出具體不同展開，交作者看內容；不要用更多審查字眼取代小說。

## 六、重新長故事的次序

1. 找回作者最初的一兩句 idea，盡量保留原話與來源。未找到最早來源時，先用本輪重述並標註，不補造歷史。
2. 暫時拿掉 Agent 後來加入的任務、流程、章數與既成結構；另外保存，不等於刪檔。
3. 說清楚當初為什麼超想看：期待親歷什麼，期待這幾個人在其中做出什麼事。避免只寫「成長」「世界觀」「伏筆」等功能。
4. 先想值得看的遭遇、人物、生活、修行誘惑與奇妙結果，再讓人物欲望和世界回應把它們連成故事。
5. 用因果與設定核對使故事可信；遇到限制時尋找仍能兌現奇想的解法，必要時提出具體重構選項。
6. 写成可讀梗概，接受三道創作審查與作者確認，再安排章節與正文。成稿後仍要檢查是否在展開時再次失真。

這是思考優先順序，不要求先編出明知違反原作的戲再補漏洞。原作與人物核心可以一開始放在手邊，但不能讓「最容易不出錯」成為選故事的首要理由。

## 七、給每個大故事留一份短紀錄

通常幾段話即可：作者原始 idea 與來源；當初最想看的經歷；後來加入的展開中哪些值得留、哪些掩蓋它；新版如何讓吸引力真正發生。

這份短紀錄從梗概陪到正文，作為對照。不可把它做成另一張大型工作清單，也不可要求每個作者畫面一字不變：可以生長得更好，但改變要有創作理由，不能無聲地縮小成安全任務。
