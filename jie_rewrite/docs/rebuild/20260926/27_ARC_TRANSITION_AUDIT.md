# 《劫》新版總綱接縫審查｜單篇成立後，整本是否仍會斷

狀態：依暫定總綱 v1.0 檢查25處相鄰轉場。以下只列需要施工處；未列者可由既有離場推力自然銜接。

## 一、必須先修的四處接縫

### 1. 〈百斷山〉→〈山野假路〉→〈升龍離鄉〉有三次高潮擁擠

百斷山已有秘境、荒初見與天地雷火；假路又有反獵、假殺荒與北海；升龍離鄉再疊登台、守閣、雷淵與第一雷。三篇單獨成立，連讀可能像下界結尾連續三次「最大事件」。

**施工判斷**：〈山野假路〉中段以關係、真假與返閣生活為主，反獵規模保持局部；北海試禁落在降速段。〈升龍離鄉〉的升龍台與大劫之間必須有一段故土日常，使登台不是守閣戰的預告片。

### 2. 〈七峰一家〉→〈一百種答案〉仍可能連成兩場比賽

即使七峰已有修山與短住別峰，篇末大比緊接百宗盟試，讀感仍可能是宗內賽後立刻校際賽。

**施工判斷**：七峰離場重點放在命藏、隊長欄與宗門生活；百宗開篇先寫百道營地與不同宗門如何吃、睡、煮茶，正式規則延後。兩篇間至少保留一次四人純生活節點。

### 3. 〈萬法歸潮〉同時承第四雷、第五雷、神火與真一，能力結果過密

古界主軸已經足夠強，若四個進度節點逐一成為高潮，會重新把高境文明壓成升級場。

**施工判斷**：歸寂放在進界前作門檻；鎮界只作古界中段與蒼梧關係結果；神火由長期五島生活積累，在篇內低調成立；真一只在離場追責與復健完成後結算。白鹿棄筆、霜林與古渡仍是讀者記住的三個高潮。

### 4. 〈三院問道〉內容足以成兩個內部大段

三院生活、聖祭失敗、荒劫排位、寶庫、第七雷與雙戰場若同速推進，篇章會再次像事件總匯。

**施工判斷**：保留一個故事位置，內部分成「三院生活與荒劫排位」及「未完成之路與三刻雷池」兩大段。寶庫只作兩段間的私密轉軸；伏殺、查案與七站訊號都壓縮為檢驗既有人際關係的外壓。

## 三、必須避免互相重複的主題

### 「不同答案」不能連說四次

七峰是一家內部彼此不服；百宗是陌生道路共同改變天地；禁都是技術必須接受居民治理；三院是三種正統都不能替學生完成選擇。正文不得都用「道有不同答案」作總結句，必須各自落在修山、留一線、否決權與失敗牆。

### 「不能替別人決定」需要逐步升級

早期是陸沉不能替同伴選路；血原是他明知仍強行取消敵人被分辨的資格；十凶是醫者不能替病患選；終局才擴大到沒有人能替世界重選。若前期就使用終局語彙，後期只會重複口號。

### 三次「家」各有不同功能

太玄閣是第一次有人教他怎麼站；太玄宗是容納七種活法的宗門之家；沉封域是即使他不在也能維持的公共之家；朝雲巢則屬於劫厄。四者不能都靠吃飯、留房間與一句「回來了」表達。

## 四、人物離場與重會接縫

1. **青璃**：百宗後不能無聲退場。須由她此前自行發起的族中交換自然帶出分路，並在後期至少有一次不為加入隊伍的回聲。
2. **封寒**：古界拒絕完美劍路後，至〈長息〉第二台之間要保留獨立成道時間；第二台不能成為久未登場後的工具性召回。
3. **洛生衣**：古世、生道、血原與十凶是一條連續人物線。她在血原中止私人雷訊後，重建關係必須靠共同查證與時間，不可下一篇自動和好。
4. **蒼梧**：古界拒絕成為永久界樁、暫返三千州後自由交印、無兵篇第六雷後入環、帝關鎮界、罪州失敗與長息離開必須逐步累積；不能到長息才突然提出自由。
5. **赤翎**：燃身後加入不等於失去鳳族生活。她在異域返本與劫後篇仍須保有族人、記憶損失與不服務命圖的選擇。

## 五、當前結論

26位置骨架可以成立，不需要再增加大篇。真正需要的不是更多事件，而是四項施工控制：

1. 下界末三篇降出高低起伏；
2. 古界與書院控制能力結果密度；
3. 五處時間橋必須在正式總綱中具名；
4. 青璃、封寒、洛生衣、蒼梧與赤翎的離場／重會另建人物線表。

下一步應建立主要人物跨篇線，核對每人「主動發起、拒絕、離場、重會、不可代答」五個節點；完成後才適合把暫定總綱改成篇章承諾與章數配置。
