# 《劫》新版卷冊架構｜十三卷與一個仙界空位

狀態：依位置00～24篇幅估算組卷。卷名全是功能性暫名，不替代未來正式書名；位置25另列仙界空位，不計入十三卷。

## 一、組卷原則

1. 一卷至少完成一次人物認知改變，不能只因換地圖分卷。
2. 相鄰卷的主要閱讀味道不得相同：求生後接生活，競逐後接城市，奇境後接剝奪，戰爭後接敵方生活。
3. 大篇可獨立成卷；短篇必須因同一問題自然相連，不能用資料夾數量湊卷。
4. 卷末鉤子優先使用人物欲望與未完成選擇，少用急報、失蹤、伏擊與新任務。
5. 每卷預估約20～50個中等場景章；實際完成承諾後可提前收束。

## 四、各卷卷末鉤子類型

十三卷不得重複使用同一類鉤子超過兩次：

- **欲望鉤子**：卷一、卷五、卷六——人物主動想看下一個問題。
- **離鄉／分路鉤子**：卷三、卷七、卷九——人物因選擇走向不同世界。
- **後果鉤子**：卷二、卷四、卷八、卷十——本卷結果使下一問題不可避免。
- **時間鉤子**：卷十一——下一卷來自多年制度與關係累積。
- **主題收束**：卷十二、卷十三——不靠新敵人預告下一卷。

## 五、位置25如何處理

位置25不先稱「卷十四」。只有當下列三項成立，才決定它是正式終卷、後日談長篇或新部開端：

1. 仙界年代與荒後續原作功業的邊界已核清；
2. 前兩座升龍台的問題能自然推出第三台，而非只剩開門；
3. 卷十三的「家」已完整成立，仙界不會把劫後生活降成過場。

在此之前，十三卷即構成一個有完整主題結束的長篇；仙界是被前文贏得的下一步，不是本書必須用更大世界追加的尾巴。
