# 第一篇〈凡軀立命〉章節架構草案

狀態：寫手1施工稿，供 PM／清道夫篇審；非正式設定。舊章號指 `published/volume01`。

## 主問題與篇界

陸沉在沒有完整功法、無人可求援的流浪中，能否承認身體既是限制，也是唯一可反覆準備和運用的道基？**入口**承序篇：六歲、祭夜灼傷與虎口磨破、體弱、持半枚太玄舊令、父親殘雷紋、斷祭杖，知道父親失蹤且只有族老第一條模糊 S1。**出口**：以肉身與地形而非未熟禁紋脫過單人追兵，右手虎口感染及指腹觸覺遲鈍留下不能輕復的代價；帶病抵太玄閣門前，未取得完整法門、未正式選體修。

## 橫向行動與保密界線

- **守舊三人**：自有帶回陸沉、維持谷中殘存秩序的意圖；用餅、繩套、慢追策略，不替已逃離族人代言。追兵後續是否死不定論。
- **外來獵利者**：追逐聽來的『沉雷谷孩子』傳聞，見無利可圖便放棄，與守舊族人分開，免得舊 ch002 與 ch003 成同一輪重複追捕。
- **途中村民**：有生活與牲棚，不因陸沉出現就展開新支線；霉餅和骨扣留下雙方互不相識的有限交換。
- **父母線**：只保留 P07 第一條父親 S1、A03 第二條殘話；陸沉不知父親在古雷道，也不知母親後手及去處。實體斷片早期不識其為《古神禁典》首頁，第二篇與第三篇依既定順序揭露。
- **能力／物件**：僅臨時低階短紋，有材料、預布、誤警和回力限制；不引第一雷，不取得完整功法。祭杖斷片可撐路、挖土，不作法器或武器；崖戰用石頭、身體與地形。太玄舊令、父親殘雷紋留在身上，不新造失而復得。第二篇入口時右手傷必須由閣老處理，遲鈍後果在後續 ch007／ch014 可回收。
