# 第五篇〈百斷山〉場景架構草稿

狀態：寫手2供 PM／顧問審核的章節架構；暫不定章數，不寫正文或改正式設定。依據：`docs/MACRO_OUTLINE.md` 第五篇、`docs/events/EVENT_WITCH_LU_CHEN_LOWER_REALM_ARC.md` 第五段、published V01 ch023～028，並核對下一篇〈真假委託〉入口。

## 主問題與進出狀態

**主問題**：陸沉帶著太玄閣採藥任務進山，卻遇見會隨天地雷火改路的古禁。他如何在宋知微、阿硯的撤退期限、文奕救人和返航期限、魔女取火禁譜、自己追問古禁之間作選擇？「改禁」第一次成功若需天地雷火，又會在離山後留下甚麼代價？

**進場**：陸沉只有神識、《古神禁典》可讀開的少量段落、基礎體修與預布短禁；不能臨戰憑空畫成熟活禁。宋知微、阿硯為閣老採礦脈裂口藥引，有明確第三聲雷撤退令。文奕有唯一返航天窗與三名被困採藥少年。魔女為自身教門位置取失落火禁譜，已與陸沉互相試探、曾正式招攬但被拒。石昊有自己的百斷山戰場。

**離場**：太玄閣取得藥引；陸沉與石昊留下短暫少年印象，與魔女完成第一次雙向救命；魔女未帶走玉匣，只取得少量校證古紋且負傷。陸沉在百斷山取得天地雷火，經淬體得到承雷資格與「禁制可在特定天地條件下自行改路」的經驗；離境後沒有可持續運用的外部雷火，骨中餘意返閣一夜失控後耗盡，**沒有雷種或成熟活禁**。文奕救出三少年、付出返航時間後焚毀古錨返上界。返閣一夜須演餘意灼傷宋知微、隔日不能重現活禁；舊傷與關係債留存，銜接第六篇時右臂固定剛拆、胸口仍有承雷舊傷。

## 場景卡：依因果排序，非固定章數

### A. 入山與任務契約

- 閣老要藥引而非寶物，三聲雷後必撤。宋知微計物資、阿硯辨裂口藥層，陸沉承認禁典亮紋只是線索。他們約定失聯訊號與截繩條件。**後果**：後續陸沉追火谷不能自動拖二人同冒險。
- 第一聲雷後陸沉誤把三道亮紋當入口，石廊翻面、左掌灼傷；宋知微指出那更像崩塌預兆。陸沉改用白灰、繩結、風粉加警示紋標路。**回收**：雷意能燒禁，卻不能同時抹去所有非禁標記。

### B. 文奕的救人與返航線

- 文奕在東側發現三名採藥少年，四穩定節點只夠保一條出口；陸沉提出依地底空響保留兩岔，並提醒不可拿最後一塊石頭「穩死」整陣。兩人分線。
- 獨立短場呈現文奕依當時可得情報選定穩節點，石廊翻面後出現新裂口，原節點才變得過穩；他撤掉自己的古玉保護換得少年轉身空間。其中一名少年昏迷、另外兩人須自己抬人，不是三名純被搬運物。**後果**：救援繞遠半日、護腕古玉裂、返航暗痕逼近極限；返航場仍須看見他承受失玉與救人延誤的成本。
- 獸潮時文奕完成救人，不被陸沉或荒代勞。最終他把三少年送往安全路線，自己趕唯一返航窗。焚錨是他選擇承擔家族與守錨人責任，古錨與因果對位永久坍縮；他不得在第六、第七篇又從下界出現。

### C. 宋知微、阿硯的藥引線與荒初見

- 陸沉與魔女入山縫後，宋阿遇獸潮，被迫離開原定退線。宋知微先保阿硯與兩包容器，阿硯辨出可暫避的裸岩並以繩向陸沉示警。兩人不可原地等救。
- 陸沉折返，因救宋阿失去火谷入口時間；石昊由自身戰場路過，一拳打開獸潮缺口，再回主峰同伴與原作戰場。陸沉以地勢、繩結和短禁輔助撤人，也要被錯判的幼獸反撲。兩人互報姓名即可，不能在此組成長期同行。
- 藥引須由三人共同採出，宋知微分成兩包，阿硯背一包；即使陸沉火谷失蹤，太玄閣任務仍有成功路徑。第三聲後宋依約割繩，阿硯可提出撤路修正，讓他從被救者進入實際工作者。

### D. 火谷取譜與雙向互救

- 魔女因教門失落火禁譜而來，備有截天絲、護脈散、退路圖與遁符；她不是在山裡等陸沉。她先辨守臺禁制的九息空窗，陸沉辨銅牌背光條件，兩人缺一不可。
- 外部強闖者按守臺換氣時機撞禁，天地雷意改道；魔女遁符只走一半便被逼回，右肩燒穿，原先自留脫身底牌確實失效。陸沉可攜玉匣獨走，卻放下匣回救；前兩次改禁失敗，手背、左指受傷，才借雷意讓火網自行移開半尺。
- 魔女越網後須返身以截天絲拉出被雷火釘住的陸沉，雙手勒出血痕；玉匣留谷被吞。兩人各救一次，兩人各失一物或受一傷。古紋只可撕得殘片，不能等價領回完整火譜。

### E. 雷火淬骨、對手反制與撤離

- 雷火沿肩、脊、腿走，陸沉先嘗試封壓與單向引流，兩者都傷及身體；魔女試強壓也被反噬，改以固定骨節與遮息助他自行走完。這是承雷資格的代價，不是立即掌控雷力。
- 追兵赤矛手與弩手針對九枚黑釘和她的假路；陸沉用黑釘作誘餌，在天地舊紋與雷火同在時維持半息流動禁線，隨即背部反噬。越過火瀑三丈再試，線延半寸即死、三指發麻。**能力邊界在同篇內當場驗證**。
- 第三聲雷後，追兵老者追蹤陸沉胸口餘光而非假身。陸沉改山壁禁紋的先後開合，魔女先過、在對側截回鎖、拖他出來；她以自己可辨的血痕引追兵，傷勢加深，不能神奇全身而退。

### F. 返閣與兩條離場

- 撤離後前兩日，陸沉把鳥群驚飛誤判為追兵，亂催短禁而使胸口餘火逆走；魔女查出山蛇，迫他承認疼痛會扭曲判斷。第三日分路，她留下有限衣角記錄與部分護脈散，自己仍帶傷追教門線。
- 陸沉回太玄閣，晚鐘觸動骨中餘意；照火谷法外引失敗，宋知微按錯位置灼手、阿硯值守地磚異光、閣老指出不可封死。四人合力熬過一夜。陸沉次日站樁、嘗試沿炭線再現仍失敗，讓「承雷骨血」與「成熟活禁」清楚分開。
- 異地收束文奕返航，先確認三少年已被送出，再在守錨人及唯一天窗之間作選擇。古錨焚毀，不留任意重開捷徑。兩部禁典各由陸沉、文奕續讀，不共享即時答案。

## 驗收紅線

1. 荒的百斷山原作主戰場與機緣照原有歸屬；陸沉只在獸潮短暫相逢。
2. 文奕的救人與焚錨均獨立成立；不可用他替魔女、荒或陸沉解決火谷主高潮。
3. 魔女因自己的取譜局真被困，陸沉救她、她再救陸沉；不得保留可隨時脫身的隱藏底牌。
4. 天地雷火不是第一雷、雷種或雷胚，不占十雷星位。低階禁制在雷火前已存在；活化僅在當地條件下短暫發生，離境僵死。第六篇回力仍會撕開舊傷。
5. 上述場景卡只固定因果與人物選擇，不把現行六章機械拉長；分章須讓每場目標、阻力、選擇、代價在正文中可見。
