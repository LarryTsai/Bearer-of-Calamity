# 北海橋段場景架構草稿

狀態：第五、第六篇後的短橋，已經 PM／清道夫審查；不改原作北海核心事件。依據：`CONTINUITY_PLAN.md`、宏綱第四篇回收條與第六篇出口、魔女事件檔第八節、published V01 ch032～034。原作第1005章〈魔女〉回述石昊與魔女首次在北海鯤鵬巢相識，聯手對付月嬋屬其後事件；第296章〈魔女再現〉亦將北海同行作回憶。published V01 ch032～034 的月嬋北海四人同場有時序風險，**新版橋段採石昊、魔女、陸沉三人短聚，月嬋質疑道路與四人同場移作帝都後待審候選**。陸沉遲到主事件後，不入核心爭奪。

## 主問題與進出狀態

陸沉為何錯過鯤鵬巢，卻仍能在北海與石昊互證道路？石昊、魔女、陸沉的短聚如何保有各自目的，並在救船時讓普通人自己選路？

- **入口**：陸沉右臂剛拆固定仍弱，胸口承雷舊傷被谷中回力重撕，左腿釘傷已拔釘但須觀察毒，左臂刀傷未癒；北海前需演休養與有限恢復，不可帶著未處理的中毒立即全力比試。石昊有谷中互認但仍自走原作線。魔女最後一次招攬已結束，追黑錢及教門漏訊有自己的行程。月嬋此段不登場，後續原作對立功能不改。
- **出口**：鯤鵬核心機緣仍完全屬荒及原作人物；陸沉在巢閉後只得到可見的救人責任與道路驗證。他與石昊短試，不決終生高下；三人救船後各自分路，陸沉返太玄閣。橋段至第七篇災兆約半年，傷勢與海上神識消耗不能跨半年憑空保持最嚴重狀態。

## 場景卡

1. **休養與渡船抉擇**：陸沉先處理谷中左腿毒與左臂刀傷，過一段可步行、不能連打的恢復期。渡船黑潮中十三名傷者使船主提出放小艇；陸沉看見巢門將閉仍留船補舷，失去入巢機會。船主與傷者自己參與取水、守舵、分量，不成純負擔。
2. **退潮傷者的木匣**：巢已閉。陸沉救翻舟，傷者抱空木匣與泡壞船票；他先穩傷、交給照料者，不能靠禁制補回失蹤者或從匣裡開出機緣。木匣與船票交接有回收。
3. **主事件後三人短聚**：石昊已帶著自己的戰後疲勞；魔女有教門追索與舊肩傷。海獸因漁網受驚，陸沉辨出網勒傷後撤錯禁改封舟、魔女割網、石昊開路；保留潮氣扭曲神識造成初判失效。魔女可用一兩句指出陸沉從無保命禁走到今日，絕不重述六段履歷或再邀入教。月嬋原有的道路質疑不在此場提前搬入。
4. **道路短試**：翌日陸沉與石昊同意以有限禁點與拳驗路；陸沉先被破局，撤去過穩回流，石昊自行改拳直取本人。雙方以可控傷勢作停手界線，石昊不因北海機緣成為陸沉陪練工具，陸沉不以此勝負索取主傳承。
5. **小船十七人**：船失舵、裂底、獸筋拖拽；握舵少年自主安排舀水與年幼者的位置，三人各自第一手失敗後改分段協作。越潮線時陸沉主動撤前段禁，讓船短暫進水換浮力，船上人須自己抓住這一息划出。清點十七人，交代船毀、物資或航路代價，不把救援寫成三人無成本表演。
6. **分路與後續**：石昊續行自己的下界行程（補天閣已覆滅，不寫回閣），魔女追教門線；陸沉回太玄閣。海上相見只互證路，魔女最後招攬不得重演，個人真名仍不創造。對太玄閣有用的物件或消息可帶回，但不能把鯤鵬機緣拆給陸沉。月嬋質疑及四人同場若要保留，移往帝都後另案核時間線與原作章節。
