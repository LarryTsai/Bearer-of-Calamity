# 第七篇〈下界風暴〉章節架構草稿

狀態：顧問供 PM／清道夫審核的篇級場景架構；非逐章定稿，不定章數，不改正式設定。依據：`docs/MACRO_OUTLINE.md` 第七篇、`docs/events/EVENT_TAIXUAN_PAVILION_SIEGE.md`、`docs/REVEAL_TIMELINE.md`、`docs/outlines/001_下界成根/CONTINUITY_PLAN.md`、published V01 ch035～044 與 V02 ch001。下文「舊 ch」均指 published V01。

## 主問題、入口與出口

**主問題**：下界大劫讓太玄閣與山外的人各自失去退路。陸沉能守住眼前的四人和一座閣，卻無法靠一次勝仗消除界雷源頭；他何以仍選擇追雷？

**入口**：北海短聚後約半年。陸沉已是洞天境體修，能依材料、地形、預備時間設低階短禁；百斷山天地雷火已耗盡，無雷種、無成熟命圖或臨戰萬能改禁。宋知微管理藥糧與記錄，阿硯能自行採購、辨路及值守；閣老舊傷使他不能遠離閣區，對舊印與界雷知情有限且惜言。下界外部消息殘缺，四人不具全知災情。

**出口**：三輪禦劫與最後一雷後，四人存活、太玄閣殘存，閣老昏迷十七日後醒；陸沉在劫後約二十三日內清點、隱傷造成關係代價、獨自追殘雷入兩界夾層，在界海雷淵取得完整界淵銀雷、第一雷位初名照命；劫厄僅以不穩魂影首次顯形。末鏡停在出口將閉、身體將墜道天界前一瞬；下一篇開場承接上界重壓。

## 因果場景卡（供 chapter-editor 拆章）

1. **四人與山外的不同日常**。宋知微與阿硯採藥已是慣例；藥鋪因路亂改價格或供貨、阿硯用自己的積蓄補三類藥材，回閣後宋知微重算糧水。山外商旅不是送情報的嘴：其原目標是把貨／家人送到可走的地點，遇到補給或封路阻力後必須自己選線。陸沉只能從口述、物價、傷者與路況推斷局部。
2. **避難群體留宿與離場**。保留孩子抱熔死銅鈴的物證，但不替姐姐宣判生死。群體進閣求水與一宿，發現太玄閣也無法長期容納、路上可能搶水或斷糧；領路者、孩子照料者各自選擇合走或分走。宋知微只給可負擔的糧／路訊並記下去向，不能讓主角一番話解決眾人命運。後續回聲只從同一路商旅或自返者帶到，不從全知旁白降下。
3. **閣內查證與撤留**。陸沉依異狀查閣基、讀零散殘卷，翌日告訴閣老；宋知微先列撤退條件與糧包，阿硯執行守燈、楔磚並可指出路況。閣老因舊傷與界雷往事不能遠行，四人選擇守閣有明確限制，不是陸沉獨斷。閣老只露出舊傷與警覺，不講清當年誤信上界命令的全貌。
4. **最後備戰及外部回聲**。在古碑示警到首雷間，既有商旅若再經過，僅能報其親見的路段或同行者選擇，消息時間應晚於其上次離開、早於封路。太玄閣據此調整入口水、地下石室與兩份乾糧包。若查不到可信路徑，刪掉回聲場而保留傳聞未定；不得憑空送來孩子姐姐的確訊。
5. **護人、引雷、走遍全閣、最後一雷**。三輪加最後一雷的四段節奏依事件檔與舊 ch038～041，不拆成新雷輪：第一輪是陸沉把人送下去，宋阿維持洞內秩序；第二輪是接引古印誤認與閣老逾界後的舊傷；第三輪是陸沉跑遍全閣、同伴以記錄和搬運協助退路；最後一雷只是照見。每輪的退路、失敗與傷必留到下一輪，不靠重置體力過關。
6. **劫後有限清點**。先救治、修危梁、盤剩糧，再演陸沉隱傷造成阿硯受傷；宋知微以承重上限新規矩改變日常，但陸沉對疼痛仍反射說「沒事」。外界可得消息只限同路回聲，允許其他避難者下落未明。陸沉觸摸未合裂痕，理解守住一閣不等於源頭已除，追雷不是為贏下一戰的獎賞。
7. **告別、雷淵與上界**。閣老醒後只給有限上界太玄宗線索，不洩完整舊事；宋阿有留下繼續守閣的具體工作。陸沉以先斬後奏方式離開，依當夜殘雷裂口入虛空。照命在雷淵以完整本源入體，只給一線保命；劫厄魂影不戰鬥。V02 ch001 的道天界重壓立刻接上，初雷仍無成熟戰力。

## 紅線與清道夫待核

- 雷劫是古接引陣被誤認引來的界雷外洩，**不是**照命雷本體提前降臨；荒正面處理原作主線大劫，陸沉守太玄閣，兩線互不取代。
- 宋知微、阿硯全程無重傷；阿硯劫後搬梁受傷屬另一事件。閣老第二輪舊傷重發而非直接被雷擊。陸沉最重傷，劫後約二十三日與閣老十七日甦醒的算式須逐章核對。
- 035～036 已有陸沉主動查問；042 已有隱傷代價。新增戲不能重新宣稱他「第一次」學會問或報傷。百斷山雷火耗盡，只留承雷骨血資格。
- 上界入口核：V01 ch044 取得照命、劫厄魂影、出口未落地 → V02 ch001 上界重壓與照命保命火。不能把上界落地提前寫在本篇，也不能讓上界首章重演一次取得雷種。
- 只有可追的消息能回閣；災害不以「某一座閣倖存」證明全界已被救。清道夫連讀新增場景與舊 035～044 重場、V02 ch001，核時間、傷勢、物件、稱呼、能力、視角及原作功能。
