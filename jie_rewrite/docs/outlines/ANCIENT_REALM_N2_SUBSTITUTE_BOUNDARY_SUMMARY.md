# 古界 N-2「代界」與第二次代界：最終版一頁摘要（供顧問附給作者）

2026-09-24 寫手1整理。依據：`jie-power-system` 重審（總判定 warning，兩處須改，已改）＋PM 裁示。**待作者確認，未落正文。**

## 一句話
蒼梧只能在退勢時替縫「扛數息」，用後當場力竭；正式窗口跨兩個退勢（相隔約一日）；牠**第一退勢代界後不再代界、自己走**；「第二次代界」只是一個牠**看見後果後選擇不用**的誘惑（用了會走不了、只能留下＝當樁，且最多多留一日，不能無限延長）。

## 規則（寫作時的硬限制）
- **代界**＝縫在退勢時本來就鬆，牠替它扛住數息；不寫開門、不寫維持通道；用後當場力竭，當日不再判災、不再代界。
- **傷**：實傷落在肩胛骨刺側，上限兩次；N-2 只用一次（第一退勢）。兩次數息各自獨立，**不寫「隔日恢復」**（肩傷舊痕不算復原）。疼痛描寫不輕於 ch025。N-3 之後不得再代界，除非另寫恢復期。ch025 頂開洩壓縫算立界，不計入上限。
- **陸沉**：只「承已測段、放、吃一次崩壓」；不造門、不定位。前提：N2-7 前有一句交代照護者已複驗、解除停雷線；「已測段」的兩個時點相對距離量測落在陸沉手上（N2-3／N2-4）。

## N2-7 時序（修訂後）
1. **第一退勢**：牠代界扛數息、力竭、留在古界側；封寒先過。
2. 陸沉與牠在古界多待一日夜；陸沉不承雷，只驗已測段；汐禾毀標記跨日進行。
3. **第二退勢**：牠**不再代界**，自己過界（不是最後一個）；陸沉承已測段、放、吃一次崩壓，最後過界；汐禾毀剩下標記，窗口閉合，古界側不再有門。

## 誘惑怎麼成立（修訂後）
牠**可以**用第二次代界（實傷第二次，也是上限），但用了會力竭到走不了、只能留下＝等於當樁。陸沉沒有禁止（他只說過「我不接受把你當成結構」），所以是牠自己的選擇；牠不用，是**看見後果**，不寫成早想好。牠看陸沉、看縫、再走；骨刺第二次顫（全篇只兩次：N2-2 被拒後、N2-7 此刻），一句就好。

## 為什麼這樣改
- 原案「第二次代界」同日不成立（第一退勢後力竭、當日不能再代）；且「隔日再扛＝拖成永久」會破壞「只扛數息」。
- 改後誘惑仍成立（有東西可以不答、有代價可以選擇不付），也不越過 power-system 限定條件。

3. 牠不用是「看見後果」而非「早想好」。
