## 四、四格人物骨架

### 蒼梧（弧線最後一步）

1. **一開始想做什麼**：用巡查者的本行找出縫，再把人送出去。當出口需要人扛，他的第一個念頭是自己留下當樁：這是最熟悉的老辦法，把自己變成結構。
2. **被什麼打破**：陸沉拒絕；界沿他只讀對一半，第一次時窗因此錯過，「只有我能讀」被打破，必須等阿磯、陸沉補另一半。
3. **只有他會做的選擇**：明知故犯重啟巡查，用代界替縫扛住數息；**窗口將盡時，他有第二次代界可用，可以把窗口拖成一直開著（＝留下當樁），他選擇不用，自己過界（不是最後一個）**。這一步兌現「界是你畫的，能不能重畫」，也回答 Act4 懸著的「我劃的界是否作數」：作數，也有期限。
4. **留給讀者的感覺**：他第一次承認自己會讀錯，並在被拒絕後仍選擇活著離開。肩胛骨刺只顫兩次：提出留下時幾乎不顫，放手時顫得比任何戰鬥都輕。
- 出界後護送失敗、只暫返（大綱硬錨）；「仍可守人的微小證據」落在他為汐禾設計的遠路分工，走後仍在運作。

### 汐禾（古界側的選擇）

1. **一開始想做什麼**：替引汐部要一扇永久的門。傷者、皇朝壓迫、下一次窗口，她只算實務帳。
2. **被什麼打破**：陸沉拒絕永久界樁；她「你不用住在這裡」的反駁成立，也真的輸了，沒被證明錯。接著阿磯交標記時附上的條件讓她看見：一扇門對誰開，取決於誰握著它。
3. **只有她會做的選擇**：**由她自己決定不要那扇門，並親手處理痕跡**（不留標記、不傳阿磯的路標、封存量測記錄），理由是實務的：為傷者開的門，也是皇朝和界屍盜的門。她負責去對族人說「沒有門」，並在名冊上劃掉幾個想出去的名字。這是引汐部第一次自己決定不要什麼。
4. **留給讀者的感覺**：她沒有被說服，她自己做了一件更難的決定。讀者記得她輸了辯論，卻贏得自己的位置。
- 她不是聽島傳人，不要讓她對陸沉說頓悟式的話；告別仍用全名。

### 陸沉（不當樁的代價）

1. **一開始想做什麼**：找一條不需要任何人賠上自己的路，沿用 ch052 起守相對距離的方法。
2. **被什麼打破**：他拒絕蒼梧當樁，卻發現拒絕本身有受害者，而他只能替最後一段承一次崩壓。
3. **只有他會做的選擇**：拒絕之後**不替自己辯護、不補償、不承諾回來**；並在最後過界時**自己承已測段、自己放、自己吃那一次崩壓**，成為最後過界者。他把 volume10 ch006 的鏡像倒過來：那次是他要當五百年界樁被父親拒絕，這次是他拒絕別人，並由自己付掩護的那一份。
4. **留給讀者的感覺**：他站到了當年父親的位置，只用行動表現，不說破，也不自我批判。
- **ch006 鏡像三個地雷**：別寫成陸沉「第一次領悟」不該當樁；別出現「那你自己呢」；別寫他自我批判。
- 不搶戲；他的相對距離讀數在拍點4 與蒼梧的讀數矛盾，不必被漂亮地解開。「承」與「放」是文字上唯一出現的動詞。

### 阿磯（告別物與交出的標記）

1. **一開始想做什麼**：什麼都不交出。「結碰水，別帶人過」是父母用命換的死記，是她最後一點確定的東西，眼前卻有三個外人要往那個方向走。
2. **被什麼打破**：陸沉與蒼梧的讀數對不上，唯一能補縫位的是她的標記。她的父母，正是信了外人指的路死在界潮裡的。
3. **只有她會做的選擇**：**她只給出縫的位置，並附條件：「你們走，別帶人。」** 這是她第一次由自己決定「信」一次外人，也是第一次替族人設線。聽島令由陸沉離開前放進她手裡：**遺物歸還，不是傳承**，不附方法，令不承擔找出口的功能。
