## 二、兩岸故事線如何自然相遇（待證假設）

1. **古界側**：汐禾徵得引汐部識潮者同意後，從 ch008 已走過的遷徙路外側選一處能安全回退的固定觀測岩，按同一岩、同一刻痕、同一套潮時連續量異常。ch023 潮陰澳只作污染反例，先不進封鎖聚落。陸沉遵兩日停雷，以記錄與親量代替即刻施術；封寒僅比較自己已見的局部空間偏移，蒼梧檢查安全退線，三人都不能宣稱對岸在哪裡。
2. **三千州側**：洛生衣在 v2 三千州 ch069 已自主決定沿界潮查斷生，古界 ch001 於入界前三日查訪推算後，從入界點轉走一條**已探過的外沿方向**；這能支持她另開獨立視角，不能證明那個方向正對古界 ch071 白脈岩。ch072 先從她已選的路續寫：回訪先前三日查到的異狀／人證、親走並記出發地與實際腳程，再以三處固定地標、地方潮時、可退路和另一名在地記錄者建立她所到之處。她可因斷生徵象自行改走其他岸段，但須把轉路的地形、時辰與理由寫出，不能直接跳到「候選對岸」。古界 ch001 之後內界經過多日，**內外流速差方向雖定、數值未定**；ch072 不宣稱與古界 ch071 同日／同潮，兩岸時間先各自記帳，待物證往返才對鐘。**先讓她持續觀測，再讓物件可能抵達**；不能物件一出現她恰好在場，也不能讓觀生的粗略遠距關係感應變跨界定位神通。若她的斷生調查實際不通向可安全觀測的岸段，ch072 仍可寫獨立查案，但接應者另選；不可硬搬她。
3. **身份與雙向性**：第一件無生命標物需有事先在古界側刻下的獨特序列、材料傷痕及送出時刻；界外人收取時須獨立記自己座標、地方時刻與原封狀態。單向消失仍算失敗。界外回送另一枚帶**新序列及一個只有收件後才可回答的問題**的標物，古界側收回後再以第三枚正確回答，才可說兩岸確曾雙向交換。接應者身分另用雙方先前共同經歷中可在正文核實的細節驗證；若查不到合適共享識別，身份保持未定，不靠一句「我認得」。
4. **路線不是單點魔術**：兩岸各自畫到標位的實際腳程、地形與安全回撤點；至少兩次不同潮次重複物件雙向交換，記可辨起點、回訊終點、最窄處承重與延遲。先做水袋／石匣等非生命重物往返及撤回試驗，才考慮健康且知情同意者可返程的小試；傷者與古界居民不得作第一次載人試驗。內外時間流速比例只從兩岸記錄推，不借「古世界路」舊比例。
5. **末班只能推算，不能預言**：待雙向路線成立後，若連續至少兩次潮次顯示可回訊承重時段縮短或岸位偏移，才用「最慢一組通行＋兩側確認＋安全撤回」的實測總時長留餘裕決定何時停放行。若沒有縮短趨勢，便沒有「末班」可宣告。界潮局部短接閉合也不等於古界消失。

## 四、給 PM／清道夫的否決條件

- 若 ch071 古界側異常始終只在五島潮時出現，不能推成界潮短接；回到候選清單。
- 若 ch072 外岸座標與時間無法由洛生衣的獨立路程支持，不能讓她「恰好接到」；另派界外 POV 研究。
- ch071 白脈岩兩潮一無異常、一因濕繩／日影與退標砂陷而未定，下一次古界側觀測須先修退路並改進量具；**ch072 的外岸圖不得倒灌成白脈岩已找到出口**。
- 若只有單向失物、遠光、殘聲或同樣顏色泥樣，判**未成立**；不往載人章派工。
- 若真一後兩日停雷、黑金界痕或汐禾營地醫療調度與研究相衝，研究延期，不能拿傷者和藥材作試物。
- 若新增規則與原門消失、蒼梧轄域暫不可定位、古世界路時間比例或已寫古界地理衝突，先修方案與綱，再派跨界正文。

**ch074 核查結果**：木檀童年以為走過望潮石脊，老柯以早於木檀出生的骨圖和親歷證詞指出那是內坡青石尖；老柯只到過望潮脊下，後來暴潮沖斷泉眼旁平石，現圖又隔著已封暗溝。汐禾停止派人探高脊，木檀改走南崖長路接藥。黎母今夜、青枝明晚所需消腫草優先；高脊沒有安全乾路與外岸可比證據，ch076 的派工條件仍未滿足。
