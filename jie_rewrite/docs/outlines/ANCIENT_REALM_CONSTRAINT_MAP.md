完整前因鏈：陸沉與封寒依禁制推演與坍縮之道感知，鎖定一處千年一遇的界潮奇異點（界壁最薄、卻遠未達正常進入門檻的位置），**兩人皆遠低於古界正常最低進入資格（約宗門長老級）**，不靠偽造境界、偷票、死者資格或禁制漏洞，而是硬解一個真正的「界」問題強行闖入（一）。玄衡是巡查界潮秩序的守序異麟，依既定巡查邏輯判定二人為蓄意破壞秩序的非法闖入者展開追殺（貨真價實的執法追殺，非感應誤判）；逃亡期間兩人強行接線使界潮更不穩定，三方被迫合作，逐漸理解彼此非敵（一）。陸沉在界潮暴亂中發現「異常安靜」的歸寂雷痕跡並主動追雷取得（二）；界潮動盪平息後，三人一同進入千年一遇開啟的古界，陸沉在古界內主動追雷取得鎮界（四）。**玄衡全程以獨立守序者身分同行，不贈雷，也不與界潮或古界共同養雷**（四）。

### 4. 內外時間流速不同

出處：`EVENT_DEADSTILL_DOMAIN_XUANHENG.md`、`SYSTEM_CULTIVATION_TIMELINE.md`、`CHECKLIST_PENDING_DECISIONS.md`第204題。

- `EVENT_DEADSTILL_DOMAIN_XUANHENG.md`四節僅提及「三人在此共同生活、歷練一段時間」「古界不能只被記住成『拿到第四、第五雷的地方』」，**未寫明具體的內外時間比例或流速機制**。
- `SYSTEM_CULTIVATION_TIMELINE.md`唯一相關的具體記載是T08列：「鎮魄五日不得覆蓋第二目標，至第十四篇〈界潮與古界〉進入古界內部第三日才滿」——這只是一個**古界內部的天數標記**（用於鎮魄冷卻機制），並非內外時間流速比例的設定。
- **關鍵澄清（容易混淆，務必區分）**：本表`SYSTEM_CULTIVATION_TIMELINE.md`另有一條T13B「古世界路／雙界平行遠行」，明確記載「同期；外界僅12～18日」的內外時間比例——**但這是完全不同的另一個事件**（Volume06b、天神書院之後、帝關正式入籍前，同行者為陸沉＋劫厄＋鎮無央＋玄衡，**不含封寒**），與本文件討論的Volume04古界戰爭史詩（同行者為陸沉＋封寒＋玄衡）**名稱相近但是兩個獨立事件，不得混用**。`CHECKLIST_PENDING_DECISIONS.md`第204題PATCH-02本身也特別提醒「明確區分兩個『古界』概念」並建議T13B改名「雙界古戰場」以免混稱。
- **最新裁定（2026-09-16，`CHECKLIST_PENDING_DECISIONS.md`第204題）**：使用者已裁定「T09B處理方向：**不覆寫**現行`OUTLINE_ANCIENT_REALM_WAR.md`，**在此基礎上加入『內外時間流速不同』**，同行編制維持陸沉+封寒+玄衡三人」。並確認「『時間流速不同』只需要織入**尚未寫的前四幕**（幕一～幕四），已發布的ch018/019不需要retcon，只要新寫的前四幕內容不與這兩章的既有具體情節矛盾即可」。
- **本文件回收結論**：「要加入內外時間流速不同」這個**方向**已是2026-09-16正式裁定、非新提案；但**具體的流速比例、機制、如何在正文呈現**均**未定**，待未來structural design階段依此方向具體設計，本文件不代為填答。

### 5. 陸沉看到的線扭曲／斷裂

出處：`CHARACTER_LU_CHEN.md`（「照命辨節點」「神識察線」「命線」等既有能力描述）vs `古界篇長篇化規劃.md`「陸沉第一次發現自己的判讀『不是看不到，而是看到的線會扭』」。

- `CHARACTER_LU_CHEN.md`既有設定中，陸沉的「線」相關能力散見於：以神識察線、照命辨節點、雷沿陣路傳導（陣法學習與破陣邊界節）；戰鬥中「照命算出對方一瞬的命線破綻」（演出手法節）；戰前「檢查地形、命線、出口」的既定行為模式。這些描述的核心是「陸沉能看見/推算出线索、節點、命線破綻」，是一種**判讀準確、可依賴**的能力設定。
- `EVENT_DEADSTILL_DOMAIN_XUANHENG.md`一節有一句直接呼應：「劫看見『應該去哪』；封寒理解『空間到底怎麼折了』。劫提供線，封寒把線重新矯正、接上」——這確認了陸沉「看線」與封寒「懂空間」是既有的互補分工設定。
- **但「古界環境本身會干擾陸沉的判讀能力、讓線扭曲斷裂」這個具體效果，在既有唯一來源檔中未找到明文記載**。`CHECKLIST_PENDING_DECISIONS.md`第204題PATCH-02曾提及「劫看到的空間線會扭曲斷裂」字樣，但該句同樣出自未被整體採納的Patch草案，且該題最終裁定只確認「加入內外時間流速不同」，**未明確裁定「線扭曲斷裂」這個具體效果是否正式採用**。
- **本文件回收結論**：「陸沉線判讀能力」本身是既有設定；「古界會讓這個能力扭曲/斷裂」是`古界篇長篇化規劃.md`（新提案）與一度討論但未被整體採納的Patch草案共同提出的**新效果**，**尚未正式定案**，應標記為「新提案，未定案」。

### 6. 封寒能補空間問題

出處：`CHARACTER_FENG_HAN.md`（六「武器與大道：坍縮之路」）、`EVENT_DEADSTILL_DOMAIN_XUANHENG.md`一節。

- `EVENT_DEADSTILL_DOMAIN_XUANHENG.md`一節直接確認：「封寒理解『空間到底怎麼折了』……封寒把線重新矯正、接上」——這是封寒空間能力與陸沉線判讀能力互補分工的既有原始出處。
- `CHARACTER_FENG_HAN.md`六之一「鐧的起源：三階段」第一階段明確記載古界期間封寒是「已經很出色的問劍峰劍修」，開始本能地想「拆」（不是破壞，是想知道「這東西如果不是照原本的方法處理呢」），**此時仍無鐧、仍用劍，只是第一次主動放下劍、開始問「我為什麼還在用劍？」**——這是坍縮之道最初的催化階段，但**尚未形成「補空間」這種具體功能性描述**，只是性格與提問方式的萌芽。
- `EVENT_DEADSTILL_DOMAIN_XUANHENG.md`安全閥節也重申：「封寒的空間、探索、吞噬能力上限在此階段首次被打開（**不含兵胚／金鐧**，此時他仍是問劍峰劍修、以劍應戰，吞噬只是純本能雛形）」。
- **本文件回收結論**：封寒對「空間」的理解與直覺是既有設定（呼應「劫提供線，封寒把線重新矯正、接上」），可以支撐「封寒能補空間問題」這個功能性描述；但這僅止於一句原則性分工描述，並無更具體的「補空間」機制設計，若未來要展開成具體場景與招式，仍需structural design階段另行設計。
