# Volume08〈異域同行與帝關守路〉整卷重建大綱（規劃稿）

## 〇、結論先講：規模判斷與最重要的一個結構性發現

**建議規模：現有40章擴增至約 92章**（新增／改動約52章，其中約50章為全新內容，2章為新開場，其餘既有40章中約38章原文保留、僅8章需要調整「入域第N日」等時間標記，不改動場次本身）。這個數字與 `CHECKLIST_PENDING_DECISIONS.md` 第178題「估計新增／重建約90章以上」的量級一致，可視為互相印證。

**理由**：兩份 author_directives 描述的內容——王族偽裝滲透、情報戰、帝族反解析、五人輪流受創、完整大道8→0→8、五星循環——作者本人明確要求「這一整段應該可以寫得很長」「不能只是一場多帝族圍毆」。这不是可以塞進現有40章縫隙裡的支線，是一個獨立量級的核心大戰役，理論上比 `OUTLINE_ANCIENT_REALM_WAR.md`（古界戰爭史詩，約18～20章）更重、更長，因為它同時要處理五個角色的獨立蛻變、一次身分危機（陸沉是不是還是陸沉）、以及作者明講「不是同一種突破」的四種伴星蛻變模式。

**最重要的結構性發現（決定了整份大綱怎麼接得上既有正文）**：

逐章讀過現有 `novel/volume08/chapter001.md`～`chapter040.md`，發現既有40章其實只描寫了**入域後約5～6天**（ch009-010越界→ch013「入域第一夜」分線→ch016「入域第一日末」短暫會合→ch017「入域第三日」→ch021「入域第五日」→ch024返程）。這與 `MACRO_OUTLINE.md` 第十七、十八篇間插段已經寫定的「**五人以異域王族身份長期潛伏**」（"長期"二字是今天才寫定的新表述）在時間尺度上直接衝突——長期滲透、情報戰、五人輪流重傷、完整大道大劫，不可能發生在5天之內，也不該被壓縮成5天，那會讓所有傷勢與蛻變失去重量（這正是作者原始裁示第三節明講「不能只是一場多帝族圍毆」要避免的錯誤）。

但幸運的是，**ch016的結尾本身就留了一個現成的縫**：

> 「多久？」「不知道。」……荒要走的路，可能讓他數日不回……第一次會合不到半刻。

ch016（入域第一日末）與 ch017（入域第三日）之間，原文本來就沒有交代這兩天發生了什麼，而且陸沉、荒雙方明確約定「下次會合沒有時限，靠『水倒流』這個雙方都能驗證的自然條件觸發，不是靠等待」。這代表：

**建議把整個「王族偽裝／情報滲透／五人輪流受創／帝族反解析／8→0→8完整大道大劫／清場／休養」大戰役，整段插入在既有 ch016 與 ch017 之間**，並將 ch017 起的「入域第三日」「入域第五日」等時間標記，改為「長期潛伏後，水倒流訊號重新出現的那一日」這類相對標記（不需要精確日數）。

這個做法的效果：
- **既有 ch001～016（含ch009-010「陸沉主動越界」）完全不用動一個字**，越界場景的張力、荒陸分線的安全閥、資訊隔離的設計全部保留。
- **既有 ch017～040（含ch017「帝城遺孤」、ch021「七路都到這裡」、ch024「黑水角鬥場」）完全不用動場次本身**，只需要把「入域第三日／第五日」這類日數標記改掉——因為這批章節現在的敘事功能改變為：**這是陸沉五人結束長期潛伏、帶著代價換來的情報、以「重塑後但依然虛弱」的狀態重新投入的最後一週**，而不是「剛入域就立刻展開的第一週」。這完全符合作者裁示「大劫散去，五人依然極度虛弱……仍然必須離開、躲藏、休養」「不能立刻去找荒」的要求——ch017之後陸沉表現出的種種資源匱乏（蒼梧傷蹄【215題四伴星改名：「蹄」為蒼梧（原玄衡）舊麒麟種族的身體部位，與蒼梧新版無支祁猿形（無蹄，具四肢/手掌）衝突，此傷勢描述待使用者/PM裁定新版對應身體部位（如「傷臂」或其他）後再回填，暫不自動改寫傷勢用詞，僅先改角色名】、承身不能離體、燃身封存、煌命身資訊延遲、赤翎羽片記憶有限）不但不會被新內容削弱，反而因為「他們才剛從天地熔爐裡活著爬出來」而更有說服力。
- ch009-010「陸沉主動越界」的**公開、不偽裝**的越界方式，與author directive「劫不是被抓，而是主動偷偷跟進」看似衝突，但在此結構下可以並存不悖：**陸沉是公開越界的（異域已知有人跨線同行），但越界之後，為了能在異域內部活動、接近帝族情報層級，他才需要偽裝成王族身分**——公開越界（一次性、被異域記住的事件）與後續的長期偽裝滲透（需要隱藏身分才能持續行動）並不矛盾，反而形成一個好的伏筆張力：**帝族一直知道「有個不在交換名單上的人跟著荒一起跨了線」，卻不知道那個人後來偽裝成了自己人**——這可以成為後段「收網」時，帝族拼圖拼出「原來那個王族就是他」的關鍵反轉點，比原始裁示裡「單純滲透未被察覺」更有戲劇張力。**這一點屬於敘事整合建議，需要 jie-canon／jie-continuity 確認是否採用。**

## 三、關鍵場次二：8→0→8完整大道大劫核心場景（第III幕第7節，約12～14章）

這是全卷戲劇重心，拆成六個必須各自成立的階段，每階段都要求「有選擇、有代價」，不能寫成單純數值歸零重新加滿。

### 階段一：仍按舊規矩擋劫，直到所有人都沒有餘力（約2章）

- 異域大劫第一輪落下時，五人仍然做前面整段一直在做的事：誰最慘，其他人就往前站。劫厄擋一輪，鑑月擋一輪，蒼梧擋一輪，赤翎（此時凰火已熄，只能用肉身硬扛）擋一輪，陸沉擋一輪。
- 這裡要具體寫出「以前一個人剩三成，另外四個還有五成」到「五個人全部只剩最後一點」的量變過程——用具體動作呈現（例如劫厄擋完一輪後連撐起頭都做不到，鑑月的鎮壓範圍以肉眼可見的速度縮小），不用抽象敘述帶過。
- 章末鉤子：下一輪大劫再落，不管誰擋，一定有人死。

### 階段二：劫偷改雷路，一個換四個（約2章）

- 陸沉利用他最擅長的雷傳導、引雷、分流、禁制節點，偷偷切斷四伴星與大劫之間原本共同承受的聯繫，把下一輪大劫全部導向自己。
- **這裡必須明確寫出他當下的心理狀態是「真的準備死」，不是「算好了能突破」**。可以用一個具體動作收束：他對四伴星說了一句聽起來像正常指令的話（掩飾真實意圖），例如「這輪我來扛，你們退到第二圈」，四伴星沒有懷疑，直到雷路變化的瞬間才發現不對。
- **這次欺瞞必須被正文明確標記為陸沉一次已知的性格回退，不能只靠後面階段五的反抗戲被動帶過**（`jie-character` 2026-09-12覆核意見：此處完全剝奪四伴星知情權與選擇權，比一般「以保護之名取消選擇」更嚴重，屬於明顯回退，需符合 `WRITING_GUIDELINES.md` 十之一-B 回退三項條件）。建議在四伴星發現真相後（章末鉤子或階段五開頭），由劫厄（伴命者關係最深）直接點破，例如一句「你又來了」；或讓陸沉事後自己承認「我知道這樣不對，我還是做了」——二者擇一即可，重點是不能讓讀者停在「他這次瞞成功了」的觀感裡。
- 章末鉤子：四伴星發現自己被隔開，雷沒有落到自己身上——**四人是在發現被騙之後才知道真相，並非陸沉事前告知取得同意**，這一點決定了階段五「四伴星反抗」的性質是「被瞞後主動選擇對抗」而非「被告知後同意配合」。

### 階段三：8→0逆拆——一個人在逆著自己的一生死去（約4章，本卷情感核心）

這是最需要「具體演出」而非「設定說明」的段落，按雷種逆序（燃身→剎那→空手→鎮界→歸寂→鎮魄→劫命→照命）分成幾個層次處理，但**不需要每雷各一章**，可以用「最先幾雷合併快速帶過＋照命/煌命單獨慢寫」的節奏（呼應原始裁示「越接近第一雷，重量反而越沉」）：

- **第八至第五雷（燃身、剎那、空手、鎮界）合併約1～1.5章**：快節奏，肉身層面的崩解為主——骨、血、經脈依序碎裂，《萬體鑄身經》撐不住，用具體感官描寫（不是"雷種出現裂痕"這種說明句，而是他清楚感覺到某個曾經救過他命的招式，此刻連帶著記憶一起從身體裡被拔出去）。

## 十、Act III-1〈建立王族偽裝〉Q1～Q5正式定案（2026-09-22，寫手1提案、使用者已完整裁決，見`docs/V08_ACT_III_CREATIVE_CANDIDATES.md`）

**Q1：陸沉如何觀察到異域辨識規則（B→A序列，D轉為戲劇事件，C為輔助材料）**——先用真身親自走一次驗證流程建立基準線（知道自己「正常通過」時系統實際發生什麼），再據此長時間蹲點觀察城門、比對他人通過時的細微差異，不是「看一百個人突然開竅」。黑市查獲的偽造證件作為輔助材料來源，不作主要解法。**觀察第三方偽裝失敗的下場**改列為戲劇張力事件而非學習方法：有人前面每一關都通過，走到複驗，停了一息，下一刻死或被抓——陸沉、封寒就站在人群裡，不能動、不能救。這一幕的作用是讓讀者知道失敗有多恐怖，讓王族偽裝不是純工程題，而是有壓力、有世界、有代價。封寒不參與規則判讀本身（讀規則是陸沉的高光，不分給封寒）。

**Q2：第一次失敗（A＋C）**——A：複驗機制觸發，第一關以為過了，第二道驗證突然亮起，差點被識破。C：技術上成功通過驗證，卻因為選錯王族階級引來社交層面的注意——路人讓路的方式不對、守衛態度變了、甚至有真王族主動搭話，封寒事後提醒：「你選太高了。」C比純技術失敗更有世界感——偽裝不只是騙過陣法，還得活成那個身分。**B（通過但留下微小痕跡）保留，可留給九之一伏筆備用**；**D（陸沉血脈特殊性觸發意外副作用）正式淘汰**，不為此另開新canon債，也避免把「驗證系統被駭」拖回血脈故事。

**Q3：代價怎麼體現（A）**——不是數值扣血，是直接打中兩人的核心：陸沉需要持續讀規則、演算、維持偽裝，導致神識延遲；封寒最擅長、最渴望碰觸未知，現在為了不暴露偽裝必須壓抑本能、不能碰。兩人痛苦方向完全相反（一個必須太多、一個必須太少），天然呼應「劫越來越多／瘋越來越少」的既定長線。**D（延遲反噬集中爆發）正式淘汰**——與九之三重合，好戲不能連著演兩次。

**Q4：封寒的角色（A→B序列，依時期分工）**——開發期（偽裝機制建立階段）：封寒是高壓測試者，主動把偽裝逼到邊界測試。實戰期（正式潛入異域社會後）：封寒轉為陸沉的「第二雙眼睛」，觀察社會反應而非系統本身——「剛才那個守衛雖然放你過去，但多看了你一次」「不是身份，你走得不像」。**落筆時須加明確切割句**，確保這是封寒對「人的反應」的觀察，不是對「規則系統」的判讀能力介入，避免與Q1「讀規則是陸沉高光」的分工原則模糊。**C（用性格缺陷做掩護）不選**，容易把封寒寫油。

**Q5：大道痕跡無法清除（A＋D，重新定義為「表象＋本質」）**——A提供「痕」本身：滅口時雷力氣息滲入因果場（見上方III-1、九之一表述，此為同一伏筆線的兩個認知階段，不是兩個獨立事件）。D提供「為什麼清不掉」：不是技術不好，是這件事已經發生過，這不是物質殘留也不是普通術法殘留，是「發生過」本身無法被清除——這是因果層級，不是技術層級。陸沉可以清血、氣、雷、禁紋、身份痕跡，甚至誤導驗證，但第一次碰到「發生過」要怎麼清？這是他對「消除」這件事理解演化的長線伏筆起點（現在想消除→更高境界明白不是所有東西都該／都能被消除→劫／因果／天譴／天地記帳串起來）。**B（目擊者死前看穿命線）留給其他故事線，不在此搶訊息；C（陸沉血脈極端情緒外洩）、E（帝族日常監測網，會讓III-5揭示點失去單一清晰性）均正式淘汰**。

**規模判斷原則（使用者2026-09-22裁定，取代先前「是否接受~92章」的懸而未決）**：不先鎖定92章這個數字，改為「先把值得活過的東西全部展開，最後它自然是70、80還是92，再看」。這批候選讓92章開始有理由，是因為它們在增加世界、人物、修仙、因果本身（異域社會如何辨識王族、技術騙過制度後如何騙過人、封寒與陸沉的分工、第一次成功為何仍留下因果、零雷後陸沉真正拔不掉的東西是什麼、四伴星如何從「陸沉+四個」變成真正的「五個」），不是加怪物、加城池、加追殺這種填充式規模——若後續展開只是這類填充，使用者寧願要40章。
