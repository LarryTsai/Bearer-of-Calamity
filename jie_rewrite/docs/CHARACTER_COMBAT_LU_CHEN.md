## 戰鬥人格與不變基本功

先看、試、留退路，再以短步、受力與近身動作把可用的一段做成。他思考快但不全知；隊友看到的元素、人手與傷情不會自動進入他的視野。體修不是只供挨打，肩、肘、腳跟與重心本身能改變戰局。雷、禁制、身體與命圖逐步相接，不能把招式寫成一直增加的新解題權限。

右虎口長期細覺遲鈍與當期腕傷／握力不足分開記：前者不表示永遠不能出拳；有具體傷才改左手、縮行程、換肩肘或交給同伴。基本體態由殘篇的腳、膝、背、呼吸，逐步變成可在重壓下重新分配支點。

## 招式演化與兵器／防禦／控場

- **KEEP／BRANCH 承重基本功**：殘篇站姿→公開四篇補根→改脈→承身日常鍛體→七峰傷後換腳、肘肩。升級不淘汰腳跟、重心與能否收手。
- **REWORK 辨看**：043煌命受殘衣誤導→實接腕肘辨真→044面對真劍停看無用命息。這是使用條件成熟，不是新雷。
- **BRANCH 禁制**：少量預刻→外火暫促→命圖記局部→禁都公共用途→三千州單次活禁雛形。第四批已依禁道主裁示§9，將百斷山006限定為雷火短暫活化，保留半息實效與反噬；03 ch048限定當場三息自散、當下無法再畫第二道，保留本篇唯一觸發及鎮魄五日代價，不再誤定終身只能使用一次。
- **EVOLVE 雷身**：三息影→半刻分工→承身→三處承災→共同傷停。被禁用不是ARCHIVE淘汰；後來能用也不是舊傷消失。
- **兵器**：短刃、石片、半令的實物證據與回收鏈另補；劫命的劍光不是取得命劍。未核到固定本命兵器，不把海報武器登入當期持有。
- **防禦**：能躲時留路，不能躲時卸力／改支點／短雷覆臂；一味硬扛不等於體修完整。封禁與鎮界皆須說清受力去向。
- **團隊**：048說明可共見線索→050先聽元素新證據→055處理既定交接失效→058停退權→059各自就位再兩息→060讓權。連攜建立在不同人實際能做什麼，非召喚隊友模組。
