# 陸沉線高潮、懸念與世界觀編輯指南

狀態：現行敘事指南 v1.0

## 一、目標閱讀感受

陸沉線必須有足以讓讀者期待、記住並回看的大場面，但精彩不能只等於更強敵人、更大雷柱或連續瀕死爆種。理想閱讀驅動是：

> 讀者知道陸沉一定會去承，卻不知道這次誰會拒絕讓他獨承、敵人會如何利用他上一次的答案，以及他終於會在哪一刻選擇停手。

每篇離場時，讀者應最牢記：

- 一個標誌性畫面；
- 一項不可逆的人物改變；
- 一筆尚未還清的代價。

其餘精彩必須為這三者讓位。

## 二、高潮分級與波形

### 三級高潮

- **A級主高潮**：改變篇章方向、人物關係或不可逆狀態；每篇只留一個，置於全篇約 75%～92%。
- **B級轉折**：改變局部任務或讀者判斷；每篇二至三個，相鄰轉折不得都以瀕死、爆種或敵人震驚收尾。
- **C級刺激點**：短戰、異象、情報、笑點、生活故障；平均二至四章一個，不必提高戰力。

### 單卷「三浪一谷」

1. **小浪**：前段建立本卷問題，不出新雷。
2. **中浪**：一次看似有效的勝利，打開更大的局勢或誤解。
3. **靜谷**：生活、療傷、查證、輪值、關係或職業段，同時埋敵方學習與延遲代價。
4. **大浪**：多條線在唯一主高潮收束；高潮後保留一至三章清點，不立即換地圖。

兩場頂級戰鬥間，至少插入一段不能靠戰力解決的故事。連續兩場衝突不得使用相同勝利條件，應輪替擊殺、救援、撤退、守時限、留證、拒絕、交班與承認不知道。

## 三、能力首秀的四拍

核心能力採以下四拍，但可跨篇錯開：

1. 需求或缺口先出現。
2. 不完整、誤用或失敗試用。
3. 正式首秀形成標誌性畫面。
4. 至少一次失敗、反噬或被敵人破解。

控制規則：

- 每篇最多一項核心新能力；新雷、命圖級結構與伴星歸位皆算核心。
- 正式首秀只解決眼前問題的六至八成，其餘由同伴、舊能力或撤退完成。
- 首秀不得同時打敗本篇最強敵、突破境界、收服伴星及取得神器。
- 標誌畫面出現時先讓讀者看見異常，不同時長篇講解機制；後續以代價與他人反應補足。
- 每次新雷登場前，至少讓一項既有能力真正解決過問題。

## 四、十雷標誌畫面

十雷的辨識不能只靠換色與更大雷柱，而要改變世界的運作方式：

| 雷 | 標誌性畫面 | 禁止簡化 |
| --- | --- | --- |
| 照命 | 巨雷短暫熄滅，只剩一處未斷命光；陸沉走向看似更危險的路 | 萬物弱點自動標記 |
| 劫命 | 血色祭線先被指掌切斷，雷聲從遠方遲到 | 隨意斬斷所有生命線 |
| 鎮魄 | 魂火各自回到原位，不被吸向陸沉；古鐘聲從神魂內響起 | 與歸寂同寫成萬籟俱寂 |
| 歸寂 | 灰、怨念與裂紋停在將爆未爆之間；安靜得令人不安 | 直接等同死亡或能量消失 |
| 鎮界 | 玄衡四蹄如界釘固定裂口，陸沉體內同時留下對稱界痕 | 瞬間修好世界 |
| 空手 | 接觸後兵器／寶術內部發力骨架逐節扭開，他的手骨同步反裂 | 一碰萬法皆碎 |
| 剎那 | 起點與終點間像少了一幀；抵達後傷口才慢一息出現 | 停止、回溯或自由瞬移 |
| 燃身 | 血管、骨紋與雷脈由內亮起，雷身一具具熄滅，灰中只剩一點命火 | 越燃越華麗、戰後迅速復原 |
| 天譴 | 雷沿已落殺劫逆流，矛尖指向使劫落下者；無罪者面前雷紋自行斷開 | 因憤怒便全城雷罰 |
| 無始 | 前九雷依次熄滅；拒絕回溯後重新亮起，軌道改變而傷痕仍在 | 白光洗地、歷史與死者全部復原 |

## 五、五條長程懸念

1. **身世**：誰把他變成祭子；母親為何離開、父親是否叛族、老族長為何放行。
2. **災源**：劫厄與多雷究竟是承災之法，還是遲早爆發的世界風險。
3. **遲援**：求救被聽見後誰會來；兩處同時求救時誰有權決定先後。
4. **關係**：陸沉何時不再把保護當成替他人決定。
5. **第十雷**：缺的究竟是最後一種力量，還是停止把自己的答案設為唯一答案。

近程問題多數在本篇回應；中程問題隔一至三篇；父母、災源與無始只保留少量長程提醒。連續兩篇未推進的主懸案應暫時退場，不反覆用舊令震動維持存在感。

## 六、公平反轉

重大反轉前至少提供「可見異常、人物動機、規則缺口」三類線索中的兩類；反轉後至少保留一部分原判斷仍為真，不能把前文全部判成騙局。

優先使用：

- 勝人輸局：反敗謫仙，卻未阻止死寂域封口惡化。
- 敵人在守更大的東西：玄衡攻擊陸沉時仍以四蹄鎮界。
- 成功成為危機：雷訊救援成功，也暴露站點流量。
- 安靜不是安全：歸寂止住暴亂，界壓仍在累積。
- 被救者拒絕離開：顧小滿依現場判斷自主守撤。
- 延遲揭價：燃身返營後才發現雷身與雷脈永久缺損。
- 最可恨者未必有死罪：公審讓雷停在讀者厭惡、但罪證不足者面前。
- 普通人完成救援：沉封事故由維護者按預案處理，告訴陸沉不用回來。

禁止依賴事前不存在的血脈能力、敵人突然變蠢、未登場強者救場或臨時修改規則。

## 七、章尾鉤子輪替

章尾可輪替資訊、決定、靜默、規則破裂、視角交接、後果、道德與日常異常，不以「更強氣息降臨」反覆收尾。

例：

- 第七站令號仍亮，心跳碼停在上一息。
- 眾人慶祝試網成功，遠處有人只記錄每座臺亮起的時間。
- 玄燼凰保住命火後，承身第二次分化沒有睜眼。
- 污雷倉傳出極弱心跳，泄雷程序已啟動。
- 三身夜裡都已到齊，桌上卻有第四只用過的碗。

章尾提出的主要問題，原則上三章內至少回應一部分；假死鉤每大篇最多一次。

## 八、世界觀展示法

每篇選擇：

- 一個最有辨識度的核心景觀；
- 兩個持續出現的職業或制度；
- 三至五個能反覆感知的聲音、氣味、溫度、材質或生活細節。

設定以人物正在辦事的阻力呈現：

- **地域**：迷路、繞道、天候、界壓與交通限制。
- **宗門**：登記、排隊、貢獻、分峰與跨峰借資源。
- **職業**：讓陣師、醫修、斥候、軍需官、船家與維護者解決主角看不懂的小問題。
- **資源**：救一處後明確少了什麼、誰承擔短缺。
- **交通**：班次、票價、節點、等待與失敗備援，不讓所有人隨意瞬移。
- **陣法**：零件、誤差、維護、輪值與熔斷，不只寫光芒。
- **法律**：讓當事者可以申訴、拒絕、查證，也讓主角受程序限制。
- **普通人**：給具體欲望，如今晚換班、孩子先過門、不願作證、保住攤位，而不是只負責感激英雄。
- **日常**：吃飯、洗衣、修牆、還書、值夜；至少一半不藏能力或大伏筆。

世界觀的核心不是強者走過很多地圖，而是：

> 每個世界早已有普通人在維護道路、藥爐、陣臺、名冊、渡口與明天；陸沉的成長不是取代他們，而是讓自己的力量接入這些生活。

## 九、各篇唯一賣點與高潮警戒

| 篇章 | 核心賣點 | 唯一主高潮／控制 |
| --- | --- | --- |
| 沉雷谷 | 祭品幼童自己命名自己 | 血祭夜主動撕封；父母真相只埋不揭 |
| 凡軀立命 | 沒有仙法的肉身求生 | 做出留下永久舊傷的自主選擇，不以打敗修士收尾 |
| 太玄閣 | 沒落山門的修行勞動與被人守住 | 三輪禦劫後仍覆滅；追雷只是尾鉤 |
| 界隙照命 | 從看見生路到斬祭子命線 | 聽雨渡劫命；照命、生、贈笛不得各自再成高潮 |
| 太玄宗 | 七峰如分工城市；多身仍過不好生活 | 古雷脈重接與小閣熔毀；無相、雷池、丹、雷訊皆降為中浪 |
| 仙古 | 勝過天驕仍被捲入更古老界災 | 與玄衡分守界裂；謫仙是假勝，歸寂是轉折 |
| 天神書院 | 頂級學府生活、荒劫同台與公共救援 | 若含完整後期，以雙戰場為主高潮；排位是中點商業大場面；必要時拆上下卷 |
| 帝關 | 戰爭是一座長期運轉的城市 | 燃身守撤離；截矛只作篇尾能力鉤子 |
| 異域同行 | 三條斷訊線共同維持回程 | 荒先帶人回、生多留一息、劫最後回；不得另得新雷 |
| 十凶血路 | 誰有權在風險成罪前殺人 | 司天鑑死戰與九雷補全；金王公審另作冷式短卷或餘波 |
| 大劫決裂 | 荒開路、劫收劫 | 拒絕回到滅族前、拒絕永恆劫序；戰力展示服從選擇 |
| 戰後 | 英雄不在，世界仍能生活 | 無更大戰；以第一次合法撤回與普通人補位收束 |

## 十、最高警戒

- 太玄篇目前能力與系統過密；鎮魄／雷魂秘地宜移至下一篇前段或獨立段。
- 仙古的謫仙、歸寂、鎮界、玄衡必須寫成「假勝→困域→守裂」一條危機，不作四次升級。
- 書院排位與雙戰場皆有主高潮規模，需明確中點／篇末分級，或拆上下卷。
- 帝關四階段跨越異域與返關後，不能包裝成連續越打越強。
- 十凶血路、九雷、劫禁區、金王公審不能連成四個天譴高潮。
- 十雷後雷身必須先補總量、同時數與續航限制，否則任何危機都能用多具完整劫解決。
- 伴星不得都因看見陸沉犧牲而歸位；鎮無央因尊重亡魂、玄衡因共同守界、燼長明因他仍想活。
- 荒劫不能每次見面都切磋；正式完整競技以書院大比為唯一核心。

## 十一、終檢

新增篇章或大事件時確認：

- 本篇最牢記的畫面是否只有一個主位？
- 局勢提升的是個人、關係、地方、戰線還是制度，是否又只提升敵人境界？
- 新能力是否遮蔽了配角、舊能力與撤退選擇？
- 世界觀是否正在限制人物行動，而不是旁白講歷史？
- 普通人是否有不圍繞主角的欲望與職業？
- 反轉是否能回看線索，且沒有否定全部前文？
- 大戰後是否留下清點、政治、關係或生活後果？
- 相鄰主高潮是否使用不同勝利條件與不同視覺語言？

精彩不是每頁都更大，而是每一次平靜都讓讀者知道水下仍有東西在走，每一次爆發都讓前文看似無關的生活、規則與人物選擇同時獲得重量。
