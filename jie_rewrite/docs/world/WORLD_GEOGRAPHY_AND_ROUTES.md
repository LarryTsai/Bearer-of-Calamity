狀態：現行設定 v1.0（回應 CHECKLIST_PENDING_DECISIONS 第 40 題；Codex 已確認採用）

用途：只畫已經在既有事件檔裡實際用到的地點與路線，不畫完整宇宙圖。未知或未定的關係一律標「待定」，不得腦補填滿。格式依 Codex 建議：起點 → 通道 → 終點 → 條件 → 時間 → 風險。

## 一、大層級結構

```
下界（沉雷谷、太玄閣所在）
  │  兩界夾層虛空（含界海雷淵）／古雷道（另一條，非陸沉主要路徑）
  ▼
上界・道天界（太玄宗真正所在的一處大界，與三千州等主線世界相連而非隸屬其下）
  │  （道天界與三千州為相連的平行大界關係，見 `factions/FACTION_TAIXUAN_SECT.md` 一、
  │   `events/EVENT_TAIXUAN_PAVILION_SIEGE.md` 十一：「道天界再與三千州等主線世界相連」）
  │
  ├─ 三千州（天才戰舉辦地，與道天界相連的另一片上界大界）
  │   └─ 仙古遺跡（週期性開啟的秘境，內部連通死寂雷域）
  │
  ├─ 九天十地（上界更高層級區域，天神書院所在）
  │
  └─ 帝關（邊荒防線，連接異域）
        └─ 異域（帝關外的敵對區域）
```

**訂正說明（2026-07-11）**：初版誤將道天界寫成三千州「其中一片區域」，與既有設定（道天界是與三千州相連的獨立大界，非其子區域）矛盾，已修正為平行相連關係。

三千州、九天十地、帝關三者的精確地理關係（例如帝關是否屬於九天十地管轄範圍、三千州與九天十地是否有直接接壤）目前設定檔沒有明確交代，本表暫標「待定」，不強行畫出邊界，避免與《完美世界》原作地理設定衝突——原作地理以 `canon/PERFECT_WORLD_CANON_TIMELINE.md` 為準，此處只補陸沉支線需要用到的相對位置。

| 古雷道入口（沉雷谷附近禁地） | 古雷道，下界通往上界核心地帶的另一條通道 | 上界端固定出口 | 需查明血祭真相的線索方能循入；非公開通道 | 陸沉出生前，父親陸承遠獨自深入；Volume10完成十二節承載 | 通道以十二節可替換承載、五席輪值維持；陸承遠左膝以下永久留於古道且住下界端（見 `characters/CHARACTER_LU_CHEN_FATHER.md` 五之二） |

古雷道與「兩界夾層虛空」是兩條不同的下界—上界通道，不可混用：古雷道是父親線可定位、可重複使用的穩定古路；陸沉前往上界所走的夾層虛空是大劫偶發撕開、無法主動重現的災變裂口，不能作為古雷道毀損後的替代路線。
