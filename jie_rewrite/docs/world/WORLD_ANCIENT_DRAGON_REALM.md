# 古龍界：回潮巢群

2026-09-25，現行正文入口：`novel/003_邊荒承劫/006_古龍界・自己的巢/`。本檔只記本篇確實出現的地方、人物與做法，不由「龍」字推定全族政體。

## 地方與交通

上界範圍內的一處殘界，與五島古界、古世界路、仙龍界分開。疊潮口有受維護的常用界門，商舟在護舟紋與既定氣道內穿行；旅客支付通行費，不必自行破界。去回航程可因沿路交貨不同，信件隨有班次的商舟遞送，不是即時跨界雷訊。

劫厄此行只到回潮巢群，不代表遊遍全界。古龍界沒有套用五島古界的1:10時間規則，也不提供正式抵仙界的資格。

## 巢群技藝與地方歷史

岩壁留有舊釘孔，居民曾將巢固定在岩上；三次水路／地脈改道後，改以公共環禁托住可換位的岩巢。更換過的紋柱石色、補紋背面的脈向記錄仍可見。此為地方可查歷史，不是龍族創世史。

公共環禁接地脈氣流、留巢間距離，各戶依自身需求選溫口、日照、風與朝向。岩巢有腹座、尾托、岩冠，龍身體量與不同姿態真會改變受力，須按本人實測接紋。岩巢是有材料與養護費的住處，不是可收掌帶走的仙器。

冷晶白脈使寒意向兩側分散，普通材料用於居住舒適；幼體可在溫口休息、玩以短水息推動的石環。沅枝家保存薄石頁與蛻鱗的成長記錄，不代表每支龍裔都採此習俗。

## 劫厄的選擇與物件

牠先見沅枝選冷晶，自己想看看；向陸沉借三枚普通靈晶，實體布囊繫爪側出行。試棠礁巢身承重折一份工材，其餘自行支付，返程款另留。放棄沅枝巢列較省料的現成住處，選自己想看的朝雲位置，花材料與工時合造，不以受傷換認同。

牠沒有蛋生幼龍的蛻鱗，只說親身記得的魂影至成體經驗；他人不替牠診斷古劫全部來歷，不封牠作龍王。新巢及備用普通銅扣留當地；兩夜實住後，沿商舟與飛行路線返灰雷原，總程約半月。信件可由疊潮口舟行轉交，需等班次，普通字號紙帶回家。
