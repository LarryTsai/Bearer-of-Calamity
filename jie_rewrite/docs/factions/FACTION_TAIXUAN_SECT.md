# 太玄宗七峰設定

狀態：現行架構 v1.2

## 零、所在大界：道天界

太玄宗位於上界「道天界」——與三千州、仙古、天神書院等主線世界相連的一處大界；下界太玄閣是太玄宗留在下界的殘脈，兩者不在同一大界。陸沉追殘雷入虛空、於界海雷淵取得界淵銀雷完整本源並命名為照命後，穿出虛空即落於道天界邊緣，緊接墜入上界災地（完整經過見 `events/EVENT_TAIXUAN_PAVILION_SIEGE.md` 十一）。

## 零之一、下界太玄閣場景細節

- **藏書室**：太玄閣建築內部一處獨立、有門可闔的房間，用於堆放前人留下、無人清理的舊書雜物（竹簡、卷軸、線裝書、單頁殘卷等），數量頗豐，沒有標記或主人姓名可辨認。與既有格局（迴廊、矮牆、柴堆、廊柱、西側石階）不衝突，屬室內空間補全（回應 `CHECKLIST_PENDING_DECISIONS.md` 第123題，正文見 `novel/volume01/chapter008.md`）。
- **雜物中的殘卷伏筆**：藏書室雜物中至少有兩卷值得留意的殘卷——一卷雷法筆記（字跡由工整漸轉潦草至空白，原主人身分匿名，僅知「他們比你先感應到雷」，暗示雷感失控的前例）；一卷劍修心得（夾有一小截巴掌長、鏽跡斑斑的斷劍殘片，頁角有反覆摩挲痕跡），兩卷仍留在藏書室原位、雷法冊子旁，未被取走或銷毀，可供後續章節回收（回應 `CHECKLIST_PENDING_DECISIONS.md` 第125題，正文見 `novel/volume01/chapter008.md`）。
- **同門現狀**：第三篇「太玄閣鑄身」（`novel/volume01/chapter014.md` 起）新增兩名同門——宋知微、阿硯，太玄閣正式從「閣老＋陸沉二人」擴充為四人。閣老對兩人的收留方式呼應其對陸沉的既定模式（不查驗身分、觀察自主意志、不主動安排教學），屬第二次「破例收徒」。太玄閣定期外購藥引（如鍛骨篇殘篇所需藥引）為既定事務性慣例，非陸沉專屬安排（回應 `CHECKLIST_PENDING_DECISIONS.md` 第132題）。

## 一、宗門結構

太玄宗共七峰：六座根本峰各立道路，主峰居中，不傳單一根本道路，而是統轄對全宗開放的通用閣。弟子先歸六峰之一確立根本道路，再依需求跨峰或至主峰通用閣選修公開課程；各峰真傳不可僅靠選修取得。

| 峰脈 | 核心方向 |
| --- | --- |
| 鎮岳峰 | 煉體、承載、改脈、鑄體 |
| 問魂峰 | 神識、魂術、幻術、鎮魂 |
| 問劍峰 | 劍修、劍意、正面殺伐 |
| 萬法峰 | 五行、雷冰風火與術法推演 |
| 天機峰 | 陣法、禁制、封印、推演 |
| 萬靈峰 | 靈植、生機、血脈、肉身修復、靈性培養與生道 |
| 主峰 | 不收根本弟子，統轄通用閣：煉丹閣、煉器閣、陣具閣等對六峰開放的公共設施 |

（原「天工峰」不再作為獨立根本峰；其煉器、煉丹、陣具、丹火、材料與藥性融合等職能，正式併入主峰通用閣，六峰弟子皆可依需求前往選修或任事，不必歸屬其中。）

## 一之一、主峰與通用閣

主峰不像六峰各自收根本弟子、傳根本道路，而是太玄宗對外統一調度資源與技藝之地：

- **煉丹閣**：煉丹、藥理、續脈、藥性融合。
- **煉器閣**：煉器、陣具、丹火、材料。
- 其餘公共設施（藏書、後勤等）視劇情需要再補。

六峰弟子皆可前往通用閣選修或以工代修，不需另外歸峰；通用閣不傳六峰各自的根本真傳，只提供輔助性的技藝與資源。

洛生衣是萬靈峰弟子，但長期在主峰通用閣的煉丹閣任事、選修丹術（見〈三、洛生衣的歸屬〉）；陸沉入鎮岳峰、修出《無相離身卷》分化出第一縷雷身後，也曾讓這縷雷身前往通用閣煉丹閣「打工」——以雷身之力換取煉丹資源與歷練。雷身可自主工作，不需本尊即時操控，但仍持續占用低強度神魂承載；多雷身長期離體、突發共鳴與回歸代價都由本尊承受。兩人的宗門煉丹相遇發生在通用閣，而非天工峰；正式事件已定為「續雷脈丹事故」。雷身打工、雷煉丹原理、煉丹閣經濟制度與事故經過，唯一來源見 `systems/SYSTEM_THUNDER_ALCHEMY.md`。

## 二、鎮岳峰

- 人數最少、修行最苦、資源消耗高、見效不如術法直觀。
- 收下的常是身有缺陷、血脈反噬、命格偏折或曾被肉身拖垮之人。
- 核心不是力大，而是將肉身煉成可承大道之器。
- 真正大戰時負責守住宗門與戰線。
- 根本真傳為《萬體鑄身經》後四篇。

## 三、洛生衣的歸屬

洛生衣是萬靈峰弟子，以洛氏生道為根。她研究生機如何存在、斷裂、延續，以及已斷之生是否能續回。

她長期在主峰通用閣煉丹閣任事、選修：

- 丹道；
- 藥理；
- 續脈；
- 丹火；
- 藥性融合；
- 特殊修復丹方。

定位固定為：

> 萬靈峰修生道，主峰通用閣習丹術。

她不是普通醫修或煉丹閣女丹師。她與陸沉在主峰通用閣煉丹閣共同處理續雷脈丹事故：洛生衣事前知情接入丹陣，陸沉第一次接受同伴自願共同承劫。陸沉的第一縷雷身也長期在此打工歷練；完整經過以 `systems/SYSTEM_THUNDER_ALCHEMY.md` 為準。

## 四、太玄舊令

太玄舊令只證明陸沉與下界太玄閣的傳承來歷，提供進入太玄宗接受查驗與考核的資格。

它可以：

- 證明陸沉不是冒名者；
- 證明下界太玄閣曾屬太玄宗支脈；
- 令守山弟子不得直接逐走他；
- 允許宗門查驗功法、令牌與因果；
- 取得參加入宗測試的資格。

它不能：

- 直接給予內門身分；
- 自動選峰；
- 自動取得真傳；
- 要求峰主收徒；
- 免除入峰試煉。

> 舊令只替他叩開太玄山門，不能替他走過山門之後的路。

## 五、岳沉淵收徒

岳沉淵收下陸沉，不是因為舊令，而是看出這副身體曾弱得幾乎撐不住，仍被陸沉一次次重新拖回來。

太玄舊令把陸沉帶進山門；真正讓他進入鎮岳峰的，是他自己站住了。

## 五之一、太玄命藏

太玄命藏不屬於六峰或主峰任何一方，是太玄宗最高層級的傳承秘境，與尋常藏經閣性質不同：

| 項目 | 藏經閣 | 太玄命藏 |
| --- | --- | --- |
| 內容 | 功法、神通、前人手札、七峰公開傳承 | 歷代太玄宗強者留下的命痕、未完成的道圖、破碎傳承、古代星圖、體質演化印記、無法用文字記載的大道烙印 |
| 取用方式 | 可抄錄、可修習的成品法門 | 由命藏內的古老傳承反過來判斷「你能承接什麼、什麼東西願意跟你走」，宗門無法替入藏者選擇 |

經藏藏法，命藏藏的是前人走過的命。

**進入資格（三層條件）**：
1. **大比名次**（2026-09-12 修訂，回應第162題）：陸沉在七峰大比個人賽正面奪得第一名，證明戰力、心性、臨場判斷與對自身道路的理解。七峰大比評審席另設獨立的「戰場判斷與承壓評級」一項評分，具體考核參賽者臨場退守進攻的判斷、以自創方式解題而非單純蠻力取勝的能力，與戰績名次分開計算、不合併也不互相取代（回應 `CHECKLIST_PENDING_DECISIONS.md` 第135、162題）。
2. **七峰認可**：太玄命藏是全宗核心，不屬於任何一峰，需宗主認可、峰主共同認可，或至少三位以上峰主同意——本峰峰主負責證明其肉身根基不會崩，其餘峰主確認其非靠邪法、奪舍或外力作弊。太玄宗宗主一職目前未設定人選，暫不展開。
3. **命藏自身回應**：真正入藏後宗門也無法替入藏者選傳承，有人只能看見一面碑，有人得一門古法，有人什麼都帶不走。

陸沉入藏後太玄命圖的完整取得經過，唯一來源見 `events/EVENT_MINGZANG_FATE_MAP_ORIGIN.md`。

## 五之二、萬劫沉封域維護席

PW-26 終戰後，太玄宗只作萬劫沉封域三方共管之一，不宣稱占有禁區或建立宗門殖民地。太玄陣師負責鎮界石、封倉結構、維護手冊和輪值訓練；生道維護者及公共見證席仍保有各自否決與監督權。

岳沉淵「一人承不住，就七個人來」的教訓成為輪值原則：陸沉與雷身算同一責任主體，不能用多身名義長期占滿值守席。陸沉失聯時，普通維護者必須能讓系統降級運轉。

## 五之三、七峰大比「新代席」規則

七峰大比是太玄宗為選拔跨峰代表隊（見 `CHECKLIST_PENDING_DECISIONS.md` 第135題）而開設的新生代選拔賽，資格門檻是「尚未取得固定峰內排位、道路尚未定型」的弟子，稱為「新代席」評選，與峰內既有的資深排位晉升考核是兩套不同制度，不互相取代。

已在峰內取得穩固排位、道路已定型的資深弟子不參與新代席評選，改以支援、監督或評審身分出席——鎮岳峰沈山河、秦照雪、陸行烈、柳青藤、韓鐵衣五人屬此類，於七峰大比期間各自以既有專長提供場邊支援（規則交涉、犯規監督、醫務觀察、情感陪伴、場邊聲援等，具體分工依各自角色檔既定專長分派）。顧小滿因入峰年齡最小、道路成型時間最晚，仍屬「新代」範疇，可以參賽。

此規則同時適用於判斷其餘六峰是否有資深弟子參賽——原則上七峰大比的參賽者皆為各峰新生代，資深弟子不與新人同場競技。

### 五之三-A、陸沉當上代表隊隊長的理由（2026-09-12 新增，回應 `CHECKLIST_PENDING_DECISIONS.md` 第165題）

**明確排除**：陸沉不是靠「神識、瞬身、禁制、雷、肉身」多線同步戰術指揮取得隊長地位——此時他鎮魄尚未取得、命圖尚未開啟，剎那（瞬身）要到第十篇才取得，任何形式的多目標即時戰術指揮均屬能力提前使用，維持 `CHECKLIST_PENDING_DECISIONS.md` 第135題「戰場大腦全面降級為單一目標同步感知＋戰鬥直覺式隨機應變」的既定安全閥不變。

**改寫後的理由**：
- 他的隊長地位不是來自臨戰時能同時處理多條戰線，而是來自**戰前準備**——磨合期間，他習慣把隊伍可能遇到的僵局逐一推演過一輪，記住每個人在什麼情況下最好用、什麼情況下該讓路，這份準備本身就是既有「慎思、先算、先準備」性格核心（見 `characters/CHARACTER_LU_CHEN.md`）的延伸，不是新能力。
- 臨戰時他仍只能單一目標同步感知，但切換速度快、直覺式判斷準確，這與「單一目標同步感知＋戰鬥直覺式隨機應變」完全相容——他負責在下一步該讓誰先上這件事上快速拍板，不是同時看顧四人的所有戰況。
- 真正促成隊長地位的是封寒主動讓出整隊權：封寒是可怕的臨戰決策者，但更適合把某一個敵人正面壓到崩潰，不擅長也不想管理隊伍節奏分配；他認為「打人我來，整隊你管」，洛生衣沒有異議，青璃在實際比較後也認可——隊長地位由隊友的信任與各自專長的自然分工共同促成，不是陸沉單方面靠超綱能力壓倒眾人。

**四人初期定位**（不涉及能力提前使用）：陸沉是戰場整合者，靠準備與判斷速度串起隊伍，不需要一直站在最前面；封寒負責正面擊潰單一目標；洛生衣負責續命與後勤支援；青璃負責範圍封鎖與遠距壓制（各自定位見 `characters/CHARACTER_FENG_HAN.md`、`characters/CHARACTER_QING_LI.md`、`characters/CHARACTER_LUO_SHENGYI.md`）。
