# 作者祕密與揭露順序控制表

狀態：現行控制文件 v1.0  
用途：區分作者真相、讀者線索、陸沉知情與其他角色知情，防止全知旁白提前洩密、角色無來源得知真相或同一伏筆重複揭曉。

## 一、揭露等級

| 等級 | 定義 | 正文可寫內容 |
| --- | --- | --- |
| S0 作者祕密 | 只有作者與控制文件知道 | 不得由旁白直接說明 |
| S1 異常 | 角色／讀者只看見不合理現象 | 可描寫現象，不解釋真相 |
| S2 錯誤解釋 | 世界內存在合理但錯誤的說法 | 可讓角色相信，不由旁白糾正 |
| S3 部分證據 | 足以推翻舊說法，仍不能拼出全貌 | 可揭露局部因果 |
| S4 角色真相 | 陸沉或相關角色得到完整答案 | 可在角色視角公開 |
| S5 公開真相 | 天下或主要群體知道 | 可作公開衝突與歷史評價 |

重要祕密原則上至少經過 S1 → S2 → S3 → S4，不直接由 S0 跳到 S4。

## 三、父母線固定揭露順序

1. 六歲滅族夜：陸沉只確認父親失蹤與血祭無法救谷。
2. 太玄閣：老人提供有限線索，隱瞞洛清禾仍可能活著。
3. 界海／道天界：父親雷紋與古雷道產生更強共鳴。
4. 父親線：確認陸承遠仍活、部分同化，取得劫族與古雷道完整真相。
5. 父親不能立刻救出，將洛清禾線索交給陸沉。
6. 母親線：進入斷裂道域，回收太玄舊令、洛氏分支與遮命真相。

不得在找到父親前完整解答洛清禾全部動機，否則父先母後失去功能差異。

## 四、稱呼本身也是揭密工具

- 六歲以前所有人只稱陸沉。
- 滅族夜後天下逐漸只知「劫」。
- 父母、洛生衣與真正親近者在關鍵時刻叫「陸沉」，用來證明他仍是人，不只是承災符號。
- 司天鑑公開文件可只記「災源・劫」，刻意抹去本名，呼應其制度化判決。
