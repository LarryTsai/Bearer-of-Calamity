# 十雷唯一設定表

狀態：現行唯一來源 v1.1

本文件是十雷名稱、進階、法則、取得階段與代價的唯一設定入口。其他角色檔、圖片文字或舊版名稱若與本文件衝突，以本文件為準。

## 一、總綱

> 追九雷而承九劫，悟無始而成自身。

雷種是承載不同劫數的器，雷法只是外在表象。陸沉確實會像追尋天地異火般主動追逐本源雷種，但目的不是把十種屬性當收藏品，而是進入九種雷道生態、親身承受九類大劫，再由自身回答第十劫。

第一至第九雷皆為外界真實存在的本源雷種，各有雷池、雷域、雷界或同等完整雷道生態；不得只因一次戰鬥、救援、頓悟或情緒爆發便在體內自然生成。照命成種、雷體成立後，陸沉須主動蒐集雷跡與古籍、選擇啟程並進入對應雷境。第十雷無始是唯一不存在外部本源、只能由九雷齊備後自身領悟而生的例外。

每雷取得故事至少包含：**需求／舊缺口 → 雷跡與線索 → 主動追索 → 雷境生態與歷史 → 守關者或競爭者 → 首次收服失敗 → 承受該雷對應之劫 → 取得 → 磨合代價與後續改變**。雷池不是寶箱，雷域不是背景；環境、雷種與取得者都必須在故事後發生改變。

雷種位階：雷胚 → 子種 → 主種 → 祖種 → 劫源。雷種決定起點，修士決定終點。

同名雷種可由不同雷池孕育；同一枚本源核心不可同時屬於多人。

**天譴執譴邊界**：天譴不能讀心或按血脈定罪。陸沉須主動進入刑衡雷界，通過問罪雷劫取得外部本源與執譴資格；其後仍須依逐人罪證、閉合因果、公開反證與刑責分級落雷。若混入私怨、隱藏反證或擴大連坐，天譴回灼命圖並使裁決失效。

**第一雷命名與破陣邊界**：初始正式名為照命，進階後稱煌命，兩者始終是同一枚雷種。照命所見「命線」包含生命、招式、禁制與陣法實際運轉的脈絡；它能照出能量交會、裂口與將斷節點，使任何仍在運轉的陣都有理論上的可追索破法，但不直接提供摧毀高境大陣所需力量。完整流程與境界上限見 `systems/SYSTEM_LU_CHEN_FORMATION_SCOPE.md`。

### 二之一、雷色與強度判定

雷色是法則顯化，不是由弱至強的固定品階。同一種雷可以因雷胚、主種與劫源階段而改變純度、核心色與異象，不能僅憑「黑、紫、金」判定勝負。

雷霆強度統一由五項判定：**色澤純度、雷光凝實度、雷聲延遲、環境異象範圍、法則作用的不可逆程度**。初階多為散亂雷弧；進一步形成固定雷紋；主種可展開雷域；祖種顯化法則異象；劫源則能使一片天地短暫服從其劫序。

| 雷種 | 主色與核心色 | 固定視覺語言 |
| --- | --- | --- |
| 照命／煌命 | 銀白，進階後含淡金 | 照出命光、災點與虛妄裂痕；不是審判之金 |
| 劫命 | 暗紅紫，伴血色細線 | 雷線如命脈被截，命中後外援與氣機逐段熄滅 |
| 鎮魄 | 靛青，內含銀青 | 雷聲低沉如鐘，魂影與心魔被壓回本位 |
| 歸寂 | 深黑，邊緣僅餘暗紫 | 光與聲先被吞沒，雷落後才出現無聲黑痕 |
| 鎮界 | 玄黃土金，裂處呈黑金 | 雷紋如界樁與山脈，先定空間再承崩壓 |
| 空手劫 | 熾白，淬體後可留黑色肉身雷紋 | 白雷穿行骨、筋、血、脈；黑紋只記錄承劫傷痕 |
| 剎那劫 | 青藍，帶銀白殘像 | 人先至、雷後鳴；殘像呈錯序而非時間倒流 |
| 燃身劫 | 暗紅轉金紅，燃盡處灰白 | 血骨如炭火重燃，越明亮代表代價越接近不可逆 |
| 天譴劫 | 冷金，核心熾白 | 雷路沿閉合罪證與因果落下；不得與煌命淡金混用；冷金與荒的暖金／熾赤大道之光需明確區分色溫，避免正文中兩人同場時視覺混淆 |
| 無始劫 | 近乎無色，極短暫映出諸色 | 不是彩雷疊加，而是萬劫歸源前的無色雷光 |

第四雷的黑色正式稱為 **玄寂神雷**，是歸寂雷成種後的主要顯化。「玄寂」表示光、聲、死氣與暴亂法則一同沉寂，不代表它天然高於其他九雷。玄寂神雷的視覺核心是「無聲、無光、吞噬感」的靜態黑——雷落之前光聲先一步消失，雷落之後才顯出無聲黑痕，沒有具體雷紋質感。此黑色與荒的代表色「玄黑」重疊度最高，須以一靜一動做出區隔：玄寂神雷強調靜態的吞噬與寂滅，荒的玄黑保留其開闢、破局的動態爆發感，不得在正文中互相借用描述語彙。

第六雷收服過程中，骨、筋、血、脈反覆被域心本源雷流擊穿並重鑄（見六、第六雷・空手劫形成），這個煉化過程會在肉身表層留下焦黑雷紋，俗稱「**淬骨黑紋**」——它是陸沉以自身接住空手本源的傷痕，不是另一枚外來雷種。淬骨黑紋是有形的、刻在皮肉表層的傷痕，伴隨可見焦痕與反震裂口，與玄寂神雷「無聲無光、無雷紋質感」的靜態黑在視覺上一眼可辨。淬骨黑紋**不是獨立雷種，也不是第四雷玄寂神雷**，不能使用寂界、沉法或壓制怨念；此傷痕會在陸沉肉身劇烈承雷時隱隱作痛、該處皮肉較脆，不是純粹的力量加成。

旁白不得僅憑雷色或雷紋直接告知讀者陸沉當前的戰力層級；角色靠雷色做出的戰力判斷只能是主觀推測（揭露等級對應 S2 錯誤解釋），必須留有被實戰推翻的空間，不能被旁白追認為準確。

由雷推演出的獨立能力（例如剎那位移、神魂震懾等，見 `docs/WRITING_GUIDELINES.md` 十四）可視需要收斂視覺、不必冠雷字；但玄寂神雷與淬骨黑紋（因需與彼此區隔）、天譴劫（因需公開執譴、可被驗證）仍須保留最低限度可辨識標記，不適用「不必雷光滔天」的內斂原則。空間類推演一律歸屬第五雷鎮界雷，時間／位移類推演一律歸屬第七雷剎那劫，不新增獨立的「空間之雷」「時間之雷」雷種。

## 三、名稱規則

- **「雷胚」是俗稱、不是階段專名**：泛指任一雷種自成種起、到穩定進階為止這段期間，尚不受主人完全馴服、會因情緒或傷勢波動而不穩的狀態，角色口語與敘述皆可用「雷胚」描述這整段區間，不專屬照命，也不因「已成種」就停止使用——第一雷成種（ch026）後至進階煌命（ch035）前，正文持續稱「雷胚」正是描述這段尚未完全穩定的區間本身，不是用詞錯誤或前後矛盾；一旦正式進階（如照命→煌命），「雷胚」一詞即應停止使用，改以進階後的正式名稱指稱。
- 照命進階為煌命；兩者是同一雷種的不同階段。
- 第二雷正式名是劫命。「截命」只作能力或進階顯化，不作雷種本名。
- 第五雷本名鎮界，鎖界是對敵運用。
- 第四雷本名歸寂，玄寂神雷是成種後的黑色主要顯化，不另占雷種星位。
- 第六雷本名空手劫，外界本源存在於無兵雷域核心；陸沉須以自身走到域心並完成煉化，不能再寫成雷種完全由體內憑空生成。虛渡與其形成、進階及底層法則皆無關。
- 第九雷本名天譴劫，天譴截矛是兵器顯化。
- 第十雷本名無始劫，無始劫天是十雷總歸一的終極顯化。

| 燃身 | **餘命燼池**（焚羽古巢深處雷域） | 帝關血戰與燼長明提供雷跡及必須學會「燃而仍求生」的需求；陸沉主動進入古巢追雷，在不以求死換力量的條件下取得燃身 |
| 天譴 | **刑衡雷界／問罪雷池** | 帝關截矛只留下道標與殺劫逆返現象；陸沉其後主動入界，經衡罪木、白羽蟲、雙面案卷石、秤書人、外域刑官真敗及完整問罪雷劫，取得外部本源與執譴資格。聞硯、四十二人與司天鑑衝突是考驗內容，不是補雷燃料 |
| 無始 | **無外部雷境** | 唯一例外。九雷齊備後，由陸沉拒絕替所有人重選、承認失去仍願重新開始，從自身道路領悟生出；世界中不存在可供蒐集的無始雷種 |

**照命前置因果（不新增雷種）**：虛神界仙王殘識先以完整禁典教陸沉辨認禁紋與力量脈絡，並留下百斷山異常雷火線索；百斷山取得的天地雷火不是雷種、雷胚或十雷星位，不能自行孕雷，只能暫時沿神識與禁紋傳導，使靜態禁制出現短暫流動並淬煉肉身承雷。下界大劫時，陸沉以禁制引雷、以受雷火淬煉的肉身承雷，守閣後追殘雷入界隙；直到界海雷淵才取得第一雷照命雛形，穿越界壓後穩定成種。不得把百斷山雷火倒寫成照命幼生期。

### 四之一、十雷戰力兌現曲線

| 節點 | 讀者應感受到的戰力 | 常規戰鬥邊界 |
| --- | --- | --- |
| 一雷 | 正式站入普通天驕層級 | 同境普通修士不再構成生死苦戰；面對普通天驕可正面交鋒 |
| 三雷 | 遠勝普通天驕 | 同境普通天驕應能穩定壓制；苦戰須來自頂尖天驕、越境、特殊規則或複合保護目標 |
| 六雷 | 一人可形成並主宰局部戰域 | 非絕頂人物或明顯境界差，不得逼他反覆重傷；可在控場同時親身斬殺主要敵人 |
| 九雷 | 綜合體系與同時期荒相當 | 荒劫切磋與分戰場須呈現對等主戰能力；非同級唯一人物不能逼出完整命圖 |
| 十雷 | 同境、無外援、全體系完整死戰可險勝荒 | 常規敵人不得再靠封雷、失憶或反覆削弱製造生死感；張力轉向多名高境強者、跨境巨頭、整界風險與必須同時救援／封劫的目標 |

此表是正文演出承諾，不只是設定比較。受傷不等於弱，但每次受傷必須換到清楚戰果、位置或保護成果；後期可以用肩骨鎖兵、以傷換入敵身等方式呈現兇狠，不能一受傷便失去主導權。九雷後「荒開路、劫收劫」只能是一次互補分工，不能固定成荒永遠斬王、陸沉永遠清理回流與善後。
### 四之二、九／十雷戰力節點不等於境界節點

- 帝關截矛只留下刑衡雷界道標與第一次接觸，不能當場形成天譴、雷胚或執譴資格。
- 第九雷必須等 PW-23D 補全自主執譴資格後，陸沉的綜合戰力才正式與荒同級；這是跨小境界的體系戰力，不代表兩人名義境界相同。
- 第十雷必須等 PW-26 無始真正形成後，才觸發「同境、無外援、全體系完整死戰由劫重傷小勝」的判定；短戰與正面對轟仍可能由荒占優。
- 戰力關係與終極分工的唯一人物來源見 `characters/CHARACTER_SHI_HAO.md` 五。

### 四之三、燃身與天譴的持有者約束

燃身劫不回應求死之念。外部燃身本源只承認能分辨「可捨之身」與「不可支付之命」、且仍真心想活著回到同伴身邊的人；它允許燃去壞死肉身與可支付力量，不替持有者取消燃命誤用、燒傷與永久損耗。玄燼凰只守池讓路，燼長明只自主同行，兩者皆不提供餘命之火或源雷。

天譴不是陣營武器，也不替陸沉證明自己永遠正確。帝關截矛只留下道標與逆返現象；陸沉須經刑衡雷界問罪雷劫取得本源與資格。每次降譴仍須以可辨罪證為錨，並由他承擔判錯因果。若罪責不明、裁定出於私怨，或自身背棄準則，天譴將削弱、失準，乃至反落持有者。

## 五、共通限制

- 每雷必須先有需求、條件與代價，不得作臨時解題能力。
- 取得不等於完整掌握；雷胚、成種、進階與劫源是不同階段。
- 雷種不可消除對應劫數的代價，只能讓陸沉有資格承受並理解。
- 無始不能無代價復活死者或任意重置世界，只能作用於已被命圖納入的區域與因果。終局中，無始一度讓陸沉有機會回到沉雷谷滅族以前，但會抹除後來與洛生衣、太玄宗、四伴星及荒共同經歷的一切——他主動拒絕這個回到過去的**誘惑**，選擇在當下重整失序世界，第十雷因此真正形成。正文須明確寫出他拒絕的是誘惑本身，並未真的執行重置，不與本條限制矛盾。無始展示給他看的只是一條「回到最初」的可能性映照，不是他已擁有任意重置世界的權力。
- **正文落點（Volume11 ch045～048）**：陸沉先完整公開左耳失聰、胸前舊裂、九星互斥、雷身記憶倒灌、面孔流失與可能死亡，不再替同伴刪減風險；其後正式拒絕的不是「沒有痛的世界」，而是由單一承載者替所有已存在者重選人生。回溯從未啟動。白光倒灌後九雷仍各自完整，陸沉主動拆掉唯一主軌，由兩具雷身分組承載，不能再以固定次序同時擠入本尊；第十空位亦沒有天雷補入。直到普通抄錄、七席與外部共同記錄先行承壓，無始才由未消失傷痕、互相矛盾的記錄及最底層生種自行成種。此階段只能重開雷序，不能恢復傷勢、死者、姓名、苦味或完整記憶，十雷劫序仍待最終幕完成。

> 無始不是回到從未失去之時，而是承認失去之後，仍願意重新開始。
> 他看見一條回到最初的路；拒絕踏上那條路後，才真正得到無始。

## 六、第六雷・空手劫形成

空手劫是陸沉主動追入無兵雷域取得的第六枚本源雷種。雷域核心確有外界空手雷種，但它不接受法器、術法或他人力量搬取，只有以本身走到域心者才能接觸並煉化。

形成地為 **無兵雷域**。此地以雷意排斥一切外物：法器越強，承受雷擊越重；外放術法、護甲、符籙、陣盤與儲物法器會逐步失效。它真正排斥的不是兵器，而是依賴；域心本源雷種也正因這條規則長年無人能帶走。

陸沉進入後，萬劫兵胎被壓制，外放雷法被撕散，《無相離身卷》的虛渡亦受空間雷壓限制。他只能以血肉承雷，使拳、掌、肘、膝和整副肉身成為雷路。骨、筋、血、脈反覆被擊穿並重鑄後，他才有資格接住域心本源，使外界空手雷種與自身肉身雷路完成煉化；不是由體內憑空誕生。

其肉身雷路的運轉原則是「骨承壓、筋傳力、血運雷、脈載劫」。雷不必先化成劍、矛或雷海；只要肉身接觸敵手，雷便能沿對方的發力結構逆入，打散肩、肘、腕與軀幹之間的力量傳遞，使敵人的攻勢由內崩散。故空手不是拒絕兵器，而是不再依靠兵器定義自己：身無一處不是兵，觸敵一寸皆可落劫。

初成的空手劫難以留力，觸碰兵器、陣紋甚至同伴時都可能本能尋找結構弱點，陸沉自身也要承受同等反震；他必須重新學會如何觸碰與收力。這項限制使空手劫不是無條件破法，更不能免除近身接觸的風險。

骨、筋、血、脈反覆被擊穿並重鑄的過程，會在肉身表層同步留下焦黑雷紋（「淬骨黑紋」，見二之一），與本源雷種入體煉化是同一場收服過程的兩面，不是另一次獨立事件；外來的是雷種本源，真正使其成為空手劫道路的仍是陸沉親身承雷。

此行與他同行的是洛生衣。雷域切斷丹藥、法器、陣盤與外放生道後，她被困於崩塌雷層中，只能以自身生機暫時維持傷勢，不能替陸沉破域。陸沉因此沒有等待萬劫兵胎恢復，而是以血肉打穿雷域救她。洛生衣的存在提供必須立刻抵達域心的理由；本源雷種來自無兵雷域，最後承接、煉化與付出肉身代價者仍只有陸沉。

> 兵可斷，器可失，劫不可卸。

空手劫不否定萬劫兵胎。兵胎把殺伐效率推到極致；空手劫證明即使失去所有外物，陸沉自己仍是根本之兵。

### 六之一、制勢指——空手劫的深化具名招式

空手劫成種後，經第九篇命圖初成、第十篇天神書院、第十一篇帝關初戰等大量實戰磨練，陸沉逐步完成「重新學會觸碰與收力」的成長弧線。第十二篇「十凶血路」Volume09 ch025～028中，他先以空手劫誤傷聞硯右臂三條主脈，再重組多年近身判力與救援搬運經驗；聞硯短暫清醒時親自指出肩、肘、腕發熱次序，並提出「不能運力，不是不能活」的停手界線，洛生衣與顧小滿分別護住命線、承接倒地，才完成空手劫的精度版本：錯開對方力勢，使其無法運力但不傷經脈根本，正式命名「制勢指」。

制勢指只解決「如何不殺地介入救人」，不是天譴執譴資格的捷徑，也不用於直接制服司天鑑。Volume09 ch030～039另行完成主動入刑衡雷界、承接群體命線、不逆返本命刑罰、問罪雷劫取得天譴後首先不落雷，以及司天鑑自承反噬並放下令牌的獨立因果。

## 七、第四、第五雷與玄衡

歸寂與鎮界屬同一段追雷遠征的前後兩層，卻有不同本源孕床：死寂雷域只提供九息無聲與界樁雷跡；歸寂本源位於獨立無聲雷池，鎮界本源位於其後方的界樁雷池／定疆雷界。兩雷功能與取得故事不可混用，也不能因地理相連便寫成一次獲得兩雷。

前段，玄衡誤認陸沉是新的失序災源；劫厄與其交戰，陸沉只以既有諸雷暫沉災亂、與玄衡固定四裂，讓玄衡看清他是承災者。此時不形成新雷，玄衡只停止敵對。陸沉其後主動追入無聲雷池，首次因抹除所有節律而失敗，改為只沉下互相撕扯的災亂後，才取得外部歸寂。

後段，陸沉循界樁雷跡主動進入定疆雷界——歸寂只能讓暴亂停止，鎮界要求他在移動界島與遷徙生態之間守住相對位置、出口與可變邊界。鎮界本源來自界樁雷池，玄衡與界壁殘雷都不能養出或替代它；永久界痕則早在死寂雷域作臨時界樁時留下，取雷首敗令其再度崩裂。玄衡在陸沉拒絕把牠留作永久界樁後結下伴星命印；待太玄命圖形成可辨識骨架後，才正式占據外環。

> 歸寂使災停止暴亂；鎮界使破碎世界重新穩定。
