# 雷池、雷種與取得方式

狀態：現行設定 v1.0

本文件是雷種孕育場所（雷池／雷域／雷眼）與四種取得方式的唯一設定入口，補充 `systems/SYSTEM_TEN_CALAMITY_THUNDERS.md`（十雷正式名稱與取得節奏）的機制層面，不覆蓋、不重複其取得節奏表。

## 一、雷池的四層結構

雷種不是憑空出現，而是孕育於不同性質的雷池、雷域、雷眼或雷劫遺址中。但不是每座雷池都能孕育雷種——一座真正的雷池分四層：

| 層級 | 內容 |
| --- | --- |
| 外層雷液 | 用來淬體、補充雷力，普通雷池只到此層 |
| 內層雷髓 | 蘊含該雷池的特殊法則，古老雷池才有 |
| 核心雷眼 | 雷池千萬年不滅的源頭 |
| 雷種 | 只有雷眼經歷特殊條件後，才可能凝成的「大道胚胎」 |

普通雷池只能煉體；古老雷池可能有雷髓；真正能孕育雷種的，必須具備獨特的天地法則、災劫歷史或強者遺留——這樣雷種才珍貴。

**與劫的體修根基之關係**：劫體修為根，遇到雷池時第一反應不是坐下吸收，而是先進池煉身、身體承得住後才有資格碰雷髓，能承雷髓才有資格靠近雷眼，能在雷眼中不崩，雷種才可能認他——這與鎮岳峰「站穩、承痛、不崩」的核心完全一致：每一次取雷，本質上都是驗證肉身這座鼎能不能再承一劫。

### 一之一、太玄宗外萬年雷池

陸沉進入太玄宗後，曾在宗門疆域外一處衰敗禁地發現一座萬年不滅的古雷池。池水墨紫，四壁被雷力熔成黑晶，地下古雷脈仍持續供給無屬性的純粹雷力；它只有適合淬體的雷液與殘缺雷紋，**不孕育十雷雷種、不代替雷種取得，也不能直接推動名義境界突破**。

陸沉曾在主峰藏經閣研習宗門任務用的基礎《子母挪移陣解》，遂在雷池旁石穴設母陣、鎮岳峰小閣地下設子陣。兩陣只在放入靈石並以陸沉雷息啟動時短暫連通，距離限於太玄宗疆域附近；連續傳送會留下可追索的空間波動，雷池本身恢復亦有上限，不能作無成本逃生或全員修煉據點。

第二具雷身穩定後，本尊、煌命身與承身（太玄初期職責稱號為「承身」）會在無任務的夜裡共同入池，以《萬體鑄身經》鍛骨、煉筋、熱血、通脈並練習雷息同步。正文可將此事寫成三身私下稱作「洗澡」的日常，但不得把第一、第二具雷身誤寫成第一、第二雷種；雷身創生順序與十雷序位是兩套不同命名制度。

這座雷池的長期作用只有四項：提高本尊承雷上限、穩固早期雷身、建立三身協作、提供有限的秘密療養處。中期可揭示其地下古雷脈是太玄宗古雷痕的一條支流，但不得翻案成隱藏祖種或另一項巨型傳承。

## 二、雷池類型與對應雷種（示意，非強制一一對應）

| 雷池類型 | 可能孕育的雷種 | 特點 |
| --- | --- | --- |
| 界海雷淵（照命所在，見 `events/EVENT_TAIXUAN_PAVILION_SIEGE.md`） | 照命雷 | 沒有底的雷淵，由無數紀元沉積的界雷、殘魂與命火孕育 |
| 萬雷淬體池 | 肉身、承載型淬煉 | 雷液沉重，專裂骨煉血，不直接孕育雷種 |
| 補斷生雷池 | 劫命雷 | 池中命流不斷自行截裂、錯接與續合；取雷者須辨明何者該斷、何者必須留下 |
| 雷魂池／雷魂域（太玄雷魂秘地深層） | 鎮魄雷 | 古戰場葬域以墓土、記名碑與殘魂循環維持各魂歸位；守墓獅分開破魂，並非以強力壓服萬魂 |
| 無聲雷池（死寂雷域只提供入口雷跡） | 歸寂雷 | 雷霆無聲但萬物仍各有節律；真正考驗是沉下互相撕扯的災亂，而非抹除聲音、生機與遺言 |
| 界樁雷池／定疆雷界 | 鎮界雷 | 五座移動界島、界紋藤與換界土金獸共同遷徙；鎮界守的是彼此仍可辨認的相對位置，不是把萬物釘死 |
| 燃身雷池／燃身雷界（焚羽古巢為入口與守池地） | 燃身雷 | 食火藤、灰羽蟲與燼鴉維持「燒去可捨之物、不焚核心命火」；玄燼凰守池但不贈源雷 |
| 無兵雷域 | 空手劫 | 外物與外放術法逐層失效；域心保存斷除外物依賴的本源雷種 |
| 三刻雷池／時隙雷域 | 剎那劫 | 晨刻、息刻、暮刻三池各守自身節律；核心不是絕對更快，而是辨明交接先後並在窄瞬抵達 |
| 焚命雷池（帝關戰場一類） | 燃身劫 | 以血肉、壽元與生命為燃料 |
| 刑衡雷界／問罪雷池 | 天譴劫 | 獨立外部源雷界；帝關截矛只留道標，陸沉主動入界，經秤書人、競逐者真敗與問罪雷劫取得天譴及執譴資格 |
| 無始（無外部雷境） | 無始劫 | 第十雷唯一例外；九雷齊備後由陸沉自身領悟而生 |

**重要澄清**：「虛渡」不是雷種，已正式歸入《無相離身卷》的身法體系（見 `systems/SYSTEM_FORMLESS_SEPARATION_SCROLL.md` 三），此表所列鎮界雷與虛空雷海的關聯僅描述地形性質，不代表虛渡是雷種或與鎮界雷同源。第一至第九雷都必須取自外部本源雷境：空手劫須由陸沉主動走入無兵雷域域心煉化本源，不得再寫成體內憑空自生；劫命則取自補斷生雷池。只有第十雷無始沒有外部雷池或雷種。

## 三、四種取得方式

十雷的取得方式不應全部是「收服」，可分四種：

| 方式 | 說明 |
| --- | --- |
| 取種 | 雷池本來就有成熟雷種，劫擊敗守護者或通過考驗後直接取得 |
| 養種 | 雷池只有雷髓胚胎，劫必須帶走並以自身雷身孕養，逐步成種 |
| 煉種 | 雷池沒有現成雷種，劫以肉身、神魂和命圖，將整座雷池煉成一枚雷種 |
| 生種 | 天地只提供條件，真正的雷種由劫自身的經歷與意志誕生 |

**節奏建議**：前九雷一律是「追索外部雷境、通過考驗、取得本源、再長期磨合」，差別只在他對天地之雷的理解逐步加深，不得把「煉種」寫成用舊雷或殘雷自行製造新雷。只有第十雷「無始」是「生種」，呼應其「回到初始、重整失序法則」的核心方向：劫走到最後才第一次不向外尋雷，而由九雷與一路累積的選擇共同逼出自己的答案。

## 四、世界觀延伸

不同雷池也是世界觀中的資源地：宗門控制低階雷池，古族佔據血脈雷池，仙古遺跡存在殘缺雷池，帝關則有戰爭與天劫共同形成的雷海。十雷因此不只是十個能力，也是劫一路走過不同時代、不同戰場的證明。

## 五、與雷訊網的邊界

萬年雷池只供雷訊令早期秘密測試與備援；供能會與三身煉體直接競爭，因此不能成為公開、永久或無限供能的基地臺。正式設計見 `SYSTEM_THUNDER_COMMUNICATION_NETWORK.md`。

人工戰雷母池、承雷樁與分雷臺不具天然雷眼，也不適用取種／養種／煉種／生種分類；其唯一來源見 `SYSTEM_BATTLEFIELD_THUNDER_POOL_NETWORK.md`。萬年雷池中期接回太玄古雷脈後永久枯竭，見 `events/EVENT_TAIXUAN_ANCIENT_THUNDER_VEIN_RECONNECTION.md`。

終戰後萬劫沉封域的「沉劫井」只是分層封印井，不是雷池、雷眼或雷種孕育地，不適用本文件的取得方式，見 `SYSTEM_MYRIAD_CALAMITY_SEALED_DOMAIN.md`。
