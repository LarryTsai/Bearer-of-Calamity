# 原作時間與修行境界控制表

狀態：現行控制文件 v1.0  
用途：引用 `../canon/PERFECT_WORLD_CANON_TIMELINE.md` 的原作節點，鎖定荒與陸沉的相對年齡／境界、陸沉能力成熟度及跨界順序。其他文件若與本表衝突，必須登記修正或例外，不得無聲改動。

## 一、不可推翻的硬規則

1. 陸沉比荒小約一歲。
2. 百斷山初遇時，荒約十一歲、陸沉約十歲。
3. 幾乎每次與荒正式相遇，陸沉的名義修為比荒低一個小境界。
4. 境界較低不等於戰力必敗；陸沉可用肉身、神魂、十雷、命圖與戰術跨小境界交鋒。
5. 荒的原作事件與境界先確定，才推算陸沉，不能為陸沉的新能力倒改荒。
6. 雷種、仙氣、極境、燃身、雷身及合體屬能力／戰力狀態，不自動等於名義修為突破。
7. 每次名義境界突破都要有事件錨點，不得在兩次相遇間無聲升級。
8. 原作事件順序與荒的核心功業不可被陸沉支線改寫。
9. 作者批准的戰力例外：第九雷於 PW-23D 補全後，陸沉可在仍低荒一小階時以綜合體系戰力與荒同強；第十雷於 PW-26 形成後，同境完整死戰可重傷小勝。此例外不改名義境界，也不轉移荒的核心功業。

## 二、「低一個小境界」如何計算

- 原作明確寫出初、中、後、圓滿時，依同一大境界內的階段計算。
- 原作只寫大境界時，不自行編造細分；記作「同大境界低一小階，具體名稱待核」。
- 洞天／搬血極境、仙氣數量、以身為種、十雷、命圖、雷身、伴星及短時爆發不折算成小境界。
- 若劇情必須同境、差兩階或陸沉暫時領先，事件檔必須寫明起訖、原因與恢復基準；目前唯一批准的戰力例外是 PW-23D 九雷同強與 PW-26 十雷完整死戰小勝，兩者均不自動改變名義境界。

## 三、凡道境界先後基準

> 搬血 → 洞天 → 化靈 → 銘紋 → 列陣 → 尊者 → 神火 → 真一 → 聖祭 → 天神 → 虛道 → 斬我 → 遁一 → 至尊

本表只固定先後，不宣稱所有網路整理中的細分時點均正確；仙氣、以身為種及仙道以後須另依原文章節核對。

- **PW-23B 標記「高優先待核」**：`canon/PERFECT_WORLD_CANON_TIMELINE.md` 8.5 節自己把「謫仙後續與十凶巢穴慘案」標成全表少數幾個「高優先待核」項目之一，而我們第十二篇十凶血路、血祭殘煞、司天鑑死戰全部掛在這個節點上（見 `CHECKLIST_PENDING_DECISIONS.md` 第 43 題）。建議這題章號核實完成前，先不要把十二篇的具體場景寫成正文定稿，設定層級的因果可以先定，但落筆順序上這是目前唯一「地基還沒確認」的一塊。
- **PW-25D 揭示荒有大時間跳躍（婚姻、親子、長時間沉澱）**：canon 表後期待建部分顯示荒終局前有一段「不得一路沿用青年期外貌／關係」的長時間沉澱期。這直接影響 `CHECKLIST_PENDING_DECISIONS.md` 第 46 題（十四篇萬古獨行是否納入）——若納入，陸沉是否要跟著這段時間跳躍一起沉澱，或選擇不沉澱、走出與荒不同步的獨立節奏，是第 46 題之外需要一併決定的新子問題，建議一併交給 Codex 與作者討論。

## 七、原作安全閥

- 陸沉不取代荒的核心傳承、重大勝利、稱號與歷史功業。
- 陸沉可處理同一大劫的另一處戰場、發現局部陰謀或承擔原作未聚焦的代價。
- 原作人物若提前與陸沉交手，其存亡與後續重大事件必須由事件檔設安全閥。
- 謫仙線以 `events/EVENT_XIANGU_RUINS_ZHEXIAN.md` 為準。
- 荒劫公開交手可場面戰平，但不得抹除名義境界差、原作排行與荒的核心道路。
