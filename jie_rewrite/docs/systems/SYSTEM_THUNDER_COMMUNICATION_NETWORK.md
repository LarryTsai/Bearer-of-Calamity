# 雷訊網系統

> 狀態：正式設定 v1.0

## 定位與命名

劫將煉器、聚靈陣、聚雷陣與《子母挪移陣解》結合，做出一套「有節點才有遠距通訊」的雷道訊息網。

- **雷訊令**：個人通訊法器，民間俗稱「傳聲令」。
- **雷訊臺**：固定基地臺，負責接收、驗證與轉送。
- **中繼臺**：跨峰、跨城或長途路線的轉接節點。
- **雷訊樁**：小隊攜帶、臨時架設的戰地中繼器。
- **雷訊網**：以上裝置組成的整體網路。

這不是憑空傳音。覆蓋、節點、能源與維護者缺一不可。

## 運作原理

雷訊令內有三層陣紋：微型聚靈紋只負責緩慢補充待機消耗；微型聚雷紋把聲音、短文、求救碼和粗略方位壓成雷律；子母定址紋則搬運極微小、無生命的雷訊標記，用來辨識收件位置。

`雷訊令 → 最近雷訊臺／雷訊樁 → 鏈式中繼 → 對方雷訊令`

《子母挪移陣解》在此只提供定址概念，不能藉雷訊網傳人、物、神魂、術法或完整記憶。附近沒有節點時，雷訊令只能退回成短距離、事先配對的傳聲法器。

## 可傳內容

- 短句傳聲與短篇雷文
- 制式求救碼、傷勢碼、撤退碼
- 經節點估算的粗略方位
- 臨時群組「雷簿」中的多人通告

不能傳送影像、整段記憶、完整神魂、遠端法術、大部功法或活物。

## 身分與保密

- 每枚雷訊令有公開令號、持有人神念印與一次性變化雷序。
- 首次使用必須當面「合印」。臨時雷簿到期自行消散。
- 軍令採主將與值守雷訊臺雙印，單一令牌不能直接調軍。
- 雷序定期輪換；遺失令可列入黑冊並撤銷令號。
- 訊息帶時刻印，降低截取後重播舊命令的風險。

系統仍可能遭截聽、流量分析、反查節點，或在令牌與神念印同時失竊後被冒名。

## 限制與故障

- 節點須預先部署；無覆蓋即斷網。
- 容量有限，過量會延遲、串音或漏訊。
- 封界、空間亂流、異域法則與死寂領域可使訊息失真或中斷。
- 節點被毀會造成局部失聯，並暴露相鄰節點的大致方向。
- 過載可能熔毀陣芯、反噬值守者，故設熔斷與只收不發模式。
- 優先級為：災害撤離、軍情、醫療求救、一般傳訊。
- 傳訊符與信使仍是昂貴但不依賴固定網路的備援。

斷訊只代表目前聯絡不到，不能直接等同隊伍全滅。

## 發展世代

1. **對令試作**：兩枚雷訊令只在夜間集合或近域工作時短距離互通，只傳數句聲音，不能跨越太玄七峰。
2. **太玄七峰網**：各峰設臺、主峰設總臺，首次形成基地臺網路。
3. **三千道州中繼網**：以城池、商路與天神書院為節點，發展雷訊樁。
4. **帝關軍訊網**：傳警報、傷勢、粗略座標、補給與撤退命令。

## 人物分工

- **劫**提出雷律、定址方式與戰場需求，製成危險核心原型，但不是突然成為全能煉器宗師。
- **太玄煉器、陣法弟子**完成令殼、通用陣紋、節點量產和維護，使網路能在劫不在時運作。
- **洛生衣**測試傷者、神魂衰弱者的安全使用，建立醫療求救碼。
- **本尊、煌命身、承身**分別參與雷律校準、陣芯刻紋與過載衝擊測試。

## 既有設定邊界

- 雷訊網不是十雷之一，也不是命圖能力或傳送陣升級。
- 雷身之間沒有天生跨界心靈通訊，仍受節點與法則限制。
- 太玄初期的三身原型測試全程封閉；公開紀錄只寫鎮岳峰、煉器與陣法小組，不提前公開多雷身秘密。
- 萬年雷池只作早期秘密測試與備援能源，且會與三身煉體爭奪能量；正式主臺由峰陣、靈石和地脈供能。
- 進入異域後，正常雷訊網完全沉默；寂渡笛的歸身之律仍是獨立、唯一的微弱返航線索。
- 帝關多雷身分守裂縫時，多身作戰才正式無法繼續對外隱藏；外界仍不知道雷核共傷與回歸代價的全貌。
- 雷訊網與戰雷池陣網可以共架、借用備援電力，但不可共用陣芯；前者傳資訊，後者搬運高能雷力。雷池過載可能燒毀鄰近雷訊臺，故須物理隔離。
- 太古星天圖展開時，雷訊網只提供指揮資訊；斷訊不等於「劫禁區」立即消失，也不能藉節點遠送十雷殺招。萬劫沉封域內只傳倉號、污染級別和撤離警報，赤倉與無聲倉可完全斷訊。

## 創作核心

**劫無法親自出現在每一處求救，所以先讓求救有機會被聽見；但聽見，也不代表來得及救下。**
