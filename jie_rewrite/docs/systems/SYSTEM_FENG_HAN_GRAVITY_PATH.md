# 封寒（瘋）坍縮之道：個人修行體系唯一設定

狀態：現行設定 v1.0（2026-09-12 新建，回應使用者裁定推翻封寒 v1.1 終態後的配套系統文件）

本文件是封寒個人大道「勢→重→引→坍縮→奇點→黑洞→白洞→歸墟」的唯一設定入口，**只適用於封寒本人**，與陸沉的十雷／劫道體系（`systems/SYSTEM_TEN_CALAMITY_THUNDERS.md`、`systems/SYSTEM_CALAMITY_ORDER_AND_SELF_RECONSTRUCTION.md`）完全獨立，不共用機制、不互相解鎖、不互相解釋。命名上刻意避開「萬劫」前綴（已用於萬劫兵胎、萬劫定序、無始劫天、萬劫沉封域）與「界劫」一詞（已是第五雷鎮界的承載之劫正式名稱），避免與既有十雷體系撞名。

## 一、與陸沉道路的關係

封寒與陸沉的大道彼此互補而非同源：

> 陸沉的道，是往外燒——劫染萬物，萬物皆歸序。
> 封寒的道，是往裡塌——萬物皆有其勢，勢盡則坍，坍盡則吐。

兩人私下常以「你往外燒，我往裡塌」互相調侃，但這只是修辭上的對照，不代表兩套體系有實際互通的機制。封寒的坍縮之道**不消耗、不借用、不干涉**陸沉的雷種、命圖或雷身；反之亦然。

## 二、路徑階段

| 階段 | 內容 |
| --- | --- |
| 勢 | 起點。感知並借用戰場既有的力量走向（敵我出招的慣性、地形重量分佈），尚不能主動創造力量，只能順勢借力 |
| 重 | 開始能主動賦予目標「額外的重量感」，讓對手動作變滯、讓自身兵胚變沉，屬於局部、短暫的效果 |
| 引 | 學會把分散的力量牽引匯聚到一點，開始能干涉戰場上不只一個目標的力場 |
| 坍縮 | 把牽引匯聚的力量壓縮到一個極小範圍內引爆或崩潰，殺傷力與範圍同步提升，也是兵胚成熟形態（俗稱「金鐧」）真正定型的節點 |
| 奇點 | 坍縮壓縮至理論上的最小點，此時兵胚能短暫形成局部吞吐力場；此階段消耗巨大，不可長時間維持 |
| 黑洞 | 吞吐力場穩定化，能持續一段時間吞納戰場上的力量、攻擊甚至法則波動，但吞入之物必須有出口，不能無限囤積 |
| 白洞 | 黑洞吞納之力的釋放端——把吞入的力量、法則波動以另一種形式反向吐出，用於逆轉戰局或反哺同伴，而非單純破壞 |
| 歸墟 | 路徑終點，黑洞與白洞不再是兩個獨立階段，而是同時、同源運作——吞與吐在同一瞬間完成閉環。此為封寒目前尚未抵達的推定終局階段，具體效果暫不硬定 |

## 三、限制與代價（比照既有呈現鐵律）

- 本路徑**不得**以具體倍數或百分比描述效果（呼應 `systems/SYSTEM_TEN_CALAMITY_THUNDERS.md` 十之二的既定呈現鐵律，同樣適用於封寒的道路），一律以質性描述（吞得住多少、吐得出多少、能維持多久）呈現。
- 「黑洞」階段的吞納並非無限——吞入之物找不到對應出口時，反噬會直接作用在封寒自己的兵胚與肉身上，這是他行事「先自己試」底線的機制對應。
- 黑洞階段能吞納的上限與封寒自身境界、肉身承受力、對坍縮之道的掌握程度成正比，不因劇情需要單方面放大吞納量（比照 `systems/SYSTEM_TEN_CALAMITY_THUNDERS.md` 一「取得完整不等於完整掌握，發揮多少取決於境界、肉身、神魂、理解」的同等限制）。
- 封寒的道路推進速度須與陸沉當前戰力相對校準：他不是獨立於全書戰力曲線之外的角色，任何階段突破仍須有完整的「需求—追索—失敗—取得—磨合」節奏，不得因單一支線登場就跳過中間過程直達後段階段。

**黑洞階段的三段式節奏（2026-09-16 retcon，回應`CHECKLIST_PENDING_DECISIONS.md`第203題定案，取代舊版單點突破設計）**：

1. **Volume06〈天神書院〉書院天煞痕**：勢→重正式發生（見`characters/CHARACTER_FENG_HAN.md`七、`CHECKLIST_PENDING_DECISIONS.md`第180/203題），此時封寒僅是「接住外力」的直觀階段，遠未觸及黑洞，不得提前使用任何坍縮/黑洞相關描述。
2. **Volume08前後（帝關前段，候選場景：封寒×雲行「未知古路」事件，`characters/CHARACTER_YUN_XING.md`九之二）——中期首次坍縮／黑洞雛形**：戰力不得超過陸沉當前八雷綜合戰力（與既有「坍縮→奇點」門檻要求一致）。此處正式落地`CHECKLIST_PENDING_DECISIONS.md`第203題定案的完整「黑洞誕生」場景（積→臨界→坍縮的推進順序，含canon對話「它不是在變重」「是旁邊的東西開始變輕了嗎」）——**此次觸及極度危險、不完整、僅存在數息、封寒事後無法自行重現，觸發後他自己也不知道剛才發生了什麼，只知道跨過了某個東西**。不得使用「持續一段時間」「主動吐出」等黑洞階段專屬效果描述，事後不能重現。
3. **中期至Volume10之間——長期追問與失敗（不需要固定事件錨點，可分散在多個既有場景中呈現）**：封寒明知那裡有一扇曾經被自己意外推開過一次的門，卻怎麼都打不開，嘗試多種錯誤方向——加更多重量、吞更多力量、讓鐧更強、把自己逼到瀕死——全部不是答案。這段是他坍縮之道推進最慢、最挫折的一段，須避免被單一場景快速帶過。
4. **Volume10長息銜接段（十凶血路後十二年、大劫決裂前夕，`novel/volume10/chapter020.md`一帶，回應RC-FH-06 retcon）——黑洞成道**：陸沉此時九雷完整、命圖未全。封寒此處才真正理解黑洞的本質**不是「很多很多的重」，而是重跨過某個界限之後，規則本身發生了變化**——這是他坍縮之道的第一次真正的大突破，正式掌握黑洞階段（可穩定維持、可重現，區別於中期那次意外雛形）。整體戰力仍不得與陸沉當前九雷綜合戰力相提並論，僅作為他個人道路的重大節點，不改變隊伍整體戰力對比。

**白洞階段的前提**（2026-09-16一併定案，回應第203題）：白洞（「承載不等於佔有」，封寒主動選擇釋放而非黑洞裝滿後被迫排放）**必須發生在封寒真正掌握黑洞、且已使用黑洞相當長一段時間之後**——只有「不放／留下」已成為他成熟大道的一部分，後續「但不能留」這句話才有真正的人物重量。因此白洞不得早於Volume10黑洞成道，具體事件時點另行設計，本文件暫不硬定。
- 兵胚形態隨修為推進變化，但每一次形態突破仍須有具體事件觸發，不得無代價自動升階（呼應全書「每次突破需事件錨點」的一貫規則，見 `systems/SYSTEM_CULTIVATION_TIMELINE.md` 硬規則第7條）。
