# 戰雷池陣網

> 狀態：正式系統 v1.0
> 軍中簡稱：雷池網

## 一、核心定位

戰雷池陣網是將預先儲存或戰場逸散的雷力收束、沉降、分流、卸壓，再作一次有限回送的戰場工事。

它不會自行產生雷力，不孕育雷種，也不是領域。它能做的是把本該在一瞬間壓垮整條防線的力量拆成數段，使不同節點有時間承接。

> 雷池網不替人贏戰；它只把本該在一瞬壓死所有人的雷，拆成一段一段，讓每一段都有人來得及承。

## 二、與雷訊網的區別

| 系統 | 傳遞內容 | 主要用途 |
| --- | --- | --- |
| 雷訊網 | 極低能量的雷律資訊 | 傳聲、雷文、求救碼、粗略方位 |
| 戰雷池陣網 | 高能量雷力與衝擊 | 蓄能、分流、卸壓、局部返雷 |

兩網可以共用地圖、守臺人和外圍工事，但不能共用陣芯。戰雷池過載可能燒毀附近雷訊臺，部署時必須物理隔離；雷訊斷線也不代表雷池網自動停機。

## 三、節點

1. **戰雷母池**：全網主蓄壓槽，以雷液、雷砂、裂雷晶等消耗介質存雷；決定總容量，不具雷眼，不生雷種。
2. **聚雷井**：接地、接天，收集自然雷暴、己方術法餘波及少量可兼容敵方雷擊，不能無中生有。
3. **承雷樁**：前線小節點，承受局部爆衝；超限時先斷樁保護主網。
4. **分雷臺**：控制流向與優先序，是最容易遭內奸改序的核心工位。
5. **鎮界錨**：第五雷與玄衡歸位後才能成熟，固定裂界附近節點的相對位置；不產能，也不能真正修好世界。
6. **泄雷渠／葬雷坑**：將超量、異質或受污染雷力導入無人區與一次性雷砂。沒有泄壓出口的雷池網必然早晚連爆。
7. **返雷門**：末端輸出口，只能替城牆、陣器或已合印的一名雷修補充一次有限爆發，不能隔空替全軍充滿法力。

網路採「一母池、多分臺、樹狀支線與斷路節」，不得全連通，避免一點中毒污染全網。

## 四、能源與損耗

能源只有四種：事前灌入的靈石／雷晶、自然雷暴、己方雷術逸散，以及屬性可解析且未超載的少量敵方攻擊。

- 太玄試作期回收率約一至二成。
- 命圖成形後約三成。
- 鎮界成熟且工事完整時最高約四至五成。
- 仙道、不朽與異域高階法則不能直接吸收反殺，只能嘗試分壓、隔離或排入葬雷坑。

雷力久置會散，屬性混雜會污染；戰後必須排空淨化。池中能量不能用來長期閉關、催生雷種、突破境界或修補本源傷。

## 五、三種模式

- **承雷**：削弱落在己方陣線上的可兼容衝擊。
- **養鋒**：收集己方逸散，供指定陣器或小隊作一次回擊。
- **斷界**：配合鎮界錨，把裂界爆壓導向預設死區，保住撤退路。

同一張網只能以一種模式為主；切換存在數息至數十息的空窗。

## 六、與劫體系的互動

- **聚雷陣**只是入口與壓縮器，聚得越快，雜質與爆池風險越高。
- **雷身**可以分守節點校準雷性；承身適合守母池，煌命身適合精細分流，本尊補移動斷點。節點反噬會沿雷核回壓，不能炸掉雷身後免費重造。
- **太玄命圖**只在有限距離內提供雷性譜與運轉次序；網越大，神識負擔越重，不能跨域永久在線。
- **鎮界雷／玄衡**穩定地脈和界裂附近節點，玄衡必須在場或留下有時限的鎮界印。
- **歸寂雷**可讓事故支線暫時沉寂，但能量仍須事後排除。
- **燃身雷**能在母池枯竭時把陸沉自身當一次性緊急能源，代價為血肉、雷脈、壽元與全網燒毀風險，只能作最後手段。
- **天譴雷**不得灌入公共網供他人發射；**無始雷**只能短時重排已存在的失序雷流，不能回溯補滿空池。

## 七、部署

勘察地脈與撤退線 → 挖母池和泄雷坑 → 鋪設無能量空渠 → 分段試壓 → 雷身逐節校準 → 鎮界錨定 → 注入雷砂／雷液 → 標示禁區與斷路口。

- 小隊型至少需要半日。
- 城防型需要數日至數月。
- 臨戰只能用三至五根承雷樁組成局部「口袋池」。
- 撤退時先放空、再熔斷、最後破壞定址陣紋，禁止滿池移動。

## 八、故障與敵方破解

- 雷性相剋會使池液變色、返雷傷己，必須切段排空。
- 前線樁毀可能造成倒灌，斷路節須犧牲整條支線。
- 界裂造成空間錯位，返雷可能落向錯誤位置。
- 守點雷身受傷會令錯誤沿共鳴壓回本尊與其他雷身。
- 池底飽和可能把地層永久雷化，形成雷災區，但不因此自動誕生雷種。
- 敵方可混入魂毒、詛咒或異域法則，迫使整池棄置。
- 內奸可調換優先路，故分雷臺須雙印、實體閘與公開流量刻度。
- 敵人也可用低強度兼容雷術餵網測容量，再突然投入異質能量逼爆；或逼守軍離開網域，因工事不能追敵。

## 九、發展階段

1. **太玄試池期（一至三雷）**：一母池、三樁，只守一院或一峰局部，無鎮界錨。
2. **仙古成網期（四至五雷）**：可守遺跡入口和撤退谷地，具分段沉寂與初級空間固定。
3. **書院戰陣期（六至七雷）**：模組化承雷樁和口袋池，沿已部署路線支援小隊。
4. **帝關軍池期（八至九雷）**：城防母池、鎮界錨、泄雷壕完整；能保撤退線，不能吞取不朽法則反殺。
5. **十雷終局**：短時歸序多座殘池的既有餘雷，完成一次全線卸劫或封尾；戰後全網枯竭或報廢。

第九雷後與荒同強、第十雷後完整死戰小勝，來源仍是十雷綜合體系。預鋪雷池網只能標示為場地準備優勢，不能拿來證明裸戰也能壓制荒；荒仍偏正面先扛，劫偏佈局、封場與收尾。

## 十、地區邊界

- **太玄**：古雷脈接續以前，萬年雷池只提供原型和近域根節點；接續後主雷眼碎裂、池水退盡，不再供戰雷池網使用。
- **三千道州／書院**：只沿商路、書院和預鋪雷池樁運作。
- **帝關**：規模最大，也最常遭炸池、污染、奪點與反定位。
- **異域**：沒有預鋪同源節點，整網失效；最多帶一枚一次性預充池，耗盡即廢，不能回充或聯絡帝關。
- **金王公審**：不得用雷池網全域封族、抽取全族修為或供應天譴；只可用帝關公有或孤立節點封存涉案證物區、保護撤離線及承接反攻餘雷，且不能遠抽太玄古雷脈。見 `events/EVENT_JIN_WANG_INDIVIDUAL_TIANQIAN_TRIAL.md`。
- **萬劫沉封域**：退役節點只部署於外環作卸壓與撤離工事，不能深入沉劫井、抽取封存災力或增幅陸沉戰鬥。
