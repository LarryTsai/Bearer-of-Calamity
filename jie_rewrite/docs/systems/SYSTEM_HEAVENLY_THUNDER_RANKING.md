# 天地異雷榜

狀態：現行世界榜單 v1.1；陸沉九雷已定案

用途：本文件是天地異雷榜前 thirty、排名口徑、天然場域、境界威脅與進入難度的唯一來源。榜單先於陸沉存在，不按陸沉取得順序排列，也不保證榜上異雷適合被他取得。陸沉九雷須在本榜完成後另案選取；未完成選取回歸以前，`SYSTEM_TEN_CALAMITY_THUNDERS.md` 仍只控制既有正文能力，不得反過來修改本榜名次。

## 一、榜單是怎麼排的

天地異雷榜比較的是：**完整天地異雷位於原生環境、展開完整天然場域時的客觀威脅**。

排名由六項共同決定：

1. 法則位階。
2. 完整場域規模。
3. 對高境修士的有效性。
4. 結果的不可逆程度。
5. 固有限制及被破解難度。
6. 孕育地、抵達路徑與周邊環境的天然危險度。

### 一之一、位置越特殊，雷通常越強

異雷長年吸收所在地的界壓、天象、法則衝突與生態循環。孕育位置越接近混沌海、紀元裂口、仙凡斷層、兩界夾層、時間錯流或古老葬域，雷種能承載的法則越高，完整雷域也越危險。

因此三者原則上呈正相關：

> **異雷榜位越高 → 原生環境越危險 → 抵達及取源越困難 → 完整場域越強。**

這不是毫無例外的數學等號，但不得出現榜前異雷生在普通山谷、毫無天然屏障，或榜後異雷反而長期佔據仙王都無法踏入之地的倒置。

### 一之二、榜位不等於持有者現在的戰力

必須分開記錄：

| 項目 | 意義 |
| --- | --- |
| 天地榜位 | 完整異雷在原生場域的客觀上限 |
| 現存狀態 | 有主、無主、失落、封鎖、沉睡或仍在原生雷境 |
| 持有者境界 | 修士自身名義境界 |
| 掌握程度 | 目前能使用多少法則、威力與場域 |

天地異雷不分子種、主種、祖種或劫源。取雷成功便取得完整雷本源；未成功便沒有取得，不以碎片或低階版本折衷。持有者當下能發揮多少，取決於境界、肉身承載、神魂、理解、磨合與場域控制，而不是雷本身只剩一部分。

完整本源入體後，原生雷境不會整座被搬進命圖；修士取得的是該雷全部法則與成長可能，卻只能按自身承載開啟其中一部分威力。高榜異雷尤其如此：越級強開完整場域，先被撕碎的通常是持有者。

例如界淵銀雷位於上下界夾層，完整界淵足以磨滅至尊並威脅真仙。早期陸沉若最終入選，必須真的穿過界海雷淵、承受完整取雷考驗並取得完整界淵銀雷；他當時只能使用照見一線生路等極小效果，是因自身境界與承載不足，不是因為拿到較低等的子種。

## 二、境界威脅分帶

本榜採《完美世界》現行境界順序：

> 搬血 → 洞天 → 化靈 → 銘紋 → 列陣 → 尊者 → 神火 → 真一 → 聖祭 → 天神 → 虛道 → 斬我 → 遁一 → 至尊 → 真仙 → 仙王

「威脅」表示完整天然場域能限制、傷害或殺死該境界，不代表必然擊殺。

| 榜位 | 完整異雷主要威脅帶 | 原生環境最低危險尺度 |
| --- | --- | --- |
| 1～3 | 仙王必須正視；可限制或傷及仙王 | 混沌、紀元或根本時序禁區 |
| 4～7 | 真仙絕地；可短暫干擾準仙王級存在 | 仙道法則裂區、兩界核心斷層 |
| 8～12 | 至尊必死風險；完整域可傷真仙 | 大界裂層、九天極域、古老冥界 |
| 13～18 | 斬我、遁一核心威脅；可逼至尊付出代價 | 古戰域、星墳、極陰極陽天象 |
| 19～24 | 天神、虛道核心威脅；部分可越至斬我 | 上界禁地、祖脈、雷暴海眼 |
| 25～30 | 神火、真一核心威脅；完整域可困天神 | 區域型雷域，具明確地形依賴 |

正文固定採用這個句法建立層級：

> 陸沉取得【天地異雷本名】，完整本源歸入命圖後，形成第幾雷位【雷位名】；實際出手再使用招式或場域名。

世人、古籍與天地榜談「玄寂神雷」；陸沉調動命圖第四雷位時稱「歸寂」；真正展開場域才稱「寂界」。三層不得互換，也不得再把照命、空手、剎那等角色能力名冒充天地原生雷名。

九雷的互補順序鎖定為：**照見 → 斷續 → 定魂 → 沉亂 → 穩界 → 歸身 → 取時 → 付命 → 問責**。它們不涵蓋創世、重置或讓九雷共同開新序，因此第十雷無始仍保有不可替代的自身領悟空位。

### 四之一、高榜雷的低境取得規則

完整天然場域的榜定威脅，不表示入口到源心每一寸都持續以同等威力轟擊。每座雷境至少具有外環、內環、源心三層：外環留下可追索異象與生態；內環依該雷法則篩選進入者；源心才承載完整本源與全域閉合時的榜定上限。

低境修士不能靠肉身硬吃完整仙道威力。陸沉取得高榜雷，必須利用環境週期、禁制、神識、守關規則及異雷自身認可走到源心；一旦誤解法則或令全域暴走，完整榜定威脅照常成立，他必死無疑。這是找到與取雷故事的難度，不是把完整異雷降格成低境版本。

界淵銀雷維持榜七，是作者裁示的世界規則：上下界夾層長年承受界壓、殘魂、命火與古路裂縫沖刷，特殊位置足以孕育真仙級完整雷域。它不能因陸沉早期取得而降榜；故事必須證明陸沉只在雷淵短暫開合與禁制路徑中抵達源心，並非正面承受整座界淵閉合。

三刻瞬雷正式列榜三：它支配根本時序交接，足以讓仙王正視，但不能停時、倒流或改寫既成結果，因此不應壓過能直接干涉天地生滅的榜二太初生滅雷。取得故事必須具備錯鐘戰報、銀砂物證與候鐘者道標三段尋雷線索，並讓陸沉先因把「快」誤認成全部答案而承受錯齡傷。

玄寂神雷與玄黃界雷雖在相近的大事件區間出現，必須是不同入口、不同歷史、不同生態、不同首敗及不同退出後果；兩次取得之間須有陸沉明知可以離開卻重新選擇追雷的完整段落，不得寫成同一副本連掉兩雷。

## 五、榜單安全閥

1. 排名影響天然威力及完整場域，不能再寫成與強度無關。
2. 孕育環境、抵達難度、取源難度與完整榜位原則上正相關。
3. 異雷不分子種、主種、祖種與劫源；取得即為完整本源，實際威力由持有者能開啟多少決定。
4. 相鄰榜位須至少在法則優先級、場域寬度、不可逆性或跨境有效性之一形成差距。
5. 前十完整場域必須能改變戰場規則，不能只是更大的落雷。
6. 後十必須保留明確地形依賴、媒介、空窗或克制，否則名次失真。
7. 高榜異雷若被低境修士取得，必須以搜尋、抵達、環境生存、守關、競爭與完整承雷證明資格；成功後得到完整本源，但不能越過自身境界直接展開榜單記載的完整仙道雷域。
8. 榜首不預留給陸沉；第十雷若由陸沉自身創生，列為榜外新雷，不可自動插入第一。
9. 本榜不照陸沉取得順序排列，也不因正文既有九雷而調整其他二十一道的世界位置。
10. 雷名描述天地來源、色彩、生態或天然異象；陸沉命圖能力名與招式名另列，不得反過來取代天地雷名。
