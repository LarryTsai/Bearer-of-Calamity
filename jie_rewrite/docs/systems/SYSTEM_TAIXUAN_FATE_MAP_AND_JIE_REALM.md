# 太玄命圖、太古星天圖與劫藏

狀態：現行唯一來源 v1.2

## 一、四層結構

| 層級 | 定義 |
| --- | --- |
| 雷種 | 十種劫數的承載節點 |
| 太玄命圖 | 陸沉體內排列十雷主星與四伴星外環的結構骨架 |
| 太古星天圖 | 太玄命圖向外展開、將戰場納入規則運行的天地領域 |
| 劫藏 | 命圖成熟後形成的體內內景世界 |

不得將命圖、星天圖與劫藏寫成同一件事。

## 二、太玄命圖

- 十雷位於主星位，四伴星位於外環。
- 負責分流反噬、排列規則、穩定雷身與保存各雷成長痕跡。
- 早期只有殘圖與星位感應（即太玄命藏取得的無星古圖，見 `events/EVENT_MINGZANG_FATE_MAP_ORIGIN.md`）；仙古後才形成可辨識骨架。
- 命圖不是外來神器，而是陸沉以太玄殘法、自身命格與十雷逐步推演出的承劫之圖。

### 二之一、必要性：沒有命圖會發生什麼

劫的十雷不是同源功法演化出的十招，而是十種完整本源——照命修補洞察生命結構、鎮魄鎮魂、歸寂使萬物歸寂、鎮界封路、燃身劫燃燒肉身、天譴劫審判罪業，最後由劫自身生出無始劫。若只是把十枚雷種全部塞進體內，結果不會是十倍強，而是雷種互相排斥、不同法則彼此衝撞、一雷壯大時壓制其他雷、雷力運行路線重疊、肉身經脈長期被撕裂，最終其中一種雷吞掉其他雷，或劫本人先崩毀。

太玄命圖首先不是攻擊神通，而是劫為了容納十雷，替自己創造出來的一套內在秩序。命圖的具體起源——七峰大比後入太玄命藏，取得一張無星古圖，因劫體內彼此衝突的力量而甦醒——唯一來源見 `events/EVENT_MINGZANG_FATE_MAP_ORIGIN.md`；本節只陳述命圖存在的必要性，不重複起源敘事。

### 二之二、核心結構

**劫核居中**：劫核不是第十一枚雷種，它代表劫自己。十雷都可以成長、變化甚至破損，但不能取代本尊——劫核確保劫駕馭十雷而非十雷駕馭劫，十種本源最後都歸於劫道，即使某一雷極端壯大也不能反客為主，第十雷由劫自身生出時有一個真正屬於他的核心。命圖中央不是「最強雷星」，而是劫本人；劫核不發雷，劫核決定所有雷為何而發。

**十雷各有星位**：太玄命圖不是把十雷熔成一團，而是保留每一雷的完整特性——照命雷仍負責照見與修補，鎮魄雷仍負責神魂，歸寂雷仍使暴亂死氣沉寂，鎮界雷仍穩界封路，燃身劫仍可燃身換勢，天譴劫仍主審判殺伐。合而不同，分而不亂：十雷不是互相消失，而是各守其位，命圖給每種雷安排自己的位置、方向與權限，這是它比普通多屬性丹田更高級之處。

**雷身為軌**：這句容易被誤解成命圖讓劫能分身，更準確的意思是——劫本來就能依靠強大神魂與肉身分出雷身（見 `systems/SYSTEM_THUNDER_BODY_SCALING.md`）；太玄命圖負責記錄、排列與調度每具雷身所對應的雷種位置。雷身出去修煉不靠命圖維持意識，但命圖能確保它們回來後第一雷仍歸第一星位、第二雷不會混入第三雷本源、各雷身力量準確回到所屬雷種、多具雷身合體時不因雷種位置錯亂而互相吞噬，三雷合體、九雷合一、十雷歸一時有明確運行路線。命圖因此是十雷分合時的經緯與軌道：劫能不能分，是身魂問題；分回來之後十雷會不會亂，是命圖問題。

### 二之三、核心能力

**十雷制衡**：命圖最根本的能力不是增幅，而是制衡。燃身劫太強可能燒毀本尊，天譴劫太強可能讓劫逐漸只剩殺伐審判，歸寂雷太強可能連自身生機都沉寂，鎮界雷太強可能讓肉身與力量運轉僵死——命圖透過其他星位制衡它們：照命雷照見燃身後的裂損、鎮魄雷守住燃身與天譴時的神魂、歸寂雷沉下失控雷力、鎮界雷穩定整體結構、玄燼凰留下燃身後的一縷命火。命圖不是把每種雷都推到最大，而是讓它們該強時強、該停時停。

**雷種互相滋養**：命圖還能讓不同雷種互相補足——照命雷發現雷種缺損、歸寂雷將雜亂法則沉下、鎮界雷穩住雷種外部結構、天譴雷淬去不純本源，最終由劫核重新定義該雷的方向。劫能藉此把殘種、子種或普通雷種逐漸推升為自己的「劫源」：照見雷種缺陷、吞納同類雷髓、再以命圖重鑄，讓普通或殘缺雷種升格（此為升格機制，不是形成機制——與第六雷空手劫「不依賴雷髓形成」的規則不衝突，見 `characters/CHARACTER_LU_CHEN.md` 十四）。命圖因此也是一座雷種熔爐與升格體系，但不是把雷全煉成一樣，而是修補各自缺陷，將它們提升成真正適合劫的版本。

**傷害與負荷分流**：命圖能把某一雷造成的負荷，沿命圖軌道分散到其他星位、肉身周天與外環——例如燃身劫爆發時，不是只由第八雷星位和一條經脈承受全部壓力，而是劫核承擔主意志、照命星監控裂損、鎮魄星穩定神魂、鎮界星固定肉身與空間、玄燼凰保住命火、其他星位分擔雷力震盪。它不能消除痛苦，也不能讓合體變得無代價，但能避免力量全部集中於一點，讓劫有機會撐過去——這也是「肉身不崩、道心不崩、命圖不崩」三者相連的原因。此機制的源頭是柳青藤的周天星脈啟發：「肉身可以像星圖一樣運轉，力量不只走經脈，也能走軌道」（見 `characters/CHARACTER_LIU_QINGTENG.md` 七）。

### 二之四、四伴星為何進入外環

四伴星不佔十雷星位，因為牠們不是劫的雷種，也不是劫的分身，而是外環守護者：劫厄是暗側主伴星，穩定劫核、感知雷種反噬與雷身回歸異常；鎮魄獅守第三雷外環，鎮魂護神識，尤其能守護雷身回歸時的神魂反噬；鎮界麒麟鎮界、吞災、定魂，將暴亂災象壓回秩序；玄燼凰守第八雷外環，保留餘命、分擔燃身反噬（各自能力細節仍以其角色檔為唯一來源）。四伴星的作用不是提供四種新主能力，而是當十雷內環失衡時，從外部幫助命圖重新穩定——內環是劫自己的道，外環是願意替他守道的同伴。

### 二之五、戰鬥運用

**快速調度十雷**：普通狀態下切換雷種需要壓下原本雷力、改變經脈運行、喚醒另一雷種、重新適應法則；有命圖後各雷星一直處於自己的軌道上，劫能更快從照命轉鎮魄、鎮界接剎那、剎那近身後切空手劫、重傷後啟燃身、最後以天譴斬殺。命圖的重要戰鬥能力，是讓十雷從十套彼此割裂的力量，變成一個可以連續運轉的戰鬥體系。

**多雷組合**：命圖讓不同雷星之間形成「星路」，因此劫不只單獨使用一雷，還能組合：鎮魄＋歸寂讓神魂與意志一同沉寂，鎮界＋剎那封鎖敵人空間再瞬間近身，照命＋天譴先照見生命與大道裂口再降下精準審判，燃身＋空手燃盡身力以最純粹肉身完成最後近戰，歸寂＋鎮界＋天譴先沉災、再定界、最後判劫。命圖的組合不是簡單的「一加一威力加倍」，而是前一雷替後一雷創造必中的條件。

**星位投影**：命圖可在劫體內運行，也能短暫投影在身後、腳下或戰場上空。初期可能只是一道模糊雷環，隨十雷增加逐漸形成中央劫核、雷星亮起、星軌輪轉、雷身虛影、四伴星外環，形成強烈威壓與領域效果——敵人看到的不是單純法相，而像是一座正在展開的雷劫天象。

**戰場級雷劫天象**：太玄命圖最終可由內而外覆蓋一片戰場：十雷星位映照天穹，雷身沿星軌降臨不同位置，四伴星鎮守外環，鎮界雷封鎖戰場，鎮魄雷壓制敵方神魂，歸寂雷沉下暴亂法則，剎那劫讓劫穿行星位，天譴劫由命圖中央降下裁決。到這時，太玄命圖不再只是劫體內的修行結構，而是劫把自己的內在修行體系直接投映成一座戰場——敵人不是在和一名雷修交手，而是在一座由十雷運行的天象之中，和整條劫道交手。

### 二之六、命圖與合體的關係

劫能分身的原因是天生神魂極強、後天肉身極強、能承受分身長期離體、能承受回歸時身魂煎熬（唯一來源見 `systems/SYSTEM_THUNDER_BODY_SCALING.md`）。太玄命圖的作用則是確保不同雷身回歸正確星位、避免十種雷力合體後彼此排斥、安排三雷／九雷／十雷合體的運行軌道、將合體後的力量轉成可控體系，讓合體不只是數值疊加，而是形態與能力升格。

最準確的一句是：沒有命圖，劫仍能分身；但當雷種越來越多，他只能分，不能真正把十雷合成一條完整大道。

### 二之七、必要性總結與核心定稿句

太玄命圖存在的必要性可收斂成四句：它不是劫能分身的原因，而是十雷不互相毀滅的原因；它不是替劫承受合體痛苦，而是讓合體後的十雷仍各歸其位；它不是單純增加雷力，而是讓十雷能制衡、滋養、組合與升格；它最終不是一幅圖，而是劫將自身大道投映天地後形成的雷劫天象。

> 劫核居中，十雷為星，雷身為軌，四伴星繞外環而行。

正式定義：

> 太玄命圖，是劫為承載十種不同雷道而生出的內在秩序。它以劫自身為核，以十雷本源為星，以雷身分合為軌，以四伴星守護外環，使彼此衝突的十雷得以各守其位、互相制衡、相互滋養並最終合為一條完整劫道。命圖修於體內時，是十雷運行之基；顯於天地時，便是一座屬於劫的雷劫天象。

## 三、太古星天圖

- 是命圖向天地投射後的高階領域，不是普通大範圍雷法。
- 能在區域內調整雷、魂、死、界、虛、時、身、罪與源的運行規則。
- 早期只能「觸規」，仙古理解殘破規則，後期才能局部「掌規」。
- 無聲渡笛（原稱焦竹笛／沉雷笛，見 `characters/CHARACTER_LUO_SHENGYI.md` 十）可作星軌節拍，協調十雷主星與四伴星外環。

### 三之一、戰場俗稱「劫禁區」

PW-23D 第九雷完整後，異域軍士開始把陸沉預鋪完成、太古星天圖充分展開的高危戰區俗稱為「劫禁區」。這不是新招式、新境界或固定領地；正式本體仍是太古星天圖。

九雷階段只能局部掌規，必須依靠鎮界錨、雷身、伴星與戰雷池陣網延長維持。PW-26 第十雷形成後，才可短暫完整展開十雷星位，覆蓋一城或一段戰線。

離開預鋪節點、母池乾涸、玄衡離位、本尊重傷或命圖失衡皆會破域。預鋪領域屬場地優勢，不改變九雷同強與十雷同境完整死戰小勝的來源。

### 三之二、不是生命禁區

「劫禁區」不屬原作生命禁區分類，不自立禁區道統、不占原作禁區地理，也不使陸沉取得禁區之主位格。既有禁區主人不因此臣服、認可或退讓。

敵人所謂禁區，只表示傳訊、逃路、替死與轉嫁代價受到限制，不代表踏入即死。敵方仍可遠程轟擊、污染節點、切斷補給、逼雷身回歸或以正面爆發破壞星位。

### 三之三、外部工事

- 戰雷池陣網提供有限供能、卸壓與雷身穩形，但不是領域本身。
- 雷訊網負責指揮資訊；斷訊不等於領域自動消失，也不能藉雷訊輸送十雷殺招。
- 無聲渡只作星軌調律，不是領域核心、跨界門或無限續航來源。
- 戰後固定的 `萬劫沉封域` 是公共災害封存設施，不跟隨陸沉移動、不增幅戰力，與太古星天圖不是同一系統。

## 四、劫藏

> 太玄命圖是圖，劫藏是圖化成的內景世界。

- 四伴星真身可在外界行動，本源、命印與伴星位落在劫藏。
- 劫藏不是儲物空間，也不收納普通活物。
- 陸沉可用神識化成「靈身」進入劫藏，與伴星交流、修補星位、整理災氣與雷種反噬。
- 靈身不是普通元神出竅；本體仍需承受外界風險，不能以劫藏逃避死亡。

## 五、以劫為種

陸沉的成熟道路定名：

> 以身承劫，以劫為種，以命圖養種。

荒以自身開路，陸沉則將每次真正承受並理解的劫煉成劫種，安放於命圖。兩條道路平行但不重複。
