# 陸沉陣法修習與破陣邊界

狀態：現行唯一來源 v1.0（2026-08-02）

## 一、正式定位

> 陸沉學陣、精於少數陣法，卻不爭陣道；太玄宗給了他陣法的骨架，他以神識、禁制與雷，讓這副骨架長成自己的模樣。

- 陣法不是陸沉的主要大道，也不另設陣道宿敵、陣塔奪魁或陣鬥競賽線。
- 他在太玄宗受過正式、持續的基礎陣法教育，不是只憑天賦臨場猜陣。
- 陣法是工程骨架與生存工具；禁制是他真正開創道路的副道；煉體與雷道仍是正面戰力根基，神識支撐觀察、記憶、精度與推演。
- 他不是全科陣師，也不擅長從無到有設計最完整的護宗、山河或星域大陣；但後期任何陣法威脅都不能把他寫成完全看不懂、只能等待陣師救援。

## 二、太玄宗正式學習內容

陸沉入太玄宗後須以課業、失敗、維修與實作逐步學會：

- 陣基、陣眼與真假節點；
- 靈力循環、能量分流與倒灌；
- 地勢借力、陣法維持與局部修復；
- 多重節點串聯；
- 傳送陣、落點校準與空間座標；
- 引雷、聚雷、雷力卸壓及雷池串聯；
- 雷訊、戰雷池網與跨界節點所需的有限工程知識。

太玄宗教他如何建立一座完整的陣；他的求生經驗則逼他追問：陣眼被毀、靈石不足、路徑倒灌、陣基暴露或敵人開始拆陣以後，剩下的結構還能如何保命、誤導與反殺。

## 三、專精與非專精

| 領域 | 陸沉的程度與上限 |
| --- | --- |
| 基礎陣理、辨陣、修陣 | 扎實；能由運轉現象反推陌生陣法的大致用途 |
| 引雷、聚雷、雷力分流 | 核心專精；長期親手建造與維護 |
| 傳送陣、空間道標 | 隨鎮界與剎那逐步變強，仍需座標、材料與穩定條件 |
| 雷池網、雷訊與戰場節點 | 開創性工程專精；依賴團隊、預鋪、供能與維護，不是單人隨手完成 |
| 禁制與陣法結合 | 個人特色；以陣承載，以禁規定觸發、權限與禁止事項 |
| 護宗、山河、星域大陣 | 能理解、協助、破局，不是最強設計者或長期維護者 |
| 幻陣、聚靈、煉丹陣等常規門類 | 只掌握辨識與自身需求所需部分 |
| 純陣道推演、陣圖競賽 | 不參與；不得另開陣塔、陣鬥奪冠或陣道宿敵線 |

## 四、為何後期能處理任何陣法威脅

「任何陣法都能處理」意指他一定能看、判斷並採取有效行動，不保證當下完整摧毀。

1. **親手布陣**：傳送陣、聚雷陣與雷池網使他理解力量如何進入、分流、放大、倒灌與修復。
2. **神識察線**：觀察靈力流向、空間波動、陣紋明滅、殺機次序與感知干擾。
3. **照命見脈**：照見陣法實際運轉的命線、交會節點、裂口與將斷之處。照命是第一雷初始正式名；進階後稱煌命，仍是同一雷種，不得倒退成兩雷。
4. **雷沿路傳導**：把細微雷力送入既有陣路，以回響描出真實骨架；幻象與假陣紋可以欺騙感官，卻仍須面對真實能量傳輸。
5. **禁制封變**：封住局部修復、權限轉換、觸發或分流，替破口爭取時間。
6. **力量完成破局**：修為足夠時由內擊穿；修為不足時只開一線、偏移一次殺機、改一處落點或爭取撤離時間。

照命的「可破任何陣」是**使任何仍在運轉的陣都有可見、可追索的生滅線**；真正破壞仍由雷力、禁制、肉身、材料與當下修為共同完成。不得把照命寫成無條件消陣神光。

## 五、處理層級

| 陣法威脅 | 合理處理結果 |
| --- | --- |
| 同境普通陣法 | 能辨識並自行破解 |
| 同境頂級陣法 | 能破解、繞過或局部反制；對方仍可變陣與設假路 |
| 高一境界大陣 | 難以正面拆除，但能護住眼前人、偏移殺機或開短暫生路 |
| 遠古完整大陣 | 只能理解部分規律、局部封禁或依允許規則短暫通行 |
| 仙王級殺陣 | 不能靠知識彌補力量鴻溝；只能更早察覺、少走一步死路並爭取逃生機會 |
| 殘缺、失控的大陣 | 最擅長類型；可利用破損、倒灌與失去控制的節點重排局部循環 |
| 雷、空間、封禁相關陣法 | 可在既定專精與境界允許下越級處理，不等於必勝 |

後期可以困住陸沉，但不能讓他失去行動：即使破不了整陣，也須至少完成辨陣、護人、局部斷路、偽造權限、延遲觸發、改變落點、記錄規律或留下第二次反制之一。

### 五之一、完整禁制的判定

完整禁制是有限規則的閉合結構，至少須能辨明禁制對象、作用邊界、觸發、供能、執行、反噬歸屬、解除條件及解除後回收。「完整」不等於公平、善良、無限範圍或無視境界；血脈豁免與管理權限可以存在，但也必須屬於明示規則並承擔相應代價。面對此類禁制，陸沉不能把照命看見生滅線等同找到漏洞，更不能因讀懂條款便反向接管；合理破局是依自洽規則取得短暫通行、迫使執行者支付既定代價，或完成禁制原有的合法解除條件。

## 六、被大陣保護的至寶

陸沉必須先分辨四層，不把所有問題混稱「禁制」：

| 層次 | 功能 | 能否處理 |
| --- | --- | --- |
| 外圍大陣 | 聚力、困殺與隔絕 | 能辨路、局部破局，未必能完整拆除 |
| 陣中禁制 | 身分、權限、封空與觸發 | 最擅長欺騙、暫停或改寫 |
| 至寶封印 | 保護或鎮壓寶物 | 可研究解封，但必須先判斷封印目的 |
| 認主禁紋 | 限制持有與催動 | 可解除部分人為限制；頂級器靈仍有自主選擇 |

最重要的判斷不是如何開鎖，而是這把鎖究竟防外人進入，還是防裡面的災物出來。破陣越快可能讓災難越早發生；因此解開不是必然正確，放棄至寶、重新封回或先救人也可成為勝利結果。

## 六之一、驗證類禁制的欺騙邊界（總原則，回應 `CHECKLIST_PENDING_DECISIONS.md` 第192題王族偽裝機制，2026-09-22定案）

陸沉可以欺騙的，是禁制裡負責「身分／權限判讀」的陣中禁制節點，不是完整禁制本身，也不是禁制之外的其他功能層。

**正式分類寫法**：192所利用的是異域驗證體系中負責「身分／權限判讀」的陣中禁制節點。物件本身的分類不因包含驗證節點而改變；祭器、血壇、至寶、認主或因果機制中的非驗證功能，仍依既有四層表獨立判定。

**為何不落入五之一「完整禁制」的陷阱**：陸沉沒有「讀懂完整禁制→找到漏洞→反向接管整套系統」；而是「煌命讀出驗證流程→找到其中屬於『身分／權限判讀』的陣中禁制節點→用既有禁制專精（欺騙／暫停／改寫）動那個節點的判讀輸出」。他改的是局部判讀輸出，不是取得整個完整禁制的控制權，五之一原文不用修改，這套機制與既有安全閥並不衝突。

**適用此欺騙邊界的通用三條件**（不只適用於192題，陸沉往後遇到其他上古禁制、身份門、血脈門都要核對，缺一不成立）：
1. 煌命能讀懂的判讀機制；
2. 可被禁制干涉的驗證節點；
3. 足夠的施工／準備時間。

**根本安全閥（較上面三條件更根本，使用者定調）**：「可欺騙」不等於「可控制」；「騙過一次判讀」不等於「取得該禁制的權限」。

**192題實例：四個驗證對象的分層判定**（供未來章節設計參照，異域城門／祭器／王族血壇／帝族因果驗證）：
- **城門**：讀取血脈後產生判讀結果——屬於此欺騙邊界的作用對象。
- **祭器**：本身不能被接管，維持既有四層表「至寶封印」層判定，不在此欺騙邊界範圍內。
- **王族血壇**：可能不只是「讀」，會實際與血脈產生作用——不能預設欺騙一定有效，必須另設機制，本節不涵蓋，留給未來章節設計時另行處理。
- **帝族因果驗證**：若驗的是「與帝族是否真有因果關係」這種真實性判定（而非可竄改的判讀輸出），是此欺騙邊界的**天花板**——陸沉騙的是判斷，不是事實本身，此類驗證原則上不可被此機制突破，避免讀者誤以為「駭一次以後所有門禁都沒用」。

## 七、固定破陣流程與失敗模式

常用流程：神識與陣理初判 → 細雷探路 → 照命確認真實命線 → 禁制封住變化／修復 → 雷或肉身擊穿局部 → 依力量決定整陣崩解或只開一線。

每場不得機械照表成功，至少保留一項失敗來源：

- 假循環故意餵給雷絲錯誤回響；
- 陣主臨場換陣、斷路或以污染反追雷源；
- 照命看見節點，肉身或修為卻來不及抵達；
- 核心不在陣內，而由外部持續重建；
- 所見破口其實是誘使闖入者解除鎮壓的陷阱；
- 為護人不能選擇最有效率的破法；
- 破局本身引起空間崩塌、倒灌或不可逆反噬。
