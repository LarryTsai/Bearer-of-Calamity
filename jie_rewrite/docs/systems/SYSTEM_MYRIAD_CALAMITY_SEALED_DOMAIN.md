# 萬劫沉封域

> 狀態：正式系統 v1.0
> 時間：PW-26 終戰後／後記接口正式建立

本文件是戰後固定災劫封存設施的唯一來源。萬劫沉封域不是原作分類中的生命禁區，不是陸沉的私人宗國、戰鬥領域或修煉洞天；它由固定土地承載，以多人制度長期隔離尚不能消解的災害。

民間可稱「萬劫禁區」或「承劫域」，但不存在正式的「禁區之主」位格。

## 一、核心定位

終戰留下的污雷、破碎法則、異域殘力、裂界餘壓與失序災象，不能全留在陸沉體內，也不能倒回人間或全部轉成他的修為。沉封域只負責：

1. 暫時封存無法即時處理的無生命災力。
2. 隔離會互相激化的異質法則。
3. 記錄來源、受害者、封存人及處置責任。
4. 為淨化、歸還天地、安全消散或繼續沉封爭取時間。

> 禁區不是因為裡面藏著他的力量，而是因為那裡存著他還沒能替眾生處理完的劫。

它不能捕捉天下災劫自我增殖，也不能把封存物煉成第十一雷、新伴星或公共武器。

## 二、形成前提

帝關戰爭期間只有臨時封存營、傷患隔離帶與戰雷卸壓工事，它們提供制度原型，不構成永久禁區。真正的萬劫沉封域須待 PW-26 終戰後清點殘留，在一片無原住民、已失去穩定循環的破碎邊域重新勘地築成。

已枯竭的太玄萬年雷池不復原、不搬遷，也不作沉封域能源。其經驗只留下「有限容量、必須泄壓、不可把人當陣材」等教訓。

## 三、區域結構

### 灰雷原

外環緩衝與作業區，設合印臺、異質檢測陣、戰雷卸壓渠、雷訊警報臺、維護營及撤離斷路節。飽和雷砂必須封裝更換，不得出售煉器。

灰雷原之外另設**生活安全帶**，與高能陣芯物理分離，可容納輪值者、短期避難者及後來形成的普通聚落。生活區不提供修煉增益。

### 斷律谷

中環分流與隔倉區，以鎮界石壁、歸寂雷溝和無屬性空倉分開災力。聲音、重力、方向與時間感偶爾錯拍，只是法則殘響，不構成時間修煉地。

| 倉級 | 內容 | 權限 |
| --- | --- | --- |
| 灰倉 | 可自然消散的普通戰雷與陣壓 | 兩名輪值者 |
| 玄倉 | 可傷肉身、經脈或普通神魂的異質災力 | 太玄陣師＋生道維護者 |
| 赤倉 | 污染、奪舍、法則侵蝕或跨界災力 | 三方共印 |
| 無聲倉 | 性質未知或因觀測活化的災象 | 公共決議後才可處置 |

### 沉劫井

核心封印井，容納短期沒有淨化方法的高危災力。它不是雷池、雷眼、劫藏入口或傳承地；井中不設王座、宮殿與祖殿，只保留維護陣臺及不可單方刪除的來源紀錄。

每層必須標記受害者、封存日期、承擔者、預估期限和下次評估日。封存只是延緩，不能把責任永久推給後世。

## 四、封存規則

- 只封已有之災，不為研究、修煉或軍備主動製災。
- 活人、完整神魂、俘虜、罪犯、戰獸與具完整自我者不得入倉。
- 發現生命節律立即停下銷毀程序，轉入救治、超渡或司法流程。
- 異質災力分倉，未知者先隔離，不因可能有價值而提前開啟。
- 每份封存物須留下來源、取樣、見證與預計處置方案。
- 封存物不得被陸沉、太玄宗、軍方或維護者私下煉器、煉丹及提升修為。
- 可歸還的族器、地脈與公共資源，危險解除後須歸還合法持有人或公共管理者。
- 涉及審判與戰爭責任的物證，在封存前須製作可核驗副本。
- 所有封倉定期再審；能修復的土地與能安全消散的災力不能為維持禁區規模而扣留。
- 仍有生靈可救時，不得為求穩定直接沉封整片區域。

## 五、容量與滿載

容量取決於空倉、鎮界石壁、歸寂雷溝、外環卸壓能力及維護人數，不隨陸沉境界等比例擴張。高危小樣本也可能獨占一座赤倉。

接近滿載時依序：停止接收可原地處理的新災、提前淨化灰倉、斷開高危區、犧牲受污染設施並公開容量不足。陸沉不得暗中以肉身或命圖充當缺失倉位。

## 六、三方共管

- **太玄維護者**：陣法、鎮界石、封倉結構與輪值。
- **生道維護者**：確認是否仍有生機、神魂或可救生命。
- **公共見證席**：由受災者、守關者與相關地方代表監督來源、資源歸還和最終處置。

陸沉是首任守域人與最高危機處理者，不是所有者。灰倉雙人共開、玄倉兩方合印、赤倉三方共印；無聲倉不得單人開啟。緊急狀態只能先封閉、斷路和撤離，不能趁機取走封存物。

## 七、維護與失聯模式

日常須檢查石壁位移、歸寂假性平靜、飽和雷砂、生機誤封與節點污染，並定期進行「沒有陸沉」的降級演練。

陸沉失聯、重傷或死亡時，系統進入**沉默維護**：停止收新災、關閉中高危通道、切斷各倉聯繫，只維持最低隔離，為其他人接手爭取時間。雷身、蒼梧與伴星不得被鑄成永久活體界樁。

## 八、與兩網的邊界

雷訊網只傳倉號、污染級別、撤離令和維護警報；赤倉、無聲倉可使訊息失真或完全中斷，斷訊不能作為遠端開倉依據。

戰雷池陣網只部署於外環，承接普通外溢雷壓、分流爆衝並保護撤離道。母池不能深入沉劫井，不能抽取封存物作戰；異域污雷、魂煞或天譴餘痕倒灌時，整段支線須棄置。

## 九、與十雷及命圖的邊界

- 照命只判讀生機與失控點，不能單獨決定銷毀。
- 劫命可斷遠端祭線，不能抹除既成傷害。
- 鎮魄可壓殘魂污染；確認完整神魂後必須移出封倉。
- 歸寂只能暫停暴動，沉寂壓力仍須處理。
- 鎮界只能穩定封倉，不能永久修好世界。
- 剎那只能有限搶修，不能令全域停時。
- 燃身只能在撤離道崩潰時作最後承壓，不是日常能源。
- 天譴不得成自動守衛，亦不得把入侵者自動列罪。
- 無始只能重排已納入、已確認的失序流，不能回溯事故、復活死者或補滿容量。
- 雷身可輪值搶修，但本尊與雷身視為同一責任主體，不能規避休整與共鳴反噬。
- 太玄命圖只在陸沉實際巡檢時提供排序與局部調律，不是永久智慧中樞。

## 十、主要故障

- 混倉反應：斷路、棄倉、撤離，不由劫一次吸收。
- 沉寂假象：表面無聲，內壓持續累積。
- 鎮界漂移：出口、撤離陣及雷訊座標錯位。
- 生機誤封：生道維護者有權立即停止程序。
- 污雷倒灌：受污染母池與支線整段報廢。
- 雷訊失真：重要命令須本地刻度、實體令和人證互驗。
- 人為盜取：有人企圖竊取天譴餘痕、異域法則或污雷煉兵。
- 容量欺瞞：任何一方不得用陸沉私下承災掩蓋滿載。

## 十一、戰後演化

沉封域正式建立後，能淨化的外圍逐步轉為「九界傷痕保全區」：保留無歸碑林、法則傷痕及高危封倉，修復完成的土地交還生者。禁區範圍原則上應縮小，而不是隨陸沉變強不斷擴張。

它最終的成功不是存在萬古，而是有一天不再需要。陸沉留下的是眾人能共同辨認、承擔和處理災劫的制度，不是永遠只服從他的神國。

## 十二、安全閥

- 非原作生命禁區，陸沉不取得禁區之主位格。
- 不孕育第十一雷、新雷種或伴星。
- 不吸天下災劫增殖，不提供無限能源、突破、時間加速、免費療傷或復活。
- 不以活人、完整神魂、罪犯、俘虜或伴星作材料。
- 不跟隨陸沉移動、不投影命圖、不增幅其戰鬥。
- 不跨界連接異域，亦不進入 PW-27／28 搶占荒的後續核心功業。
- 可降級維護但並非永不崩壞，最終方向是縮小與拆除。
