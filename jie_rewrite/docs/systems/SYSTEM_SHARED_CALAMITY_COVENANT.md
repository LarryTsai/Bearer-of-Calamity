# 共同承劫契約

狀態：現行唯一來源 v1.1（Volume11 ch052～056原型已落地）

## 一、目的

共同承劫不是把劫族血祭換成更好聽的名字，而是讓承擔災劫的人始終保有知情、拒絕與退出的權利。它只適用於陸沉終局建立的劫序與自願承劫者，不改寫《完美世界》原作修煉體系、仙域秩序或荒的歷史功業。

## 二、四條底線

1. **本人同意**：只有當事人能交出承劫命印；宗族、師門、軍令與親屬不得代簽，未成年者不得成為正式承劫者。
2. **知情與撤回**：承劫前必須看見可預估代價；進入不可逆階段前可撤回，不因退出被定為怯戰、罪人或不祥。
3. **上限與輪替**：任何人都不能成為永久祭品。個人到達承載上限後，劫序拒絕繼續壓入災劫，缺口改由輪替、資源調度與多人分攤處理。
4. **公開留痕**：每次由誰提出、誰同意、誰受益及誰實際承擔，均在公共命圖留下不可抹除紀錄；掌權者不能只留下英雄名號而刪除決策責任。

## 三、撤回與緊急狀態

即使退出可能使一城陷入危險，個人撤回權仍存在。制度不能偷偷退回「找一個最好欺負的人去死」，而必須公開呈現缺口，啟動輪替與分攤。共同承劫不保證零代價，只禁止把代價永久藏在無權拒絕的人身上。

## 四、第一次公開示範

Volume11 ch052～053 中，七席以不同角色加入：洛生衣持醫療停權、抄錄員留痕、守衡譯式、禾回報劫化自我、柳青藤調度、玄衡從命圖外提供界壓基準；開營孩子只核對退出欄，不承雷、不成正式承劫者。所有席位均有時限、上限與外部強制斷開條件。

第一輪真正退出者為禾：她無法分清體內聲音後立即斷連，造成三名劫化者再聚合及一段自我永久消失，仍沒有人要求她回來。孩子完成兩輪核對後亦按上限離席。這兩次退出證明權利在高成本時仍然有效。

> 新道路成立的證明，不是有人願意成為英雄，而是有人可以不做英雄。
