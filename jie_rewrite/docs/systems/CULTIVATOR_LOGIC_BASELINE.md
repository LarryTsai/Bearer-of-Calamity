### 6.1 與《仙人視角守則》（`docs/XIANXIA_PERSPECTIVE_CHARTER.md`）六類合法理由的對照

守則第三節：合法理由有六類（境界不夠、傷勢／力竭、資源不足、時間不夠、場域限制、角色刻意選擇）；「有禁制／有陣法／天道規則」單獨不算理由；刻意的人體尺度是作者設計，不是缺陷。本節理由類別對照如下：

   - 若是「留白」→ **不得判正文有錯**，登記缺口（BL-xx）；
   - 若本書已有專屬理由（第六節）且場景中有具名機制 → 通過；
   - 若只寫「有禁制／有陣法」→ 依審查草案規則，不算理由。
2. **問「幾萬年為何沒解決」時**，先查3.x既有回答；沒有的，標「待作者」，不得自行推論歷史。
3. **不得替本書補設定**：包括飛行規則、儲物器、神識半徑、搜魂、護城陣、命牌、奪舍、輪迴。
4. **注意「用字」陷阱**：「瞬身」禁用；「雷汛／雷訊」；「司天鑑」是人；「命牌」不存在；「慢半拍」專屬洛生衣；「古界」有三個不同事件。
5. **範例（Pass）**：volume06 ch037、volume06b ch041、volume07 ch025、volume07 ch021；**範例（濫用風險）**：#1 異域法則排外、#5 雙簽/停手權/責任簿。
6. 本檔為 v0.1；BL-01~BL-37 缺口經作者裁定後應回填本檔或設定檔。
