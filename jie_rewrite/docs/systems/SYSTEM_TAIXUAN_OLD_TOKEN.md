# 太玄舊令唯一設定表

狀態：現行唯一來源 v1.0（回應 CHECKLIST_PENDING_DECISIONS 第 39 題，Claude／Codex 共識版）

本文件是太玄舊令（半枚陸沉持有、半枚洛清禾持有／太玄閣老人保管相關）完整令牌、命印功能、辨認依據與後期用途的唯一設定入口。其他角色檔、圖片文字或舊版名稱若與本文件衝突，以本文件為準。

## 一、基本性質

太玄舊令只證明下界太玄閣的傳承來歷，提供查驗與入宗考核資格，不直接授予弟子身分（見 `factions/FACTION_TAIXUAN_SECT.md`）。舊令只叩門，不給特權——這條限制在合令、命印共鳴等後續功能上同樣適用，不因情感重量而放寬。

## 二、兩半令牌與命印共鳴

陸沉持有的半枚太玄舊令，與洛清禾持有的另一半原是同一塊，彼此命印仍能共鳴。命印共鳴只能證明「兩半同源」以及洛清禾曾親手持有過這半令牌，**不能**：

- 即時顯示洛清禾目前的位置、傷勢或生死狀態；
- 直接打開她所困的斷裂道域。

尋母分成兩階段：陸沉持有的單半令只能讀出模糊路標，引導他抵達斷裂道域外圍；到達外圍後，兩半令牌隔界共鳴並短暫合令，才恢復精確入口。陸沉仍須自行修復通道並承擔風險——太玄舊令不是救出母親的萬能鑰匙。

## 三、合令畫面（正式）

兩半令牌拼合的瞬間，不是機械鎖扣的咔嗒聲，而是陸沉第一次「感覺到」一個從未謀面的母親曾經活著的溫度，殘留在另一半令牌上。

> 半枚令牌認得出另一半，是因為它們原本就是同一塊；陸沉認得出母親，卻只能靠這點殘留的溫度。

## 四、太玄閣老人的辨認依據

太玄閣老人辨認陸沉手中半枚舊令時，依據的是令制、太玄傳承印與令牌本身的保存方式，**不是**僅憑洛清禾的私人命印便直接替宗門授予身分。這條限制同時保留了「舊令只叩門」的制度性原則，以及母親信物的情感功能，兩者不互相取消。
