# 《萬體鑄身經》設定

狀態：現行唯一來源 v1.0

## 一、總綱

> 萬法先鍛身，百脈始成基。先鍛其身，後承其道。

《萬體鑄身經》無固定屬性，不直接提供殺伐神通。它整理骨、筋、血、脈，使凡軀成為可承載自身大道的器。

## 二、全宗公開前四篇

太玄宗各峰弟子皆可修習，但通常只修到足以承載本峰大道。

| 篇章 | 功能 |
| --- | --- |
| 鍛骨 | 令骨骼承壓，不因靈力反噬崩裂 |
| 煉筋 | 令筋膜傳力，不因爆發斷裂 |
| 熱血 | 令氣血持續運轉，不因長戰枯竭 |
| 通脈 | 令百脈承法，不因大道入體崩壞 |

## 三、鎮岳真傳後四篇

只有鎮岳峰保存完整道路。

| 篇章 | 功能 |
| --- | --- |
| 改脈 | 依缺陷與道路重整經脈、血脈與力量通路 |
| 納材 | 將天地材料、特殊力量或災痕煉入肉身，但不得無限制堆疊 |
| 鑄體 | 從自身最易崩潰之處反向鑄成獨有特殊體 |
| 承道 | 令肉身不只承載大道，而能成為大道的一部分 |

鎮岳峰六人的六極體不是完美先天體，而是由缺陷、傷痕、血脈反噬與人生死關反向鑄成。

## 四、下界殘篇與上界完整版

- 下界太玄閣保存鍛骨、煉筋與部分熱血法；通脈只有殘缺口訣。
- 太玄閣老人用殘篇替陸沉建立最初承載，不足以完成特殊鑄體。
- 上界太玄宗保存公開前四篇。
- 陸沉被岳沉淵收入鎮岳峰後，才接觸後四篇真傳。

## 五、陸沉的用途

- 骨承雷壓。
- 筋傳雷力。
- 血維持多雷種共同運轉。
- 脈承受雷種互相衝突。
- 改脈與納材建立十雷主星的肉身落點。
- 鑄體與承道使太玄命圖、雷身、分身及劫藏不脫離本體根基。

《萬體鑄身經》不是前期過渡功法，而是十雷體系直到終局仍存在的底層架構。

> 雷若無身承，便只是天威；身若能承雷，方成劫道。

## 六、限制

- 疼痛本身不等於修行成果。
- 納材若與自身道路不合，會形成永久排斥與肉身畸變。
- 鑄體不能照抄他人的特殊體；陸沉只取六極啟發，不繼承六體。
- 不得用雷法麻痺痛覺繞過身體回饋。
