# 《萬體鑄身經》設定

狀態：現行唯一來源 v1.1

## 一、總綱

> 萬法先鍛身，百脈始成基。先鍛其身，後承其道。

《萬體鑄身經》無固定屬性，不直接提供殺伐神通。它整理骨、筋、血、脈，使凡軀成為可承載自身大道的器。

### 一之一、陸沉為何鍛體

陸沉不是因為喜歡正面搏殺才走上體修，也不是得到功法後才忽然發現肉身重要。他幼年每一次判錯都可能真死，神識看得見、思考跟得上，身體卻常常來不及執行；因此他最早的求生方式是先看、再算、提前留下退路。《萬體鑄身經》把這份恐懼變成一條可修的路：**他不要再有任何東西，能只因他的身體太弱而殺死他。**

這個動機必須貫穿太玄宗正文。別人鍛體是為了更強，陸沉首先是為了不再讓肉身成為所有計畫中最先崩斷的一環。恐懼不會在一次訓練後消失；它先變成近乎殘酷的自律，再逐步被同門與洛生衣逼著轉化為「能承擔，但不能把自己當作免費代價」。

### 一之二、肉身是最後一道禁

《萬體鑄身經》與禁制不是兩條互不相干的副線。禁制教陸沉預先安排敵人會走到哪裡；鍛體則使他在所有外物被拆掉時，仍能把骨、筋、血、脈當作禁紋節點。雷可沿四路傳遞，接觸可反查對手的發力結構，傷勢也會成為必須被控制而非假裝不存在的代價。

後期的正面強大必須回收早期的身體落差：敵人封神識、封外雷、拆禁具、鎖命圖、斷同伴聯繫後，以為只剩一個失去布置的禁制師；真正留下的卻是他用數百章煉成的最後一件兵器——他自己。這不是突然增加「肉身底牌」，而是《萬體鑄身經》從求生、承雷、承傷一路累積到可獨立破局的必然結果。

## 二、全宗公開前四篇

太玄宗各峰弟子皆可修習，但通常只修到足以承載本峰大道。

| 篇章 | 功能 |
| --- | --- |
| 鍛骨 | 令骨骼承壓，不因靈力反噬崩裂 |
| 煉筋 | 令筋膜傳力，不因爆發斷裂 |
| 熱血 | 令氣血持續運轉，不因長戰枯竭 |
| 通脈 | 令百脈承法，不因大道入體崩壞 |

## 三、鎮岳真傳後四篇

只有鎮岳峰保存完整道路。

| 篇章 | 功能 |
| --- | --- |
| 改脈 | 依缺陷與道路重整經脈、血脈與力量通路 |
| 納材 | 將天地材料、特殊力量或災痕煉入肉身，但不得無限制堆疊 |
| 鑄體 | 從自身最易崩潰之處反向鑄成獨有特殊體 |
| 承道 | 令肉身不只承載大道，而能成為大道的一部分 |

鎮岳峰六人的六極體不是完美先天體，而是由缺陷、傷痕、血脈反噬與人生死關反向鑄成。

## 四、下界殘篇與上界完整版

- 下界太玄閣保存鍛骨、煉筋與部分熱血法；通脈只有殘缺口訣。
- 太玄閣老人用殘篇替陸沉建立最初承載，不足以完成特殊鑄體。
- 上界太玄宗保存公開前四篇。
- 陸沉被岳沉淵收入鎮岳峰後，才接觸後四篇真傳。

## 五、陸沉的用途

- 骨承雷壓。
- 筋傳雷力。
- 血維持多雷種共同運轉。
- 脈承受雷種互相衝突。
- 改脈與納材建立十雷主星的肉身落點。
- 鑄體與承道使太玄命圖、雷身、分身及劫藏不脫離本體根基。

《萬體鑄身經》不是前期過渡功法，而是十雷體系直到終局仍存在的底層架構。

> 雷若無身承，便只是天威；身若能承雷，方成劫道。

## 六、限制

- 疼痛本身不等於修行成果。
- 納材若與自身道路不合，會形成永久排斥與肉身畸變。
- 鑄體不能照抄他人的特殊體；陸沉只取六極啟發，不繼承六體。
- 不得用雷法麻痺痛覺繞過身體回饋。
