## 二、新增且必須進入唯一來源的角色與文明

### 文奕

文奕不是一次性解說者，而是貫穿第一、第三、上界、仙古與帝關的長線核心配角。他與陸沉在虛神界共同取得同樣完整的《古神禁典》。文奕讓陸沉由臨場破解走向系統建構，陸沉讓文奕由完美繼承走向創造新範式。其唯一人物來源為 `characters/CHARACTER_WEN_YI.md`。

### 文家與禁都文明

- 文家是上界古老禁制世家，有自己的仙王祖典、教育與祖禁體系；尋找《古神禁典》不是因為文家沒有傳承。
- 禁都是多個仙王世家、古宗與禁門共同構成的古老禁道聖城，不屬於文家，也不是陸沉、文奕創立的新職業聚落。
- 萬禁會是最高禁道盛會。文奕可正式奪魁；陸沉的核心戲劇不是冠軍，而是以「奪禁」打破規則世家的封閉答案。
- 第一盛世留下《天禁經》《萬紋古書》《封界道典》；第二盛世由諸王開道，《古神禁典》的仙王提出但未完成活禁；陸沉與文奕共同推進第三盛世。

### 鳳族與界路

鳳族是長居九天殘缺道則與異域完整道則交界層的守界古族。燼長明是其中的獨立個體；她燃盡救陸沉、重生後自主選擇同行。餘命燼雷是界路天地孕育的外部異雷，不是鳳族或燼長明贈與。

### 異域情報網與帝族收網

異域篇需要王族身分、情報層級、帝族反偵察與最後收網，但裁示刻意未定死偽裝王族、帝族數量、族名與能力。這些應在第八卷逐幕設計時建立事件／勢力唯一來源，不可搶先硬定。

## 四、三線必須形成同一條因果鏈

1. 禁道線建立陸沉讀規則、改結構、留下可維護系統的能力；文奕是不可替代的對照者。
2. 界路篇讓此能力面對兩界道則結構戰，也讓燼長明先成為同伴，再讓第八雷完成認可。
3. 第八雷讓陸沉學會燃身仍求生並預先承受完整道則，是異域偽裝與五人大劫的前置。
4. 異域古禁使玄衡受本源傷；完整大道再摧毀五人的舊根基，形成五個獨立生命彼此承劫的五星循環。
5. 帝關與終戰把個人技巧變成可交付、可共同維護的禁陣文明，完成第三次禁道盛世回報。

## 五、不可直接沿用的舊案

- 「守池讓路 → 先取第八雷 → 燼長明其後加入」與新裁示衝突，不能只改地名。
- 「公開陪荒越界 → 側線清路 → 很快返關」不足以承接王族潛伏與完整大道蛻變。
- 「萬禁碑林取得同源鑰記」不能替代共同取得完整《古神禁典》，也不能替代禁都、萬禁會與文家篇。
- 不得把玄衡改成泛稱麒麟、把燼長明拆成玄燼凰與鳳兩人，或擅改燼長明性別。
