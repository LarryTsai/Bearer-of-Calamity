## 第一組：宿敵與第九雷

### 1. 天罰一脈傳人的本名

**狀態：✅ 已回填** — `characters/CHARACTER_RIVAL_TIANFA.md`

**Codex 推薦答案：司天衡。**「司天」代表代天巡察，「衡」代表衡量天下災禍，稱號推薦「天律」。

**Claude 意見：不同意「司天衡」，已改用「司天鑑」。** 玄衡是既有四伴星，跟宿敵只差一字，容易讓讀者搞混。已與作者確認改名，「鑑」取鑑察、明鏡照罪之意。

**最終決定：** 司天鑑（取代司天衡）。

### 2. 司天鑑第一次正式登場的位置

**狀態：✅ 已回填** — `events/EVENT_TIANSHEN_ACADEMY_HUANG_VS_JIE.md`、`characters/CHARACTER_RIVAL_TIANFA.md`

**Codex 推薦答案：天神書院大比，觀看荒與劫決戰。**

**Claude 意見：同意，且已依此寫入正式設定。** 與三階段登場節奏（仙古埋痕跡→天神書院登場→十凶血路死戰）完全吻合。

**最終決定：** 天神書院大比觀戰，已定稿。

### 3. 司天鑑為何不在天神書院立刻處決劫

**狀態：✅ 已回填** — `characters/CHARACTER_RIVAL_TIANFA.md` 四之二

**Codex 推薦答案：孟天正阻止，且當時證據不足。** 只能留下「巡天災印」進行監察。

**Claude 意見：同意，補上「為何沒有當場動手」的因果缺口。** 孟天正已展現過對劫的認可，由他出面壓下處決衝動，人物邏輯站得住。

**最終決定：** 孟天正阻止＋證據不足，只留巡天災印監察。

### 4. 司天鑑與劫第一次真正死戰的位置與導火線

**狀態：✅ 已回填（含安全閥複查）** — `MACRO_OUTLINE.md` 第十二篇、`characters/CHARACTER_RIVAL_TIANFA.md` 四之三、`events/EVENT_XIANGU_RUINS_ZHEXIAN.md` 八（安全閥複查）

**Codex 推薦答案：第十二篇「十凶血路」。** 司天鑑準備處決一批受謫仙萬靈血祭留下的「血祭殘煞」污染、其中少數已異變但仍保有人性的倖存者；洛生衣主張分離救治，陸沉出手阻止。

**Claude 意見：同意，已依此寫入正式設定。**

**Codex 第二輪：** 請 Claude 檢查此場景如何遵守謫仙與十凶巢穴的原作安全閥，以及「侵蝕」應採原作概念或中性災變。

**Claude 複查結論：** 司天鑑處決的對象是十凶巢穴慘案「倖存者」，不改寫謫仙笛音坑殺二十萬生靈的既定事實與死亡人數；「血祭殘煞」是本作原創的污染機制，不借用、不等同原作任何已命名概念，也不與是否引入「黑暗侵蝕」（見第 9、35 題）預先綁定；此戰不涉及謫仙本人在場，不影響其黑暗動亂期死亡與復活的既定線。符合安全閥，複查通過。

**最終決定：** 第十二篇十凶血路；導火線採血祭殘煞倖存者處決爭議，暫不連黑暗物質。作者授權定案，安全閥複查通過，已回填。

### 5. 第九雷「天譴」是否由天罰一脈提供

**狀態：✅ 已回填** — `characters/CHARACTER_RIVAL_TIANFA.md` 四、`systems/SYSTEM_TEN_CALAMITY_THUNDERS.md` 四

**Codex 推薦答案：否。** 天罰一脈只能引來、借用天譴。陸沉承受司天鑑的代天刑罰、業力反噬及被處決者的因果後，自行取得執譴資格。

**Claude 意見：同意「否」的大方向，具體機制建議採用並回填。**

**最終決定：** 否，天譴非天罰一脈所授；具體機制已回填。

### 6. 司天鑑最後是否被說服

**狀態：✅ 已回填（含與老族長弧線的區隔）** — `characters/CHARACTER_RIVAL_TIANFA.md` 四之三

**Codex 推薦答案：理念上不被完全說服，行動上選擇相信陸沉一次。** 終局時可把巡天權柄交給陸沉，自己承擔天罰反噬。

**Claude 意見：同意，這個分寸抓得很好，避免落入宿敵被感化的俗套。**

**Codex 第二輪修正：** 應和老族長區隔——老族長因舊方法已證明無效而放手；司天鑑則在陸沉仍可能成災的情況下，明知有風險仍交還選擇權。

**最終決定：** 理念不變、行動上選擇相信陸沉一次；與老族長的區隔（認輸 vs. 賭一把）已寫入正式設定。
